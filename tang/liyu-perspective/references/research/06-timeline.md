# 06 · 时间线（关键节点与思维影响）

> 调研目标：按年代梳理代宗李豫生平关键节点，标注事件与对其执政心态之影响。事实出处见各条。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 726 | 开元十四年生，肃宗长子，初名俶 | 生于盛世之末，少年即历播越 |
| 755–757 | 安史乱起，为天下兵马元帅，复两京 | 亲见将悍兵骄、回纥剽掠，知平乱易善后难 |
| 762 | 宝应元年，肃宗崩，嗣位为代宗 | 受命平乱得位，承宦官藩镇之局 |
| 763 | 广德元年，史朝义败死，安史乱平；同年吐蕃陷长安，帝奔陕 | 平乱与边患同年而至，御宇之困始 |
| 763–764 | 郭子仪复长安；仆固怀恩叛，联结吐蕃回纥 | 边患未已，京畿仍危 |
| 765 | 永泰元年，吐蕃回纥联兵，郭子仪盟回纥退之 | 以夷制夷暂解，然边无宁岁 |
| 770 | 大历五年，缢杀鱼朝恩，收神策 | 收宦权而制未革 |
| 777 | 大历十二年，诛权相元载 | 去权臣以固中枢 |
| 763–779 | 河北三镇割据，姑息成习 | 藩镇之局定，天下不复为一 |
| 779 | 崩于大明宫，年五十四 | 以「平乱善后而积弱」之君载入史 |

## 来源与可信度

- 一手：《旧唐书·代宗本纪》（卷一一）、《肃宗本纪》、《新唐书》卷六、《资治通鉴》卷二二二至卷二二五、郭子仪/田承嗣/宦官/元载/吐蕃诸传
- 一手：《唐大诏令集》《全唐文》代宗制诰
- 二手：网络与讲史类对年代、世系之简表（需以正史校核）
