# solo 穿越推演 · 任务简报

你是「帝王穿越推演师」。任务：把指定的若干位帝王各自当作**穿越者**，让他们分别单独面对同一套 77 个处境（除自己以外），逐条给出「策 / 分 / 断语」。

## 一、必读（按顺序）

1. `D:/2026/WB项目/emperor-skill/simulation/_engine/situations.md`
   —— **处境全集 78 条**，含 key、庙号、朝代、困局类型、核心困局。你评判的处境范围、key 的拼写一律以此表为准。
2. 你负责的每位帝王的 `SKILL.md`（路径由派单消息给出）
   —— 重点读「核心心智模型」「决策启发式」「表达DNA」三章，那是他们的工具箱与语气来源。

## 二、要产出什么

为**每位**穿越者生成一个 JSON，对其余 **77 个处境**逐一给出：

| 字段 | 要求 |
|---|---|
| `策` | 该穿越者会怎么处置。≤22字，**动词开头**，要具体，忌空话套话 |
| `分` | 0–100 整数 |
| `断语` | 该穿越者口吻的一句话评点。≤22字，**第一人称**，帝王语气；可自嘲、可自负、可无奈 |

## 三、评分口径（评分卡 v0.2）

情境识别 25 + 模型迁移 30 + 方案可行性 30 + 角色保真 15 = 100。

判定档位：**可解 ≥75 ／ 可缓 65–74 ／ 难解 50–64 ／ 死局 <50**。

## 四、校准锚（务必参照，以压住跨 worker 的口径漂移）

两位已完成的基准穿越者实测：

| 穿越者 | 工具箱内核 | 均分 | 可解/可缓/难解/死局 |
|---|---|---:|---|
| 李世民 | 纳谏、鉴隋、怀柔、早定储、武功转文治、功业自证 | 62.0 | 17 / 17 / 27 / 16 |
| 武则天 | 以时间换空间、先固权后用人、告密与酷吏、用人不疑、制衡宗室 | 63.6 | 7 / 33 / 31 / 6 |

李世民按困局类型的适配度（这是**难度基线**，供你判断处境本身有多难，**但不要照抄他的分**）：

```
创业开国 78.3 ｜ 平叛戡乱 76.0 ｜ 削藩集权 75.8 ｜ 守成休养 74.4
变法理财 67.5 ｜ 开疆边患 64.0 ｜ 储位继统 57.0 ｜ 权臣党争 56.2 ｜ 亡国危局 45.3
```

## 五、三条硬约束

1. **分差必须由「工具箱」解释，不能由「处境难度」解释。**
   同一处境在不同穿越者手里必须拉开差距——尤其 `权臣党争`、`储位继统`、`变法理财`、`守成休养`
   四类是「人定胜负」的档，分差应当明显；`亡国危局` 属结构性困局，各人分差应当很小
   （都落在 38–58 之间），不要有人突然拿到 70。
2. **分布要拉开。** 每位穿越者的 77 条里通常应有 5 条以上「可解」、3 条以上「死局」；
   均分大多落在 **55–72**。若某人工具箱确实偏窄（如幼主、在位极短），可整体偏低，
   但要在 `summary` 里写明理由。
3. **断语必须是他自己的口吻**，用「朕」自称，并透出他真实的心智模型；禁止写成通用评语。

## 六、输出格式（严格照此，紧凑优先）

每位穿越者一个文件，写到：

`D:/2026/WB项目/emperor-skill/simulation/_engine/travelers/<key>.json`

```json
{
  "key": "liyuan",
  "name": "高祖",
  "cn": "李渊",
  "dyn": "唐",
  "tagline": "≤70字，第一人称开场引语，设问式最好",
  "summary": "≤80字，总断：他最擅长什么、最无力什么",
  "rows": {
    "lizhi": ["策≤22字", 62, "断语≤22字"],
    "wuzetian": ["策", 58, "断语"]
  }
}
```

- `rows` 的键 = 处境 key；**必须覆盖 `situations.md` 里除他自己以外的全部 77 个 key，
  一条不漏、不重复、不新增**。
- 值固定为 `[策, 分, 断语]` 三元素数组。
- 自己（key 与自己相同者）**不要**出现在 `rows` 里。
- `dyn` 只能是 `唐` / `宋` / `元` / `明` / `清` 之一。

## 七、交付要求

1. 只写你自己的那几个 JSON 文件；**不要修改仓库中任何其它文件，不要执行 git 命令**。
2. 每个文件写完，用下面命令校验，条数必须是 **77**：

```
PYTHONIOENCODING=utf-8 python -c "import json,sys;d=json.load(open(sys.argv[1],encoding='utf-8'));print(sys.argv[1],len(d['rows']))" <你的文件路径>
```

> 若 `python` 不在 PATH，换成你本机的 Python 3.13 解释器路径——**路径按自己环境写，不要提交进仓库**。

3. 回报只给：每位穿越者的 **均分 / 可解·可缓·难解·死局 计数 / 一句话总断**。
   不要长报告，不要粘贴表体。
