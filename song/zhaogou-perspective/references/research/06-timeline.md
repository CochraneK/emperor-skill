# 06 · 时间线（关键节点与思维影响）

> 调研目标：按年代梳理高宗生平关键节点，标注事件与对其执政心态之影响。事实出处见各条。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1107 | 徽宗第九子，生于宫中，母韦贤妃 | 本非储贰，养成「不争而自全」底色 |
| 1121 | 封康王 | 亲王远支，未入权力中心 |
| 1126 | 靖康出使金营得脱，为天下兵马大元帅 | 死里逃生，悟「兵权与身家」之要 |
| 1127 | 靖康之变二帝北狩；南京应天府即位，建炎 | 重建宋室，确立「中兴以存身为先」 |
| 1129 | 苗刘兵变逼退位，韩世忠入援复辟 | 亲历将骄兵变，深恶武人干政 |
| 1129–1130 | 金兀术搜山检海，浮海避兵至温台 | 备尝流离，「遇强则走」成惯性 |
| 1130 | 回越州，后定都临安（行在） | 东南为根本之局定 |
| 1137–1141 | 收韩世忠、张俊、岳飞兵权；杀岳飞 | 「强干弱枝」祖训践行至极 |
| 1141 | 绍兴和议成，称臣纳币、划淮为界 | 「以和止兵」定调，偏安格局成 |
| 1155 | 秦桧死，收其党权，独揽 | 制衡之术得验 |
| 1162 | 禅位孝宗（太祖后赵昚），为太上皇 | 嗣统之困解，退养西湖 |
| 1187 | 崩，年八十一，葬永思陵 | 终以「南渡偏安之君」载入史 |
