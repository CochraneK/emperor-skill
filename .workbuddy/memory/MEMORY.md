## 四、口径铁律（踩过坑，必须遵守）

1. **总分与均分严格同序**——每人 77 条，总分 = 均分 × 77，不存在「总分高但均分低」。
2. **「全库均分（合并）」≠「人均极差」**——前者是全部记录合并求平均（用于难度排行），后者是各人均分之间的最高−最低（用于人定胜负）。**不同源，不可互相推算。** 曾误把后者当「全库均分」写进表，差 0.1。
3. **组内名次跨组不可比**——每位穿越者的处境集合都排除了自己的处境，且各朝处境集合不同。
4. **按时间顺序呈现**——朝代先后（唐→宋→元→明→清）→ 即位年 → 同年次序，依据 `_engine/reign_order.json`。只有报告内「最能接住/最接不住 Top5·Bottom10」按分数。
5. **类型均分是混合量**——同时反映「处境难度」与「参评者构成」，不可当纯难度读（「创业开国」单体第 1 → 全库第 5）。
6. **改排序逻辑后必须验证统计量复现**：只改排序时逐项统计须分毫不变——先单份试渲比对基准值（李世民 62.0 / 17-17-27-16），再全量。
7. **不采信子代理口头回报的数字**，一律以落盘文件实算为准。
