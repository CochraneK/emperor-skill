质量审查 · Nuwa Audit v2

旧 checker 只负责工程合规；真正的出口验收同时看 provenance、evidence 与语义蒸馏质量。

L1
Provenance

确认 Sources → Research → Skill 的真实血缘。

L2
Evidence

来源真实性、证据等级、事实/史评/推断分界。

L3
Semantic

特异性、抽象质量、反证、张力、可迁移性与信息密度。

L4
Engineering

schema、目录、角色协议与 corpus 兼容性。

修复不是“一律重跑”

KEEP 保留 · CLEAN 去冗余 · PATCH 局部补强 · REDISTILL 复用合格研究重蒸馏 · RERESEARCH 重建证据 · REVIEW provenance 不明时保留核查。

最低字数、KB、关键词次数不是 Nuwa 质量。Genericity Test 与 Counter-evidence Test 用于防止“格式全绿但人物模型空泛”。
