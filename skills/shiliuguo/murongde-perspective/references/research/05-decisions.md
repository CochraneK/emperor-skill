# 慕容德 · 决策证据

| 决策 | 情境 | 可观察逻辑 | 结果 |
|---|---|---|---|
| 多次主张乘前秦之衅 | 前秦出现裂缝/淝水败 | 把外部崩解视作复国窗口 | 早期未被采纳 |
| 邺→滑台 | 后燕中山失陷、魏压河北 | 放弃难守旧中心，携人口与车乘迁移 | 建立南部新中心 |
| 滑台→青齐 | 滑台叛降北魏 | 重新寻找人口、农业与地形更优区域 | 占广固、建立南燕 |
| 在青齐吸收本地知识 | 新统治区 | 通过当地士人降低信息缺口 | 官僚整合增强 |
| 称帝与制度化 | 新区域控制稳定 | 把临时“承制”升级为独立国家 | 南燕成形 |
| 立慕容超 | 无子、病重 | 宗室可用性优先 | 完成权力交接 |

关键链条：旧中心失效 → 携组织迁移 → 寻找新地理锚点 → 吸收当地知识 → 再制度化。
