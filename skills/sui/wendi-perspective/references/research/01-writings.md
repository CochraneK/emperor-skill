# 文帝杨坚 · 01 诏书/政令辑录

> 依据一手正史《隋书·高祖文帝纪》（卷一）、《全隋文》核验蒸馏；所录系文帝亲政诏敕。

## 一、伐陈诏（开皇八年三月戊寅，source: web 核验，《隋书·文帝纪下》《全隋文》卷二）
- 声讨陈后主之暴，宣示「一车书」之志。文曰：
  > 「昔有苗不宾，唐尧薄伐，孙皓僭虐，晋武行诛。有陈窃据江表，逆天暴物……自古昏乱，罕或能比……天之所覆，无非朕臣……岂容对而不诛，忍而不救……以上天之灵，助勘定之力，便可出师授律，应机诛殄，在斯举也，永清吴越。」
- 此为文帝统一天下前之征伐檄文，其文气铺陈陈叔宝之恶，以「吊民伐罪」自居。

## 二、平陈后诏（开皇九年四月，source: web 核验）
- 平陈告成，诏曰：
  > 「今率土大同，含生遂性，太平之法，方可流行……兵可立威，不可不戢；刑可助化，不可专行……戎旅军器，皆宜停罢；伐路既夷，群方无事，武力之子，皆可学文……京邑庠序，爰及州县，生徒受业……朕君临区宇，于兹九载，开直言之路，披不讳之心。」
- 灭陈之后诏令偃武修文、停罢军旅、兴学育人，并开直言之路。

## 三、禁请登封诏（开皇九年六月，source: web 核验）
- 群臣以平陈请封禅，文帝不许：
  > 「岂可命一将军除一小国，遐迩注意，便谓太平，以薄德而封名山，用虚言而干上帝，非朕攸闻。而今而后，言及封禅，宜即禁绝。」
- 文帝以平陈为「一将军除一小国」，谦拒封禅——颇见其务实、不务虚名。

## 四、减租诏（开皇十二年，source: web 核验）
- 诏以「宁积于人，无藏府库」为怀：
  > 「既富而教，方知廉耻，宁积于人，无藏府库。河北、河东今年田租三分减一，兵减半功，调全免。」

## 五、颁新乐诏（开皇十四年，source: web 核验）
- 文帝雅重古乐、郑卫淫声尽除：
  > 「在昔圣人作乐崇德，移风易俗……自晋氏播迁，兵戈不息，雅乐流散……比命所司，总令研究，正乐雅声，详考已讫，宜即施用……人间音乐流僻日久，弃其旧体，竞造繁声……宜加禁约，务存其本。」

## 六、仁寿四年托政之诏（source: web 核验，《隋书·高祖纪下》）
- 仁寿四年春正月甲子幸仁寿宫，乙丑诏：
  > 「赏罚厘革，事无巨细，并付皇太子（杨广）。」
- 此诏将朝政尽付太子广，为文帝晚年之大事；其后文帝崩于仁寿宫，死因存疑（或云为太子广所弑）。
