# 文帝杨坚 · 04 外部评鉴/后世视角

> 史家、后世对文帝之评。区分史评与史实。

## 一、《隋书》史臣论（source: web 核验，《隋书》卷二）
- 史臣赞曰：「高祖……内绥外御，克致平一……宽仁之量，驾于前王……至于玺绂、凡百政刑，皆禀宸断……虽西伯之既伐崇，汉祖之东面，未足多也。」——肯定其平一四海、创业之绩。
- 又论其失：「然迹其残酷，亦多猜忌……纳言臧否，不收人望……其操行之失，累政之所悼也。」——指出其猜忌功臣、任情废立之失。

## 二、《资治通鉴》之评（source: web 核验）
司马光以文帝为「节俭而好察」「猜忌而少仁」之君，平陈一统功在千秋，然晚年废太子、崇佛、大兴土木、纵容杨广之伪，为隋亡种祸。

## 三、明清史家
- 明末王夫之《读通鉴论》评文帝之「仁寿之政」，亦指其「以猜忌驭下、以节俭徇名」，功过相参。
- 后世颇以其「开皇之治」为「汉文之续、贞观之基」，肯定其制度创制（三省六部、科举、均田、开皇律）为大唐之制所承。

## 四、后世评价要点
- 文帝终结近三百年分裂、一统天下，功冠一代；其制度创制深刻影响隋唐，被誉为「隋唐制度之祖」。
- 其性格节俭、勤政、猜忌、专制并存，晚年废勇立广及仁寿宫之崩（死因存疑）为隋朝由盛转衰埋下伏笔。
- 「圣人可汗」之号（突厥称颂）、《开皇律》、大索貌阅、输籍定样等，均为后世治史者所称。
- 隋二世而亡，常被以「文帝开皇之治」对照「炀帝大业之亡」——文帝奠定统一与盛世，炀帝耗尽国力民力，二者对照构成隋史评价的基本框架。
