# 文帝杨坚 · 02 对话/互动实录

> 依据一手正史《隋书·高祖文帝纪》及《隋书》诸传核验蒸馏。

## 一、入总朝政、代周之始（source: web 核验，卷一本纪）
- 大象二年，宣帝崩，静帝幼冲，内史上大夫郑译、御正大夫刘昉矫诏引杨坚入总朝政、都督内外诸军事。杨坚「深自晦匿」而权柄渐归。
- 王轨、宇文宪尝言于武帝：「普六茹坚相貌非常……恐非人下，请早除之。」帝曰「此止可为将耳」。文帝「甚惧，深自晦匿」——可见其于北周之隐忍。

## 二、代周受禅（source: web 核验，卷一本纪）
- 大定元年二月，周帝以「众望有归」禅位于坚，遣大宗伯赵晁奉皇帝玺绂、百官劝进，「高祖乃受焉」。开皇元年二月甲子，「自相府常服入宫，备礼即皇帝位于临光殿，设坛于南郊，遣使柴燎告天」。

## 三、平陈之役（source: web 核验，卷一本纪）
- 开皇八年十月，「将伐陈，有事于太庙，命晋王广、秦王俊、清河公杨素并为行军元帅以伐陈」。
- 开皇九年，「贺若弼败陈师于蒋山，获其将萧摩诃；韩擒虎进师入建业，获陈主叔宝。陈国平，得州三十、郡一百、县四百」。

## 四、责降陈叔宝（source: web 核验，《资治通鉴》卷177）
- 平陈后文帝坐广阳门，「使内史令宣诏责以君臣不能相辅，乃至灭亡」，陈叔宝「愧惧伏地屏息不能对」；既而宥之，其后「每引用，见之甚厚」。

## 五、君臣之辨（source: web 核验）
- 元谐尝请「以突厥可汗为候正、陈叔宝为令史」，文帝曰：「朕平陈国，本以除逆，非欲夸诞。公之所奏，殊非朕心。」——文帝不以灭陈为夸耀，重务实、轻虚炫。

## 六、废太子勇、立晋王广（source: web 核验，卷一本纪）
- 开皇二十年冬十月乙丑，「皇太子勇及其诸子并废为庶人，杀柱国史万岁……以晋王广为皇太子」。
- 文帝晚年关乎储位之重大决断，改立杨广；其后仁寿四年帝崩，广即位，史传有「弑父」之说。

## 七、临终托政（source: web 核验，卷一本纪）
- 仁寿四年春正月甲子幸仁寿宫；夏四月，「上疾甚，卧于仁寿宫」，乙丑诏「赏罚厘革，事无巨细，并付皇太子」。其后文帝崩（一说被弑）。
