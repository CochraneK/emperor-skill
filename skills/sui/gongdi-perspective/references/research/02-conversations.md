# 恭帝杨侑 · 02 对话/互动实录

> 依据一手正史《隋书·恭帝纪》（卷五）核验蒸馏。

## 一、李渊入长安、拥立为帝（617，source: web 核验）
- 大业十三年十一月壬戌，李渊攻入长安后，「尊炀帝为太上皇，奉帝（杨侑）纂业」，杨侑于大兴殿即皇帝位，年号义宁。杨侑以炀帝之孙、元德太子之子，被李渊「奉以继统」——实为李渊取长安后收天下名分之器。

## 二、晋唐王总万机（617-618，source: web 核验）
- 即位次日，「以光禄大夫、大将军、太尉唐公（李渊）为假黄钺、使持节、大都督内外诸军事、尚书令、大丞相，进封唐王」；旋诏「军国机务，事无大小，咸归相府」——杨侑名义为帝，实则朝政尽归李渊。

## 三、逊位禅唐（618，source: web 核验）
- 义宁二年三月，炀帝死于江都兵变；五月，李渊见代隋时机成熟，「逼杨侑禅让」。杨侑颁逊位诏引尧舜禅让之典，李渊遂受禅建唐，改元武德，降封杨侑为酅国公。

## 四、酅国公之闲居（618-619，source: web 核验）
- 杨侑禅位后「闲居长安」，「唐以上（杨侑）为酅国公」。武德二年（619）夏五月崩，时年十五（一作武德二年八月、一说遇害），谥曰恭皇帝，葬于庄陵。

## 五、史臣论（source: web 核验，《隋书·恭帝纪》）
- 史臣曰：「恭帝年在幼冲，遭家多难，一人失德，四海土崩……既钟百六之期，躬践数终之运，讴歌有属，笙镛变响，虽欲不遵尧舜之迹，其庸可得乎！」——谓隋祚数终、唐运当兴，恭帝虽欲不禅亦不可得。
