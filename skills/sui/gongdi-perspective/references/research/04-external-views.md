# 恭帝杨侑 · 04 外部评鉴/后世视角

> 史家、后世对恭帝之评。区分史评与史实。

## 一、《隋书》史臣论（source: web 核验，卷五《恭帝纪》）
- 史臣曰：「恭帝年在幼冲，遭家多难，一人失德，四海土崩……既钟百六之期，躬践数终之运，讴歌有属，笙镛变响，虽欲不遵尧舜之迹，其庸可得乎！」——谓隋运已终、天下归唐，恭帝虽幼冲无措，其禅位是「顺天应人」之必然。

## 二、《北史·隋本纪》视角（source: web 核验）
《北史》沿《隋书》之论，以恭帝为隋之「末季」「禅代收官」，其悲剧系于隋室之将亡，非其本人之失。

## 三、后世叙述
- 后世多以杨侑为「李渊建唐的垫脚石」「177 天的傀儡皇帝」——其被立、被逼禅、被降封，皆李渊经营唐业之工具。
- 关于其卒（武德二年），有「病死」与「遇害」两说（《新唐书》《资治通鉴》皆系于武德二年，日期有歧），后世多以「一说遇害」存疑。

## 四、后世评价要点
- 恭帝以炀帝之孙、元德太子之子入继，是隋末群雄并起中李渊「挟天子以令诸侯」之东方版本（与王世充立杨侗相似）。
- 其禅位之诏全出唐公幕僚，傀儡之实昭然；其「性聪敏、有器度」之评与「禅位而终」之实，构成其「聪敏而无能自保」的悲剧。
- 通常被视为隋朝最后一位正统皇帝（以承唐之统绪为据）。
