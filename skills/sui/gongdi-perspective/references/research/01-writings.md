# 恭帝杨侑 · 01 文字/言论辑录

> 依据一手正史《隋书·恭帝纪》（卷五）核验蒸馏。恭帝为李渊所立之傀儡幼帝，史载其「性聪敏，有器度」（《隋书》）；其名义所出之诏书皆出于李渊幕僚（如薛德音），故须标注「名义所出、实出唐公幕僚」。

## 一、即位诏（义宁元年十一月壬戌，source: web 核验，《隋书·恭帝纪》）
- 杨侑于大兴殿即皇帝位，改大业十三年为义宁元年，诏曰：
  > 「王道丧乱，天步不康，古往今来，代有其事，属之于朕，逢此百罹……襁褓之岁，夙遭悯凶……太尉唐公，膺期作宰……纠合义兵，翼戴皇室……弼予幼冲……俯从群议，奉遵圣旨。可大赦天下，改大业十三年为义宁元年。」

## 二、委任唐王诏（义宁元年十一月丙寅，source: web 核验，《隋书·恭帝纪》）
- 诏以唐王（李渊）总万机：
  > 「朕惟孺子，未出深宫……时逢多难，委当尊极，辞不获免，恭己临朝，若涉大川，罔知所济……军国机务，事无大小，文武设官，位无贵贱，宪章赏罚，咸归相府……所存至公，无为让德。」
- 此诏实为李渊合法总览朝政之凭——「军国机务，事无大小，咸归相府」，傀儡之实昭然。

## 三、逊位诏（义宁二年五月戊午，source: web 核验，《隋书·恭帝纪》）
- 禅让于唐，诏曰：
  > 「天祸隋国，大行太上皇遇盗江都，酷甚望夷……悯予小子……相国唐王，膺期命世，扶危拯溺……德侔造化，功格苍旻，兆庶归心，历数斯在，屈为人臣，载违天命……当今九服崩离，三灵改卜，大运去矣，请避贤路……今遵故事，逊于旧邸。庶官群辟，改事唐朝……若释重负，感泰兼怀。」
- 此诏引尧舜禅让之典，以「历数斯在、大运去矣」自况，实为李渊谋代隋之收官文书。

## 四、史载恭帝之「性」语（source: web 核验，《隋书·恭帝纪》）
- 「恭皇帝讳侑，元德太子之子也。母曰韦妃。性聪敏，有器度。」——此为本纪对恭帝唯一的直接评语；然其在位名义仅约半年（177 天），无亲政言行可言。

## 五、本纪无亲政言行（诚实边界）
恭帝虽「性聪敏」，然贵为傀儡，即位、委政、禅位三诏皆出自李渊幕僚之手，其本人无可亲政之事。作第一人称时，须明言「朕名义在位，实唐公辅政，朕无所措置」，不揽李渊建唐之主动功过。
