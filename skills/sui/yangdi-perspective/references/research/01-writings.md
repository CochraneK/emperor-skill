# 炀帝杨广 · 01 诏书/政令辑录

> 依据一手正史《隋书·炀帝纪》（卷三、卷四）、《资治通鉴》核验蒸馏；所录系炀帝诏敕。

## 一、营建东都诏（大业元年三月，source: web 核验，《隋书·炀帝纪上》）
- 「诏尚书令杨素、纳言杨达、将作大匠宇文恺营建东京……徙豫州郭下居人以实之。」又「营显仁宫，采海内奇禽异兽草木之类，以实园苑。徙天下富商大贾万家于东京。辛亥，发河南诸郡男女百余万，开通济渠，自西苑引谷、洛水达于河，自板渚引河通于淮。」

## 二、征高句丽诏（大业八年正月，source: web 核验，《隋书·炀帝纪下》）
- 声讨高句丽之诏，其文铺陈「高丽小丑，迷昏不恭……彼华壤，剪为夷类」，宣示「亲总六师、用申九伐」之志：
  > 「武有七德，先之以安民；政有六本，兴之以教义。高丽高元，亏失藩礼，将欲问罪辽左，恢宣胜略……今宜授律启行，分麾届路……朕躬驭元戎，为其节度……以此众战，势等摧枯。」

## 三、西巡张掖诏、经营西域（大业五年，source: web 核验）
- 炀帝西巡张掖，命裴矩说高昌王、伊吾吐屯设等，西域二十七国谒于道左，「皆令佩金玉，被锦罽，焚香奏乐」；置西海、河源、鄯善、且末等郡，大开屯田、通西域之路。

## 四、大业律诏（大业三年，source: web 核验）
- 炀帝修订《大业律》，宽于文帝之《开皇律》：「旧律……其死刑……皆宜除之」，使刑部之法稍宽。

## 五、开科诏（大业二年，source: web 核验）
- 诏以「军国异容，文武殊用……自今以后，诸授勋官者，并不得回授文武职事」——炀帝进一步完善科举、分科举士，勋官不预治民之职。

## 六、南巡江都诏（大业元年/六年，source: web 核验）
- 炀帝多次南巡江都，「上自江都御龙舟，入通济渠，遂幸于涿郡」；其龙舟之制、船队之盛，载《隋书》及《通鉴》。
