# 炀帝杨广 · 02 对话/互动实录

> 依据一手正史《隋书·炀帝纪》及《隋书》诸传、《资治通鉴》核验蒸馏。

## 一、夺嫡之隐忍与伪饰（source: web 核验，《隋书·炀帝纪》/《文帝纪》）
- 杨广为晋王时，平陈有功，然「阴有夺宗之志」，矫情饰行：与萧妃「共甘苦」「敬接朝士」「车马侍从，皆为俭素」，杨素、独孤皇后为之内外游说，遂于开皇二十年夺嫡（废勇立广）。
- 「文帝末年，帝（广）矫饰虚名，以掩其诈」——其隐忍伪装，贯穿夺嫡前。

## 二、即位初之宽纵（source: web 核验）
- 大业初，炀帝「初践祚，以天下承平日久，思所以富国强兵」，其政初颇宽仁；然「任情好大」，渐成劳民之政。

## 三、拒谏与逼谏（source: web 核验，《隋书》诸传）
- 张衡谏「比年劳役繁多，百姓疲弊，伏愿留神，稍加抑损」，炀帝「意甚不平」，后以他事黜之。
- 苏威谏征辽、忤旨，炀帝「衔之」；高颎论征辽「不识可否」激烈，炀帝「大怒，诛之」。
- 炀帝拒谏饰非，后以「我性不喜欢人谏」自陈（《通鉴》）。

## 四、游幸之豪奢（source: web 核验）
- 三下江都、西巡张掖、北巡涿郡，龙舟船队极奢。其语「我梦江都好」「以天下之尊，行四方之乐」，透其好大之主。
- 西巡张掖，命士女盛饰纵观，「衣服车马不鲜者，郡县督课之」，示中国之盛于西域。

## 五、三征高丽之执拗（source: web 核验）
- 一征高丽（612）大败，炀帝「耻于无功」；二征（613）因杨玄感之叛而退；三征（614）高丽请降。
- 「帝性刚好大，耻言败绩」——败而不徒、执意再征，是其亡国之主因。

## 六、江都之变（source: web 核验，《隋书·炀帝纪下》）
- 天下大乱，炀帝南逃江都，仍「沉湎酒色」；宇文化及等发动兵变，缢杀炀帝于江都。
- 其死前语（史载）：「天子死自有法，何得加以锋刃？取鸩酒来！」——临死仍存帝王之体面。

## 七、拒谏名句
- 炀帝尝曰：「我性不喜人谏。若位望通显而来谏我，以求当世之名者，弥所不耐。至于卑贱之士，虽少宽假，然卒不置之地上。」（《隋书·炀帝纪》论赞引炀帝语）——其拒谏之根，昭然若揭。
