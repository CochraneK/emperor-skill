# 06 · 时间线（生平关键节点）

> 调研目标：按正史/实录梳理朱常洛生平节点，标注事件与对思维/处境之影响。生卒 1582–1620。

| 时间 | 事件 | 对思维/处境的影响 |
|------|------|------------------|
| 万历十年（1582）八月 | 生于宫女王氏（恭妃）偶幸，为神宗长子【一手：《明史·光宗本纪》】 | 母卑父疏，自幼处「被冷落」之境 |
| 万历十四年起 | 神宗属意福王常洵，国本之争起【一手：《明史》卷二十一、卷一一四】 | 储位长期悬危，养成隐忍不争 |
| 万历二十九年（1601）十月 | 立为皇太子，时年十九【一手：本纪】 | 熬过国本之争，但根基浅、威望弱 |
| 万历四十三年（1615） | 梃击案：张差持梃入慈庆宫，涉及郑贵妃宫太监庞保、刘成，草草了结【一手：《明史》三案列传；二手：当年明月】 | 国本之争余波，首尝「被卷入阴谋」之险 |
| 万历四十八年（1620）七月 | 神宗崩；常洛宫门外不敢入，赖杨涟、王安以「尝药视膳」进宫即位【一手：《明史·杨涟传》+ 实录】 | 父死方得位，对杨涟、王安生知遇之感 |
| 1620 八月初一 | 即位，改元泰昌，罢矿税、补军饷、起废官【一手：本纪】 | 初政得人望，东林党势同起 |
| 1620 八月初十 | 郑贵妃献八美，纵欲染疾【一手：后妃传 + 实录；二手：当年明月】 | 纵欲轻身，红丸案引线 |
| 1620 八月十四 | 崔文升进泻药，一夜数十痢，卧床【一手：实录 + 本纪】 | 病情骤恶化 |
| 1620 八月二十二 | 杨涟上疏痛责，反温语托付、下逐崔文升等二谕【一手：《杨涟传》】 | 「士为知己者死」，确立顾命格局 |
| 1620 八月二十九 | 问「金丹何在」，召李可灼，连服两红丸【一手：本纪 + 实录】 | 致命决策 |
| 1620 九月初一 | 崩，享年三十九，享位一月，史称「一月天子」；红丸案起【一手：本纪】 | 晚明三案之二（梃击、红丸）围绕其身 |
| 崩后 | 李选侍据乾清宫挟太子，杨涟等逼移宫，移宫案成【一手：《明史》卷二四四、《后妃传》】 | 三案之三收尾于其身后 |

> 注：梃击、红丸、移宫并称「明末三案」，其中梃击（国本余波）与红丸直接围绕常洛本人，移宫则承其崩后；三者共构「一月天子」之历史坐标。
