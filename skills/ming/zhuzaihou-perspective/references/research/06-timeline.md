# 06 · 时间线（朱载垕生平关键节点）

> 调研目标：梳理其生平关键节点，标注事件与对思维/执政风格的影响。一手出处为主。

| 时间 | 事件 | 对思维/执政的影响 |
|------|------|------------------|
| 1537.3.4（嘉靖十六年正月） | 生于京师，世宗朱厚熜第三子，母杜康妃 | 非长子，排行居中，养成谨慎 |
| 1539.2 | 封裕王（与太子、景王同日受封） | 早定藩王身份，非储君预期 |
| 1549.3 | 庄敬太子朱载壡薨，储位空缺；世宗信「二龙不相见」，不立新储 | 长期边缘化，父子疏离，「战战兢兢」生存智慧之始 |
| 1552 | 高拱任裕王讲官，用心教导，深得信任 | 潜邸旧臣纽带，奠定即位后倚任高拱之基 |
| 1560冬 | 郭希颜请建储被斩；1561.2 景王就藩 | 立储之争险恶，愈知谦抑自保 |
| 1565.1 | 景王朱载圳死，裕王为独子，储位方固 | 二十年悬疑终结，但身心已惯蛰伏 |
| 1567.1.23（嘉靖四十五年十二月） | 世宗崩，徐阶草遗诏；2.4 即位，改元隆庆 | 即位即废弊政、释海瑞、停玄修、减赋——「与民更始」母题 |
| 1567（隆庆元年） | 准贩东西二洋（隆庆开关，月港） | 务实开放、破祖制之决断 |
| 1567–1570 | 徐阶独断→去位；李春芳、高拱相继主政 | 委政阁臣、不掣肘的执政定型 |
| 1570（隆庆四年） | 把汉那吉降明；高拱、张居正主纳以为筹码 | 边务以谈判代战争之思路成型 |
| 1571.3（隆庆五年） | 封俺答为顺义王、许互市；海瑞巡抚应天 | 「息民」「太平」达于顶点；用贤不疑 |
| 1572.5.26（隆庆六年） | 崩于乾清宫，年三十六；太子朱翊钧（万历）即位 | 六年而殁，承上（嘉靖）启下（万历张居正改革） |

> 排除声明：知乎、微信公众号、百度百科未引用；生卒与纪年据《明史》《明穆宗实录》。
