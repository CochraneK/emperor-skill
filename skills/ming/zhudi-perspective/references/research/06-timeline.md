# 06 · 时间线（朱棣关键节点与对思维/执政的影响）

> 调研目标：梳理朱棣生平关键节点，标注事件与对思维/执政逻辑的影响。中文，标注出处（一手优先）。

| 时间 | 事件 | 对思维/执政的影响 | 出处 |
|------|------|------------------|------|
| 1360（洪武前） | 生于应天，为太祖第四子，母硕妃（生母有异说） | 非嫡非长，自幼知「家业非己」，养成早慧、不甘人下的心理底色 | 一手：明史成祖本纪 |
| 1370（洪武三年） | 封燕王（11岁） | 例行封王，远不如太子朱标受宠，强化「边缘皇子」自我认知 | 一手：明史诸王表 |
| 1380（洪武十三年） | 就藩北平 | 直面北虏前线，由「皇子」转为「边帅」，开启军事生涯 | 一手：明史/明实录 |
| 1390（洪武二十三年） | 首次统兵出塞，降乃儿不花 | 证明统帅才，确立「从战争中学习战争」的自信与用兵风格 | 一手：明实录/明史 |
| 1392（洪武二十五年） | 太子朱标卒，子允炆立为皇太孙 | 继统顺序外移，夺位念头的潜在种子（后人叙事）；其时对藩王仍恭顺 | 一手：明史 |
| 1398（洪武三十一年） | 太祖崩，建文帝即位，急削藩 | 生存危机倒逼——或束手就戮，或举兵自救 | 一手：明史建文朝 |
| 1399–1402 | 靖难之役，渡江入南京 | 以武力夺嫡成功，奠定「成大事不拘常礼、天命在兵」的执政哲学 | 一手：明史成祖本纪 |
| 1402（建文四年） | 即位，革除建文年号，诛方孝孺等 | 「诛首恶、安余党」的控制术成型；留下篡位「惭德」 | 一手：明史 |
| 1403（永乐元年） | 命修《永乐大典》；设内阁 | 文化大一统 + 制度分权雏形；以文治消弭道统争议 | 一手：明实录/明史 |
| 1405（永乐三年） | 郑和首下西洋 | 「耀兵怀远」的海洋外交开启，建构朝贡体系 | 一手：明史郑和传 |
| 1406（永乐四年） | 始营建北京宫殿 | 北迁战略启动，为「天子守国门」布局 | 一手：明史 |
| 1410（永乐八年） | 第一次亲征漠北，败本雅失里于斡难河 | 「以攻为守」的北边战略确立 | 一手：明史本纪 |
| 1414（永乐十二年） | 第二次亲征，败瓦剌马哈木于忽兰忽失温 | 维持漠北均势，威震蒙古 | 一手：明史本纪 |
| 1420（永乐十八年） | 设东厂 | 宦官特务集权的标志，雄猜控制术制度化 | 一手：明史刑法志 |
| 1421（永乐十九年） | 正式迁都北京 | 「天子守国门」落地，政治中心北移 | 一手：明史/明实录 |
| 1422–1424 | 第三、四、五次亲征 | 连年北征耗国力，末次崩于榆木川（1424，65岁） | 一手：明史本纪 |
| 1424（永乐二十二年） | 崩于北征归途 | 一生以「马上天子」始、以「马上天子」终 | 一手：明史 |
