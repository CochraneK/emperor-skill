# 06 · 时间线（建文生平关键节点）

> 调研目标：按年份梳理朱允炆生平和建文朝关键事件，标注对思维/执政的影响。年份据《明史》本纪及诸传。

| 时间 | 事件 | 对思维/执政的影响 |
|------|------|------------------|
| 1377（洪武十年） | 生于应天，为太子朱标嫡次子（一说庶长子） | 深宫成长，未历开国艰难 |
| 1392（洪武二十五年） | 父朱标卒，允炆被立为皇太孙 | 少年定储，承"仁孝"母题；与朱棣叔侄张力始 |
| 约1392后 | 与太祖论削藩，献"怀德制礼削地改封用兵"五策 | 形成"先礼后兵、以德服人"执政基调 |
| 1398（洪武三十一年） | 朱元璋崩，允炆即位，改元建文，年21 | 甫即位即面临藩王尾大不掉之局 |
| 1398（即位初） | 诏行"建文改制"：更官制、服色，慕《周礼》；减赋宽刑 | 理想化儒家秩序登场，重文轻武 |
| 1398–1399 | 用齐泰、黄子澄议，先后废周、齐、湘、代、岷诸王 | 削藩操切，授燕王"清君侧"口实 |
| 1399（建文元年） | 朱棣于北平起兵"靖难"，以"诛奸臣"为名 | 文战开启，建文"仁柔"执政风格受极限考验 |
| 1399 | 下"毋伤叔父"令，前线将士缚手 | 伦理压过战争逻辑，成战略软肋 |
| 1399 | 放还朱高炽三兄弟归燕 | 纵虎归山，朱高煦后成燕军骁将 |
| 1399–1402 | 用耿炳文、李景隆、盛庸等屡易将帅，战局反复 | 书生谋国、临阵易将，指挥系统紊乱 |
| 1402（建文四年） | 金川门叛开（李景隆、谷王朱橞），燕军入南京 | 中枢被从内部攻破，败局定 |
| 1402 | 宫中火起，允炆"不知所终"（焚死/逃亡两说） | 下落成千古疑团；方孝孺等被诛，建文朝"革除" |
| 1402后 | 朱棣即位，改元永乐；建文年号被革除 | 官方叙事以成祖为正统，建文史料多缺 |

## 来源

- 一手：《明史》卷四·恭闵帝本纪、卷一四一诸臣传、《明太宗实录》起兵诏。
- 学术：吴晗《朱元璋传》、陈梧桐《洪武皇帝大传》、孟森《明史讲义》。
- 二手透镜：当年明月《明朝那些事儿》第二十四—二十六章（通俗叙事，作蒸馏透镜）。
