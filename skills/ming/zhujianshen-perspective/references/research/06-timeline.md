# 06 · 时间线（关键节点 + 对思维/执政的影响）

> 调研目标：梳理朱见深生平关键节点，标注事件与对其执政思维的影响。来源见各条标注。

| 时间 | 事件 | 对思维的影响 |
|------|------|----------------|
| 1447（正统十二年） | 生于南宫，英宗朱祁镇长子 | 生于帝王家，幼年即处权力漩涡 |
| 1452（景泰三年） | 景泰帝废其为太子，改立己子 | 童年失储位，养成隐忍、不较一时之性格 |
| 1457（天顺元年） | 英宗复辟（夺门），复为太子；于谦被杀 | 亲见忠良横死，埋下日后平反之念 |
| 1464（天顺八年） | 英宗崩，即位为帝，改元成化 | 宽仁守成基调确立；即下求言恤民诏 |
| 成化初 | 诏复于谦官、赐祭、录其子 | 以平反收人心，显政治气量（宽厚一面） |
| 成化二年(1466) | 万贵妃封贵妃，专宠后宫 | 私情重于名分，中宫久虚、皇嗣几绝 |
| 成化三年(1467) | 命赵辅、李秉讨建州女真，「犁庭扫穴」 | 守在四夷、以兵靖边的边功思维 |
| 成化十二年(1476) | 李子龙案后设西厂，汪直领之 | 倚内臣刺事、以厂卫代廷议的执政惯性 |
| 成化十三年(1477) | 商辂谏罢西厂，旋复设 | 纳谏而终不舍权，显「外宽内执」 |
| 成化中 | 传奉官滥授、宠李孜省/僧继晓 | 私恩授官、信道方术，纲纪渐弛 |
| 成化六年(1470) | 孝宗祐樘生，母纪氏被逼死，秘养 | 内侍力保己出，矛盾于专宠与继嗣之间 |
| 成化十六年(1480) | 汪直、王越威宁海子大捷 | 边功多由宦官主之，亦为西厂之延续 |
| 成化二十三年(1487) | 万贵妃卒，宪宗悲曰「我亦将去」；同年崩 | 情系一人，崩于其年，终年38 |

## 说明

- 时间线与事件以《明史》本纪、列传及《明实录》为准（一手）；
- 宫闱细节经史臣叙述，本 Skill 据以凝练，未增现代心理分析。
