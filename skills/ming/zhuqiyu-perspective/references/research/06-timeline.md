# 06 · 时间线（关键节点 + 对思维的影响）

> 调研目标：梳理景帝生平关键节点，标注事件与对执政思维/人格的影响。来源见各条标注。

| 时间 | 事件 | 对我思维的影响 |
|------|------|----------------|
| 1428（宣德三年） | 生于宫中，宣宗次子，母贤妃吴氏 | 起点即「非嫡长」之嗣——守成而非开创的命定角色 |
| 1435（宣德十年） | 兄祁镇（英宗）即位，封郕王 | 安心为藩王弟，「逢节拜兄」的安稳预期成形 |
| 1449（正统十四年·秋） | 土木堡之变，英宗北狩；孙太后命监国 | 猝然被推入权力中心，「国不可无君」的危机感压倒个人意愿 |
| 1449（正统十四年·九月六日） | 即皇帝位，遥尊兄为太上皇，改元景泰 | 由「不欲位」到「受命安社稷」，被动担纲的母题确立 |
| 1449（正统十四年·十月） | 从于谦议，拒南迁、守京师，北京保卫战 | 识人委任之得：全权付谦而国门得守，奠定「用人不疑」信念 |
| 1450（景泰元年） | 也先送还英宗；帝迎于东安门，置南宫禁锢 | 「尊其名、制其实」的两全术成型；兄弟猜防自此不可解 |
| 1452（景泰三年·五月） | 废太子见深（兄子）为沂王，立己子见济 | 私心入储位，将公器系于己嗣，拒异议之专断加剧 |
| 1453（景泰四年·十一月） | 太子见济薨，储位遂虚 | 易储之功一朝成空，留下「后继无人」的根本焦虑 |
| 1457（景泰八年·正月） | 帝不豫，拒群臣复立太子之请 | 病中拒储，制造权力真空——决策链最致命的缺口 |
| 1457（景泰八年·正月十七） | 石亨、徐有贞、曹吉祥夺门，迎英宗复位 | 一夜失国；闻变唯「好，好」二字，被动结局的极致反讽 |
| 1457（景泰八年·二月） | 废为郕王，旋薨，年三十，谥戾，葬金山 | 守成之君的悲剧终章；成化中复帝号，名分迟来的平反 |

## 说明

- 时间线与纪年以《明史》本纪、《英宗/景泰实录》为骨；夺门当夜细节正史极简，《明朝那些事儿》补全处已标二手透镜（见诚实边界）。
- 死因「暴薨」正史未明言被害，相关「被弑」之说属悬案，不纳入主线。
- 成化间复尊帝号，标志后世对其「再造之功」的再评价，本 Skill 已采此定论。
