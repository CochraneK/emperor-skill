# 06 · 时间线（关键节点 + 对思维的影响）

> 调研目标：梳理万历帝生平关键节点，标注事件与对执政思维的影响。来源见各条标注。

| 时间 | 事件 | 对我思维的影响 |
|------|------|----------------|
| 1563（嘉靖四十二年） | 生于裕王府，为隆庆帝第三子 | 生于藩邸，幼承母（李贵妃）严教 |
| 1568（隆庆二年） | 六岁立为皇太子 | 早定储位，深知「国本」二字分量（后为自身所困）【一手：《明史·神宗本纪》】 |
| 1572（隆庆六年） | 十岁即位，改元万历；两宫太后委政张居正 | 少年倚贤相，养成「借能臣之力、再亲揽大权」的执政底色【一手：《明史》《神宗实录》】 |
| 1573–1582 | 张居正辅政，行考成法、一条鞭法，史称万历中兴 | 亲见集权改革之效，亦亲历「被压着大气不敢出」的束缚感【一手：《明史·张居正传》+二手：《明朝那些事儿》】 |
| 1582（万历十年） | 张居正卒 | 亲政转折点；由倚信转为疑忌 |
| 1583–1584 | 清算张居正：抄家、夺谥、子孙戍边 | 收回权柄、立独断；对「权臣」终身警惕【一手：《神宗实录》万历十二年】 |
| 1592（万历二十年） | 宁夏之役平哱拜；同年发兵抗倭援朝 | 三大征启幕，亲决军国、扬威边陲的自信顶峰【一手：《明史·神宗本纪》】 |
| 1592–1598 | 朝鲜之役（抗倭援朝） | 力主救藩，对诈和深疑；耗帑而威立【一手：《神宗实录》】 |
| 1598–1600 | 播州之役平杨应龙 | 三征毕，国帑大耗【一手：《明史·神宗本纪》】 |
| 1587（万历十五年）起 | 渐不视朝，章奏留中、缺官不补 | 由「亲裁」转向「消极不朝」反制文官；行政渐弛【一手：《明史》赞、黄仁宇《万历十五年》】 |
| 1578–1601 | 国本之争：欲立朱常洵，群臣争立朱常洛 | 皇权与文官礼法拉锯二十余年，终屈于「祖制嫡长」，立常洛为太子；对言官由忍到厌【一手：《明史》《神宗实录》】 |
| 1596 起 | 派矿税使（税监）四出搜刮 | 内帑充盈而民怨沸腾，党争与民变并起【一手：樊树志《万历传》】 |
| 1615（万历四十三年） | 梃击案：二十余年不朝后露面定案 | 以「谁都别再折腾」切断争论，显压制式独断【二手：《明朝那些事儿》+《明史》略载】 |
| 1620（万历四十八年） | 崩，年五十八；庙号神宗 | 四十八年在位为明代最长；留「明亡实亡于神宗」之史评【一手：《明史·神宗本纪》】 |

## 说明

- 时间线与事件以《明史》《神宗实录》及樊树志《万历传》、黄仁宇《万历十五年》为准；
- 「在家办公、工于心计」等现代叙事透镜出自《明朝那些事儿》（二手），不与史料原文混同；
