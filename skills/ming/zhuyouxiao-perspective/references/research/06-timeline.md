# 06 · 时间线（朱由校生平关键节点）

> 调研目标：梳理朱由校（明熹宗/天启）生平和在位关键节点，标注事件与其对思维/执政的影响。
> 信源：一手《明史》本纪第二十二·熹宗、明实录；二手《明朝那些事儿》。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1605（万历三十三年） | 生于光宗（时为皇长子）藩邸，母王才人 | 生母早失恃，由乳母客氏乳养，埋下"只信身边人"之根 |
| 万历后期 | 祖父万历怠政、父常洛久不得立，教育荒废 | "不怎么读书，却很喜欢做木匠"，匠作成精神寄托【二手：《明朝那些事儿》】 |
| 1620（泰昌元年/万历四十八年） | 光宗暴崩，经移宫案即位，年十五，改元天启 | 少年被推上帝位，依赖拥立诸臣与近侍 |
| 1620 冬 | 封乳母客氏为奉圣夫人，魏忠贤（李进忠）渐用事 | 权力内廷化，信任圈层收缩至乳母与宦官 |
| 1621（天启元年） | 沈阳、辽阳陷于努尔哈赤；命熊廷弼经略辽东 | 辽东危局开端，多赖督抚、亲政无力 |
| 1622（天启二年） | 广宁失守，王化贞弃城、熊廷弼罢 | 辽东河以东尽失，退守辽西 |
| 1624（天启四年） | 杨涟劾魏忠贤二十四大罪，帝切责涟 | 与东林决裂，阉党清洗启动 |
| 1625–1626（天启五至六年） | 杨涟、左光斗等东林六君子死；毁天下书院；《点将录》立 | 阉党极盛，朝纲大坏 |
| 1627（天启七年） | 帝病笃，召信王朱由检，传位，崩，年二十二 | 以"吾弟当为尧舜"托身后，弟崇祯立，旋诛魏忠贤 |

## 备注

- 生卒：1605–1627，在位 1620–1627（天启年号 1621–1627）。
- 死因：正史记为"上不豫"而崩；《明朝那些事儿》叙其西苑泛舟落水染疾，历来有异说，本 Skill 不采单一定论。
