# 06 · 时间线（生平关键节点与对思维/执政的影响）

> 调研目标：按编年梳理朱祐樘生平，标注事件与对其执政思维的影响。出处以《明史》本纪、实录为准。

| 时间 | 事件 | 对思维/执政的影响 |
|------|------|------------------|
| 1470（成化六年） | 生于西宫，母纪氏（孝穆纪太后），父宪宗朱见深 | 生于深宫危局，自幼不知己为皇子 |
| 1470—1475 | 万贵妃专宠，宫人孕者多遭堕胎；纪氏秘产，祐樘被宫人、太监（张敏等）密养于安乐堂 | 童年孤隐、朝不保夕，埋下"宽厚惜下、重情"底色 |
| 1475（成化十一年） | 张敏告知宪宗，祐樘被召见，立为皇太子；生母纪氏旋暴卒，张敏惧吞金死 | 六岁方见天日，亲历生母横死，深知后宫之险 |
| 1475—1487 | 养于周太后仁寿宫，太后戒"无食万贵妃所进"；万贵妃召宴，对"何不食"答"疑有毒" | 幼习临危自守、不露怯，养成谨慎内敛 |
| 1487（成化二十三年） | 宪宗崩，九月祐樘即位，次年改元弘治 | 新君立志"拨乱反正"，终结成化佞幸之政 |
| 1487—1488 | 斥首辅万安、罢传奉官数千、逐僧道方士、停斋醮；下求言诏，开午朝 | 确立"去弊—任贤—守成"执政主轴 |
| 1488（弘治元年） | 召七十三岁王恕为吏部尚书，整吏治；开经筵日讲 | 倚重老成能臣、尊儒重道，虚心纳谏成形 |
| 1488—1495 | 马文升掌兵部劾贪、刘大夏理兵政；弘治八年（1495）李东阳、谢迁入阁，成"三阁臣" | 弘治中兴人才矩阵就位，文官政治达成熟 |
| 1490s | 一生只立张皇后，不纳妃嫔（明代唯一一夫之帝）；生朱厚照、朱厚炜（厚炜早夭） | "重情专一"成其人格标识，亦致子嗣单薄 |
| 1498—1499 | 弘治十一年南京乡试、十二年会试科场案（唐寅案），祐樘令核查、依法处置 | 务实依法、不庇士林，示"公断" |
| 1502（弘治十五年） | 问刘大夏兵政之弊，委以整饬马政边防 | 问症于专才、信任能臣的对话式理政 |
| 1504—1505 | 弘治十七八年间病体日沉，仍勤政不辍 | "以劳代寿"，透支早逝之伏线 |
| 1505（弘治十八年）五月 | 崩，遗命太子"任用刘健、李东阳、谢迁"，嘱"仁明刚断"；武宗朱厚照嗣位 | 托孤得人而教子失严，中兴随其崩而转衰 |

## 补充：时间线未载但影响思维的隐性节点

- **万贵妃之祸**（成化朝全程）：其童年全部阴影之源，塑造"不纵欲、不滥刑、重保全"的反弹式执政。
- **生母纪氏之死**：终其世未明正凶，成其"宽厚中藏隐痛"的性格张力。
