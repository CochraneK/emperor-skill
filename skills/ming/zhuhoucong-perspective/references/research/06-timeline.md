# 06 · 时间线（朱厚熜关键节点与对思维的影响）

> 调研目标：梳理其生平关键节点，标注事件与对思维/执政逻辑的影响。年份与事实据《明史》《明世宗实录》。

| 时间 | 事件 | 对思维/执政逻辑的影响 |
|------|------|---------------------|
| 1507 | 生于安陆兴献王藩邸，为兴献王朱祐杬世子 | 藩王之子，非东宫嫡脉，养成「名分须自争」之意识 |
| 1519 | 兄朱厚照（武宗）无嗣，政局动荡 | 早识权力无常，善观衅而动 |
| 1521 | 武宗崩，以藩王世子奉遗诏入嗣，即帝位，改元嘉靖 | 「继统不继嗣」之争开端，立威于文官集团 |
| 1521–1524 | 大礼议：与杨廷和集团对抗，定生父尊号 | 确立「名分即权力」「朕意已决」的独断风格 |
| 1524 | 左顺门事件，廷杖、贬谪异议诸臣 | 皇权压服礼官，御下以威为主 |
| 1530s | 早中期行新政、核田赋、抑宦官，史称「嘉靖中兴」 | 励精图治、收权立威的盛年阶段 |
| 1542 | 壬寅宫变，宫婢谋弑，帝移居西苑万寿宫 | 益信道教、专事斋醮，转入「静摄独断」模式 |
| 1542–1562 | 严嵩专政二十年，帝以术驭之 | 「威福自朕出」、臣下相制而权不下移 |
| 1550 | 庚戌之变，俺答入寇至京师 | 北边防务危机，促边墙整饬与兵制反思 |
| 1550s–1560s | 东南倭患大起，委胡宗宪、用戚继光俞大猷平倭 | 「戎务」务实用人，重能将、严赏罚 |
| 1562 | 严嵩倒，徐阶继任首辅 | 权臣轮替自如，制衡术成熟 |
| 1566 | 海瑞上《治安疏》，帝留中不杀 | 晚年容直、自比「非纣」，显清醒一面 |
| 1567 | 崩于西苑，庙号世宗，葬永陵 | 御极四十五年，明代在位第二长之君 |

> 时间线据《明史》本纪与《明世宗实录》整理；叙事性细节参考《明朝那些事儿》作通俗透镜，已声明其非正史。
