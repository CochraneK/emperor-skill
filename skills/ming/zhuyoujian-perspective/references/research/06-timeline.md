# 06 · 时间线（关键节点 + 对思维的影响）

> 调研目标：梳理其生平关键节点，标注事件与对执政思维/抉择的影响。来源见各条标注。

| 时间 | 事件 | 对思维的影响 |
|------|------|----------------|
| 1611 | 生于北京，明光宗第五子 | 深宫长大，未预朝政，养成冷眼旁观之习 |
| 1622（天启二） | 封信王 | 远中枢、避魏忠贤之锋，亦少历练 |
| 1627（天启七） | 兄天启崩，入承大统，次年改元崇祯 | 十七岁临危受命；入宫首夜坐烛达旦，疑惧生根【史料·《明史》】 |
| 1627–1628 | 逮治魏忠贤、定逆案 | 立威果决，奠定「除奸务尽」心智，亦启普遍猜疑 |
| 1629–1630 | 袁崇焕下狱磔死 | 自毁长城，多疑驭下定型；边将寒心【史料·《明史·袁崇焕传》】 |
| 1630s | 陕北连旱，李自成、张献忠并起 | 民变如燎原，勤政难补制度溃，运会之叹渐生【史料·谈迁《国榷》】 |
| 1630s–1640s | 十七年易阁臣五十余 | 以术驭下、刚决少恕臻于极致，无人敢任事【学术·樊树志《崇祯传》】 |
| 1644.3（甲申） | 李自成逼京，南迁之议不行 | 困于「弃宗庙」与「死社稷」两难，终择留守 |
| 1644.4.25 | 煤山自缢，王承恩从死 | 「君王死社稷」终局，君主责任观之极致践行【史料·《明史》+ 《明季北略》】 |

- 时间线与事件以《明史·庄烈帝本纪》、谈迁《国榷》、计六奇《明季北略》及樊树志《崇祯传》为准；个别月份来自私史，已交叉核对。
