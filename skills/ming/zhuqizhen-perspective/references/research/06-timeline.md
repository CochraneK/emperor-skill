# 06 · 时间线（朱祁镇生平关键节点）

> 调研目标：按时间梳理朱祁镇生平，标注事件与对其思维/执政的影响。一手据《明史》本纪/实录，二手叙事还原标《明朝那些事儿》。

| 时间 | 事件 | 对思维的影响 |
|------|------|----------------|
| 1427 | 生于宫中，宣宗朱瞻基长子，母孙皇后 | 生于权力中心，自幼享至尊 |
| 1435 | 宣宗崩，九岁即位，次年改元正统 | 幼冲嗣位，养成倚仗辅臣/师傅之习惯 |
| 1436 | 张太皇太后命五辅臣（三杨等）辅政 | "有所欲行必与议"——早期尚能纳辅 |
| 约1442 | 娶钱氏为后，二人情深 | 一生温情来源，患难不移之锚 |
| 1442 | 张太皇太后崩，王振渐专权 | 唯一能制阉者去，亲信裹挟之始 |
| 1449.7 | 受王振怂恿下亲征诏，率二十万出征 | 被动决策、缺独立判断之暴露 |
| 1449.8 | 土木堡之变，被也先俘（北狩） | 从至尊跌为俘虏，世界观剧变 |
| 1449–1450 | 北狩，赖袁彬哈铭、除喜宁 | 识破陷阱、体认患难真情 |
| 1450 | 归国，即被弟朱祁钰幽南宫 | 由俘而囚，弱者之痛亲历 |
| 1450–1457 | 南宫七年，钱后针线自给 | 忍辱待时，恤弱之仁萌芽 |
| 1457.1 | 夺门之变（石亨/徐有贞迎），复位改元天顺 | 被动接机会，却为"合法性"所迫 |
| 1457.1.23 | 杀于谦（"意欲"罪），天下冤之 | 最大污点，事后深悔 |
| 1457–1461 | 厚赏"还乡团"，后石亨骄、曹吉祥谋反 | 晚年临乱反镇定，平叛显决断 |
| 1464.1 | 崩，遗命废宫妃殉葬 | 仁政转折：亲历弱者方生真仁 |
| 1464 | 太子朱见深（宪宗）继位 | 明代唯一两度为帝者落幕 |

## 注记
- 年龄：被俘时二十三岁，崩时三十八岁。
- 两朝：正统（1436–1449）、天顺（1457–1464），中间景泰（弟祁钰）隔断，同一人两度即位【一手：《明史·英宗本纪》】。
- 叙事心理细节（如"好、好、好""开门"一吼）出自《明朝那些事儿》还原，标二手。
