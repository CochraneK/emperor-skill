# 05 · 决策（咸丰朝关键抉择与得失）

> 调研目标：梳理咸丰在位十一年的关键决策，标注史料来源与框架推断，呈现其决策逻辑与局限。

## 一、立储之争（即位前）

- **藏拙守仁**：校猎不伤生、问治术以仁孝对，得道光属意而立【文本·《清史稿·杜受田传》；野史成分需核对 / 一手：清史稿】。
- 得失：以"不争"取位，却埋"临事无断"之根（框架推断其长短期错位）。

## 二、即位初政（1850）

- **罢穆彰阿、耆英，开言路**：示振作、斥奸邪，立意可嘉【文本·《清史稿·文宗本纪》 / 一手：清史稿】。
- **思用林则徐主粤**：徐未至卒，错失早期御夷良机【文本·《清史稿·林则徐传》 / 一手：清史稿】。

## 三、平太平天国之乱（1851–）

- **命曾国藩办团练**：倚汉臣平内患，然「疑忌掣肘」削弱效率【文本·《清史稿·曾国藩传》 / 一手：清史稿】。
- 决策张力：倚汉平乱 vs 满汉猜防，二者并存未解（框架推断结构性约束）。

## 四、御第二次鸦片战争（1856–1860）

- **签《天津条约》（1858）**：城下之约忍辱【文本·《筹办夷务始末》（咸丰朝）/ 一手】。
- **北狩热河、留奕訢议和（1860）**：弃都保身，圆明园被焚；《北京条约》丧权【文本·《清史稿·文宗本纪》 / 一手：清史稿】。
- 得失：暂保政权存续，却失国都威望、创权力真空（框架推断其政治代价）。

## 五、权力交接（1861）

- **顾命八大臣 + 抬举懿贵妃**：双头布置意图制衡，因早崩、沟通不足反致辛酉政变、慈禧尽夺权【文本·《清史稿·文宗本纪》《后妃传》 / 一手：清史稿；意图为框架推断】。
