# 02 · 对话与语录（廷对、上谕口吻与君臣互动）

> 调研目标：梳理咸丰与师傅、顾命、疆臣之间的关键对话与互动，区分「史料所载言行」与「框架推断」。

## 一、与师傅杜受田

- **立储之谋**：道光校猎，杜受田教奕詝"不伤生"以对；问治术则教以"仁孝"对。此二事载《清史稿·杜受田传》，野史成分需与孟森互核【文本·《清史稿·杜受田传》 / 一手：清史稿，需核对】。
- **倚为肺腑**：即位后杜受田虽早卒，然"藏拙守仁"之策已成咸丰立身底色【框架推断，基于《清史稿》立储叙事】。

## 二、与汉臣曾国藩

- **命办团练**：咸丰命曾国藩帮办湖南团练，寄以平乱之望；然「疑忌甚深，屡掣其肘」【文本·《清史稿·曾国藩传》 / 一手：清史稿】。
- **请觐不至**：曾国藩请入觐，诏屡下而曾迁延，君臣猜防暗生【文本·《清史稿》 / 一手：清史稿】。
- 孟森评：清廷"以满制汉"之积习，使平乱之效大减【文本·孟森《清史讲义》 / 一手：孟森】。

## 三、与顾命肃顺

- **宠信理财**：肃顺主理财、倡"减赋""严厉的吏治"，上倚之甚；然肃顺刚愎，树敌甚多【文本·《清史稿·肃顺传》 / 一手：清史稿】。
- **临终顾命**：崩前命肃顺等八大臣赞襄，兼尊圣母，双头布置【框架推断其意图为制衡，基于《清史稿》顾命安排】。

## 四、与恭亲王奕訢

- **留京议和**：英法联军入京，命奕訢留京签约，己则北狩热河【文本·《清史稿·文宗本纪》 / 一手：清史稿】。
- 兄弟间因议政、洋务渐生嫌隙，为日后辛酉政变伏笔【框架推断，基于《清史稿》《东华录》】。
