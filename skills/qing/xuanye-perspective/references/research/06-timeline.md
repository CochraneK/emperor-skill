# 06 · 时间线（康熙生平关键节点与思维影响）

> 调研目标：梳理玄烨（1654–1722）生平关键节点，标注事件与对执政思维的影响。依据《清史稿·圣祖本纪》《清实录》及孟森《清史讲义》。

## 一、编年骨架

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1654 | 生于景仁宫，世祖第三子，庶出（母孝康章皇后） | 非嫡非长底色，自幼知君位之险 |
| 1661 | 8岁即位，次年改元康熙；四大臣辅政 | 冲龄践祚，养成「隐忍蓄势、待时而动」 |
| 1667 | 亲政（14岁），仍受鳌拜掣肘 | 亲政而权不在手，强化收权之急 |
| 1669 | 擒鳌拜、亲揽大权 | 「一击必中、先固君权」决策哲学定型 |
| 1673–1681 | 撤藩引发三藩之乱，八年始平 | 「养患不如早图」「慎始而后决」 |
| 1678–1679 | 开博学鸿儒科、设明史馆 | 以文治收道统、安士林之政略展开 |
| 1683 | 用施琅平台，设台湾府 | 「海疆必纳入版图」的经略观 |
| 1685–1689 | 雅克萨之战、《尼布楚条约》 | 对俄务实外交、分势御边之智 |
| 1690/1696/1697 | 三征噶尔丹，漠北悉定 | 「心腹之患必亲征犁庭」的拓边观 |
| 1708/1712 | 胤礽两立两废，九子夺嫡起 | 仁而过宽、立储两难，晚年最大痛点 |
| 1712 | 谕「滋生人丁永不加赋」 | 安民薄赋、与民休息之德政定型 |
| 1712–1722 | 晚年倦勤、储位虚悬 | 「守成之主难在善终交接」的历史警示 |
| 1722 | 崩于畅春园，在位六十一年 | 清代在位最久，「守成兼开拓」之君落幕 |

## 三、关键节点逐条：处境、心迹与出处

- **1661（顺治十八年，8 岁）即位**：世祖以痘疾骤崩，遗诏立第三子玄烨。诸书载其幼年已出痘而得免疫，故为议立所取【史料原文/一手：《清史稿》卷六《圣祖本纪》一；异说：西洋教士汤若望劝立之说见教会文书，中土官书不载，并存】。【框架推断】以冲龄入承大统而权在四大臣，其处境是「位尊而力弱」，只能观察、不能发声——此后「隐忍而后发」的行事节奏由此奠定。
- **1669（康熙八年，16 岁）擒鳌拜**：亲政已两年而鳌拜专擅如故，帝以小内监习布库（摔跤）为名，召鳌拜入而立擒之，宣布三十款罪，念其旧劳免死、籍没拘禁【史料原文/一手：《清史稿》卷六、卷二四九《鳌拜传》】。【框架推断】以游戏为掩护、不惊动朝堂而一击成擒，说明他此时已明白「力不足则先示弱，动手必须一次成功」。这一年重要，在于它把「如何夺权」固化成他此后反复使用的动作模板。
- **1673—1681（康熙十二—二十年，20—28 岁）三藩之乱**：尚可喜请归老辽东，吴三桂、耿精忠相继疏请徙藩以为试探；廷议久不决，帝断以「撤亦反，不撤亦反」，遂下撤藩之令。三桂反于云南，耿、尚并起，陕西王辅臣响应，东南西北一时俱震【史料原文/一手：《清史稿》卷六—七、《清圣祖实录》；《清史稿》卷四七四《吴三桂传》】。【框架推断】八年苦战是他一生最险的窗口：八旗劲旅已不如入关之时，只能倚绿营汉将、分而击之，以「不罪胁从」瓦解叛方。此役之后他更倾向「患起于微时即除」，对准部之连年用兵即其延长。
- **1683—1684（康熙二十二—二十三年，30—31 岁）平台与设台湾府**：施琅克澎湖，郑克塽降。廷议多主「迁其人、弃其地」，帝独采施琅「弃之必酿大祸」之议，设台湾府及台湾、凤山、诸罗三县，隶福建【史料原文/一手：《清史稿》卷七、卷二六〇《施琅传》】。【史论/二手】孟森谓此举「定东南数百年之局」，非仅取一岛而已【史论/二手：孟森《清史讲义》】。这一年重要，在于他否定了多数廷臣的「弃地省事」，把海疆纳入常规行政。
- **1685—1689 雅克萨与《尼布楚条约》**：两攻雅克萨，俄人请和；遣索额图与俄使会议于尼布楚，定以额尔古纳河、外兴安岭为界，立碑刻满、俄、拉丁文【史料原文/一手：《清史稿》卷七、《清圣祖实录》；《尼布楚条约》拉丁文本】。【框架推断】愿以一纸界约换北边数十年无事，说明其排序是「能约则约、不能约则战」——先安西北，故可在东北让步。
- **1690／1696／1697 三征噶尔丹**：乌兰布通、昭莫多两战，末役亲赴宁夏督师，噶尔丹穷蹙仰药死，漠北喀尔喀内附【史料原文/一手：《清史稿》卷七、《清圣祖实录》】。【框架推断】年近五十仍亲冒风雪出塞，与其说是好战，不如说是「腹心之患必须自己看着办完」——此事他不愿交予任何人。
- **1708／1712 两立两废太子胤礽**：一废于热河，罪状列「不遵朕训」「暴戾」等；旋复立，越三年再废，自是储位虚悬，诸皇子各树党援【史料原文/一手：《清史稿》卷七、卷二二〇《诸王传》；《清圣祖实录》康熙四十七年、五十一年】。【框架推断】对外用兵之果断，在亲子身上全数失效，反复立废反使诸子之争坐大。异说：继位遗诏有改窜之讼，学者多所辨驳，本稿存而不论。
- **1712（康熙五十一年）「滋生人丁永不加赋」**：谕以「海宇承平日久，户口日增」，将丁银定额，后遂为「摊丁入亩」之先声【史料原文/一手：《清史稿·食货志》二、《清圣祖实录》】。这一年重要，不在军事而在财政观念的定型：以「永不加赋」换取民间对朝廷的长期认可。

## 四、纪年与异说处理

- 康熙朝纪年以《清圣祖实录》《清史稿》为准，二者无大舛；凡与朝鲜《李朝实录》、西洋教士书信相异处（如传位细节、储位之争），本稿并列不裁断。
- 月份诸书不载者标「约」或直书「诸书不载」，不伪造精确日期。
