# 06 · 时间线（弘历关键节点与对思维的影响）

> 调研目标：梳理清高宗弘历生平关键节点，标注事件与对执政思维的影响。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1711 | 生于雍亲王藩邸，圣祖（康熙）钟爱，命育之宫中 | 以嫡孙承大统的合法性底色，自幼仰慕圣祖 |
| 1735 | 雍正崩，即位为帝，改元乾隆 | 即位即定「法祖从宽」，以守成兼开拓立基 |
| 1736 起 | 承雍正密折、军机处之制，乾纲独断 | 集权重于一人，朱批直达成执政风格 |
| 1747–1749 | 第一次平大小金川 | 以武功立威，开启「十全」用兵逻辑 |
| 1751–1784 | 六次南巡阅河 | 仿康熙、重河工，亦养成好大喜功之习 |
| 1755–1759 | 平准噶尔、定回部 | 西域底定，「大一统」自评成核心自信 |
| 1773 | 开四库全书馆，修《四库》 | 文治极盛，同时兴文字狱「寓禁于征」 |
| 1776 | 第二次平金川告成 | 十全武功渐齐，自评愈满 |
| 1787–1788 | 靖台湾林爽文 | 边功累加，好名求全之念益重 |
| 1793 | 拒马戛尔尼通商（敕英王书） | 天朝自大、闭关之局益固，错失开窗之机 |
| 1796 | 禅位嘉庆，自称太上皇帝而训政 | 践「不逾圣祖六十年」之诺，仍握实权 |
| 1799 | 崩于养心殿，和珅旋被诛 | 盛世落幕，由盛转衰之转折成定评 |

> 来源：以《清高宗实录》《清史稿》本纪、蒋良骐/王先谦《东华录》及孟森《清史讲义》为主干，与通俗清史互参。
