# 少帝刘辩 · 04 外部评鉴/后世视角

> 史家、后世对少帝（弘农王）之评。区分史评与史实。

## 一、《后汉书》（范晔）之评（source: web 核验）
- 何皇后纪（卷十下）末，范晔论何后：「初，太后新立，当谒二祖庙……时有识之士心独怪之，后遂因何氏倾没汉祚焉。」——把东汉末之倾覆归于何氏（少帝母族）之政。
- 《董卓传》以「废立从意」「陵虐朝廷」写董卓废少帝，明示少帝之被废属权臣跋扈，非少帝有失德可指（卢植「行无失德」为董卓议废时之正面辩护，反衬少帝无辜）。

## 二、袁山松《后汉书》记少帝临刑（source: web 核验）
袁山松详载少帝与唐姬诀别之歌，其笔端多同情——「坐者皆歔欷」「王谓唐姬曰……自爱，从此长辞」，是史家对这位被废幼主悲剧命运的哀婉。

## 三、《后汉纪》（袁宏）视角
袁宏《后汉纪》在同一年代叙述中记何进之死、董卓之暴，将少帝之废立定位为「宦官外戚相争 → 军阀乘乱废立」链条上的一环，非少帝个人问题。

## 四、后世评价要点
- 少帝常被视作东汉末皇权奔溃的「过渡符号」：自其被董卓废立，东汉实际已名存实亡，进入军阀混战。
- 唐姬守节（誓不再嫁、被李傕俘不屈）成为后世哀咏少帝的辅线。
- 悲歌「天道易兮我何艰」被后世视为亡国之音的先声，常被引于论汉魏禅代、皇权更替。
