# 少帝刘辩 · 02 对话/互动实录

> 依据一手正史核验蒸馏。

## 一、张让/段珪劫持少帝（189 年 8 月）
- 何进被杀后，中常侍张让、段珪等劫少帝及陈留王（刘协）幸北宫；司隶校尉袁绍勒兵尽诛阉人。张让、段珪等复劫少帝、陈留王走小平津，尚书卢植追击斩之。
- 少帝与陈留王「夜步逐萤火光，行数里，得民家露车共乘之，还宫」——此为史载少帝唯一一段身在现场的历险。

## 二、董卓迎驾、见帝（source: web 核验，董卓传注引《山阳公载记》/《典略》《英雄记》）
- 董卓远见火起、引兵急进，至城西闻少帝在北邙，往奉迎。「帝见卓将兵卒至，恐怖涕泣」（《典略》：「帝望见卓涕泣」，公卿谓卓有诏却兵，卓曰「公诸人为国大臣，不能匡正王室，至使国家播荡，何却兵」）。
- 董卓与少帝言，「不能辞对」，而「与陈留王语，遂及祸乱之事」。卓以陈留王为贤、且为董太后所养，卓自以与董太后同族，遂有废立之意。

## 三、董卓大会废立之议（source: web 核验，董卓传）
- 董卓集议废立，曰：「大者天地，其次君臣，所以为政。皇帝闇弱，不可以奉宗庙、为天下主，今欲依伊尹、霍光故事，更立陈留王，何如？」
- 尚书卢植独曰：「今上富于春秋，行无失德，非前事之比也。」（董卓怒，罢坐；明日复集，策废少帝）
- 袁绍谏：「汉家君天下四百许年，恩泽深渥，兆民戴之。恐众不从公议。」董卓曰：「天下之事，岂不在我？我今为之，谁敢不从！」袁绍「横刀长揖而去」。（《英雄记》）

## 四、被废、被害（source: web 核验）
- 「卓乃遂策废皇太后，迁之永安宫，其夜崩。废皇帝史侯为弘农王，立陈留王为皇帝。」
- 初平元年（190），「卓闻东方州郡谋欲举兵，恐其以弘农王为主，乃置王阁上，荐之以棘」，遣郎中令李儒进鸩，少帝不肯饮，强之，乃与唐姬及宫人饮燕别，悲歌后「饮药而死，时年十八」。
- 初平元年二月，「葬弘农王于故中常侍赵忠成圹中，谥曰怀王」。
