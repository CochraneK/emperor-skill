# 06 · 时间线（章帝生平与建初、元和、章和朝大事）

> 调研目标：为 SKILL.md 提供刘炟（汉章帝）的生平与在位大事的时间轴。一手材料以《后汉书·肃宗孝章帝纪》卷第三为主。

## 一、生平分期

| 年份 | 事件 |
|------|------|
| 57年 | 刘炟生，明帝第五子，母贾贵人；由明帝所宠之马贵（后马后）抚育，后立为太子 |
| 永平三年（60） | 马贵人为皇后，同年立刘炟为皇太子；「少宽容，好儒术，显宗器重之」 |
| 永平十八年（75）八月 | 明帝崩，壬子即皇帝位，年十九；尊皇后为皇太后；葬明帝于显节陵 |
| 建初元年（76） | 以赵熹为太傅、牟融为太尉并录尚书事；诏以上林池御田赋与贫人；牛疫三州大旱温 |

## 二、建初朝（76—83）

| 年份 | 事件 |
|------|------|
| 建初二年（77） | 立贵人窦氏为皇后；班超击姑墨大破之 |
| 建初三年（78） | 马防为车骑将军；冬立皇子庆为皇太子 |
| 建初四年（79） | 会诸儒于白虎观，亲称制临决，讲议五经同异作《白虎议奏》（《白虎通》）；立皇子庆为太子之次年 |
| 建初五年（80） | 日食自省诏「上累三光、痛心疾首」；班超击疏勒破之 |
| 建初八年（83） | 铸金剑投伊水；邓训、班超等经营西陲 |

## 三、元和朝（84—86）

| 年份 | 事件 |
|------|------|
| 元和二年（85） | 著胎养令（产子复勿算三岁、怀妊赐谷免夫算）；迎气五郊、顺时理狱 |
| 元和三年（86） | 废皇太子庆为清河王，立皇子肇（和帝）为皇太子 —— 因宋贵人、梁贵人受窦后构陷，废太子庆 |

## 四、章和朝（87—88）

| 年份 | 事件 |
|------|------|
| 章和元年（87） | 南巡狩；遣使祠沛高原庙；祥瑞屡臻、大赦赐爵 |
| 章和二年（88）二月 | 帝崩于章德前殿，年三十一；遗诏无起寝庙；户 7456784、口 43356367；葬敬陵，庙号肃宗 |

## 五、备注（源与可信度）

- 以上均据《后汉书·肃宗孝章帝纪》卷第三（一手本纪），卷次/句读以中华书局点校本为准。
- 窦后构陷宋、梁二贵人及废太子庆事，详见《后汉书·章帝纪》与诸贵人传、清河孝王庆传（source: web 核验）。
- 班超西域事本纪从略，详见《后汉书·班超传》卷四十七。
- 后世「东汉之衰自章帝始」等为史评（见 04-research），非本纪所载，写 SKILL 时须与一手本纪区分。
