# 06 · 时间线（顺帝生平与永建、阳嘉、永和朝大事）

> 调研目标：为 SKILL.md 提供刘保（汉顺帝）的生平与在位大事的时间轴。一手材料以《后汉书·孝顺冲孝质帝纪》卷第六为主。

## 一、生平分期

| 年份 | 事件 |
|------|------|
| 115年前后 | 刘保生，安帝之子；母李氏，为阎皇后所害 |
| 永宁元年（120） | 立为皇太子 |
| 延光三年（124） | 为乳母王圣、大长秋江京、中常侍樊丰所构陷，「太子坐废为济阴王」 |
| 延光四年（125）十一月 | 安帝崩、北乡侯立（200余日病卒）；孙程等十九人中黄门「共斩江京、刘安、陈达等，迎济阴王……即皇帝位，年十一」；诛阎显兄弟 |

## 二、永建朝（126—131）

| 年份 | 事件 |
|------|------|
| 永建元年（126） | 即位数诏大赦、「荡涤宿恶、与人更始」「与阎显江京等交通者悉勿考」 |
| 永建四年（129） | 拒桂阳太守文砻献大珠、「太官减膳、珍玩不御」 |
| 永建年间（126—131） | 纳虞诩等议除输赎之弊、整饬吏治；复安定北地上郡归旧土；屡赈灾、录囚理冤 |

## 三、阳嘉朝（132—135）

| 年份 | 事件 |
|------|------|
| 阳嘉元年（132） | 立皇后梁氏（梁商女）；「史官始作候风地动铜仪」（张衡）；太学新成、试明经补弟子；冬「初令郡国举孝廉，限年四十以上……诸生通章句，文吏能笺奏」——阳嘉新制 |
| 阳嘉二年（133） | 诏「朕以不德，统奉鸿业……灾眚屡见……务悉心直言」；京师地震 |
| 阳嘉四年（135） | 「初听中官得以养子为后，世袭封爵」；执金吾梁商为大将军 |

## 四、永和、汉安、建康朝（136—144）

| 年份 | 事件 |
|------|------|
| 永和元年（136） | 改元永和、大赦；宗祀明堂 |
| 永和四年（139） | 中常侍张逵等人有罪诛（宦官自相构陷） |
| 永和六年（141） | 大将军梁商薨，河南尹梁冀为大将军；且冻羌马贤败没，边患 |
| 汉安元年（142） | 改元汉安；诏举贤良方正能探赜索隐 |
| 建康元年（144） | 帝崩于玉堂前殿，年三十；梁太后临朝、梁冀专权；其后冲帝、质帝、桓帝相继 |

## 五、备注（源与可信度）

- 以上均据《后汉书·孝顺冲孝质帝纪》卷第六（一手本纪），卷次/句读以中华书局点校本为准。
- 梁冀鸩弑顺帝之说本纪有异辞（一作梁冀鸩弑、一作帝崩），以点校本考订为准。
- 阳嘉新制之议详《后汉书·左雄传》卷六十一；张衡地动仪见《张衡传》。
- 「终溺于私嬖近习」之评为范晔史赞（见 04-research），非本纪一手诏令。
