# 06 · 时间线（和帝生平与永元朝大事）

> 调研目标：为 SKILL.md 提供刘肇（汉和帝）的生平与在位大事的时间轴。一手材料以《后汉书·孝和帝纪》卷第四及《孝殇帝纪》为主。

## 一、生平分期

| 年份 | 事件 |
|------|------|
| 79年 | 刘肇生，章帝第四子；母梁贵人，为窦皇后所谮、忧卒，窦后养以为己子 |
| 建初七年（82） | 立为皇太子 |
| 章和二年（88）二月 | 章帝崩，壬辰即皇帝位，年十岁；尊窦皇后为皇太后、太后临朝；以邓彪为太傅录尚书事 |
| 永元六年（94） | 诏举贤良方正能直言极谏，帝亲临策问、选补郎吏；更有力地亲政 |

## 二、永元朝武功与外拓（89—97）

| 年份 | 事件 |
|------|------|
| 永元元年（89） | 窦宪出鸡鹿塞，稽落山大破北匈奴，登燕然山刻石勒功而还 |
| 永元二年（90） | 窦太后封窦宪大将军；月氏遣兵攻西域长史班超，超击降之；罢盐铁之禁纵民煮铸 |
| 永元三年（91） | 窦宪遣耿夔金微山围北单于、获其母阏氏，北匈奴破灭；复置西域都护、戊己校尉（班超为都护） |
| 永元四年（92） | 窦宪潜图弑逆被发，和帝与郑众等定策收捕窦氏党、窦宪及弟自杀；假苑囿陂池与贫民 |
| 永元五年（93） | 诏选举良才为政之本；开仓赈禀三十余郡 |
| 永元九年（97） | 班超遣甘英使大秦（罗马），至条支临大海而返 |
| 永元十二年（100） | 蒙奇、兜勒（远国）遣使朝贡 |

## 三、晚年与崩（105年）

| 年份 | 事件 |
|------|------|
| 元兴元年（105）冬十二月 | 帝崩于章德前殿，年二十七；遗诏爱民恤刑；其后殇帝刘隆婴儿即位、邓太后临朝 |

## 四、备注（源与可信度）

- 以上均据《后汉书·孝和帝纪》卷第四（一手本纪），卷次/句读以中华书局点校本为准。
- 甘英使大秦、「蒙奇兜勒」事本纪从略，详见《后汉书·西域传》（source: web 核验）；「至条支、临大海（地中海东岸）而未抵罗马」为今人考订口径。
- 郑众为宦官干政之始见《后汉书·宦者列传》，属范晔专传之论（见 04-research），非本纪一手事迹。
- 户口、垦田之盛（口 5300 余万）为永元间统计（source: web 核验）。
