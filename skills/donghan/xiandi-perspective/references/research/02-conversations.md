# 献帝刘协 · 02 对话/互动实录

> 依据一手正史《后汉书·孝献帝纪》（卷九）及注核验蒸馏。

## 一、董卓迎驾时之应对（source: web 核验，董卓传注引《山阳公载记》《典略》）
- 少帝被废立前，董卓迎驾：「与陈留王语，遂及祸乱之事。卓以王为贤。」——刘协（时为陈留王）面对董卓言辞对答得体、能言祸乱之事，董卓遂以为贤、有废立之意。

## 二、被李傕劫持、面斥权臣（source: web 核验，袁宏《后汉纪》）
- 李傕兵入宫劫驾，太尉杨彪谏「自古帝王无在人家者」，李暹曰「将军计定矣」；献帝被劫幸李傕营，「擂鼓迫帝」，帝「大怒欲责之」，侍中杨琦劝以忍。
- 李傕入见，「带三刀」，献帝当面数其罪；李傕出而喜曰「陛下贤主也」。
- 郭汜欲令车驾幸高陵，献帝拒之：「祖宗皆在洛阳，灵怀皇后宅兆未立，未遑谒也。梦想东辕，日夜以与……遂终日不食。」——献帝面对军阀，偶有坚持与威仪。

## 三、东归途中（source: web 核验，卷九 兴平二年）
- 车驾东归，李傕、郭汜追乘舆战于东涧，王师败绩；献帝幸曹阳露次田中、幸安邑，颠沛疲惫，「百官披荆棘，依墙壁间……群僚饥乏，尚书郎以下自出采稆，或饥死墙壁间，或为兵士所杀」。

## 四、曹操迎驾许都（source: web 核验，卷九 建安元年）
- 建安元年八月，「车驾至洛阳，幸故中常侍赵忠宅……是时宫室烧尽，百官披荆棘」；「辛亥，镇东将军曹操自领司隶校尉，录尚书事」「庚申，迁都许」「冬十一月，曹操自为司空，行车骑将军事，百官总己以听」——献帝自此入曹操掌握。

## 五、衣带诏（source: web 核验，卷九 建安五年；注引《献帝起居注》/《三国志·先主传》）
- 五年春正月，「车骑将军董承、偏将军王服、越骑校尉种辑受密诏诛曹操，事泄。壬午，曹操杀董承等，夷三族。」——董承自称受献帝衣带密诏，此案即「衣带诏」事件（真实性有争议，需注明「一说」）。

## 六、伏皇后被杀（source: web 核验，卷九 建安十九年）
- 「十九年……十一月丁卯，曹操杀皇后伏氏，灭其族及二皇子」——献帝为曹操废黜/诛杀皇后伏氏，帝势之弱于此极矣。
