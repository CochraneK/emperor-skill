# 献帝刘协 · 01 文字/言论辑录

> 依据一手正史《后汉书·孝献帝纪》（卷九）及注核验蒸馏；本纪所载献帝诏敕语录逐条辑录。

## 一、追尊生母王夫人之诏（source: web 核验，《后汉书·孝献帝纪》卷九 兴平元年）
献帝加元服，有司奏立长秋宫，献帝诏：
> 「朕禀受不弘，遭值祸乱，未能绍先，以光故典。皇母前薨，未卜宅兆，礼章有阙，中心如结。三岁之戚，盖不言吉，且须其后。」
（随后追尊王美人为灵怀皇后，改葬文昭陵。）

## 二、悯恤老儒之诏（source: web 核验，卷九 兴平元年九月）
> 「孔子叹'学之不讲'，讲则所识日忘。今耆儒年逾六十，去离本土，营求粮资，不得专业。结童入学，白首空归，长委农野，永绝荣望，朕甚愍焉。其依科罢者，听为太子舍人。」

## 三、救灾开仓、查验作糜（source: web 核验，卷九 兴平元年）
- 三辅大旱，谷一斛五十万、人相食，「帝使侍御史侯汶出太仓米豆，为饥人作糜粥，经日而死者无降。帝疑赋恤有虚，乃亲于御坐前量试作糜，乃知非实」；后诏「未忍致汶于理，可杖五十。自是之后，多得全济」。
- 另有汉纪所载献帝言：「米豆五升得糜二盆，而民委顿何也，朕甚愍之。」——此为献帝少有的亲政恤民之举与精准之察。

## 四、被废为山阳公前世事（source: web 核验，卷九 建安二十五年）
- 二十五年冬十月，「皇帝逊位，魏王丕称天子」，献帝奉魏王，出为山阳公，邑一万户，「位在诸侯王上，奏事不称臣，受诏不拜，以天子车服郊祀天地」。

## 五、本纪史论与赞（source: web 核验，卷九）
- 论曰：「天厌汉德久矣，山阳其何诛焉！」
- 赞曰：「献生不辰，身播国屯。终我四百，永作虞宾。」（虞宾谓尧子丹朱为宾之典，喻山阳公为魏之宾，终享汉四百载之遗礼。）
