# 01 · 制诰、政令与诏书（明帝本纪及永平典制）

> 调研目标：提炼刘庄（汉明帝）通过其诏书、政令与言论表达的核心立场，区分「史书所载帝之言行」与「后世框架之推断」。明帝即位、养老、修渠、征匈奴诸诏集中于《后汉书·显宗孝明帝纪》（卷第二）。

## 一、即位与继体守文

- **即位诏**（中元二年四月丙辰）：「予末小子，奉承圣业，夙夜震畏，不敢荒宁。先帝受命中兴，德侔帝王，协和万邦……朕承大运，继体守文，不知稼穑之艰难，惧有废失。圣恩遗戒，顾重天下，以元元为首。」并赐天下男子爵人二级、鳏寡孤独笃癃粟人十斛，赦中元元年四月己卯赦前所犯之施刑及郡国徒【一手：《后汉书·显宗孝明帝纪》卷二】。
- **托孤与定位**：「方今上无天子，下无方伯，若涉渊水而无舟楫。夫万乘至重而壮者虑轻，实赖有德左右小子。」以高密侯邓禹为太傅，东平王刘苍为骠骑将军——「可以受六尺之托，临大节而不挠」【一手：同上卷二】。
- **「继体守文」**：即位于中元二年（57年），年三十；「继体守文」自道其守成之君定位（武功定祸乱属先帝，守文德是其本分）【一手：同上卷二】。

## 二、礼制与孝治

- **明堂宗祀祭祀诏**（永平二年正月辛未）：宗祀光武皇帝于明堂以配五帝，「仰惟先帝受命中兴，拨乱反正，以宁天下，封泰山，建明堂，立辟雍，起灵台，恢弘大道，被之八极」；制礼作乐，班时令，敕群后【一手：《后汉书·显宗孝明帝纪》卷二】。
- **养老礼诏**（永平二年冬十月壬子）：临辟雍初行养老礼。「尊事三老，兄事五更，安车软轮，供绥执授。侯王设酱，公卿馔珍，朕亲袒割，执爵而颤。祝哽在前，祝噎在后。升歌《鹿鸣》，下管《新宫》，八佾具修，万舞于庭」；赐三老李躬、五更桓荣（授朕《尚书》之师）爵关内侯食邑五千户【一手：《后汉书·显宗孝明帝纪》卷二】。
- **以孝兴学**：永平九年「为四姓小侯开立学校，置《五经》师」；明帝重《孝经》，「倡孝治天下」（source: web 核验）；「亲御讲堂，命皇太子、诸王说经」（永平十五年东巡幸孔子宅，祠仲尼及七十二弟子）【一手：同上卷二】。

## 三、安民与水利

- **春耕戒扰诏**（中元二年十二月甲寅）：「方春戒节，人以耕桑。其敕有司务顺时气，使无烦扰。」并斥「选举不实，邪佞未去，权门请托，残吏放手，百姓愁怨，情无告诉」，令有司明奏罪名【一手：《后汉书·显宗孝明帝纪》卷二】。
- **修汴渠诏**（永平十三年四月壬申前后，兼十三年诏）：王吴督修汴渠，「自汴渠决败六十余岁……今兖豫之人多被水患……宜任水势所之，使人随高而处，公家息壅塞之费，百姓无陷溺之患……今既筑堤理渠，绝水立门，河汴分流，复其旧迹」【一手：《后汉书·显宗孝明帝纪》卷二】。
- **公田赐贫、戒奢诏**（永平九年四月/十二年）：「诏郡国以公田赐贫人各有差」；「丧贵致哀，礼存宁俭。今百姓送终之制，竞为奢靡……糜破积世之业，以供终朝之费，子孙饥寒，绝命于此」，令有司申明科禁【一手：同上卷二】。

## 四、制外戚与以法驭下

- **抑外戚、防干政**：永平二年少府阴就子丰杀其妻郦邑公主贵，就坐自杀；明帝屡严禁外戚宾客犯禁，「权门请托，残吏放手」之诘。明帝「性褊察」以其术御下，《后汉书·明帝纪》论赞言「帝尤任文法」（source: web 核验）【一手/史评混合】。
- **楚王英案**（永平十三年十一月）：「楚王英谋反，废，国除，迁于泾县，所连及死徙者数千人」；十四年「前楚王英自杀」。此案牵连甚广，汉明一朝以法绳宗室诸侯最严之一案【一手：《后汉书·显宗孝明帝纪》卷二】。

## 五、北征与通西域

- **征北匈奴**（永平十六年二月）：「遣太仆祭肜出高阙，奉车都尉窦固出酒泉，驸马都尉耿秉出居延，骑都尉来苗出平城，伐北匈奴。窦固破呼衍王于天山，留兵屯伊吾庐城。耿秉、来苗、祭肜并无功而还。」【一手：《后汉书·显宗孝明帝纪》卷二】
- **初置西域都护**（永平十七年十一月）：「遣奉车都尉窦固、驸马都尉耿秉、骑都尉刘张出敦煌昆仑塞，击破白山虏于蒲类海上，遂入车师。初置西域都护、戊己校尉。」班超时从窦固征西，后独留镇抚西域【一手：同上卷二】。
- **哀牢内属、置永昌郡**（永平十二年正月）：「益州徼外夷哀牢王相率内属，于是置永昌郡，罢益州西部都尉。」【一手：同上卷二】

## 六、遗诏与户口之盛

- **遗诏俭葬**（永平十八年八月崩）：「遗诏无起寝庙……唯四时设奠，置吏卒数人供给洒扫可也。」（又作「前作寿陵，制令流水而已」）【一手：《后汉书·显宗孝明帝纪》卷二，source: web 核验】
- **户口滋殖、刑狱减省**：永平年间「天下安平，人无徭役，岁比登稔，百姓殷富，粟斛三十，牛羊被野」（永平十二年岁首语）；史称户口由光武末两千余万增至三千四百余万，断狱仅及前代十分之二二，「明察善断，法令分明」【一手+史评：《后汉书·显宗孝明帝纪·论》】。
