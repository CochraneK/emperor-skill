# 04 · 外界评鉴与后世争议（明帝治平与苛察之评）

> 调研目标：收集后世史家与前人视角对刘庄（汉明帝）的评价与歧见，用于 SKILL.md 的「价值观与反模式」「内在张力」——既见其「治平」，亦见其「苛察」。

## 一、范晔《后汉书·显宗孝明帝纪》论赞（一手史评）

- **治平之颂**：论曰「显宗丕承先业，夙夜寅畏……招集名儒，说经于雍……肃宗（章帝）遵承建武、永平之政，时则阈内乂安，百姓殷富，断狱得情，号为自理，吏称其官，民安其业，远近肃服，户口滋殖焉。」（节录大意）——明章之治承光武余烈，户口由两千万余增至三千四百余万，断狱仅为光武时三分之一【一手：《后汉书·显宗孝明帝纪·论》卷第二】。
- **「然帝性褊察，好以耳目隐发为明」**：论赞亦指出明帝「性褊察」，好用耳目监察、苛刻于下——这是对明帝苛察性格最直接的一手史评（source: web 核验）【一手：《后汉书·显宗孝明帝纪·论》】。

## 二、后世史家对明帝「明察苛细」的两面评

- **苛察之弊**：明帝「以法绳下」，亲理细务，楚王英之狱「所连及死徙者数千人」，牵连过广，为后世所议；马防等外戚虽有戒，然「卫尉防、光等奢侈踰制」仍见诸纪传【一手：《后汉书·显宗孝明帝纪》及《马援传》，source: web 核验】。
- **治平之功**：明章之治被视作东汉盛世，与文景并称（「永平之政」），断狱省减、户口滋殖、北逐匈奴、复通西域，皆其对匈奴与西域的战略决断所致【一手+史评：同上卷二及《班超传》】。

## 三、佛教传入与白马寺的传说层面

- 楚王英为明帝异母弟，最早崇奉佛教（「诵黄老之微言，尚浮屠之仁祠」，见《后汉书·楚王英传》）；明帝「夜梦金人，遣使天竺求法」，白马驮经入洛阳、建白马寺——此为后世通说（《魏书·释老志》《弘明集》等），**非《后汉书》本纪所载**，属传说/后世文献层，需与一手本纪严格区分【source: web 核验，非正史本纪】。
