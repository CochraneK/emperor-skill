# 06 · 时间线（明帝生平与永平朝大事）

> 调研目标：为 SKILL.md 提供刘庄（汉明帝）的生平与在位大事的时间轴。一手材料以《后汉书·显宗孝明帝纪》卷第二为主。

## 一、生平分期

| 年份 | 事件 |
|------|------|
| 28年 | 刘庄生，光武第四子，母阴皇后；「生而丰下，十岁能通《春秋》，光武奇之」 |
| 建武十五年（39） | 封东海公 |
| 建武十七年（41） | 进爵为王 |
| 建武十九年（43） | 立为皇太子；师事博士桓荣，学通《尚书》 |
| 中元二年（57）二月 | 光武崩，戊戌即皇帝位，年三十；尊皇后为皇太后；以邓禹为太傅、刘苍为骠骑将军 |
| 永平元年（58） | 率公卿朝于原陵；辽东太守祭肜使鲜卑击赤山乌桓大破之 |

## 二、永平建政期（永平元年—八年）

| 年份 | 事件 |
|------|------|
| 永平二年（59） | 宗祀光武于明堂，始服冠冕行礼；行大射礼；冬行养老礼（尊三老李躬、五更桓荣）；阴就子丰杀妻，就坐自杀 |
| 永平三年（60） | 立贵人马氏为皇后，皇子炟（章帝）为皇太子；日食自省诏 |
| 永平五年（62） | 东平王苍罢归藩；北匈奴寇边 |
| 永平八年前后 | 越骑司马郑众报使北匈奴；初置度辽将军屯五原曼柏；日食引咎，令百官极言 |

## 三、西南与北边经营期（永平九—十三年）

| 年份 | 事件 |
|------|------|
| 永平九年（66） | 大有年；为四姓小侯立学校、置《五经》师 |
| 永平十年（67） | 广陵王荆有罪自杀，国除 |
| 永平十二年（69） | 哀牢王率众内属，置永昌郡；遣王吴修汴渠自荥阳至千乘海口；「天下安平，人无徭役，百姓殷富」 |
| 永平十三年（70） | 汴渠成；楚王英谋反，废国除迁泾县，连及死徙数千人；日食制「咎在朕躬」 |

## 四、北征与通西域鼎盛期（永平十四—十八年）

| 年份 | 事件 |
|------|------|
| 永平十四年（71） | 楚王英自杀；初作寿陵 |
| 永平十五年（72） | 东巡幸孔子宅祠仲尼及七十二弟子，亲御讲堂命诸王说经；遣窦固、耿秉屯凉州 |
| 永平十六年（73） | 四路伐北匈奴，窦固破呼衍王于天山、屯伊吾卢；祭肜、耿秉、来苗无功而还（班超随窦固使西域定鄯善） |
| 永平十七年（74） | 击白山虏于蒲类海、入车师，初置西域都护、戊己校尉；哀牢儋耳僬侥诸种慕义贡献 |
| 永平十八年（75） | 八月壬子，帝崩于东宫前殿，年四十八；遗诏无起寝庙、俭葬 |

## 五、备注（源与可信度）

- 以上均据《后汉书·显宗孝明帝纪》卷第二（一手本纪），卷次/句读以中华书局点校本为准。
- 班超入西域事本纪从略，详见《后汉书·班超传》卷四十七（source: web 核验）。
- 白马寺、佛教传入属后世传说层（《魏书·释老志》等），非本纪所载，写 SKILL 时须与一手史实区分。
