# 06 · 时间线（光武帝建武大事与思维演变）

> 调研目标：以时间线梳理刘秀从南阳起兵到光武中兴的关键节点及其对思维/决策风格的影响。时间与事件据《后汉书·光武帝纪》上、下及本地档案（source: web）。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 前5 | 生于南阳蔡阳（今南阳），高祖九世孙 | 宗室血脉、家道中落、少事稼穑之底色 |
| 王莽天凤中 | 至长安受《尚书》，略通大义 | 儒术熏染、「柔道」「经明」之基 |
| 8–23 | 王莽新朝，天下连岁灾蝗、寇盗锋起 | 「新莽失道、汉当复兴」之正当性自觉 |
| 22（地皇三年） | 与李通等起于宛，十月与长兄刘縯会众举兵 | 起兵之始，「刘氏复起」之谶验 |
| 23（更始元年） | 昆阳之战，以数千兵大破王寻、王邑百万之众 | 「柔能制刚」之信心，乱世脱颖之凭 |
| 23 | 长兄刘縯为更始所害，光武深自引过、不敢着丧 | 识「乱世须自掌权、隐忍自晦」之痛 |
| 23–24 | 行司隶校尉、大司马事，持节北渡河镇慰州郡 | 由宗室偏将转方面之帅 |
| 24–25 | 破王郎、收铜马（封渠帅、推赤心置于腹），号「铜马帝」 | 「怀柔收编、推心置腹」之统御法 |
| 25（建武元年六月） | 鄗南即位，祝文告天，建元建武，定都洛阳 | 「再造汉祚」之正名完成 |
| 25–36 | 历十一年，平更始余部、赤眉、隗嚣、公孙述，36年定蜀 | 「统一天下」之武功，中兴之基成 |
| 26（建武二年） | 封功臣皆为列侯；「退功臣而进文吏」渐行 | 「集权+抑臣」执政范式成型 |
| 26起 | 设尚书台、抑三公（省大司徒司直等） | 集权于上、防尾大之制 |
| 建武六年起 | 省并四百余县、吏职减损十置其一；三十税一 | 「安民恢复、省事简政」之政纲 |
| 建武六年起 | 王莽时奴婢免为庶人；屡诏释奴、除弃市律 | 「天地性人为贵、安民释奴」之德政 |
| 建武中 | 度田令清查田亩，遭豪强牚蔽、郡县上下其手 | 触动既得利益，引发「度田风波」 |
| 中元二年（57） | 二月戊戌崩于南宫前殿，年六十二，遗诏俭葬 | 以「中兴之主、约省安民」之誉留训 |

> 注：时间线与事件据《后汉书·光武帝纪》上、下及本地档案（source: web）互校；「度田风波」细节（建武十五年前后何敞、刘隆案）见相关列传，未逐字核毕，标为 source: web 待核。
