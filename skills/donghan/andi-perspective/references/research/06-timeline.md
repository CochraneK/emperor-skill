# 06 · 时间线（安帝生平与永初、延光朝大事）

> 调研目标：为 SKILL.md 提供刘祜（汉安帝）的生平与在位大事的时间轴。一手材料以《后汉书·孝安帝纪》卷第五为主。

## 一、生平分期

| 年份 | 事件 |
|------|------|
| 94年前后 | 刘祜生，章帝孙、清河孝王刘庆之子，母左姬；「年十岁，好学《史书》，和帝称之」 |
| 延平元年（106）八月 | 殇帝崩，邓太后与兄邓骘定策禁中，迎立刘祜；「即皇帝位，年十三。太后犹临朝」 |

## 二、永初、元初朝（106—120，邓太后临朝期）

| 年份 | 事件 |
|------|------|
| 永初元年（107） | 西羌乱起、断陇道，车骑将军邓骘、征西校尉任尚讨之；「计金授官」卖官之端；假公田、赈贫民 |
| 永初元年—元初（107—） | 羌乱绵延十余年，军费浩繁，徙民避寇 |
| 元初年间 | 西域、鲜卑时有侵扰，赈灾、整肃并行，然国势渐困 |

## 三、建光、延光朝（121—125，安帝亲政期）

| 年份 | 事件 |
|------|------|
| 建光元年（121） | 邓太后卒，安帝始亲政 |
| 建光、延光间 | 宠信乳母王圣、大长秋江京、中常侍樊丰等，佞幸用事；太尉杨震抗言见斥、饮鸩自杀 |
| 延光三年（124） | 王圣、江京、樊丰等共构陷太子刘保，「太子坐废为济阴王」 |
| 延光四年（125）三月 | 南巡狩，至宛「帝不豫……帝崩于乘舆，年三十二」；秘不发丧，还宫乃宣；阎皇后临朝、兄阎显定策，立北乡侯刘懿 |

## 四、备注（源与可信度）

- 以上均据《后汉书·孝安帝纪》卷第五（一手本纪），卷次/句读以中华书局点校本为准。
- 废太子刘保、王圣樊丰构陷事见《后汉书·顺帝纪》卷六（安帝崩后追述）及《宦者列传》；杨震之死见《杨震传》。
- 羌乱始末见《后汉书·西羌传》卷八十七。
- 「汉祚衰微自此而始」之论为范晔史赞（见 04-research），非本纪一手事迹/诏令，写 SKILL 时须区分。

## 五、逐年纪事补编（107—125）

- **永初元年（107）· 十四岁**：诏「以广成游猎地及被灾郡国公田假与贫民」【史料原文/一手：《后汉书·孝安帝纪》卷五】。时邓太后临朝，诏制主体在邓氏，帝年十四未预其谋；日食罪己诏属汉代诏书常式，不宜径认为安帝自撰【框架推断】。
- **永初元年至五年（107—111）· 羌乱**：先零诸羌叛，断陇道；邓骘、任尚讨之无功。永初五年诏「陇西徙襄武，安定徙美阳，北地徙池阳，上郡徙衙」，以内徙避寇【史料原文/一手：《后汉书·孝安帝纪》卷五、《西羌传》卷八十七】。本纪不载其廷议一语，其对羌事之态度只能存疑【框架推断】。
- **永宁元年（120）· 二十七岁**：夏四月立子刘保为皇太子，改元永宁【史料原文/一手：《后汉书·孝安帝纪》卷五】。太子母李氏为阎皇后所害，事见《顺帝纪》，其年诸书不系明，故不擅定【史料原文/一手：《后汉书·顺帝纪》卷六；年份诸书不载】。
- **建光元年（121）· 二十八岁**：三月邓太后崩，帝始亲政；追尊父清河孝王刘庆为孝德皇、母左氏为孝德后【史料原文/一手：《后汉书·孝安帝纪》卷五】。旋以乳母王圣等交谮，邓骘免就国，与子弟皆自杀，一说不食而死【史料原文/一手：《后汉书·邓骘传》；异说并列】。自十三即位至是始得亲政，隐忍十五年，一朝得柄即翻太后旧案、尽逐邓氏；其决绝之速，非徒报宿憾【框架推断】。
- **延光二年（123）**：以班勇为西域长史，将兵出屯柳中，西域由是复通【史料原文/一手：《后汉书·西域传》《后汉书·班勇传》】。
- **延光三年（124）· 三十一岁**：乳母王圣、大长秋江京、中常侍樊丰等共构陷太子刘保，太子坐废为济阴王【史料原文/一手：《后汉书·顺帝纪》卷六、《后汉书·宦者列传》】。同年太尉杨震奏劾樊丰等，帝不听，遣震归本郡，震行至城西几阳亭饮鸩而卒【史料原文/一手：《后汉书·杨震传》卷五十四】。听近幸而废独子、逐三公，两事同岁；其时帝对乳母、宦官之信任已过于朝臣与骨肉【框架推断】。
- **延光四年（125）· 年三十二**：南巡狩，至宛不豫，崩于乘舆【史料原文/一手：《后汉书·孝安帝纪》卷五】。崩地本纪未确指县邑，后世地志有系于宛、系于叶之别【异说：并列不裁断】。

## 六、身后一年（延光四年三月—永建元年，125—126）

- 阎皇后尊为皇太后，临朝；兄阎显为车骑将军、仪同三司，定策立北乡侯刘懿为嗣【史料原文/一手：《后汉书·顺帝纪》卷六、《后汉书·安思阎皇后纪》】。
- 同年冬十月，刘懿崩，在位不盈一岁【史料原文/一手：《后汉书·顺帝纪》卷六】。十一月，孙程等十九人斩江京、刘安等，迎济阴王刘保即皇帝位，是为顺帝；阎显等伏诛，阎太后迁于离宫【史料原文/一手：《后汉书·顺帝纪》卷六、《孙程传》】。明年改元永建（126）【史料原文/一手：同上】。
- 安帝所定之嗣、所废之太子，不出一年尽覆，而覆之者即其所倚之宦官；范晔论东汉之衰，正以此际为转折【史论/二手：《后汉书·孝安帝纪》卷五·论赞】。
