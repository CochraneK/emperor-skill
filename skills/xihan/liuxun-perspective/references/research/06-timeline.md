# 06 · 时间线（刘询：从巫蛊遗孤到中兴之主）

> 调研目标：编年呈现刘询自出生、即位至崩殂的关键节点，标注每一事件对其「霸王道杂之」执政思维之塑造。据《汉书·宣帝纪》及诸传、《资治通鉴》整理。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 前91（征和二年） | 巫蛊之祸：戾太子据自杀，史皇孙刘进（宣帝父）及王夫人死；刘病已（宣帝）生数月系郡邸狱 | 「宗室遗孤、几死于狱」的底层记忆，使其深知民间与宫廷之险 |
| 前87（后元二年） | 武帝崩，遗诏「掖庭养视」病已，录其籍 | 由「罪孥」转为「宗室近属」，名分一线得续 |
| 前87–前74 | 遇赦出狱，养于掖庭、寄养外家史氏，长於民间，娶许广汉女许平君 | 「兴于闾阎、知民事艰难」，微行察吏、重守相之念由此而生 |
| 前74（元平元年） | 昭帝崩、昌邑王贺立二十七日废；霍光等迎立病已，即位更名询，时年十八 | 继统凭「大宗名分」，初受制于霍光，隐忍蓄势 |
| 前73–前70（本始） | 本始二年大举伐匈奴，与乌孙夹击重创之；本始四年地震诏免租赋 | 雪耻立威、继武帝外攘之业；灾则恤民，王霸并用初显 |
| 前69–前66（地节） | 地节二年霍光死；地节四年霍禹等谋反觉，族诛霍氏，收兵权归许史，魏相去副封 | 亲政开端，「去权臣、收权柄」成执政范式；信赏必罚含冷酷一面 |
| 前67（地节三年） | 立许后子刘奭为太子；屡诏举贤良、假公田贷种安流民 | 重继嗣名分；以实政安民，综核名实之治风成型 |
| 前64（元康二年） | 诏更名询以便民避讳；元康中频褒廉吏、赈高年 | 「以民为本、便民为先」的帝王自觉 |
| 前61–前58（神爵） | 赵充国平羌屯田（神爵中）；神爵四年赐高年帛、振贷勿收 | 「先难后从、以实核议」的廷议作风；惠政常态化 |
| 前60左右（神爵中） | 郑吉破车师、降日逐王，置西域都护，治乌垒城 | 「都护常置、控西域」成为疆理西陲之定策（置年异说二/三年并存） |
| 前57–前54（五凤） | 匈奴五单于争立内乱；常惠等再击之 | 乘匈奴乖乱、推亡固存，威服北夷之机 |
| 前53–前51（甘露） | 甘露元年呼韩邪单于称臣；甘露三年单于入朝、登渭桥受藩；同年石渠阁议经、麒麟阁图功臣 | 「单于稽首」为中兴极盛；文治（石渠）与旌功（麒麟阁）并立 |
| 前49（黄龙元年） | 崩，葬杜陵，庙号中宗 | 以「中兴之主」留训；然「乱我家者太子也」之叹，预示元帝后之衰 |
| 前48以降 | 太子刘奭继位（元帝），柔仁好儒，渐离霸王道 | 宣帝治术之「霸」转元帝之「儒」，国势由盛转衰（史论/二手评） |

> 注：宣帝在位以用户给定 era 前74–前48 标署；本表内年号编年依《汉书·宣帝纪》通行系年，黄龙以后崩年与「前48」之尾数差异属纪年异说，并列不调和。
