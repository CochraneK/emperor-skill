# 06 时间线 · 孺子婴（刘婴，西汉末帝号·王莽居摄所立「孺子」，公元6–9 名义在位，未即帝位）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。孺子婴生平极薄，且本人无思维活动传世，故「对思维之影响」一栏只能写为「作为被动符号所受之塑造」，严格标注为框架推断。所有节点以《汉书·王莽传》《资治通鉴》汉纪（卷三五–三九）为准。

## 一、关键节点（附对「身份/处境」之影响）

| 时间 | 事件 | 对身份/处境的影响 |
|------|------|--------------|
| 约公元4年（生年史不载精确） | 生于长安，为宣帝玄孙、广戚侯刘显之子 | 出身宗室远支，幼弱，无预政之可能 |
| 公元5年（元始五年） | 平帝崩，无子；王莽选二岁之孺子婴立为皇太子，号「孺子」 | 被立为嗣君符号，实由王莽摄；身份自此被「幼冲」定义 |
| 公元6年（居摄元年） | 王莽居摄、称「假皇帝」，南面听政，孺子退居虚位 | 君名与君权彻底分离；孺子沦为法统牌位 |
| 公元8–9年（居摄三年/初始元年–始建国元年） | 王莽即真帝位，建号「新」，策孺子为定安公（安定公），「永为新室宾」 | 西汉宗庙废绝，孺子由嗣君降为公，帝号不被承认 |
| 公元9年起（始建国后） | 王莽以孺子「未龀，不令就国，置邸长安，敕乳母不得与语」 | 被幽禁、断语，连基本社会化都被剥夺，彻底失声 |
| 公元23年（更始元年） | 绿林入长安、诛王莽；孺子困居长安，史不详其状 | 王莽既败，孺子作为符号重现于乱局，仍无自主记载 |
| 公元25年（更始三年） | 方望、弓林等于临泾立孺子婴为天子，旋为更始遣李松击破，斩婴（一说乱兵所杀） | 成年后仍被利用为旗帜，终被杀，西汉宣帝一系嗣君符号终结 |

## 二、史料成书背景与互核

- 【史料原文/一手】《汉书·王莽传上、中、下》为孺子事主源，班固以编传体将孺子附于王莽篡汉全程，记事至王莽败、孺子幽长安。
- 【史料原文/一手】《资治通鉴》卷三十五至三十九以编年系孺子事于汉纪，司马光显「立幼—居摄—即真—封公—被杀」之因果线，与《王莽传》互证。
- 【史料原文/一手】《汉书·平帝纪》《诸侯王表》补孺子世系：宣帝玄孙、广戚侯刘显子，世系清晰。
- 【史论/近一手】后世史评（如《汉书》王莽传赞）以王莽为「穷凶极恶」，孺子为被借之具；属史论，不作立论根基。
- 【互核结论】孺子「立—居摄—封公—幽—被杀」五节点在《汉书》《通鉴》一致；唯「被杀时地、死因」有临泾立而旋斩 / 乱兵所杀两说，《通鉴》两存，本 Skill 依主流载之，不调和。
- 【成书背景说明】班固为东汉初人，距孺子事未远，叙事近一手；司马光《通鉴》为北宋编年，已带史臣取舍，凡涉纪年以《汉书》本传与《通鉴》互核。孺子无本纪、无个人传记，史料稀薄为本维度根本限制。

## 三、小结

- 一手节点与互核均出《汉书·王莽传》《平帝纪》《诸侯王表》《资治通鉴》汉纪。
- 史不载声明：孺子生年精确、母族、自述、思维活动，史皆不载；凡无可靠出处者宁标「史不载」，不编造名言或内心独白。
- 框架推断：各节点「对身份/处境之影响」一栏为基于史事的归纳，非史书明言孺子之思维（其亦无思维记载），逐条标注。
