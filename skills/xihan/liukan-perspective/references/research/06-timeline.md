# 06 时间线 · 刘衎（汉平帝，前9–公元6，9岁即位、14岁崩）

> 维度定义：关键节点表 + 对思维之影响，含史料成书背景与互核。
> 平帝本人无"执政思维"，本时间线之"对思维的影响"指：本 Skill 视角下，各节点如何塑造对"幼主—摄政"之理解，及对王莽代汉进程的把握。凡影响栏皆【框架推断】式归纳。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 前9（元延四年） | 刘衎生，元帝庶孙、中山孝王兴之子，母卫姬，初名箕子 | 本为远支宗亲幼童，入继前与帝位无涉；"名箕子"见其本非储贰 |
| 前1（元寿二年六月） | 哀帝崩无嗣；太皇太后王政君收玺，王莽为大司马定策 | 幼主入继之机：宗庙需嗣，而权臣握定策之柄——"名位"由此易主 |
| 前1（九月） | 中山王即皇帝位（平帝），9岁；王政君临朝，王莽秉政 | 养成"朕有其名而无其柄"之根本处境：政自莽出，百官总己以听 |
| 公元1（元始元年） | 群臣奏莽功，赐号"安汉公"；越裳献白雉，比周公 | 摄政者以"功+符瑞"双轨合法化专权；平帝成"受瑞之君"符号 |
| 公元2（元始二年） | 黄支国献犀牛；王莽奏立明堂、辟雍 | "太平已洽"叙事加码，改制（托古）序幕；平帝仍旁观 |
| 公元3（元始三年） | 王莽女为皇后，见于高庙；卫姬留中山不得至 | 姻亲固权+母族见隔，平帝"常有怨忿"——亲疏皆不由己 |
| 公元4（元始四年） | 王莽加号"宰衡"；起明堂、辟雍、灵台 | 摄政者名器逼近天子；平帝之"君"名愈发空洞 |
| 公元5（元始五年） | 王莽子宇通卫氏事败死，诛卫氏支属及异己；刘歆奏立古文经"诏可"；加九锡；冬十二月平帝崩（疑被鸩） | 清洗+立经+九锡三线并行，代汉只待幼主殁；平帝崩成悬案，王莽旋立孺子婴居摄 |
| 公元6 | 王莽立宣帝玄孙婴（孺子婴）为皇太子，居摄，号令天下 | 汉统名存实亡；平帝一朝实为"王莽代汉"之过渡终幕 |

## 二、史料成书背景与互核

- 【史料原文/一手】《汉书·平帝纪》为平帝事主源，编年记其即位、安汉公、符瑞、纳后、立经、崩，叙事克制。
- 【史料原文/一手】《汉书·王莽传》补摄政进位、隔绝卫氏、王宇事、九锡、上椒酒诸节，与《平帝纪》互证。
- 【史料原文/一手】《资治通鉴》汉纪承《汉》节叙，编年系平帝事于"王莽专政"脉络。
- 【史论/近一手】班固"赞曰：政自莽出"定评平帝朝本质；"上椒酒"暗讽毒杀，留异说。
- 【互核结论】平帝"即位—安汉公—纳后—立经—九锡—崩—孺子婴居摄"链条在《汉》《通鉴》一致；死因（疾 vs 鸩）异说并列不调和。
- 【成书背景说明】班固仕东汉，距平帝未远，《汉书》本纪经修史加工；凡涉王莽褒贬多带史臣取舍，谈平帝须分"史载事实"与"班固史论"。

## 三、小结

- 一手节点与互核均出《汉书》《通鉴》；死因异说如实并列。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
