# 06 时间线 · 刘恭（西汉前少帝，前188–前184 在位约四年，吕后称制）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。刘恭史料极薄，时间线以《史记·吕太后本纪》《汉书·高后纪》为主源，编年参《资治通鉴》汉纪；"对思维之影响"一栏为基于史事之归纳推断，非史书明言，逐条标推断。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 前195–前188（惠帝朝） | 刘恭为惠帝宫人所生，吕后杀其母、冒称己子（孝惠皇后子）养于后宫（背景，据《吕太后本纪》） | 其"名分"自出生即被篡造；童稚不知，然此局注定其"有名无实"之终身底色（框架推断） |
| 前188（惠帝七年） | 惠帝崩，吕后立刘恭为帝，史称前少帝；吕后遂临朝称制 | 以孩稚即帝位，实权尽归吕后；养成"名为天子、实为人傀"之思维（框架推断） |
| 前187–前184（在位约四年） | 吕后称制，行王陵/陈平/周勃等相权更迭、诸吕封王等事；《史》《汉》于其间不书少帝言行 | 其"在位"为吕后称制之别名；思维长期处于"被遮蔽、无表达"之状态（框架推断） |
| 前184左右（稍长） | 刘恭渐长，闻生母被杀、己非真皇后子，出怨言："后安能杀吾母而名我？我壮即为变！"（据《吕太后本纪》） | 唯一一次"自主发声"：识破身世之局，以怨言对抗权力；思维由"沉默"转向"明知而直"（框架推断） |
| 前184（怨言后数日） | 吕后闻患之，幽之永巷、言帝病、左右莫得见，旋废之，改立常山王义（刘弘，后少帝） | 怨言即取祸之始；思维与自由同遭剥夺，由"帝"降为"囚"（框架推断） |
| 前184（废后不久） | 吕后幽杀前少帝刘恭（史仅书"幽杀"，不载死状） | 童帝以"知而无力"之姿终结；其怨言成西汉外戚立幼之最早警示（框架推断） |
| 前180（身后六年） | 诸吕灭，大臣以"非惠帝子"为由废杀后少帝刘弘及诸弟，追认前少帝等"不当奉嗣"，另立代王（文帝） | 其身世被身后政治化；"非惠帝子"之辩兼具史疑与权力操作（框架推断） |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·吕太后本纪》为刘恭事主源，叙其立、怨言、幽废、幽杀，附于吕后称制叙事；司马迁去汉未远，然《史记》成于武帝朝，涉吕后称制、诸吕之事已带后世修史之取舍。
- 【史料原文/一手】《汉书·高后纪》班固承《史记》而叙，西汉官修正史互证；于其世系仍以"少帝""所名子"概称，不书其名。
- 【史料原文/一手】《资治通鉴》汉纪（司马光）以编年系刘恭事于"惠帝崩—吕后称制"节点，胡三省注及诸吕灭后"非惠帝子"之辩。
- 【史论/近一手】注家（颜师古、司马贞等）于"少帝是否惠帝亲子"有异说，或信冒名之说、或疑大臣之辩为诛吕借口；异说并列不伪称定论。
- 【互核结论】刘恭"立—怨言—幽废—幽杀"四节点在《史记》《汉书》《通鉴》三史一致；唯"名与世系"有"吕后冒名所名子"与"非惠帝子（大臣之辩）"二说并存，史无定论。
- 【成书背景说明】正史本纪经后世修史加工，凡涉"吕后称制之褒贬""少帝身份之定性"，不得径作刘恭本人主张；谈及其事须区分"史载事实 vs 后世史论/政治定性"。

## 三、身份与世系存疑之特别说明

- 【史料原文/一手】《史记》《汉书》于前少帝刘恭多称"少帝""所名子"，不书其名、不书其生父确系惠帝与否；冒名杀母之说出于《吕太后本纪》叙事，大臣"非惠帝子"之辩出于诛吕之后。
- 【框架推断】是否惠帝亲子历来有争议，本 Skill 依《本纪》主流载"吕后杀母冒名所名子"，并明标"身份与世系存疑"；凡无可靠出处者宁标「史不载」，不以后世推测当事实。属史料互核结论。

## 四、小结

- 一手节点与互核均出《史记·吕太后本纪》《汉书·高后纪》《资治通鉴》汉纪；身世异说如实并列。
- 框架推断：各节点"对思维之影响"一栏、身份存疑说明，均基于史事之归纳推断，非史书明言。
- 史不载：死状、临终、亲政言行——凡无可靠出处者宁标「史不载」。
