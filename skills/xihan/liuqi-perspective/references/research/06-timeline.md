# 06 · 时间线（汉景帝刘启：生于前188 – 崩于前141，在位前157–前141）

> 调研目标：编年呈现景帝从即位到崩的执政轨迹，标注每阶段「对思维的影响」。纪年依《汉书》前元、中元、后元三段（西汉无年号，武帝始建）。时间以公元前纪年，世系/纪年异说并列不调和。一手：《史记·孝景本纪》《汉书·景帝纪》《吴王濞列传》《绛侯周勃世家》《酷吏列传》《资治通鉴》汉纪。

## 一、编年表

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 前188 | 生于代邸，文帝刘恒中子，母窦氏（后为窦太后） | 生于藩王之家，自幼习「守成保身」之局，宗室倾轧为潜意识底色 |
| 前179前后 | 文帝立，景帝立为太子（母宠、长公主援） | 储位养成「继体守文」自我定位，非开拓之主预期 |
| 前157 | 文帝崩，景帝即位；元年赦天下、赐爵、令田半租（三十税一） | 「守文安民」执政基调确立，轻赋成定制，思维锚定「保成业」 |
| 前156 | 中元前，与匈奴和亲、通关市，以李广程不识备边 | 对外「守势蓄力」思维成型，不启兵端、留开拓于后人 |
| 前155–前154 | 从晁错《削藩策》，下削楚、吴、赵、胶西支郡之令 | 由纯守文转向「强本弱枝」，思维出现强硬集权维度（分水岭） |
| 前154 | 七国之乱起（吴王濞等以「诛晁错、清君侧」为名）；袁盎献斩晁错计，景帝「吾不爱一人以谢天下」斩错；叛不止，拜周亚夫太尉，三月平乱 | 初判误（杀晁错缓师）、旋即纠偏（用亚夫），「务实能改、冷峻权变」思维定调 |
| 前154后 | 平乱后诏诸侯不得治国、天子置吏，立左官律、附益法 | 「削藩升为削权」制度转折，中央集权落地，思维由应急转长效 |
| 前153–前150 | 废栗太子荣为临江王，立王夫人子彻（武帝）为太子 | 「断而不拖、记怨而决」性格外显；外戚（长公主）牵动继统，思维非纯独断 |
| 中元年间 | 两次减笞、定箠令；中元二年改磔为弃市 | 「轻刑安民」与「削藩用威」双轨并行思维彰显 |
| 中元–后元 | 任郅都（苍鹰）、宁成（乳虎）为酷吏治宗室；临江王荣下狱自杀，窦太后怒，景帝免都 | 「外宽内峭、双轨治理」成熟；母权—法度张力中显退让，思维含「忌刻而受制于亲」 |
| 后元三年（前141） | 景帝崩，遗诏出宫人归其家、减省丧仪；太子彻即位，是为武帝 | 「守成安民」自认功业收束；开拓之业移交武帝，思维遗产为「转折节点」 |

## 二、关键转折标注

- **转折一（前155–154）**：削藩令标志「守文→集权」之切换，是景帝区别于文帝之最大思维变量。
- **转折二（前154 七国之乱）**：斩晁错（误）—用亚夫（正）的连续决策，固化其「冷务实、能纠偏」执政人格。
- **转折三（继统与酷吏）**：废立与酷吏之治，显「外宽内峭」双轨，亦暴露其受母后与外戚牵动之局限。

## 三、纪年与世系异说（并列不调和）

- 【史料原文/一手】《史记》《汉书》同载景帝为文帝中子、母窦太后，世系无大异；惟「立为太子」之因（母宠 vs 年序）叙述侧重不同，属叙述角度之差。
- 【框架推断】在位年数：前157–前141 共16年，《汉书》分前元、中元、后元三段；个别事件系年（减笞、改磔具体年）注家偶有参差，存而不强合。
- 【史论/二手】庙号称谓：西汉诸帝多无庙号，景帝称谥「孝景皇帝」，「汉景帝」乃后世习称，非其生前帝号；其生前即帝，无需追尊说明。

## 四、小结

- 一手：以上事件系年与细节出《史记》《汉书》本纪列传及《通鉴》。
- 框架推断：各事件「对思维的影响」为据史叙事推得，非帝自述。
- 史论/二手：庙号称谓、褒贬评价标注来源。
