# 03 表达DNA · 刘骜（汉成帝，前33–前7 在位）

> 维度定义：句式、词汇、语气、节奏、确定性、引用习惯（≥6 项）。凡由史料推得而非本人原话者，必须标注「据史料推得」。

## 一、句式

- 【据史料推得】成帝本人口语传世极少，其「表达」主要经史臣转述与其诏令呈现。诏令句式多为西汉帝王标准体：起手「诏曰 / 制曰」，先陈灾异或时令（「乃者……」「朕闻……」），再以「其令 / 其赦 / 赐……」下断。廷对则用「善其言而止」「吾将思之」式短答，少长篇雄辩。
- 【据史料推得】与武帝、宣帝之强势独断句不同，成帝句式偏「承接、优容」——劝诫来则「善之」，权臣言则「辄听」，呈现「不立异、不峻拒」的守成君主句法节奏。

## 二、词汇

- 【史料原文/一手】《汉书·成帝纪》高频词：灾异、赦、赐、举、恤、郡国、列侯、宗室、太后、大司马——集中于「守成、恤民、尊母、安宗亲」语义场。
- 【据史料推得】私生活侧《外戚传》出现：微行、弋猎、斗鸡、走马、后庭、昭仪、合德——构成其「耽乐」语义场，与诏令「恤民」语义场形成鲜明反差。
- 【据史料推得】其朝政治词汇以「王氏 / 五侯 / 大司马 / 领尚书事」为核心，反映外戚辅政之时代术语。

## 三、语气

- 【据史料推得】公众 / 诏令语气：宽缓、守成、遇灾修省，带儒术化帝王的「谦冲恤下」腔调（「朕甚闵焉」「其务修省」）。
- 【据史料推得】私域 / 微行语气：纵弛、亲狎，「自称富平侯家人」、与张放「俱卧起」，是去威仪之主；对班婕妤辞辇能「善而止」，显其早年尚存温厚。
- 【史论/二手】班固赞其「升车正立，不内顾，临朝渊嘿，尊严若神」——此系史臣对其容仪之美评，非语气本身，作史论参照。

## 四、节奏

- 【据史料推得】执政节奏「前谨后弛」：少好经书、宽博谨慎 → 壮而耽乐、怠于政事。其诏令频下（灾异辄诏），但「诏多而行寡」，形成「言频而事怠」的节奏错位。
- 【据史料推得】廷对节奏以「听言—善之—不行」为固定小节，清议虽盛而实政不举，节奏上呈现「开言路而不纳言」的循环。

## 五、确定性

- 【据史料推得】在「尊母、安宗亲、恤民赦罪」上近乎习惯性确定（依礼而行，不必深虑）；在「抑王氏、裁外戚」上高度不确定、拖延不决（知患而不能去）。
- 【据史料推得】在「私宠赵氏、微行纵乐」上放任自决、毫不犹疑；唯独于「国本继统（无嗣立嗣）」拖延至末年方立定陶王欣，显示其在「家事可纵、国事难断」上的确定性错位。

## 六、引用

- 【史料原文/一手】成帝诏令喜引「灾异 / 时令 / 先王」为据，承西汉儒术化诏式；校书诏则承「右文」之制，引经传以立校理之名。
- 【据史料推得】其本人未见引诗书以自辩之原话传世；史臣书其「好经书」乃少时之事，壮年则「溺于酒色」而疏儒业，故「引经」多见于其朝制度而非个人辞令。

## 七、小结

- 以上六维（句式 / 词汇 / 语气 / 节奏 / 确定性 / 引用）皆据《汉书·成帝纪》《外戚传》《元后传》《刘向传》《谷永传》《张放传》叙事与诏令推得；凡非成帝原话者均标注「据史料推得」，未伪造其口语或文集。
