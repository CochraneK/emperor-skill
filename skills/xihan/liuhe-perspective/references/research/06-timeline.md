# 06 时间线 · 刘贺（昌邑王 / 汉废帝 / 海昏侯，前92–前59）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。刘贺一生"骤起骤落"，节点以"出生—就国—被立—二十七日—废归—就国海昏—卒—考古重现"为轴。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前92 | 生于昌邑，为武帝之孙、昌邑哀王刘髆之子 | 宗室近属、诸侯王子之身份底色，养成"近中枢而远朝堂"的诸侯心态 |
| 约前88 | 父昌邑哀王刘髆薨，刘贺嗣为昌邑王（就国） | 幼年袭封，就国不治民而近倡优——龚遂、王吉屡谏其逸游，埋"任情"之性 |
| 前74（昭帝元平元年） | 昭帝崩，无嗣；大将军霍光定策，迎昌邑王贺入嗣 | 骤由诸侯王入继大统，"喜而忘危"——未识长安权臣格局，思维尚停留昌邑 |
| 前74（入立后27日） | 以昌邑故人易中枢，发诏"千一百二十七事"；霍光率群臣连名奏劾，上官太后制诏废之 | "骤进易臣"遇"权臣先发"，思维由"任情用亲"被强行截断——二十七日成其一生最大转折 |
| 前74（废后） | 废归昌邑故国，赐汤沐邑二千户，昌邑国除为山阳郡 | 由"帝"骤贬为"庶几乎王"，养成"被动承受、不争以全"的废后思维 |
| 前74–前63 | 居昌邑/山阳，宣帝遣张敞察之，贺示"清狂不惠"以释疑 | 以"示弱自污"换性命，思维转向"避祸存身、不预事" |
| 前63（宣帝元康三年） | 宣帝封贺为海昏侯，就国豫章（今南昌），食邑递减 | 远封江南，彻底远离中枢；"废帝→列侯"的二次身份定义，思维归于地方诸侯之安分 |
| 前59 | 卒于海昏侯国，国除（子嗣旋绝） | 废帝一生以"不被正统承认"收束——帝号不为后世承认为正统，思维遗产成"短祚之鉴" |
| 2015（现代） | 南昌海昏侯墓（刘贺墓）发掘，出简牍、孔子衣镜、刘贺玉印、金器等 | 考古以实物"复活"其文化形象，与《汉书》"淫乱"叙事对峙，触发"罪名虚实"之现代重估 |

## 二、史料成书背景与互核

- 【史料原文/一手】《汉书·昭帝纪》以编年登录"元平元年……昌邑王贺立……六月废"，为节点骨架；《汉书·武五子传》《霍光传》补废立细节与"千一百二十七事"。班固东汉初据西汉档案与《史记》余绪熔铸，距事约百年，属近一手叙事。
- 【史料原文/一手】《资治通鉴》卷二十四（汉纪十六）承《汉书》节叙，胡三省注疏通纪年与霍光之谋；北宋编年已带史臣取舍，凡涉纪年以《汉书》本纪互核。
- 【一手/考古】海昏侯墓（2011 年起勘探、2015 年主墓发掘）出土"刘贺"玉印、奏牍、简牍、孔子衣镜、金器，由江西省文物考古研究院等发布考古报告，直接确证墓主与随葬内容，为时间线末端的"实物续章"。
- 【互核结论】"昭帝崩—迎立—二十七日废—归昌邑—封海昏—卒"六节点在《汉书》三处（纪、传、霍光传）一致；唯"千一百二十七事"之性质（真失德 vs 权争构陷）与"清狂"之真伪存异说，并列不调和。墓主确认以玉印为定论，早期嗣子之疑已消解。
- 【成书背景说明】正史叙事经班固修史剪裁，《霍光传》立"光忠而定策"基调，刘贺"淫乱"之塑形与霍光之"功"互为表里；现代以考古实物对冲此叙事，构成"文本 vs 实物"的双重证据链。

## 三、小结

- 一手节点与互核均出《汉书》（纪/传/霍光传）、《资治通鉴》卷二十四；考古续章属【一手/考古】。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
- 诚实保留：刘贺"帝号不被后世承认为正统"——其名不列西汉正统帝系，仅以"废帝/昌邑王/海昏侯"三层身份流传；时间线须据此如实标注。
- 异说并列：罪名虚实、清狂真伪、墓主确认（已定）之细微讨论——不调和并列。
