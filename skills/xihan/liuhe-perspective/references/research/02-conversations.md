# 02 对话 · 刘贺（昌邑王 / 汉废帝 / 海昏侯，前92–前59）

> 维度定义：君臣问答 / 廷议 / 谏诤 / 使节对答 / 临终顾命。刘贺在位二十七日，对话材料集中于《汉书》所载废立前后数段；其废后之对答多经史臣转述，须区分"史料原文/原话"与"框架推断"。

## 一、龚遂、王吉之谏（就国与即位前后的师臣对话）

- 【史料原文/一手】《汉书·武五子传》载刘贺在昌邑国时，中尉龚遂、郎中令王吉屡上书谏其逸游、近倡优。王吉谏书有"（大王）……今者大王幸方与，曾不终日驰骋……"之类之辞，劝其修经术、远游畋。此属臣对君之谏议，为刘贺"就国时期"的一手对话记载（文辞为班固述意，大意如此）。
- 【史料原文/一手】龚遂尤切，史载其"（谏）……大王……"反复以"危亡"相警；及贺被征入立，龚遂随行并"涕泣"谏其收敛。此对话性质为师臣对少主之规训，是刘贺"被立前已有儒臣约束"的旁证。
- 【框架推断】二人之谏显示刘贺就国时已显"好声色、近小人"之倾向，然亦反证其身边并非全无正士——昌邑旧部中龚遂、王吉实为其"正臣"，与后来被霍光一概清洗之"昌邑群臣"须区分。属因果推断。

## 二、入立途中与即位初的对话（废立叙事中的言动）

- 【史料原文/一手】《汉书·武五子传》载刘贺被征入长安即位数日前，途中有"（贺）……"之对答与动作：其于道中不素食、与从官戏、甚至"使从官略女子载衣车"——虽为叙事，然显示其即位前的言行状态，属近一手记载。
- 【史料原文/一手】即位后，霍光等权臣与刘贺之间就人事（骤用昌邑故人、更易节旄）形成事实上的张力；《汉书》虽未录二人公开廷辩之全文，然"持节诏诸官署征发千一百二十七事"即此类"以诏令对话"的量化痕跡。
- 【框架推断】刘贺与霍光之间缺乏可见的"正面廷对"，反映其"以故人代旧臣"之动作已绕开、激怒当轴权臣；废立之祸根在"无言而行的权力置换"。属权力结构推断。

## 三、废立现场：太后、霍光与刘贺（核心对话）

- 【史料原文/一手】《汉书·霍光传》《武五子传》载废立之时：霍光率群臣白太后，太后幸未央宫承明殿，诏禁门毋内昌邑群臣；刘贺入，左右执缚其从官。太后（上官太后，昭帝之后）面数其过，刘贺"（王）……"被促令伏前。史载其被数落"……（你）为人臣子，当伏……"之辞，刘贺无完整自辩之辞传世。
- 【史料原文/一手】同场，群臣奏"千一百二十七事"等于前，太后乃下诏"……其废勿事……"——废黜以"制诏 + 群臣连名奏"的形式完成，刘贺之"发言权"在《汉书》叙事中被压缩至近乎沉默。
- 【框架推断】废立现场的"失语"或为史臣剪裁，亦或为实情：刘贺骤遇权臣与太后联手，几乎无体制内还手之力。其"无自辩"恰成后世"罪名可能系构陷"之疑点之一。属叙述结构推断。

## 四、废后之对答：张敞察贺、宣帝之防

- 【史料原文/一手】《汉书·武五子传》载宣帝立后，疑忌废帝，遣张敞就国察之；张敞与之周旋，归奏"贺清狂不惠、废忘"，并云其尝自言"（我）……"（张敞转述其语，大意谓己已为废人、不复预事）。此对话为废帝与使者之间的一手（转述）记载。
- 【史料原文/一手】后宣帝复封贺为海昏侯（就国豫章），并"削其邑户"以防其复起；贺就国后"（与故人）……"之对答亦见史载片段。其废后处境之对话，整体呈"被观察、被防范"之基调。
- 【框架推断】张敞"清狂不惠"之评，可能为保全贺（示其不足忌）亦为坐实其不堪；贺是否真"狂"或系自污以全，史无明证，二者并列不调和。属动机推断。

## 五、临终与墓主确认（无对话传世）

- 【史料原文/一手】《汉书·武五子传》载刘贺"立二十七年，卒"（按：自废归昌邑至卒约十一年；"二十七年"为班固系其生于昌邑之年计），死后"无子"或子嗣旋绝，国除。其临终无对话传世，仅载卒与国除之事实。
- 【一手/考古】1980 年代与 2015 年两次发掘，墓出"刘贺"玉印，确认墓主即废帝刘贺——此属实物"署名"，非对话，却为全案身份之定论。

## 六、小结

- 一手（史料原文 / 原话 / 一手考古）：龚遂王吉之谏、入立途中的言动、废立现场太后数过与群臣奏、张敞察贺之奏，均出《汉书》；"刘贺"玉印属【一手/考古】。
- 框架推断：昌邑正臣与"昌邑群臣"之区分、废立"失语"之疑、张敞"清狂"之双重修辞——均逐条标注。
- 诚实保留：刘贺在废立现场几无完整自辩之辞传世，"其言"多为史臣叙事或转述；凡其内心对白均标"框架推断，非其本意"。
