# 05 决策 · 刘准

> 刘准的在位期具有丰富政治事件，但个人决策证据有限。本文件把“顺帝朝发生的决策”与“可归因于刘准本人”分开。

## 决策归因审计

### 1. 节俭、求贤等诏令

以顺帝名义发布，说明朝廷公共政策和合法性话语，但个人作者/主张不可确认。

**编码**：`court_policy = observed`；`personal_decision = unverified`。

### 2. 对沈攸之、袁粲等反萧力量的处置

顺帝在位时期发生大规模精英冲突，但叙事中心是萧道成集团的军事与政治行动。不能据此形成“刘准镇压反对派”的模型。

### 3. 萧道成权位逐级升级

从辅政到太尉、太傅、相国、齐公、齐王，最终受禅，构成一个清晰的 power-transfer pipeline。形式上的册命属于顺帝朝制度流程，但实际议程由萧道成集团控制。

### 4. 禅位

《宋书》《南史》都记录最终禅位；《南史》对武装压力和刘准不愿出宫的细节尤其明确。

因此：

- `formal_abdication = TRUE`
- `voluntary_abdication = FALSE/LOW_CONFIDENCE_AS_VOLUNTARY`
- `military_coercion = HIGH_EVIDENCE`

### 5. 退位时的即时反应

相比长期政策，退位时的躲避、惊怒、哭泣等更接近刘准本人可观察行为。但这只能支持“面对直接生存威胁时的即时反应”，不能外推成一般性决策风格。

## 可提炼的制度机制

1. **合法连续性壳层**：控制实际权力的一方可能暂时保留旧王朝君主，以降低权力切换成本。
2. **权位递进抽空**：实际掌权者可通过一系列正式授职逐步把名义君主的权力转化为自己的制度权力。
3. **受控禅让**：程序形式可以完整存在，但真实选择集已经被武力和议程控制压缩。
4. **退位后的残余合法性风险**：失去皇位不等于失去政治象征价值，因此被废君主可能继续受到严密监视甚至杀害。

## 不可提炼

- 刘准的财政理念；
- 刘准的军事战略；
- 刘准的用人哲学；
- 刘准对萧道成长期的真实判断；
- 刘准成年后的潜在治国能力。
