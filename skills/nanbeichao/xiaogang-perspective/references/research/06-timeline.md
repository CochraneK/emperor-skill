# 06 · 时间线底稿（萧纲，503–551：从天家文童到宫体诗祖与傀儡帝王）

> 调研目标：编年呈现萧纲由皇子至遇弑的关键节点，并标注每节点「对思维的影响」，供 SKILL.md「时间线」节直接复用。
> 史料门禁：一手取《梁书》卷四《简文帝纪》、《南史》卷八、《资治通鉴》梁纪；异说并列。时间用年号/公元并注。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 503（天监二年） | 生于建康，梁武帝萧衍第三子，母丁贵嫔 | 天家文人底色；「七岁有诗癖」之自觉早植，文心先于政心 |
| 506（天监五年） | 封晋安王 | 宗法顺位中居三，非嫡长，养成「被给定」之自我定位 |
| 523（普通四年） | 出为雍州刺史，镇襄阳 | 稍历外任，然重心仍在文事，权略、武备未深 |
| 531（中大通三年） | 昭明太子萧统薨，以第三子立为皇太子 | 「顺位被动」成型：储位非谋而得，文人入储贰 |
| 531–548（居储贰期） | 引徐摛、庾肩吾等东宫文学，宫体诗遂盛 | 「文章放荡」「立身谨重」二分法确立；文之自觉达极盛 |
| 548（太清二年） | 侯景渡江，围台城；简文以太子监国抚军 | 「文人临危」初显：措置循旧、少独断，短于权略 |
| 549（太清三年） | 台城陷、武帝崩；侯景拥立为帝，改元大宝 | 「傀儡帝王」之局定：名分在朕而政归侯景 |
| 549–550（大宝元年） | 欲亲政则「景辄抑塞」，唯以诗文自遣 | 「虚己待物」「诗以自伤」成主要生存方式 |
| 551（大宝二年） | 侯景废为晋安王，旋以土囊压杀之，年四十九 | 文人临危之局限尽显，以身殉其文；南梁旋亡 |

## 附：纪年异说与小注（并列不调）

- 生年：诸书同作天监二年（503），无异；《南史》同。
- 立储之议：以「废嫡（昭明之子）立庶（萧纲）」为非（礼法）vs 以「武帝家法、萧纲素受眷」为可（南朝惯例）；并存。
- 台城陷落月日：《梁书》《南史》《资治通鉴》纪年略同，惟细节（武帝崩之确切情形）叙述稍异，并存待考。
- 被弑细节：《南史》载「熟读《老子》、引被覆面、土囊压杀」，《梁书》略同而辞有详略，并存。
- 宫体诗盛期：以「居储贰（531–548）为鼎盛」为主流；亦有以为「出藩雍州（523 后）已开其端」，两说并存。
- 文集流传：今传《梁简文帝集》为后人辑本，篇目真伪间有异说，引用其诗文须据通行整理本，标【据史料推得】者不径作定本。
