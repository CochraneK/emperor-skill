# 06 · 时间线底稿（陈叔宝，553–604：从深宫太子到南朝末帝）

> 调研目标：编年呈现陈叔宝由太子至末帝、被俘至卒的关键节点，并标注每节点「对思维的影响」，供 SKILL.md「时间线」节直接复用。
> 史料门禁：一手取《陈书》卷六《后主纪》、《南史》卷一〇《陈本纪下》、《资治通鉴》陈纪/隋纪；异说并列。时间用年号/公元并注。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 553（梁承圣二年） | 生于江陵，宣帝陈顼（时质于西魏）长子，小字黄奴 | 生于乱离、幼离父，深宫养成，不知稼穑 |
| 566–568 前后 | 归建康，为宣帝（陈顼）所立为太子 | 居东宫，以文酒自好，与江总等游，奠定宴乐底色 |
| 582（太建十四年） | 正月宣帝崩，太子叔宝即位，大赦，次年改元至德 | 「委政有司、自耽宴乐」成执政基调；深宫天子不问政 |
| 583–586（至德） | 以江总为尚书令，狎客文酒日盛；疏沈皇后、宠张丽华 | 「近狎客、远直臣」心智固化；视政务为可委之闲事 |
| 584（至德二年） | 起临春、结绮、望仙三阁，极宫室之侈 | 「竭民力以自奉」的奢靡信条成型，以侈为常 |
| 587（祯明元年） | 改元祯明；后主置张贵妃于膝共决政务 | 内宠移权，张孔用事，政出多门之实态确立 |
| 588（祯明二年） | 隋以晋王广为元帅大举伐陈；群臣请备防，后主曰「王气在此」不为备 | 「王气天堑自欺」达于顶点，边警被化约为常事 |
| 589（祯明三年）正月 | 隋军渡江，建康陷；后主与张孔入景阳井被俘，陈亡 | 南朝终结，帝号亡于隋；「吾自有计」终成笑柄 |
| 589 后 | 被送长安，隋文帝封长城县公，给赐厚 | 由帝王降为降虏，自逸以待终，不图恢复 |
| 604（仁寿四年） | 卒于长安，年五十二，葬洛阳邙山 | 末帝终局，「逸豫亡身」成史鉴定评 |

## 附：纪年异说与小注（并列不调）

- 「王气在此」语系年：《南史》系于隋军将济江时；《资治通鉴》系于祯明二年隋已大举时，小异并存。
- 三阁起年：《陈书》《南史》并作至德二年（584），无异。
- 后主享年：《陈书》《南史》并作五十二（553–604），无异。
- 被俘细节：「与张孔俱入井」《陈书》《南史》《资治通鉴》并载；井称「景阳井/胭脂井」，地望在台城，实物故址尚存。
- 修史加工提示：《陈书》（唐姚思廉）、《南史》（唐李延寿）本纪已含隋唐史臣褒贬，凡论赞均标【史论/二手】，凡原言标【原话/一手】。
