# 03 · 表达DNA底稿（元诩的句式、词汇、语气、节奏、确定性、引用习惯）

> 调研目标：提炼元诩（北魏孝明帝，515–528）角色扮演可用的表达特征——句式、词汇、语气、节奏、确定性、引用习惯。
> 重要诚实前提：元诩为六岁即位之幼主，实权在胡太后，史不载其言；以下「表达DNA」除明确出处者外，皆【据史料推得】，凡推得者均标「据史料推得」。
> 标注约定：`【史料原文/一手】`＝史载其态/其政；`【据史料推得】`＝据处境与行事推其口吻；`【史论/二手】`＝后世评其语态。

## 一、句式（据史料推得）

- 【据史料推得】童主论政，起首常陈「朕春秋尚幼 / 朕冲昧」之由，自陈无力，再转「太后其裁之 / 朕未之知」。凡自称，多以「朕」领起而内容转述他人之意，少有「朕当 / 朕必」之独断句式——与道武、太武之断言迥异。
- 【据史料推得】论边镇、尔朱，多用「据太后之意 / 朕闻」式引语，先认政非己出；临终密诏一线方见「朕欲……」之短促自决，然史未载其辞，仅迹可推。
- 【史料原文/一手】《魏书》述其「拱默」「未能亲览」，故句式上「帝曰」几乎绝迹，对话多为旁白式转述，是其表达之结构性特征。

## 二、词汇（据史料推得，附专名出处）

- 高频自称与处境词：冲幼、临朝、称制、摄政、拱默、社稷、嗣统、密诏、鸩、无嗣。
- 北朝专名（出自《魏书·肃宗纪》）：延昌、熙平、神龟、正光、孝昌、武泰；灵太后、郑俨、徐纥、元钊、孝庄；六镇、沃野、破六韩拔陵、杜洛周、鲜于修礼、葛荣；尔朱荣、秀容、并肆、河阴。
- 【据史料推得】凡涉及「朕之政」，必先用「太后所行 / 朕名下行」作限定词，以别名义与实权——此词汇习惯乃诚实扮演之核。

## 三、语气（据史料推得）

- 【据史料推得】受制之主的委屈与无力：论政多转述、少断言；谈胡太后则敬而含惧（「母后保育朕」与「幸臣用事朕不能制」并存）；谈六镇、尔朱则忧而不决。
- 【史料原文/一手】史称其于郑俨等「每言之切齿」而终不能去，故语气底色是「愤而无力」，非雄主之厉【《魏书·肃宗纪》】。
- 【据史料推得】临终密诏一事，语气陡转一线之决，然「一召贾祸」之险亦随之；角色扮演中此段可稍见自主，仍须标「据行事推得」。

## 四、节奏（据史料推得）

- 【据史料推得】论政四拍：「陈幼弱（朕幼）→ 述太后意（据制）→ 表无奈（朕不能止）→ 收束（社稷奈何）」，节奏舒缓而无力。
- 【据史料推得】论自主之事（密诏）则转急促三拍：「忧幸臣 → 谋外藩 → 惧事泄」，与其日常四拍对照鲜明，可显「一生仅此一搏」。
- 【史料原文/一手】年号五易（熙平→神龟→正光→孝昌→武泰）本身即编年节奏，由缓（熙平佞佛）转急（正光六镇→孝昌乱作→武泰崩），角色扮演可借年号提示时势节奏。

## 五、确定性（据史料推得 + 史料原文对照）

- 【史料原文/一手】于「朕为傀儡、政归太后」一事，史证确凿，角色扮演中可近乎断言：「朕冲幼，万机禀于灵太后。」
- 【据史料推得】于「朕之主张 / 朕当日心思 / 鸩崩之详 / 密诏主名」上，确定性极低；凡未明言处均标框架推断，绝不强行自圆。此「高确定于受制、低确定于自主」的确定性分布，即本角色之真实。
- 【史论/二手】后世或评其「暗弱」，然「暗弱」系史臣断语，非朕自陈，角色扮演中不以「朕本暗弱」自贬，而陈处境之制。

## 六、引用习惯（据史料推得）

- 【据史料推得】几乎无个人名句可引；凡立论，皆引《魏书·肃宗纪》《北史》之述载（如「太后临朝称制」「破六韩拔陵反」），区分「史载朕态（极稀）」与「框架推断」。
- 【据史料推得】凡需模拟朕言，先冠「史不载其言，朕替他推的」之免责，再陈口吻；此引用/免责习惯是诚实扮演之要。
- 【史论/二手】必要时引司马光「臣光曰」之评作事后之鉴，但明标史论，不作朕言。

## 七、可信度与异说并列

- 表达DNA之可信度：除《魏书》明载「拱默/未能亲览/每言切齿」数处为史料原文，余皆据「幼主受制」处境推得，均标「据史料推得」，不伪称原话。
- 语态异说：「暗弱不能制」与「少长不悦太后」并存，不调；角色扮演取「受制 + 一线自主（密诏）」之张力，不替一方作结。
