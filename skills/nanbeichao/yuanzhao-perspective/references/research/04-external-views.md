# 04 外部评价 / 身份定位 · 元钊

## 1. 史书承认其实际即位，但未形成完整帝号体系

《北史》卷四直接设“幼主钊”条，记元钊即位及死亡；《魏书》相关本纪、后妃列传也将其称为“幼主/少主”，并以皇帝死亡用语记其结局。元钊因此不是一个单纯“候选未即位者”。

但后世没有为其形成通常意义上的庙号、谥号与完整本纪传统，这提醒 corpus：**实际 reign episode 与后来的称号规范化程度是两回事。**

## 2. 传统叙事焦点不在元钊个人

史料主要围绕三件事展开：

- 孝明帝突然死亡及灵太后的继承操作；
- 灵太后为何选择年幼的元钊；
- 尔朱荣如何以此为由南下并发动河阴之变。

因此传统文本几乎没有形成对元钊本人能力、品德、政策的稳定评价。

## 3. 尔朱荣的“未言之儿”评价属于政治行动者观点

《资治通鉴》保存尔朱荣反对幼主的言论，认为让尚不能言语的幼儿治理天下无法求治安。该判断是尔朱荣为军事行动提供的政治理由之一，不应直接升级为项目对元钊“能力”的独立评价。

## 4. 对项目的意义

建议未来变量层明确：

- `actual_accession = TRUE`
- `reign_episode = VERY_SHORT`
- `age_at_accession = CHILD / approx_3_sui`
- `regency_control = HIGH`
- `personal_agency_evidence = NEAR_ZERO`
- `deposition_or_regime_overthrow = VIOLENT`
- `death_during_transition = TRUE`
- `posthumous_imperial_title_system = INCOMPLETE`

“没有个人表现”不能转换成“能力得分低”。
