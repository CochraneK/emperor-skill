# 06 · 时间线底稿（萧鸾生平与执政大事，及对思维的影响）

> 调研目标：以表格梳理萧鸾（南齐明帝，452–498）从宗室辅政到屠戮称帝、再到崩殂的关键节点，并标注每事「对思维的影响」，作为 SKILL.md「时间线」章的一手事料。一手取《南齐书·明帝纪》《南史·齐本纪下》《资治通鉴·齐纪》；推得标【框架推断】；史论标【史论/二手】。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 452（宋文帝元嘉末） | 萧鸾生，字景栖，小名玄度；父始安贞王萧道生（高帝萧道成之兄）早卒，由高帝抚育，爱过诸子 | 旁支养子之身份，使其自幼知「名分可借、血胤非唯一」；既蒙抚育之恩，又始终为「非嫡」之人，埋下「名分焦虑」 |
| 479（建元元年） | 高帝建齐，封萧鸾为西昌侯 | 以宗室长辈居爵，然非帝系直系，深知「爵位出于推恩，非出于继统」 |
| 482（建元四年） | 高帝崩，武帝萧赜立；萧鸾历官至侍中、尚书左仆射等 | 历事两朝，熟睹中枢权力运作，养成「居密勿、掌机要」之执政习惯 |
| 493（永明十一年） | 武帝崩，郁林王萧昭业（武帝孙）立，萧鸾受遗辅政 | 由「宗室重臣」转「摄政」，第一次掌握废立之机，心智模型「辅政—夺权」路径确立 |
| 494 七月（隆昌元年） | 与萧谌、萧坦之、王晏定谋，弑郁林王，迎海陵王萧昭文 | 「以辅政之名行废立」首次实操成功，确证「名分可借刀而成」 |
| 494 十月（建武元年） | 废海陵王、弑之，即帝位，改元建武；追尊父萧道生为景皇帝 | 非嫡而入继，故急追尊本生以补宗法；「名分先于实力」心智固化 |
| 494 十一月 | 诛鄱阳王萧锵、随郡王萧子隆，遣诛安陆王萧子敬；晋安王萧子懋反，败诛 | 屠戮宗室启动，「按威胁度排序清除」算法成型；疑忌由潜而显 |
| 495（建武二年） | 北魏孝文帝南侵，陷司豫徐梁诸州；四月诛萧谌及西阳王子明等三王，六月诛王晏 | 外患与内诛并行，「内狠外怯、重心偏内」决策结构确立；首功功臣亦不免 |
| 497–498（建武四年至永泰元年） | 北魏再南侵，陷新野、北襄阳，沔北五郡失；裴叔业、崔慧景赴援无功 | 北顾无力，转益疑内；「守境待敝」成对外定式 |
| 498 正月（永泰元年） | 大司马王敬则于会稽举兵反，遣将讨斩之 | 连宗室旧将亦反，印证其「人人可为威胁」之预设，疑忌循环自我证实 |
| 498 七月（永泰元年） | 萧鸾疾甚，崩于正福殿，年四十七；遗诏太子宝卷（东昏侯）即位，托孤徐孝嗣、沈文季、江祏 | 顾命托旧臣，与其「功臣不可信」之心法自相矛盾；所托旋为东昏诛，齐祚速危 |
| 498 后 | 东昏侯萧宝卷昏暴，江祏等被诛，南齐陷入混乱，数年后为萧衍（梁）所代 | 屠戮自翦本支、失藩屏，客观上速齐之亡——王夫之「自翦其本支，而齐祚遂促」之评【史论/二手】 |

## 备注

- 年号对照：郁林王在位称「隆昌」（494），萧鸾即位改「建武」（494–497），末年改「永泰」（498）。
- 【框架推断】其思维演进主轴：「名分焦虑（旁支养子）→ 摄政得机（辅政）→ 借刀废立（494）→ 按威胁排序屠戮（494 起）→ 疑忌循环自我证实（至崩）」。每一节点都强化下一节点的确定性。
- 异说并列：屠戮动机有「防弊」与「猜忍」两说；本纪（萧子显修）于屠戮多曲笔，凡褒贬标【史论/二手】，不混作其自白。
- 名言核查：萧鸾无确凿留世名言；凡查不到出处者，宁书「史不载其言」。
