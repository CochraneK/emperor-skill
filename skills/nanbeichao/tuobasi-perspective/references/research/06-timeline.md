# 06 · 时间线底稿（拓跋嗣即位到崩的编年）

> 调研目标：以编年表呈现拓跋嗣（北魏明元帝，392–423）从生到崩的关键节点，并标注每一节点对其执政心智的影响，作为下游 SKILL「时间线」节的一手底稿。
> 史料门禁：一手取《魏书·太宗纪》《北史·魏本纪》《资治通鉴》晋纪/宋纪；二手仅胡注与现代史论。标注约定同前。

## 一、编年总表（时间 | 事件 | 对思维的影响）

| 时间 | 事件 | 对思维的影响 |
|---|---|---|
| 392（登国七年） | 拓跋嗣生，道武帝长子，母刘贵人 | 生于开国草创之世，自幼见刑政之严 |
| 403（天兴六年） | 封齐王 | 早列藩位，习国事 |
| 409春（天赐六年） | 立为皇嗣；母刘贵人赐死（子贵母死）；悲泣获咎，出奔 | 亲历「防外家」之制与「孝而见逐」，立守成、忍辱、不骤动之心 |
| 409秋（永兴元年） | 清河王绍弑道武；嗣归平城诛绍即位，大赦改元，蠲调恤孤 | 定乱以「安社稷、收民心」为纲，守成基调成型 |
| 409–413（永兴间） | 承道武旧法，未大更张；巡省风俗、察举不法 | 固「不紊旧章」之念 |
| 413（永兴五年） | 诏郡国举才、以经术进用 | 文治落到制度，与「礼儒生」习性相表里 |
| 414（神瑞元年） | 大饥；开仓赈乏、躬行俭约、听民出关就食 | 固「与民休息、灾异修省不兴作」之念 |
| 415（神瑞二年） | 太史请迁都邺；帝问崔浩「二者孰急」，罢迁都 | 成「以静制动、先议后断」决策风格；倚重崔浩之始 |
| 416–421（泰常元—六） | 建制沿旧；礼儒生、好览史传；与宋通好 | 守成与文治并行，对外持静 |
| 422（泰常七年） | 宋武帝崩、少帝立；下诏数宋，命奚斤等南征，取滑台、虎牢、洛阳；立焘为太子（杜氏赐死） | 验「乘衅取地」之略，拓境河南；继统与防衅并重 |
| 423（泰常八年） | 寇谦之献道书，稍信之；疾，托孤崔浩、长孙嵩、奚斤；崩，焘立（太武） | 文治崇道收尾，守成之局既定；托孤为「倚重谋臣」终章 |

## 二、节点详释（一手叙事）

- 【史料原文/一手】409 立嗣母死、出奔、归诛绍即位：此年三变（失母—出奔—即位），是明元心智塑形的枢纽，《太宗纪》叙之甚详【《魏书》】。
- 【史料原文/一手】414–415 饥与迁都之议：神瑞连岁旱饥，帝以「赈＋俭」应之，并以一问罢迁都，是其「静」的最完整标本【《魏书》《资治通鉴》】。
- 【史料原文/一手】422 南征：乘宋丧取河南，连下三城，是守成之君少有的主动扩张，亦见「乘衅」一面【《魏书·太宗纪》】。
- 【史料原文/一手】423 托孤崩：以太子属老臣，北魏由守成转入太武之雄略【《魏书》《崔浩传》】。

## 三、心智演化的时间线索（框架推断）

- 早期（409 前）：「孝而见逐」→ 忍、不骤动。
- 中期（409–415）：定乱守成 → 「承旧章、恤兆民、问谋臣」。
- 晚期（422–423）：乘衅南征＋立嗣防衅＋崇道托孤 → 「守中有动、文治收官」。
- 据史料推得：其心智非静态「纯守成」，而是「静为主、乘机为用」的复合体；此推得，非其自言。

## 四、纪年异说并列

- 生年：《魏书》《北史》皆作登国七年（392），无异。
- 在位止年：423 崩，两书同；泰常八年即 423，无误。
- 南征年份：《魏书》系泰常七年（422），《资治通鉴》宋纪同；并列不调和他说。

## 五、可信度总则

- 全表事件皆一手（本纪/编年），演化线索标【框架推断】，异说标并列。
- 凡史不载其言处，宁书「史不载其言」而不补。
