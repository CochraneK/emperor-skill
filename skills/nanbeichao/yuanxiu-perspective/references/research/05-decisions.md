# 05 决策 · 元脩

## 1. 接受高欢拥立，但保持政治警觉

元脩被斛斯椿找到时先问“非卖我耶？”，显示他知道拥立不是单纯荣耀，也可能意味着被更强行动者利用。最终接受皇位，但史料没有把这一选择描述成毫无保留的依附。

## 2. 减征与亲理冤狱

即位初年，孝武朝调整租调，并多次记元脩亲自纳讼、理冤狱。与一般制度文书相比，亲临司法活动是较强的个人行动证据。

可安全编码：
- `tax_relief_policy = OBSERVED_AT_COURT_LEVEL`
- `personal_judicial_involvement = OBSERVED`

## 3. 主动准备摆脱高欢

永熙三年，元脩“内图高欢”，重用斛斯椿、王思政，增设军队、分置督将，并用“伐梁”公开叙事掩护实际北讨目标。

这是元脩最重要的个人决策：他愿意把名义皇权与高欢既有军事实力之间的矛盾推到公开军事冲突。

## 4. 亲总六军并西走

元脩亲率六军十余万至河桥，但部众在局势恶化时大量离散。他随后率核心人员西走关中，接受宇文泰接应。

这说明元脩有主动军事行动意愿，但**意愿与组织控制能力必须分开**：亲征和军队名义规模并不等于可靠控制链。

## 5. 西迁后的有限自主

进入长安后，元脩仍为皇帝，但宇文泰成为关键军事支柱。宇文泰杀元明月引发元脩强烈不满，君臣关系恶化，最终元脩遇鸩而死。

这形成连续结构：从高欢到宇文泰，元脩不断试图避免皇帝彻底沦为军事强人的合法性工具，但始终缺乏足以独立维持政权的强制资源。

## 可提炼的机制

1. **被拥立不等于长期服从**：代理人选择的领导者可能在获得名义权力后反向追求实权。
2. **名义主权需要强制能力支撑**：没有稳定军权，皇帝名号难以转化为独立控制。
3. **公开动员目标可以服务秘密战略**：元脩以伐梁为表面目标，实际准备北讨高欢。
4. **撤退可以保存合法性但转移依赖对象**：西迁摆脱高欢，却进入对宇文泰的新依赖。
5. **象征权威与资源控制长期错位会产生高冲突**。

## 不宜过度推断

- 减税诏不能单独证明元脩有完整经济学思想；
- “好武事”不能证明军事才能高；
- 西奔不能简单编码为怯懦或战略英明；
- 与高欢、宇文泰冲突不应被心理化成单一“多疑”或“权力欲”。
