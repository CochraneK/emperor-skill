# 04 外部评价 / 身份定位 · 元廓

元廓为西魏文帝第四子，早封齐王。元钦被废后由宇文泰集团立为帝。

在其名义统治下，西魏推行周礼六官等重要制度重构；宇文泰死后不久，元廓逊位宇文觉，西魏终结。

## 数据建议

- `installed_after_deposition = TRUE`
- `effective_power_holder = 宇文泰/宇文氏集团`
- `major_institutional_reform_during_reign = TRUE`
- `personal_authorship_confidence = LOW`
- `abdicated_to_successor_dynasty = TRUE`
