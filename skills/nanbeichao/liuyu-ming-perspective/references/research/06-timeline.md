# 06 · 时间线（宋明帝泰始朝大事与思维演变）

> 调研目标：以编年梳理刘彧自被囚、夺位到崩、权落萧道成的关键节点，及对其思维/决策风格之影响。据《宋书·明帝纪》《南史·宋本纪下》《资治通鉴》卷一三〇—一三三。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 439（元嘉十六年） | 生于建康，宋文帝刘义隆第十一子，母沈婕妤 | 宗室幼子、非嫡非长，养成「隐忍自晦」底色 |
| 452（元嘉廿九年） | 封淮阳王，后改湘东王 | 闲王无兵权，养成「借幸臣、待时」之习性 |
| 464–465（景和） | 孝武帝崩，侄刘子业（前废帝）立；彧被囚辱，号「猪王」 | 识「乱世宗室朝不保夕」，立「忍垢待时、一击夺位」之心 |
| 465十一月 | 与阮佃夫、寿寂之弑废帝于华林园，即帝位，改元泰始 | 「以密谋与幸臣夺位」之执政范式开端 |
| 466正月起 | 晋安王刘子勋被拥于寻阳（义嘉），四方叛；遣刘休仁等讨平，八月杀子勋 | 「内平宗乱」之自信，亦启「胜而益疑」 |
| 466–469 | 平叛后大诛孝武诸子（子绥、子顼、子房等）及文帝诸子（休仁、休祐等） | 「宗室即隐患」之偏执固化，自翦屏藩 |
| 466–468 | 泰始中被魏击败，失徐、兖、青、冀等州，淮北陷魏 | 「外失疆宇」之挫，南朝由攻转守 |
| 467前后 | 疑功臣，赐死吴喜、寿寂之；倚阮佃夫等恩幸，行「中旨」 | 「不信宗室高门、专任私人」之集权偏路 |
| 泰始六年（470） | 立总明观，征学士，分玄儒文史；自著经义 | 「以文治饰乱后」之取向，重文轻武 |
| 471（泰始七年） | 晚年尤信鬼神、多忌讳，左右离心 | 迷信与猜忌互为表里，决策益偏 |
| 472四月（泰豫元年） | 崩，年三十四；遗诏袁粲、褚渊、刘勔顾命，萧道成典禁兵 | 顾命委武将，埋篡逆之种 |
| 472后 | 子刘昱（苍梧王）立，道成渐专权；479篡宋建齐 | 明帝「屠宗室、任恩幸」之局，终资萧道成 |

## 附：思维演变的主线

刘彧之执政逻辑，可沿一条由「隐忍」到「猜忌」再到「自失其柄」的线索理解：被囚辱时养成「忍垢待时、借私人夺位」之底色；夺位后为固权而大屠宗室，由「除患」渐成「猜忌成性」；不信高门转任恩幸，皇权看似直达，实则权移武将；晚年信鬼神、多忌讳，决策益偏，外失淮北、内无屏藩，终以顾命委萧道成，自启篡逆。此线并非直线下滑，其间有平义嘉之武功、立总明观之文治，然屠戮与失地之积弊，非一时武功文教所能补——史论「宋自此衰」，实肇于泰始。

> 注：编年据《宋书·明帝纪》《南史·宋本纪下》《资治通鉴》互校；年号泰始（465–471）、泰豫（472）依本纪。个别月日与通鉴异说未逐字核毕，标为待核。
