# 06 · 时间线底稿（陈蒨 · 520–566）

> 调研目标：以表格梳理陈蒨生平大事与其执政思维之形成线索，供 SKILL.md「时间线」章直接取用。
> 史料门禁：一手取《陈书·世祖纪》《南史·陈本纪》《资治通鉴》陈纪；评断/推得标【史论/二手】/【框架推断】。
> 标注约定同 01。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 520 | 生于吴兴长城，陈道谭之子、陈霸先之侄（史称临川王） | 宗室出身而非嫡子，养成「知分寸、待时」之底色 |
| 侯景乱中（548–552） | 转侧兵间，备尝丧乱流离 | 【框架推断】早识「民困于乱」，为日后「与民休息」埋因 |
| 557 | 陈霸先代梁建陈（武帝），陈蒨参预藩屏之事 | 亲见「开国须靖内、宗室须倚」之局 |
| 559 | 武帝崩，陈蒨即位，改元天嘉 | 「守成绥靖」主线确立；首务在定江表 |
| 560 | 王琳东下，遣侯瑱等拒于芜湖，琳败奔齐，江表悉定 | 「乘未集而破、逆众疑而断」成用兵心法 |
| 561 | 讨东阳留异，安都破之，异奔晋安 | 「守成必靖内、豪强遏命则讨」益坚 |
| 562–563 | 讨临川周迪、闽中陈宝应，先后平之 | 「用兵靖内、不以恩纵」之践 |
| 563 | 侯安都骄横，赐死之，诏列其罪 | 「用其能而防其志、制其名收其实」之断 |
| 561–565 | 屡下劝农、薄赋、赈恤、安辑流亡之诏 | 「民安则国实」休养闭环成型，天嘉之治具象化 |
| 天嘉中（560–566） | 留心刑狱、春夏停决重囚、多所原宥 | 「宽仁听讼、求其真」之执政口吻 |
| 天嘉中 | 常所调敛务从俭约、不饰宫室、后宫无金翠 | 「以俭立国」自宫廷始，与遗诏呼应 |
| 566 | 崩，遗诏「丧事所须，务从俭约」，托孤于到仲举、刘师知、安成王顼 | 以「俭约、分权顾命」收官，留「宗室与近臣相争」之后效 |
| 身后 | 太子伯宗立（废帝），后安成王顼篡位（宣帝） | 【史论/二手】顾命分权之效未竟，验其「制其名」之难 |

> 说明：陈蒨生年《陈书》《南史》系于「梁天监中」，约 520；在位 559–566（天嘉 560–566、天康 566）。上表「对思维的影响」多属【框架推断】，以史实为锚、不臆造心迹。
