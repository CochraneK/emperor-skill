# 05 决策 · 元朗

> 元朗不是无行为记录的幼主，但现有史料仍不足以把中兴朝主要军政行动安全归于其个人。因此采用“个人能动性有限 + 制度角色可观察”的蒸馏方式。

## 1. 接受高欢集团奉立

元朗从渤海太守被奉为皇帝，在信都即位。是否由本人主动谋求、是否有谈判条件，史料不足。

可安全记录：`accepted_accession = OBSERVED`；`personal_accession_strategy = UNKNOWN`。

## 2. 以皇帝名义授予高欢最高军政权

即位后高欢成为丞相、都督中外诸军事等。制度上这是皇帝朝廷的任命，实质上高欢本就是拥立者和军权持有者。

可安全提炼的是：**形式授权往往把既有事实控制转化为正式制度权力。**

## 3. 逊位

高欢战胜尔朱氏后重新评估皇位人选。《北史》记元朗于河阳逊位；另有“自以疏远，请逊大位”的叙述，但该情境下高欢掌握决定性力量，因此不能把它简化为完全自主退位。

## 4. 退位后政治存续失败

元朗先被封安定郡王，后被孝武帝政权杀害。退出最高职位并未消除其曾称帝形成的潜在合法性风险。

## 可提炼的制度机制

1. **皇号作为指挥接口**：联盟需要一个被承认的最高号令来源以维持组织一致。
2. **事实权力制度化**：拥立者通过皇帝名义把既有军事控制写入正式官职。
3. **合法性载体可替换**：当政治阶段变化，原先够用的候选人可能因宗支、声望等条件被更换。
4. **退出职位不等于退出政治风险**：曾经称帝的身份具有持续的象征价值。

## 不可安全编码

- 元朗的长期财政/军事理念；
- 元朗是否赞成高欢全部政策；
- 元朗真实逊位意愿的强度；
- 元朗个人对尔朱氏的战略判断。
