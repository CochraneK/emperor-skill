# 06 · 时间线（刘劭从立储到伏诛 · 思维演变）

> 调研目标：以编年梳理刘劭自为太子至太初败亡的关键节点，及其对思维/决策风格的影响。时间与事件据《宋书·二凶传》《南史》《资治通鉴》互校；其原话散佚、译文未逐字核对，凡推得均标出。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 元嘉六年（429） | 立为皇太子，文帝长子，正嫡之位早定 | 「嫡长当继」之自负，埋下「废我即乱」的执念 |
| 元嘉中 | 与弟濬信女巫严道育，行巫蛊厌魅文帝 | 以邪术图位，思维渐离正道，信方士而疑亲父 |
| 元嘉末 | 巫蛊事渐露，文帝怒责劭、濬，欲废太子 | 「父已疑我」之危机感，逼出先发制人之念 |
| 元嘉三十年春（453.2前） | 文帝与徐湛之、江湛夜谋废立（立宏/褘） | 废立之谋坐实其「不得不为」的被害叙事 |
| 元嘉三十年二月（453.2） | 夜率张超之入宫，弑文帝于合殿，杀潘妃、徐湛之、江湛 | 一念决天下，以弑立威；伦常之裂不可逆 |
| 同月 | 诈为遗诏，即帝位，大赦，改元太初，立濬录尚书事 | 名分系于伪诏，思维转入「以诈固位」模式 |
| 太初元年（453） | 袁淑谏死、王僧绰见杀，拒谏诛异己 | 杀止谏，决策回路闭锁，无人敢争 |
| 太初元年（453） | 武陵王骏起兵江州，移檄讨凶；四方多响应 | 「逆藩」之斥不敌「讨凶」之大义，虚怯渐显 |
| 太初元年四—五月（453） | 分兵守台城六门、凿堑拒新亭、石头 | 守而不攻、内顾宫城，暴露无四方之略 |
| 太初元年五月（453.5） | 孝武帝军克建康，劭逃武库井被引出斩，濬及诸子皆死 | 数月而亡，思维定格于「速得速失」之鉴 |

## 附：前期生平与身后定谳（补编年之未竟）

- **出生与早年（约元嘉初，426 前后）**：劭为文帝长子，生于建康东宫。其生母袁皇后以怨愤卒，劭由文帝亲鞠，少即立为太子，养尊处优而性渐急戾【一手：《宋书·后妃传》《二凶传》】。
- **东宫蓄势**：为太子数十年，统领东宫甲士、亲近武人，与弟濬交密，渐成「东宫—始兴王」一体之势，为后来一夜发难蓄力【一手：《宋书·二凶传》】。
- **巫蛊之链成形**：经东阳公主婢王鹦鹉、女巫严道育往来传书，厌魅之谋自元嘉中延至末年，终致文帝欲废【一手：《宋书》】。
- **身后之判**：孝武帝刘骏即位（孝建元年，454）后，追贬劭、濬为「元凶」，臧其族、毁其记载，南朝正史不复以庙号谥号予之；「元凶劭」遂成弑父篡位之定名【一手：《宋书·二凶传》《南史》《资治通鉴》】。
- **史系占位**：编年上，《资治通鉴》于元嘉三十年二月至五月间仍系劭事于宋纪，等于在纪年轴上保留其「数月之君」之实，却于正统不予承认——此即「实存而名黜」之典型【一手：《资治通鉴》卷一二七】。

> 注：纪年以《宋书·二凶传》《资治通鉴》宋纪为本；太初元年号在正统史系中仅数月，孝武帝即位后追贬劭为「元凶」，不承认其庙号谥号。其原话、诏文多散佚，转引译文亦未逐字核对；凡推得之心路均已标注。
