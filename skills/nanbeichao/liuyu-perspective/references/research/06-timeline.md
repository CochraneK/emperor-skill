# 06 · 时间线底稿（刘裕，363–422：从北府行伍到宋武开国）

> 调研目标：编年呈现刘裕由布衣至开国帝的关键节点，并标注每节点「对思维的影响」，供 SKILL.md「时间线」节直接复用。
> 史料门禁：一手取《宋书》卷一–二《武帝纪》、《南史》卷一、《资治通鉴》晋纪/宋纪；异说并列。时间用年号/公元并注。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 363（晋兴宁元年） | 生于京口（彭城刘氏南渡支，自云楚元王刘交后），家贫，贩履为业，性尚侠 | 寒微底色：「朕本行伍，知民间疾苦」之自期；不附士族清谈 |
| 399–402 | 孙恩卢循之乱，刘裕以一队将校起，转战有功，崭露头角 | 认「乱世以军功定身」；北府兵集团初成其基 |
| 404（元兴三年） | 京口起兵讨桓玄，复晋室，旬月入建康 | 「正名讨逆」范式确立；识「中枢不可假人」 |
| 405–407 | 入朝辅政，抑桓氏余党，威望日隆 | 由将而相，思「以相权揽全局」 |
| 409–410（义熙五–六年） | 北伐灭南燕，俘慕容超献建康 | 「料敌于未战、逆众议而断」成其心法；功业跃升 |
| 410–411 | 回师破卢循，保建康 | 定「集中兵力、后发制人」战术信条 |
| 412（义熙八年） | 袭杀荆州刘毅 | 「共起之恩不敌国法之公」；同志亦可为敌 |
| 413（义熙九年） | 义熙土断、并省侨州；诱诛诸葛长民 | 「以法裁权贵、强干弱枝」；触士族而益坚其志 |
| 415（义熙十一年） | 讨平司马休之，内无可抗者 | 代晋之内碍尽除，篡志渐明 |
| 416–417（义熙十二–十三年） | 北伐后秦，克洛阳、长安，俘姚泓；却月阵破北魏 | 功业顶峰，「恢复中原」成其最大遗产；然急于南归 |
| 417 | 南归建康，留子义真守长安；后长安失于赫连勃勃 | 「代晋优先于守土」之抉择；遗「得地复失」之憾 |
| 418（义熙十四年） | 受宋公、宋王爵，备九锡 | 「禅让剧本」铺陈；「三让而后受」礼数成型 |
| 420（永初元年） | 代晋称帝，国号宋，改元永初，封晋恭帝为零陵王 | 「寒人代晋、天命攸归」叙事完成；南北朝之南朝始 |
| 421（永初二年） | 弑零陵王，诛司马氏宗室殆尽；下节俭、建制诸诏 | 「忍虐」之名著；立「母后不临朝、异姓不王」之约 |
| 422（永初三年） | 崩于西殿，年六十，庙号高祖，谥武皇帝；顾命徐傅谢檀 | 以「人和为社稷本」收官，而「用人之疑」遗患宋初 |

## 附：纪年异说与小注（并列不调）

- 生年：诸书同作 363，无异。
- 南归动机：一说「急于代晋」（司马光），一说「朝中刘穆之死、恐内变」（部分注疏）；并存。
- 屠戮程度：司马氏之诛《宋书》《南史》俱载，程度或有夸大，然「尽除宗室」为共识。
- 庙号谥号：史称「高祖武皇帝」，生前为帝，非追尊，故身份卡不须标「追尊」字样。
