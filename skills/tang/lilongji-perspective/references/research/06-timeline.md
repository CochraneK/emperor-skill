# 06 · 时间线（关键节点与思维影响）

> 调研目标：按年代梳理玄宗生平关键节点，标注事件与对其执政心态之影响。事实出处见各条。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 685 | 垂拱元年生，睿宗第三子 | 生于武周倾覆之世，自幼知宫廷血火 |
| 710 | 临淄王起兵诛韦后，拥父睿宗复位 | 初尝「先发制人」之效，立夺宫自信 |
| 712 | 受禅即位，是为玄宗 | 由定乱亲王转为守成之君 |
| 713 | 先天政变，诛太平公主及其党 | "不制于人"成执政首义，权柄尽收 |
| 713–720s | 用姚崇、宋璟，开元之治成 | "得相则治"成范式，励精图治 |
| 733–736 | 张九龄为相，后罢，李林甫入 | 择相始失，渐委政而逸乐生 |
| 742 | 改元天宝，宠杨贵妃 | 由治转逸，私爱渐凌公义 |
| 744–755 | 安禄山兼范阳平卢河东三镇，宠信日深 | "外重内轻"之局成，未能觉 |
| 755 | 安史乱起，禄山反于范阳 | 承平弛备之报，仓皇失措 |
| 756 | 马嵬兵变，缢贵妃、杀国忠；西幸蜀，太子灵武即位 | 父子相疑，退为太上皇 |
| 757 | 两京收复，还京居兴庆宫 | 形同闲置，追忆开元 |
| 762 | 宝应元年崩，肃宗先一日崩 | 以"由盛转衰之君"载入史 |

## 来源与可信度

- 一手：《旧唐书·玄宗本纪》（卷八—九）、《睿宗本纪》、诸臣传、《新唐书》本纪、《资治通鉴》唐纪
- 一手：杜佑《通典》兵制食货、王溥《唐会要》文治事
- 二手：网络与讲史类对年代、世系之简表（需以正史校核，《旧唐书》成于后晋、文气驳杂，纪年或有舛）
