# 06 · 时间线（武则天）

> 调研目标：按时间梳理武则天一生关键节点，标注"对思维的影响"。据《旧唐书》《新唐书》本纪及《资治通鉴》唐纪。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 624 | 生于并州文水，父武士彟 | 非关陇旧族之家，养成"非门第亦可为"底气 |
| 638 | 入宫为太宗才人，赐号武媚 | 初窥宫廷权力之残酷，习得自全之智 |
| 649 | 太宗崩，为尼感业寺 | 跌至谷底，深谙失势者之忍 |
| 655 | 高宗立为皇后，逐褚遂良、贬长孙无忌 | 首度以"废立"证明女主亦可操权 |
| 660s | 高宗风疾，委政于后 | "二圣"之局渐成，执政自信日增 |
| 674 | 上元元年，与高宗并称"二圣"，号天后；上建言十二事 | "渐进夺权"范式确立 |
| 683 | 高宗崩，废中宗、立睿宗而称制 | 临朝称制，权力在握 |
| 688 | 垂拱四年，洛水瑞石、《大云经》符命，诛李唐宗室 | "符命建国""酷吏罗织"成型 |
| 690 | 天授元年，革唐命，称圣神皇帝，国号周 | 女主称帝成事实，酷吏政治鼎盛 |
| 692–697 | 用狄仁杰、姚崇；科举大兴、殿试武举立 | "科举破阀"与"酷吏镇国"并用 |
| 697 | 诛来俊臣，酷吏之网稍弛 | 政权已固，转以循吏治天下 |
| 698–701 | 从狄仁杰言，迎庐陵王立为嗣 | "归葬去帝"之念萌 |
| 705 | 神龙政变，中宗复位；崩，遗制去帝号 | 还政李唐，立无字碑任评 |

> 注：武周纪年与唐纪互校，《旧唐书》讳饰处已参《新唐书》《资治通鉴》；个别月份细节存异说。
