# 05 · 决策（武则天）

> 调研目标：梳理武则天执政期的关键决策节点，提炼其决策逻辑（if-then 式），并附史料出处。决策多据《旧唐书》《新唐书》《资治通鉴》本纪与列传。

## 一、称帝与合法性

- **借符命进位**（垂拱四—天授元年，688–690）：得洛水瑞石、伪撰《大云经》、累现祥瑞，群臣上表，遂革唐命称帝。逻辑：既有宗法不容女主 → 借共享符号重述天命【一手：《旧唐书》卷六】。
- **渐进夺权**（674–690）：二圣→称制→称帝，三阶段不骤裂冠。逻辑：夺权分步推进，使制度人心渐适应【一手：《旧唐书》卷六、《新唐书》卷七六】。

## 二、权力巩固

- **酷吏清洗**（685–697）：用周兴、来俊臣、索元礼，立告密之风，诛李唐宗室与关陇旧臣。逻辑：权力未稳、反对根深 → 先高压清除核心威胁【一手：《旧唐书》卷一八六《酷吏传》、《资治通鉴》卷二〇四】。
- **铜匦广听**（垂拱二年，686）：铸四匦受天下书，兼收民意与情报。逻辑：掌握信息优于掌握表态【一手：《唐会要》卷五五】。
- **诛来俊臣**（697）：政权已固，诛酷吏以平众怒、收人心。逻辑：酷吏为患则弃之【一手：《资治通鉴》卷二〇六】。

## 三、制度与用人

- **科举破阀**（690 后）：始设武举、殿试，重进士科，擢狄仁杰、姚崇、宋璟、张柬之。逻辑：开新选拔通道，使新生力量依赖自身而非旧秩序【一手：《新唐书》卷四四《选举志》、《旧唐书》各本传】。
- **北门学士**（上元后）：引文学之士分宰相之权，使"建言十二事"得行【一手：《新唐书》卷七六】。

## 四、继嗣与身后

- **立庐陵王**（698–701）：从狄仁杰"姑侄与母子孰亲"之言，迎李显还，定立子。逻辑：不可两全时选最不坏且保身后安者【一手：《旧唐书》卷八九《狄仁杰传》】。
- **遗制去帝号**（705）：崩前"去帝号，称则天大圣皇后"，合葬高宗、立无字碑。逻辑：不自我定论，化解争议【一手：《旧唐书》卷六】。

## 五、决策启发式提炼（供 SKILL.md）

1. 秩序不容其位 → 借符号重述合法性
2. 权力未稳 → 先酷吏清除核心威胁
3. 立新权力基础 → 开新选拔通道
4. 欲掌实情 → 设直达言路为耳目
5. 夺权 → 分阶段进位
6. 继嗣两难 → 选最不坏且保身后安
