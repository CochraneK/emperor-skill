# 06 · 时间线（关键节点与思维影响）

> 调研目标：按年代梳理李治生平关键节点，标注事件与对其执政心态之影响。事实出处见各条。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 628 | 生于长安，太宗第九子，母长孙皇后 | 非嫡长，性宽仁，「仁弱可保兄弟」成储之资 |
| 643 | 承乾废、魏王泰黜，立为太子 | 以「不害兄弟」得储，养成守成宽缓底色 |
| 649 | 即位，改元永徽，长孙无忌等辅政 | 守贞观旧制，「永徽之治有遗风」自我定位确立 |
| 653 | 颁《永徽律疏》（唐律疏议） | 守成立法、制度因革之执政范式成型 |
| 655 | 废王皇后、立武昭仪，贬长孙无忌褚遂良 | 「废王立武」解关陇之围，亦启武后参政之渐 |
| 657–663 | 灭西突厥、百济（白江口）、高句丽 | 「竟太宗之业」边功为唐极盛，外强中干之局并生 |
| 660 | 患风眩头重、目不能视，委政武后 | 实权潜移，「同听政」始，主导权渐失 |
| 664 | 上官仪请废后遭诛，「二圣」临朝 | 权柄尽归中宫，朕失独断之局彻底形成 |
| 666 | 封禅泰山，改元乾封 | 礼文示承平，然朝政日委武后 |
| 675–680 | 太子弘薨、贤废、哲（中宗）立 | 骨肉之祸迭兴，宽仁之誉与家祸并存 |
| 683 | 崩，谥天皇大帝，庙号高宗，葬乾陵 | 以「守成而失权、竟功而启祸」之君载入史 |

## 来源与可信度

- 一手：《旧唐书·高宗本纪》（卷四）、《新唐书·高宗本纪》、《资治通鉴》唐纪
- 一手：《唐律疏议》、《唐会要》、《册府元龟》（典制）
- 二手：网络与讲史类对年代、纪年之简表（需以正史校核，《旧唐书》文气驳杂、纪年或有舛）
