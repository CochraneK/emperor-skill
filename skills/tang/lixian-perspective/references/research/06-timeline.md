# 06 · 时间线（李显）

> 调研目标：按时间梳理中宗一生关键节点，标注"对思维的影响"。据《旧唐书》《新唐书》本纪及《资治通鉴》唐纪。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 656 | 高宗第七子，母武则天，生于长安 | 生于鼎盛，不知祸之将至 |
| 680 | 立为皇太子（原英王） | 储位来得突兀，根基浅 |
| 684 | 嗣圣元年即位，旋被武后废为庐陵王，幽房州 | 一夕为帝一夕为囚，深种"复位即赦"之念 |
| 684–698 | 房州十四年，与韦氏同幽厄、备尝艰险 | "不相制御"之誓成执政隐患 |
| 698 | 被召还，复为皇太子 | 母威余悸，复位念愈强 |
| 705 | 神龙元年，张柬之等诛二张、迫武后退，朕复辟 | "赖臣复位"但"政不出己"之局始 |
| 705–706 | 大赦、复流人、封五王；旋贬杀五王 | 宽纵与功臣难驭并存 |
| 707 | 重俊之变，太子杀武三思兵败死 | 家祸及国，储位之乱显 |
| 707–710 | 韦后干政、安乐求皇太女、宴乐无度 | 实权旁落，无力自救 |
| 710 | 景龙四年六月，崩于神龙殿（韦后、安乐所鸩） | 复位之君终以被弑收场 |

> 注：中宗朝纪年多经睿宗、玄宗朝修订，《旧唐书》讳饰处已参《新唐书》《资治通鉴》考异；被鸩细节存异说。
