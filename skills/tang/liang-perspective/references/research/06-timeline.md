# 06 · 时间线（文宗李昂关键节点）

> 调研目标：以编年梳理唐文宗李昂（809–840）生卒、嗣位、执政转折与崩逝，标注每节点对「思维/执政逻辑」的影响。出处从简，详见 01–05。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 809 | 生于元和四年，穆宗第二子，母萧氏 | 贵胄而非嫡长，养成「以志补位」之心 |
| 826 | 敬宗被弑，王守澄迎立为帝，年18，改元大和 | 以宦官得位，深知阉患，立志去之 |
| 827–833 | 恭俭图治、汰冗官、禁浮屠、刻石经 | 以俭德收心，然权未入手 |
| 835 | 甘露之变，李训郑注谋诛宦官事泄，千余人死 | 一搏失败，皇权尽丧，终身受制家奴 |
| 835后 | 谓周墀「去河北贼易，去朝中宦官难」 | 自比周赧汉献，沉郁自嘲成型 |
| 836–840 | 牛李党争夹击，开成石经雅乐示文治 | 治仅表面，内耗不止 |
| 840 | 崩，年32；太子李成美为仇士良所废 | 连身后储嗣亦不得自主，去宦之志成空 |

> 注：纪年据《旧唐书》《新唐书》本纪互校；月份细节从《资治通鉴》唐纪六〇—六二。
