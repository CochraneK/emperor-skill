# 06 · 时间线（元明宗和世㻋关键节点，含对思维的影响）

> 调研目标：梳理和世㻋（1300–1329）生平关键节点，标注事件与对思维/执政取向的影响。年号说明：明宗天历二年（1329）即位，沿用天历年号，**未及改元而崩**（题目参数「至顺」实为文宗后期年号，明宗未用，详见诚实边界）。

## 时间线表

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1300 | 生于元廷，武宗海山（后为武宗）长子，母亦乞列思氏 | 自幼以「武宗嫡长」自居，血统正统感为一生底色 |
| 1307 | 武宗即位，立弟仁宗为太子，约「兄弟叔侄世世相承」 | 植入「约誓政治」信念：帝位当依约在武宗一系流转 |
| 1311 | 武宗崩，仁宗立，背约迹象渐显 | 正统期待与现实落差之始 |
| 1316（延祐三年） | 仁宗立己子硕德八剌（英宗）为太子，封和世㻋周王、出镇云南 | 被排除于继承之外，约誓首次破局 |
| 1316 | 就国至延安，与武宗旧臣谋变事泄，西走金山之北 | 流亡草原—西域十余年，草原认同与西北诸王根基成型 |
| 约1316–1328 | 流亡漠北—西域，西北诸王多附之 | 「草原流亡者」身份强化，与中原汉地治理经验脱节 |
| 1328（泰定帝崩） | 两都之战：燕铁木儿拥文宗胜，天顺帝败亡 | 文宗据大都，然依约当让位于武宗之子（明宗） |
| 1328（天历元年） | 文宗遣使迎明宗「让国」 | 明宗信其诚，视为约誓回归 |
| 1329（天历二年）正月 | 和世㻋于和宁之北即帝位，是为明宗；立文宗为皇太子 | 「叔侄相承」理想达成，然根基在漠北、对中原权臣无防 |
| 1329（天历二年）三月 | 谕保全文宗旧臣、大赉诸王 | 宽仁保全之策，未削燕铁木儿权 |
| 1329（天历二年）八月 | 至旺忽察都（上都南），与文宗宴后会，暴卒 | 天历让国逆转，在位仅半年，约誓政治以死验证 |
| 1329 后 | 后八不沙被鸩；二子妥懽帖睦尔（顺帝）、懿璘质班（宁宗）后由文宗抚养 | 家族遭清洗，武宗—明宗一系暂落 |
| 1332（文宗崩） | 文宗传明宗之子以「赎前愆」，先立宁宗、后立顺帝 | 明宗一系终归帝位，悲剧获迟来的正名 |

## 对思维的总影响

1. **约誓正统观**：武仁之约塑造其「帝位依约在武宗一系」的执念与天真。
2. **草原流亡者认同**：十余年漠北流亡使其成为「草原—西北」政治体的代表，与文宗之中原根基层抵牾。
3. **宽仁而失防**：信兄弟、保全旧臣，却无制衡权臣之术，终酿暴卒。
4. **悲剧性历史定位**：半年而崩、被鸩疑案，使其成为元代继承乱局中最醒目的牺牲者。
