# 06 · 时间线（铁木真 / 成吉思汗）

> 编年：自出生（异说）至崩（1227），并延及 1229 年忽里台立窝阔台。
> **era 标注为 1206–1227（建国至崩）**，此前为「建国前」段，此后的汗位空档另注。
> 凡纪年有异说者，一并列入「异说」栏，不调和。

## 主表

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1162？（异说 1155／1167） | 生于漠北斡难河（鄂嫩河）上游，孛儿只斤氏，父也速该，母诃额仑 | 生年无定论；幼年丧父、部众离散，为其「先整合内部」取向的现实起点 |
| 约 1170s | 也速该被塔塔儿人毒死，部众叛去，诃额仑携诸子艰困求生 | 【史论/二手】后世论者多以此为「弱者必须结盟与自强」经验之来源；**非其自述** |
| 约 1180s | 与札木合结为安答（义兄弟），后分道；依附克烈部王汗（脱斡邻勒） | 学会「借力—自立—反客为主」的联盟次序 |
| 1189？ | 被部分贵族推举为汗（**异说：《秘史》与《史集》系年不同**） | 首次体会「被推举」而非「自取」的合法性来源 |
| 1201–1202 | 与王汗联军败札木合「古儿汗」联盟；与王汗关系破裂 | 联盟的尽头是决裂——先礼后兵的名实次序成形 |
| 1203 | 灭克烈部，王汗败亡 | 漠北最大的一次内部整合完成 |
| 1204 | 灭乃蛮部，塔阳汗死；札木合被执而死（**死法诸源异说：自杀／赐死／处死**） | 草原统一完成，「向外取」的通道打开 |
| 1205／1207／1209 | 三次征西夏，1209年西夏主纳女请和 | 初习攻城与「以贡求和」的处理方式 |
| **1206** | **斡难河源大会，建九斿白旗，上尊号「成吉思」，建大蒙古国** | 建国即同批定千户、怯薛、断事官、文字、札撒——**制度一次性成套落地** |
| 1206 | 命失吉忽秃忽为断事官，设「青册」记判例 | 以成文判例取代部落习惯法的开端 |
| 1206 | 命塔塔统阿以畏兀儿字母书写蒙古语 | 以文字承载法度与命令，超越口头传递 |
| 1211 | 誓师伐金；野狐岭大破金军 | 由草原战争转入对定居帝国的正面战争 |
| 1215 | 取中都（今北京） | 取而不即守——**中原须委人经略** |
| 1217 | 封木华黎为太师国王，「太行之北，朕自经略；太行之南，卿其勉之」 | 形成「划界授权、便宜行事」的委任模式 |
| 1218 | 灭西辽（屈出律）；召耶律楚材 | 用人跨越族属与旧主关系 |
| 1219 | 讹答剌杀商队与使者；遣使责问不果；亲征花剌子模 | **先立名后动兵**：坐实对方「背约」之名 |
| 1219前后 | 也遂妃请定继嗣；诸子会上术赤与察合台相争；定窝阔台为嗣 | 继嗣须生前明定，然仍须忽里台认可——双轨并存 |
| 1220–1221 | 破布哈拉、撒马尔罕、玉龙杰赤；摩诃末败亡；札兰丁败于印度河 | 战果与屠戮并存，为其最大张力 |
| 1222 | 丘处机西觐，问「长生久视之道」，答「有卫生之道，而无长生之药」 | 所求被当场否定而不怒，嘉其直，赐号「神仙」 |
| 1223 | 哲别、速不台于迦勒迦河败斡罗思与钦察联军 | 探路式远征的价值——不以占领而以侦察与威慑收效 |
| 1225 | 还漠北；《也松格碑》（成吉思汗石）立于本年（现存最早蒙古文石刻） | 纪功入石，蒙古文已用于国家叙事 |
| 1226 | 以西夏背约为名再征西夏 | 名义先行的再次运用 |
| 1227 | 西夏主出降后被杀，西夏亡；**七月帝崩（年六十六，诸源异说）**；遗策「假道于宋，直捣大梁」；令秘不发丧 | 身后四年灭金之役的蓝图由其临终布置 |
| 1227–1229 | **汗位空档：拖雷监国二年**（《元史》记太祖崩后拖雷监国） | 说明指定继嗣并不等于权力即时移交 |

## 追尊事实（必须明写）

- **生前未称帝。** 1206 年受尊号「成吉思（汗）」，《元史》所书「成吉思皇帝」
  系明初修史者以汉制译写蒙古语「汗」。其建立者为**大蒙古国**，**从未称帝、从未入主中原**。
- **「元太祖」为忽必烈建立元朝后追尊之庙号**（至元三年，1266 年，追谥「圣武皇帝」，
  庙号太祖；武宗至大二年 1309 年加谥「法天启运圣武皇帝」）【一手：《元史·祭祀志·宗庙》／本纪末】。
  **加谥之年诸本系年或有参差，并列不调和。**
