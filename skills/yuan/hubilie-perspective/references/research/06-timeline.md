# 06 · 时间线（关键节点底稿）

> 调研目标：梳理忽必烈生平关键节点，标注事件与对思维/执政的影响。纪年以《元史》本纪为主，世系纪年出入处与《史集》《元朝秘史》互校。

| 时间 | 事件 | 对思维的影响 | 出处 |
|------|------|--------------|------|
| 1215 | 生于漠北，拖雷第四子，母唆鲁禾帖尼 | 戎马世家而受母教知书，养成"能用汉法"底色 | 一手：《元史》本纪/后妃传 |
| 1251 | 蒙哥即大汗位，命总领漠南汉地军国庶事 | 始得经营中原之权，广纳藩府儒士 | 一手：《元史》本纪 |
| 1253–1254 | 远征大理，兵不血刃而下 | 以"怀远"定边、攻心为上 | 一手：《元史》本纪 |
| 1256 | 营建开平府（后上都） | 草原与中原之间立根本，双轨布局之始 | 一手：《元史》地理志 |
| 1259 | 蒙哥死钓鱼城，忽必烈围鄂州 | 汗位危机倒逼速断 | 一手：《元史》本纪 |
| 1260 | 即汗位于开平，建元中统；与阿里不哥争位 | 行汉法、正朝仪立新政，二元治理成型 | 一手：《元史》卷四本纪 |
| 1264 | 败阿里不哥，统一蒙古本部 | 草原正统在手，转向经略中原 | 一手：《元史》本纪 |
| 1271 | 改国号大元，取《易经》"乾元" | "名号即正统"成型 | 一手：《元史》卷七本纪诏 |
| 1272 | 升燕京为大都，定为京师 | 政治中心南移，行汉地都城制 | 一手：《元史》地理志 |
| 1273 | 克襄阳、樊城 | "先取枢纽"战略奏效 | 一手：《元史》刘整/阿里海牙传 |
| 1274 | 命伯颜大举伐宋 | 三道并进、沿江而下 | 一手：《元史》伯颜传 |
| 1276 | 伯颜入临安，宋帝出降 | "勿妄杀"收民心，混一势成 | 一手：《元史》本纪/伯颜传 |
| 1279 | 崖山之战，南宋亡 | 天下混一，一统之局定 | 一手：《元史》本纪 |
| 1280前后 | 遍设行省、立司农司、行钞法 | 制度创设期，以行省与农政固本 | 一手：《元史》百官/食货志 |
| 1274/1281 | 两征日本失利；继征安南爪哇 | 晚年"疲中国以事远夷"，攻守失衡 | 一手：《元史》外夷传 |
| 1294 | 崩于大都，庙号世祖 | 一生以"薛禅汗"始、以"大元皇帝"终 | 一手：《元史》本纪 |

> 信源说明：纪年世系出入以《史集》（波斯文汉译）、《元朝秘史》（蒙古文汉译）交叉校正。《元史》明初仓促成书，错漏与重出颇多，已与《新元史》《元典章》互校。知乎/微信公众号/百度百科未引用、未采纳。
