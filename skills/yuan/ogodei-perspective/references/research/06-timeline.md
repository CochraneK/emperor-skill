# 06 · 时间线（窝阔台 / 元太宗）

> 编年：自出生（异说）至崩（1241），并延及乃马真后称制与 1246 年贵由之立。
> **era 标注为 1229–1241（受推举至崩）**；**1227–1229 为拖雷监国之空档，必须明写，不得与在位年相连**。
> 凡纪年有异说者，一并列入异说总表，不调和。

## 主表

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1186？（异说 1189） | 生，成吉思汗第三子，母孛儿帖 | 生年无定论；幼年即在统一草原的战事中度过 |
| 1219 前后 | 定嗣之会，太祖指窝阔台为嗣（**《元史·太祖本纪》不载**，见《蒙古秘史》§254–255 与《史集》，两源措辞不同） | 合法性来自「先帝之命」，此后其一切政策皆以此为本 |
| 1220–1221 | 从父西征，攻讹答剌、玉龙杰赤等城（**过程详略诸源互异**） | 亲历攻城与督战，知城守之坚与攻取之难 |
| 1226–1227 | 从征西夏 | 亲见其父崩于军中，知「秘不发丧」与权位交接之危 |
| **1227** | **太祖崩（七月）。汗位空档开始** | 指定继嗣不等于权力即时移交 |
| **1227–1229** | **拖雷监国二年**（《元史》记太祖崩后拖雷监国；拖雷守「灶」，掌本土与斡耳朵） | **此为空档期，非窝阔台在位期，不得连书** |
| **1229（己丑）秋八月** | 诸王百官大会于**怯绿连河曲雕阿兰**之地，以太祖遗诏被推举为大汗（《元史》作「即皇帝位」，系明初修史者措辞）；据《秘史》有推辞再三方受之举 | 合法性 = 先帝遗命 + 宗亲大会 + 三让之仪，三者缺一不安 |
| 1229 | 定汉地与西域两套赋调之制；始立朝仪 | 各因其俗、各用其人的双轨自始定型 |
| 1229–1230 | 驳「尽去汉人为牧地」之议，答耶律楚材「卿试为朕行之」，立十路征收课税使 | 以「试办—验效」裁决主张之争 |
| 1230 | 亲征金，取河东诸地 | 由「受命」转向「行先帝未竟之策」 |
| 1231（辛卯）秋 | 十路进廪籍与金帛，岁入果足；即日拜耶律楚材为中书令 | 以实绩加委，不以言辞加委 |
| 1231 | 遣搠不罕使宋假道，至沔州被杀；拖雷由宝鸡入大散关，经宋境汉中出唐邓 | **使者被杀即出兵之名**，与太祖同一结构 |
| 1232 | **三峰山之战**（钧州）：拖雷大破金军主力，完颜合达、移剌蒲阿败死 | 假道之策奏效，金之主力尽丧 |
| 1232 | **拖雷暴卒**（死因异说并列：代兄受疾而死／被忌而亡／病卒） | 功高之弟的暴卒，成继嗣史悬案 |
| 1233 | 速不台围汴京，金哀宗走归德、蔡州 | 灭金进入收官 |
| 1234 正月 | 蒙宋联兵破蔡州，金哀宗自缢，**金亡** | 先帝遗策至此完成 |
| 1235 | **城和林，作万安宫**；定都于鄂尔浑河畔 | 由帐幕游徙转向定都——从征服集团到统治机构 |
| 1235 | 发**长子西征**：拔都为帅、速不台为先锋，诸王长子从征 | 以集体出兵消化宗亲张力 |
| 1236 | **乙未籍户**（括中原户口定赋役）；**丙申分封**（投下之制，五户丝） | 理财有基，然宗亲分权亦成定局 |
| 约 1239–1240 | 拔都与贵由军中失和，召贵由责之并令谢罪（**《元史》本纪不载**，见《史集》） | 宗亲之争以长幼与等级裁断，非以军功 |
| 1238 | **戊戌选试**（经义、词赋、论三科试儒士，一说得士 4030 人） | 以其术取其人，儒户自此有籍 |
| 1240–1241 | 西征军入波兰（里格尼茨）、匈牙利（莫希） | 兵锋远至欧洲中部 |
| **1241（辛丑）十一月** | **帝崩**（《元史》仅记「崩」；《史集》记其嗜酒，卒与酒相关，一说中风） | 未定储而崩，制度性间隙立即显现 |
| 1241–1246 | **乃马真后（脱列哥那）称制五年**，至 1246 年贵由方立 | 忽里台与后妃称制之间的间隙是制度性的，非偶发 |

## 追尊事实（必须明写）

- **生前未称帝。** 1229 年受宗亲大会推举为**大汗（合罕）**；
  《元史·太宗本纪》所书「即皇帝位」为**明初修史者措辞**。
- **「元太宗」为忽必烈建立元朝后追尊之庙号**：至元三年（1266 年）追谥「**英文皇帝**」，
  庙号**太宗**。【一手：《元史》卷二《太宗本纪》末】
- **本人无亲笔文书传世**；今存相关成文材料多为臣下拟制之条格与本纪所引诏令摘要。
