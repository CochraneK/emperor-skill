# 06 · 时间线（关键节点与思维影响）

> 调研目标：按年代梳理顺帝生平关键节点，标注事件与对其执政心态之影响。事实出处见各条。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1320 | 生于北方，明宗和世㻋长子 | 生于流亡前夜，血脉即系「夺位疑案」 |
| 1329 | 父明宗「天历让国」后暴卒（史称被鸩），随母谪徙 | 幼年即尝「父死、被逐」之创，养成隐忍底色 |
| 1330–1332 | 流放高丽大青岛、再迁广西静江大圆寺 | 「流离播越」十余年，深谙失势者之忍；日后善「待时」 |
| 1333 | 宁宗夭，文宗后迎立为帝，时年十三；燕铁木儿主政 | 即位而不亲政，习「受制而默」之自全术 |
| 1335 | 诛燕铁木儿侄唐其势，伯颜益专 | 亲见权臣之横，埋「待时废奸」之念 |
| 1340 | 与脱脱合谋黜伯颜，伯颜贬死 | 首度以智除权臣成功，信心与权术俱进 |
| 1341 | 命脱脱为相，至正更化始 | 「倚一相而革新」成其执政范式 |
| 1343–1345 | 修辽、金、宋三史成 | 文治自我定位，以「继统修史」收道统 |
| 1344 | 脱脱丁忧辞相，更化即弛 | 悟「一相去则政荒」，然未建制度以补 |
| 1351 | 贾鲁治河，韩山童、刘福通红巾起 | 民变起于腹心，中枢调发渐失措 |
| 1354 | 脱脱总兵征高邮，被谗削权、寻死 | 失最后重兵，局势不可逆；悔而晚 |
| 1360s初 | 崇西僧、行演揲儿法、十六天魔，搠思监/朴不花用事 | 怠政自弃，以「敬佛」解崩坏之局 |
| 1364–1365 | 孛罗帖木儿入京、被诛；太子奔还，父子相疑 | 宫廷内斗耗尽最后元气 |
| 1368 | 明军克大都，帝北遁上都→应昌 | 「北狩」保蒙古本位，元亡而元不绝 |
| 1370 | 崩于应昌（北元昭宗立） | 终以「失中原、守漠北」之君载入史 |

## 来源与可信度

- 一手：《元史·顺帝本纪》（卷三九—四七）、《明宗本纪》《宁宗本纪》、诸臣传、权衡《庚申外史》
- 一手：柯劭忞《新元史·顺帝本纪》、屠寄《蒙兀儿史记·顺帝本纪》
- 二手：网络与讲史类对年代、世系的简表（需以正史/《新元史》校核，尤其《元史》仓促成书、纪年或有舛）
