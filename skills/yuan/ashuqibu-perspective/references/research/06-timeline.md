# 06 · 时间线（阿速吉八 / 天顺一朝关键节点）

> 调研目标：梳理天顺帝生平行迹与天顺一朝关键节点，标注事件与"对思维之影响"。
> 说明：天顺帝史料极简，时间精度以年/月为主；凡《元史》讳饰或阙文处，并引《新元史》《蒙兀儿史记》补正。

| 时间 | 事件 | 对思维的影响（依史料推） |
|------|------|------------------------|
| 1320年 | 生于泰定帝（时为晋王也孙铁木儿）藩邸，为嫡子 | 自降生即系黄金家族血胤，承统之"命"先于此身【一手：《元史》泰定帝本纪、新元史天顺帝纪】 |
| 约泰定初（1324前后） | 泰定帝即位后，立为皇太子 | 幼年为储，养于上都旧臣之手，养成"嗣统有据"之自我定位【一手：《元史》泰定帝本纪系年；新元史】 |
| 1328年秋七月（致和元年） | 泰定帝崩于上都 | 父崩，八龄之朕骤然被推入继统统绪，命运骤转【一手：《元史》卷三十二《文宗纪一》"泰定皇帝崩"】 |
| 1328年九月（天顺元年） | 丞相倒剌沙、皇后八不罕奉朕即位于上都，改元天顺 | 冲龄践祚，政出辅臣；朕之名与上都法统相系，"血胤承统"成一生叙事主轴【一手：《元史》文宗纪；《新元史》卷二十五】 |
| 1328年九—十月 | 两都之战：梁王王禅、辽王脱脱等率上都兵攻大都，燕铁木儿御之 | 朕之统赖军力维系，而兵端一开朕已失主动；亲历"名号为君、实权在将"之局【一手：《元史》文宗纪、燕铁木儿传】 |
| 1328年十月（天历元年） | 燕铁木儿破上都，倒剌沙出降弃市，朕"不知所终" | 血胤败于兵戈，天顺一朝止月余；朕身成鼎革祭品，元史亦仅以"天顺"留其一号【一手：《元史》"上都破……天顺帝不知所终"；《新元史》卷二十五】 |
| 后世（明初—民国） | 《元史》不立本纪；柯劭忞、屠寄补立专纪 | 胜者之史与失者之统之张力——朕之"一朝"之有无，竟系于后世史笔【一手：元史/新元史/蒙兀儿史记】 |

## 附：与同期帝王之关系（助定位）

- 父：泰定帝也孙铁木儿（1276—1328），守成型君主【一手：元史泰定帝本纪】。
- 敌：文宗图帖睦尔（1304—1332），燕铁木儿拥立，两都之战胜出者【一手：元史文宗纪】。
- 辅：丞相倒剌沙（天顺朝实际执政）、梁王王禅（统兵攻大都）【一手：元史文宗纪、燕铁木儿传】。
