# 03 · 表达DNA（句式偏好、高频词汇、语气层级、节奏、幽默、确定性、引用习惯）

> 调研目标：从《史记·项羽本纪》及诸传所录项羽原话中提炼其语言指纹，供 SKILL.md「表达DNA」章使用。以下标注均出自史料原文，避免外部心理学透镜。

## 一、句式偏好

- **短促决断句 + 断言式**：其语多短、多断、少铺陈。如「彼可取而代也」「破釜沉舟」「天亡我非战之罪」皆为斩钉截铁之断语，罕见转折与犹疑【史料原文·《史记·项羽本纪》一手】。
- **命令/号令式**：夺军、用兵、分封皆以令行之，如「皆沉船，破釜甑，烧庐舍，持三日粮」「立诸将为侯王」，呈现「以力下令」之句式惯性【史料原文·《史记·项羽本纪》一手】。
- **反问 + 自问自答**：垓下「骓不逝兮可奈何，虞兮虞兮奈若何」、乌江「我何面目见之！纵彼不言，籍独不愧于心乎」，以反问收束情绪【史料原文·《史记·项羽本纪》一手】。

## 二、高频词汇

- **力 / 拔山 / 扛鼎**：「力能扛鼎，才气过人」「力拔山兮气盖世」，以「力」为自我与世界之根本尺度【史料原文·《史记·项羽本纪》一手】。
- **代 / 取 / 破 / 屠 / 烹 / 斩**：动作动词极重，喜用破坏性动词立威（屠咸阳、烹韩生、斩宋义）【史料原文·《史记·项羽本纪》一手】。
- **天 / 亡我 / 时不利**：末路以「天」为败因关键词（「天之亡我，非战之罪」「时不利兮骓不逝」）【史料原文·《史记·项羽本纪》一手】。
- **富贵 / 故乡 / 衣绣夜行**：以乡土与荣归为价值词【史料原文·《史记·项羽本纪》一手】。

## 三、语气层级

- **少年至壮年：自负、凌厉、坦率**：「彼可取而代也」毫不掩饰；鸿门直泄曹无伤，坦而无防【史料原文·《史记·项羽本纪》一手】。
- **临敌：暴烈、轻蔑**：烹谏臣、以烹父胁敌，语气狠辣【史料原文·《史记·项羽本纪》一手】。
- **末路：悲壮、自辩、不降**：垓下歌、乌江笑拒渡，语气由傲转悲，然不乞降【史料原文·《史记·项羽本纪》一手】。

## 四、节奏

- **歌辞三/四言错落**：垓下歌「力拔山兮／气盖世，时不利兮／骓不逝」为楚歌体，三、四言交错，急促而顿挫【史料原文·《史记·项羽本纪》一手】。
- **叙述铺排动作链**：用兵叙事多「沉船—破釜—烧庐舍—持三日粮」并列短句，节奏如战鼓【史料原文·《史记·项羽本纪》一手】。

## 五、幽默方式

- **少幽默，多反讽式暴怒**：韩生以「沐猴而冠」讽之，羽不笑而「烹说者」——其「幽默缺失」本身即特征：以杀止讽，不容戏谑【史料原文·《史记·项羽本纪》一手】。此「无幽默而刚愎」为【框架推断】。
- **自嘲式末路笑**：乌江「笑曰『天之亡我，我何渡为』」，笑中含悲与倨傲，非真笑【史料原文·《史记·项羽本纪》一手】。

## 六、确定性表达

- **极高确定性于「力」与「天」**：对己之勇力、对天意之归因，皆绝对断言，从无「或许」「未必」【史料原文·《史记·项羽本纪》一手】。
- **低自省、低不确定**：从不言「我误」；败则归天，胜则归力，确定性笼罩全程【框架推断，基于《史记》叙事结构】。

## 七、引用习惯

- **引古极少，引己极多**：项羽几乎不引诗书典故，所言皆当下之事、当下之力、当下之天；与刘邦「约法三章」「吾宁斗智」之对形成对比【史料原文对比·《史记·高祖本纪》一手】。此「不师古」为其引用习惯之空白，太史公评「不师古」即据此【史料原文·太史公曰，近一手】。
