# 06 · 时间线（太祖关键节点）

> 调研目标：以时间为轴列出太祖生平与执政关键节点，标注「对思维的影响」，与 SKILL.md 时间线互为表里。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 927 | 生于涿郡将门 | 将家底色，自幼习兵 |
| 948–959 | 仕后周，从世宗柴荣征战，累迁殿前都点检 | 亲见兵变立君、藩镇之祸，成「收权」执念 |
| 960 | 陈桥兵变，黄袍加身，代周建宋，改元建隆 | 以兵夺国，故深知兵权不可假人 |
| 961 | 杯酒释兵权，解宿将典军 | 「以文制武」国是立，重文抑武成型 |
| 963 | 平荆南（南平） | 先南后北首捷，统一方略启动 |
| 964–965 | 平后蜀 | 连胜累积国力，戒蜀主之奢 |
| 963–968 | 文臣知州、通判、转运使、更戍法 | 制度消割据之术系统化 |
| 971 | 平南汉 | 岭南入版籍 |
| 975 | 平南唐，李煜降 | 江南尽定，「卧榻」之喻见统一决心 |
| 976 | 吴越纳土（后年）；冬，斧声烛影崩，传弟光义 | 继位疑案留「兄终弟及」张力，统一未竟 |

> 注：年号——建隆(960–963)、乾德(963–968)、开宝(968–976)。燕云未复、统一未竟为太祖遗留之局。
