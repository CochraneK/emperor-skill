# 05 · 关键决策与因果（理宗朝）

> 调研目标：梳理赵昀在位期间的关键决策、因果链条与得失，供心智模型与决策启发式抽取。

## 一、定策入继（1224）

- 史弥远矫诏废济王竑，立朕为帝。得位之正先亏，使「君权出于相」成例【一手：《宋史》卷四一、卷四七三《史弥远传》】。
- 因果：立身不正 → 容忍构杀济王、迟不雪冤 → 后世讥「以私恩废公」。

## 二、端平更化（1233–1234）

- 弥远死，亲政，召真德秀、魏了翁，立四书于学官，崇程朱理学【一手：《宋史》卷四一、卷四三七】。
- 因果：以道统收士林 → 党论再起、实政不举 → 文化盛而事功衰。

## 三、联蒙灭金（1233–1234）

- 遣兵会蒙古灭金，雪靖康之耻【一手：《宋史》卷四一、卷四一二《孟珙传》】。
- 因果：复仇灭金 → 失去金为缓冲 → 蒙古直接南下 → 宋蒙百年之祸。

## 四、端平入洛（1234）

- 图复三京，兵入洛阳粮绝溃归，损失惨重【一手：《宋史》卷四一、卷四一七《赵葵传》】。
- 因果：冒进恢复 → 大损国力、与蒙交恶 → 宋蒙战争正式爆发。

## 五、晚年怠政与贾似道专权（1259–1264）

- 开庆鄂州之役后委政贾似道，景定间「专制国命」，朕宴安寝处【一手：《宋史》卷四六、卷四七四《贾似道传》】。
- 因果：怠政委佞 → 边防洞开、襄樊受困 → 宋势日蹙，为亡国伏笔。
