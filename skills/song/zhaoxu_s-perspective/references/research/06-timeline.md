# 06 · 时间线（关键节点与思维影响）

> 调研目标：按年代梳理神宗生平关键节点，标注事件与对其执政心态之影响。事实出处见各条。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 1048 | 英宗长子，生于庆历八年 | 生于「庆历新政」之后，承积弱之积 |
| 1067 | 治平四年英宗崩，即位，改元熙宁，年二十 | 少年嗣位，以「大有为」自任 |
| 1068 | 熙宁元年越次召王安石，上《百年无事札子》 | 「变法则强」之信念确立，倚安石为臂 |
| 1069 | 熙宁二年置条例司，行青苗等新法 | 理财强兵之政全面铺开 |
| 1071–1072 | 熙河开边，复熙河等州 | 武功之盛，对夏战略包抄成 |
| 1074–1076 | 安石两罢两复，帝「自任其事」 | 果决而不回，党争自困 |
| 1080 | 元丰三年复三省六部、正官制 | 制度之功，寄禄职事分 |
| 1081 | 元丰四年五路伐夏，灵州失利 | 用兵受挫，富强梦裂 |
| 1082 | 元丰五年永乐城败，死者二十余万 | 帝「临朝痛悼」，最大遗憾 |
| 1084 | 元丰七年《资治通鉴》成，御制序 | 文治之托，留不朽业 |
| 1085 | 元丰八年崩，哲宗立，高太后垂帘 | 在位十九年，新法随元祐更化而罢 |

## 来源与可信度

- 一手：《宋史·神宗本纪》（卷一四—一七）、王安石/司马光/王韶/徐禧诸传、《食货志》《兵志》《职官志》、《长编》
- 一手：司马光《涑水记闻》、王偁《东都事略》、马端临《文献通考》、王安石《临川集》
- 二手：网络与讲史类对「王安石变法」之简化叙事（需以正史/《长编》校核；《宋史》仓促成书、纪年或舛）
