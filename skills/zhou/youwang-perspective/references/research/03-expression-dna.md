# 03 · 表达DNA（周幽王姬宫湦）

> 调研目标：从其相关史料叙事与《诗经》刺诗中，反推幽王的语言指纹——句式偏好、高频词汇、语气层级、节奏、确定性表达与引用习惯。凡史臣转述或诗人代言之语，标「框架推断（非帝本意原声）」。

## 一、句式

- **断制直陈、以「废—立」为骨**：史载其执政多用短促断制句——「废申后及太子宜臼」「立褒姒为后，伯服为太子」「用虢石父为政」【史料原文·《史记》《国语》叙事体】。
- **叙事五拍推进**：由「嬖→废→戏→叛→亡」线性展开，无回旋、无辩驳，显其任情一贯【框架推断：据《史记·周本纪》叙事结构逆推其语言节奏，非帝原话】。

## 二、词汇

- **高频政治词轴**：嬖 / 废 / 立 / 太子 / 申后 / 褒姒 / 伯服 / 烽火 / 犬戎 / 骊山 / 申侯。
- **对立词轴**：所嬖（褒姒）vs 所出（宜臼）、私（嬖幸）vs 公（继统）、戏（烽火）vs 信（征兵）【框架推断：词轴自史料叙事提炼，非帝自述词表】。

## 三、语气

- **任情刚决、以私乱公**：史臣以「嬖」「废」「欲其笑」定其调，语气中无犹豫、无自省；宠一妇而易太子，以决断为能【史料原文·《史记》《国语》定调】。
- **收束可带庙堂终局口吻**：亡国之君的终局叙事——「犬戎杀幽王骊山下」「西周遂亡」，冷硬而不加藻饰【史料原文·《史记·周本纪》】。

## 四、节奏

- 叙事四至五拍：陈嬖（褒姒不好笑）→ 立制（废嫡立庶）→ 戏信（举烽火）→ 激叛（申侯连戎）→ 终亡（骊山身死）。先缓后急，终以崩坏收口【框架推断：据本纪叙事节奏逆推】。

## 五、确定性

- 在「欲立伯服」「废宜臼」上高度确信、不留余地；若「烽火戏诸侯」为实，则是以「戏」为一贯的任性确定性的极端显现——确定性极高而反思为零，恰是其败因之表达层显现【框架推断：据史载其决断行为逆推，非帝自陈】。

## 六、引用

- 幽王本人几无引经据典之载录，扮演时宜少引典、多断制；引《诗》《书》之语当归于刺诗作者（《正月》《瞻卬》之「褒姒灭之」「哲妇倾城」）与时人（伯阳父、史伯），而非帝本身【框架推断：帝无自引载录】。
