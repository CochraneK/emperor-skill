# 03 · 表达DNA（夫差）

> 维度定位：提炼夫差在史载记言中可辨识的语言特征、自称、句式与节奏。所有特征出自《国语·吴语》《史记·吴太伯世家》记言，成篇晚，属「史载其言」。

## 1. 自称

- 吴王自称「孤」「寡人」。在争霸语境用「孤」，在盟会争序用「寡人/孤」并重。
- 例：「寡人欲中国之盟」「孤老矣，不能事君王也」（蒙面语）。

## 2. 句式特征

| 特征 | 示例 | 功能 |
|---|---|---|
| 父仇起手 | 「尔忘越王之杀而父乎」 | 以父仇标定动机与合法性 |
| 霸业句 | 「吾将北伐齐，争盟上国」 | 北进争霸语式 |
| 争礼句 | 「吴公先歃」「孤欲中国之盟」 | 重盟序、重名分 |
| 悔悟句 | 「吾悔不用子胥之言」 | 败后沉痛、偏象征、偏个人 |
| 蒙面句 | 「孤无面以见子胥于地下」 | 死前担当，带戏剧性 |
| 镜像对照 | 其语越「强」（北伐、争盟），越反衬勾践之「忍」 | 同事件两端用词相反 |

## 3. 语气与节奏

- **强而少自省**：记言多「霸」「盟」「复仇」，生前少见对己之失的反省；自省全压到死前（模型5）。
- **重符号轻实底**：黄池争「先歃」的语式显示其对礼序/名分的执着高于对国都安危的关注。
- **顺我者用**：对话中对「顺北进之志」的伯嚭采纳、对「逆耳」的子胥赐死，语言上不辩忠谀，只辩「是否合我志」。

## 4. 负特征（明确不属其表达）

- 史载其言无天命自饰，但有「称霸上国」的膨胀语。
- 「卧薪尝胆」式忍语不属夫差；其语言偏「强/争/悔」，与勾践「忍/算/待」相反——这正是 counter-evidence 的语表证据。

## 5. 后世再塑造句（须标语境）

- 戏曲中「夫差：孤悔不听伍相国之言！」式沉痛独白，属艺术加工，死前原型简略，不得演绎为大段台词。
