# 06 · 时间线（关键节点 + 对思维的影响 + 史料成书背景与互核）

> 调研目标：以年表呈现周显王（姬扁）一生与在位四十八年的关键节点，并标注每一节点对其执政心智的影响；末附史料成书背景与互核说明。

## 一、关键节点表（元年 = 前368）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 前368（显王元年） | 烈王崩，弟扁立（显王）；时三晋、田齐已立，周室卑 | 即位即处弱势，天子之「分」已由先王割让殆尽，养成「守分无可守」底色 |
| 前367（二年） | 西周威公少子根叛，赵、韩立之于巩，分东周（王畿再裂） | 连本畿都控不住，实权再削一层，「贺之存名」由策略渐成唯一选项 |
| 前364（五年） | 秦献公败魏于石门，斩首六万；显王贺秦献公，献公称伯（《周本纪》） | 西方骤强，王室主动称贺——「以礼敬换虚名」范式确立 |
| 前362 | 秦献公卒，孝公立 | 秦政将变，西土之危未已 |
| 前361（八年） | 秦孝公下令求贤，卫鞅（商鞅）入秦（《秦本纪》《商君列传》） | 变法之端启于西，周室只能旁观其成 |
| 前360（九年） | 致文武胙于秦孝公（《周本纪》） | 名分再授秦，等于承认秦跻霸主之林 |
| 前356 / 前350 | 商鞅两度变法，秦骤强（《商君列传》《秦本纪》） | 「霸王出秦」之谶（太史儋语）渐验，西土之惧成定局 |
| 前344（约二十五年） | 逢泽之会，魏惠王称王；《周本纪》书「秦会诸侯于逢泽，朝天子」 | 诸侯公开称王，礼防松动；王室犹存「朝天子」之名 |
| 前334（三十五年） | 徐州相王，魏齐互尊为王（《魏世家》《田敬仲完世家》《战国策》） | 王号不再为天子独享，显王以沉默默认 |
| 前325（四十四年） | 秦惠王称王；《周本纪》紧接「其后诸侯皆为王」 | 名分彻底崩解，显王之世成「名存实亡之极」的节点 |
| 前321（四十八年） | 显王崩，子慎靓王定立 | 长君四十八年，享国久而不能图实，虚器传于赧王而终亡 |

## 二、史料成书背景与互核

- **《史记·周本纪》**：司马迁据《春秋》《国语》《战国策》及汉初所传周史材料编成；东周部分记事极简，「显王」世系仅寥寥数条，凡涉其个人言行多付阙如，故本技能对其内心动机之补述均标「框架推断」。（一手正史，然东周记事简略）
- **《史记·秦本纪》《商君列传》《魏世家》《田敬仲完世家》《苏秦列传》**：互补诸侯侧面的第一手纪传材料，用以互证「商鞅变法」「徐州相王」「苏秦说显王」等节点。（一手正史）
- **《战国策》**：策士言行汇编，记徐州相王、纵横之议最详，与《史记》互证；然多游士润色，凡涉谋略细节须审慎。（一手诸子/策士文献，近一手）
- **《竹书纪年》（古本辑佚）**：魏国史官编年，可校《史记》系年；东周部分残佚，仅作旁证。（一手编年，辑本）
- **《资治通鉴·周纪》**：司马光编年通史，叙事已带史臣取舍（如臣光曰礼论），属后世编年视角，与《史记》互核。（编年正史，近一手）
- **系年互核声明**：逢泽之会《周本纪》系于秦、诸家多系于魏；徐州相王、《周本纪》显王十三年「石门之捷」与五年「贺献公」条互见，系年有小异。本技能一律以《周本纪》原文为底本，并在相关章节注明异说，不妄改纪年。
