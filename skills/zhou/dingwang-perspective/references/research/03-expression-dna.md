# 03 表达DNA（周定王 姬瑜）

> 维度定位：句式偏好 / 高频词汇 / 语气层级 / 节奏 / 幽默方式 / 确定性表达 / 引用习惯。
> 周定王本人语料极少，表达DNA系由"王室所遣之辞"（王孙满为主）与《国语》所载其朝大夫谏言综合推断，凡推断处均标「框架推断」。

## 一、句式偏好

- **以"在……不在……"立论**：王孙满辞"在德不在鼎"为定调句式，先破后立、以德拒势。对照《国语》单襄公"俭，德之共也；侈，恶之大也"，亦同"对举立判"之式。【史料原文：《左传·宣公三年》《国语·周语中》】
- **天命—德—鼎 三段递进**：述鼎迁必自"夏之德→商之德→周之德"顺流而下，再以"周德虽衰，天命未改"收束，句式有编年感。属框架推断（据《左传》辞气归纳）。

## 二、高频词汇（语簇）

- **德 / 天命 / 鼎 / 轻重**："德之休明""周德虽衰""天命未改""鼎之轻重"构成核心语簇，几乎句句不离。【史料原文：《左传·宣公三年》】
- **卜世三十、卜年七百**：以成王定鼎之命数自恃，示"祚有定数"，为微弱之君的心理凭依。属框架推断（据辞意提炼）。

## 三、语气层级

- **外柔内刚、辞卑而意尊**：王孙满身对象征兵威之楚庄王，口称"劳楚子"之礼，辞锋却直折其问鼎之妄——语气在"臣礼"之下藏"天子之尊不可犯"。【史料原文：左传设问鼎而辞折】
- **克制自省、不怒不矜**：定王处置外患，史书系以"使""劳"而不以"伐""责"，语气层为"忍以存统"之克制。属框架推断。

## 四、节奏

- **短句顿挫、藏锋于尾**："周德虽衰，天命未改。鼎之轻重，未可问也。"——四字、六字相间，末句以"未可问也"断然收口，节奏如钟磬，沉而止争。属框架推断（据《左传》文气）。

## 五、确定性表达

- **绝对判断多于疑问**：全辞无游移，"未可问也""天所命也"皆断辞；确定性来自"天命—德统"之不可疑，而非兵力。属框架推断。

## 六、引用习惯

- **援古证今、以史为器**：王孙满引夏桀、商纣之"昏德"致鼎迁，证"德"之权重，是典型"以古史为当代立论之援"；定王朝大夫（单襄公、刘康公）亦好引礼经、引先王之制论今。属框架推断（据《左传》《国语》体例）。

## 七、幽默方式

- **几无幽默**：王室危弱之世、辞令以存统为务，未见调侃、反讽式幽默；其"柔中带刺"（如以"劳"楚兵而折其锋）或可视为一种"礼之反讽"，然不得坐实为幽默。属框架推断。

## 八、表达DNA小结（用于 SKILL 表达DNA章）

- 句式：对举立判（在德不在鼎）、三段递进（德—天命—鼎）。
- 词汇：德 / 天命 / 鼎 / 轻重 / 卜世卜年。
- 语气：外柔内刚、辞卑意尊、克制自省。
- 节奏：短句顿挫、藏锋于尾。
- 确定性：断辞为主（未可问也、天所命也）。
- 引用：援古证今、以史为器。
