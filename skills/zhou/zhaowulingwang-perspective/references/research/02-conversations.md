# 02 · 对话与即时反应（赵武灵王赵雍）

> 维度定位：记录其在**被追问、被反对、被质疑**场合的反应方式。对话材料几乎全部来自《战国策·赵策二》《史记·赵世家》，属**后世编纂的记言**，但对话结构（谁问什么、他如何回应）保留了可分析的行为模式。

## 1. 面对「你会被天下人笑话」——先自陈顾虑，再抬高出价

**场景**：议胡服前，向肥义抛出顾虑。

- 他先说：「今吾将胡服骑射以教百姓，而世必议寡人，**奈何**？」
- 肥义以「论至德者不和于俗，成大功者不谋于众」回之。
- 他随即更正：「寡人**非疑胡服也**，吾恐天下笑之。」——即他澄清自己犹豫的不是方案，而是**羞辱成本**。
- 然后自己把价码抬高到不可回退的地步：「**虽驱世以笑我，胡地、中山，吾必有之。**」

【传世文本·《战国策·赵策二》】

**模式**：先自曝弱点（把反对意见抢先说出来）→ 换得谋臣给出「不必顾议」的授权 → 再用一句对赌式断言把退路封死。这是他启动高争议事项的固定动作，而非一次性的豪言。

## 2. 面对宗室领袖的正面抵制——不压服，亲自登门，换判据

**场景**：叔父公子成称疾不朝，并上言「袭远方之服，变古之教，易古之道，逆人之心，畔学者，离中国」。

他的处理顺序：

1. 先派王孙緤（使臣）去说：「家听于亲，国听于君，古今之公行也……今胡服之意，非以养欲而乐志也。」——先礼、先讲规矩。
2. 使者回报后，他说「吾固闻叔之病也」，**亲自到公子成家**请求。
3. 到府后**更换判据**：不谈华夷，只谈「便用/便事」，再谈地形敌情，最后谈国耻（引水围鄗）。
4. 公子成再拜稽首：「臣愚不达于王之议，敢道世俗之闻……臣敢不听令。」乃赐胡服。

【传世文本·《战国策·赵策二》】

**模式**：反对越硬，他越低姿态、越亲往；但**判据绝不让步**——低的是姿态（礼下之），硬的是标准（苟可以利民，不一其用）。梁启超以此对比商鞅：「鞅则罚太子而刑师傅，武灵则先施于公叔而礼下之……公叔变而举国皆变。」【现代史论·梁启超】

## 3. 面对技术官僚型反对（牛赞）——只谈器械与地形，不谈礼法

**场景**：原阳改骑邑，牛赞以「国有固籍，兵有常经」反对，提出「利不百者不变俗，功不十者不易器」。

他直接反击其知识结构：「**子知官府之籍，不知器械之利；知甲兵之用，不知阴阳之宜。**」并给出失效条件：「今重甲循兵，不可以逾险。」

牛赞「再拜稽首」，遂胡服率骑入胡，「出于遗遗之门，逾九限之固，绝五径之险，至胡中，辟地千里」。

【传世文本·《战国策·赵策二》】

**模式**：对技术型反对者，他不讲价值，只讲**适用条件与失效边界**——把争论锁在「什么地形下什么兵种有效」。

## 4. 面对强邻与对手——亲自取证，不惜身入险地

**场景（前299年后）**：自号主父，「欲令子主治国，而身胡服，将士大夫西北略胡地，而欲从云中、九原，直南袭秦。于是**诈自为使者入秦**」。

> 「秦昭王不知，已而怪其状甚伟，非人臣之度，使人逐之，而主父驰已脱关矣。审问之，乃主父也。秦人大惊。主父所以入秦者，**欲自略地形，因观秦王之为人也**。」

【传世文本·《史记·赵世家》】

**模式**：最高决策者亲自做战略侦察，且侦察对象是**地形 + 对手人格**两项。这是其「勘察优先」最极端的一次执行。

## 5. 面对继承难题——反复改口，最后失去裁决权

**场景链条**：

1. 立韩夫人之子**章**为太子（前325年后）。
2. 得吴娃（孟姚，前310年），宠之，「不出吴娃之宫数岁」，生子**何**，遂废章立何。【传世文本·《史记·赵世家》】
3. 前299年传国于何，自号主父。
4. 吴娃死后（前301年）怜章，「欲分赵而王章于代」，**为大臣所阻**而未决。【传世文本·《史记·赵世家》】
5. 前295年沙丘，章与田不礼作乱，杀肥义；章败，逃入主父宫，**主父纳之**。公子成、李兑围宫，杀章；因惧主父报复，继续围困，「宫中人后出者族」，主父「探雀鷇而食之」，三月余饿死。【传世文本·《史记·赵世家》《资治通鉴·周纪》】

**模式反证**：此处他与前四场对话的表现**完全相反**——前面每次都能把争议锁定在功能判据上并收束，唯独在自家继承问题上，他既不能下决断（欲分国而犹豫不决），又不能在危机中给出可执行的指令（纳章而招围）。这是本人物最重要的行为断裂点，SKILL.md 必须以**内在张力**而非「晚年昏聩」的标签来处理。

## 6. 对话中未出现的内容（拒绝回答/沉默处）

- **无其悔过的自述**：沙丘被围三月，史书未记其任何言语，只记「探雀鷇而食之」。与夏桀留有「吾悔不遂杀汤于夏台」不同，赵雍名下**无任何临终言辞**。此为真实缺口，SKILL.md 不得代拟。
- **无与秦昭王的实质对话**：入秦是伪装，未留下交谈记录；「怪其状甚伟」是秦方观察，非对话。
