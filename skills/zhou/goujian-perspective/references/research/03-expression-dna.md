# 03 · 表达DNA（勾践）

> 维度定位：提炼勾践在史载记言中可辨识的语言特征、自称、句式与节奏，供 SKILL.md「表达DNA」抽取。所有特征出自《国语·越语》《史记·越王勾践世家》的记言，成篇晚，属「史载其言」而非孤之口述录音。

## 1. 自称

- 越君自称「孤」「寡人」（春秋诸侯常称）。在恳切语境用「孤」，在外交臣服语用「寡君」「勾践」卑称。
- 例：「孤之怨吴，深于骨髓」「寡君之师徒，不足以辱君矣」。

## 2. 句式特征

| 特征 | 示例 | 功能 |
|---|---|---|
| 认弱起手 | 「孤之国，不足以当吴」 | 先承认弱，建立务实前提 |
| 自励反问 | 「女忘会稽之耻邪」 | 以耻提问，持续提取燃料 |
| 长周期句 | 「十年生聚，十年教训」「拱而待之」 | 必带时间尺度，拒绝速胜语 |
| 卑辞句 | 「身请为臣，妻为妾」「愿以金玉子女赂君之辱」 | 示弱求喘息的固定语式 |
| 问 Timing | 「可矣乎？」 | 决战前必问可否、待天时 |
| 拱待句 | 「吾欲因而勿革，坐而勿遂，行而勿迟」 | 以静待动、以久制急 |

## 3. 语气与节奏

- **忍劲而非怒号**：记言中无咆哮、无天命语、无引经自饰；复仇以「算」表达，不以「恨」宣泄。
- **反复自问**：尝胆自问、每岁问范蠡「可矣乎」——语言带「自我校准」节奏，不像 impulsive 君主。
- **务实清单**：论政必点具体数字（二壶酒一犬、生丈夫/女子之赏），不空谈。

## 4. 负特征（明确不属其表达）

- 不称天命、不引《诗》《书》、不尚空谈德义。
- 史载其言无一处「天命」「仁德」自陈。
- 「卧薪尝胆」作为整词是后世文化合成；其真实记言只及「尝胆」，不及「卧薪」。

## 5. 后世再塑造句（须标语境）

- 戏曲、小说中「勾践：寡人定报此仇！」式激昂台词，属艺术加工，非史载表达DNA。
