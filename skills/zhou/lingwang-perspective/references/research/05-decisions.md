# 05 · 重大决策与历史转折（言行一致与否 / 事后反思）

> 调研目标：梳理周灵王在位可考的重大决策，评估其言行一致性与可观察之后果，区分「史料原文」与「框架推断」。灵王之世无开疆、改制之类大决策，其「著事」全系谷洛壅川一役；余者多为「守名分」之被动存续。

## 一、核心决策：壅谷水以保王宫

- **决策内容**：灵王二十二年（前 550），谷洛斗将毁王宫，王决意壅谷水、使东流于河以远王宫【史料原文：《国语·周语下》「王欲壅之」】。
- **言—行一致**：王「欲壅」即「卒壅之」，言与行高度一致——其护宫之念当即化为决断，不疑不辩【史料原文：《国语·周语下》「王弗听」「王卒壅之」】。
- **后果（分两层）**：
  1. 直接：壅川之工是否成、宫是否保，《国语》正文未明言「宫毁」；后世注疏与传说多传「谷洛竭、王宫室毁」或「壅竟成而水东入河」，可信度待核【框架推断 / 传说：见 06-timeline 互核】。
  2. 政治：太子晋「壅者亡、导者兴」之戒未用，王室失一可采之贤谋，且父子政见相左公开化【史料原文：太子晋谏 + 王弗听】。
- **事后反思**：灵王本人未见反思之载（无自责文、无改命诏）；仅「太子晋蚤卒」后，废储之事未竟。其「弗听」之果，史以「宫毁 / 水患」之传说显其偏，属后世追评，非王自省【框架推断】。

## 二、关联决策：拒太子晋之谏

- **决策内容**：面对长子以共工、鲧、禹为戒的长篇危言，灵王选择「弗听」【史料原文：《国语·周语下》】。
- **性质**：此为「护宫执见」压倒「顺水性之智」之取舍；亦可视为人主「不欲以子言易己断」之自尊——属决策中的价值排序，非单纯昏聩【框架推断：动机由叙事推】。
- **转折意义**：太子晋之贤未及用，且蚤卒；灵王后嗣景王亦微弱，「储贤不终」成东周王室之积弱节点之一【框架推断，见《左传·昭公》景王后事】。

## 三、被动存续：守名分、受朝聘

- **决策内容（非主动制）**：灵王以「受鲁襄公朝」「不预晋楚弭兵」之态存共主之名，未行制衡方伯之实策【史料原文：《史记·周本纪》朝周；《左传·襄公二十七年》弭兵】。
- **言行一致**：其「守礼存名」之取向与东周王室一贯姿态一致；然「名存实亡」之反差亦由是定局【框架推断】。
- **转折意义**：弭兵之会（前 546）由诸侯自盟，王室被置于局外，可视作「共主虚位」之一标志性转折——此非灵王之策所致，而为积势之显【框架推断】。
