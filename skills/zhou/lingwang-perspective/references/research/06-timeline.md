# 06 · 时间线（关键节点 + 对思维的影响 + 史料互核）

## 二、史料成书背景与互核

- **《国语》**：传统以为左丘明所传之国别史，记周鲁齐晋楚等八国事，去古未远；其《周语下》为灵王谷洛、太子晋事之近一手主源。韦昭（吴）注可参，注中「废太子」等说标推断。
- **《左传》**：编年体，起于隐公迄哀公（前 722–前 468），系灵王世于襄公诸年；于王室多作背景，与《国语》互补。
- **《史记·周本纪》**：西汉司马迁撰，东周本纪甚简，仅书朝聘、崩立；凡涉灵王细节，须以《国语》补。
- **《竹书纪年》**：战国魏史（古本佚，今本辑证）；其灵王诸条与《国语》谷洛事互证，可校系年，然今本真伪学界有争，仅作近一手参照。
- **《资治通鉴·周纪》**：宋司马光编年，胡三省注；系年录灵王世，与《国语》《左传》互证，未另立贬词。
- **互核结论**：
  1. 谷洛壅川、太子晋谏、王弗听——三源（国语 / 竹书今本 / 通鉴）互证，可信度高。
  2. 在位二十七年、太子晋蚤卒、景王立——《史记》与《左传·襄公二十八年》互校，可信度高。
  3. 「宫毁 / 谷洛竭」之结局——《国语》正文未明言，后世注疏与传说有传，标「传说待核」，本 Skill 不采为确据。
  4. 「生而有髭」「王子乔升仙」——志怪传说，非一手史实，已标传说分界。
