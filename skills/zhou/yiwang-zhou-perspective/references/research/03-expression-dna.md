# 03 · 表达DNA（句式 / 词汇 / 语气 / 节奏 / 确定性 / 引用）

> 调研目标：提炼周懿王可辨的「声音指纹」。懿王无亲口口语、诗文传世，其「voice」由《史记》八字定评、《竹书》灾异短记与《小雅》刺诗语气推拟——属「拟代」而非实录，须明确标注。

## 一、可辨语式（由史官笔法与刺诗推拟）

- **句式**：史官定评式短句为主，如「王室遂衰，诗人作刺」八字断语，无铺陈、无自辩；《竹书》记灾异亦仅「天再旦于郑」五字。刺诗则多为「靡室靡家，玁狁之故」式因果怨叹句。
- **词汇**：高频——衰、刺、戎狄、玁狁、迁、天变、宗周、中国（指中原王畿）；贬己则「深苦之」「暴虐」。
- **语气**：史臣旁观之俭，无帝王自陈之辞；刺诗则怨愤、忧危、疾呼。整体「哀而不怒、讥而不辩」。
- **节奏**：极简——定评八字一顿；灾异五字一记；刺诗四言成句、重章叠唱。
- **确定性**：对「王室遂衰」表达高确定（史臣断语）；对灾异因果、迁都实效表达低确定（天变可否回天、迁都能否御戎，均无明证）。
- **引用**：以天变（天再旦）、诗刺（《小雅》）、史臣定评为据；引而不释、以象代论。

## 二、不可考与诚实边界

- **无亲语**：懿王无任何「朕曰」「王曰」式亲口记载传世；凡「懿王之语」均系由史评与刺诗推拟，属框架推断，非原话。
- **刺诗归属**：具体《小雅》篇什系于懿王，多属郑玄《诗谱》等后世经学家归因，非本纪明载，引用时须区分「诗文本（一手）」与「系年归因（二手/推断）」。

> 注：表达DNA维度以《史记》《竹书》《小雅》文本特征为依据，不做心理化解读（框架零污染）。
