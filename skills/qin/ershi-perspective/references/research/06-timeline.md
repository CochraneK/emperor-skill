# 秦二世（胡亥）时间线底稿

> 关键节点 + 对思维的影响 + 史料成书背景与互核。区分【史料原文】与【框架推断】。

| 时间 | 事件 | 对思维的影响 |
|---|---|---|
| 前210 夏 | 【史料原文】始皇崩于沙丘，赵高、李斯矫诏立胡亥，赐死扶苏、蒙恬（《李斯列传》） | 胡亥以"少子得立"起，自始便依赖赵高、李斯，未建独立帝王判断 |
| 前210 秋 | 【史料原文】二世即位，尊赵高为郎中令（《秦始皇本纪》） | 决策权渐移赵高，形成"问赵高而后行"的思维惯性 |
| 前209 春 | 【史料原文】"复作阿房宫""征材士五万屯卫咸阳"（《秦始皇本纪》） | 纵欲与强征并行，民怨积累 |
| 前209 秋 | 【史料原文】陈胜吴广大泽乡起义（《陈涉世家》），天下响应 | 二世仍信赵高"此特群盗"之说，拒闻实情 |
| 前208 | 【史料原文】李斯下狱腰斩；赵高"指鹿为马"（《李斯列传》《始皇本纪》） | 信息彻底被赵高垄断，二世丧失现实感 |
| 前207 夏 | 【史料原文】巨鹿之战项羽破秦军（《项羽本纪》） | 秦主力尽丧，二世始惧 |
| 前207 秋 | 【史料原文】赵高弑二世于望夷宫，立子婴（《秦始皇本纪》） | 至死被动，乞为黔首而不得 |
| 前207 冬 | 【史料原文】子婴诛赵高；旋刘邦入咸阳，秦亡 | 二世朝三年而亡，秦祚终结 |

> 【框架推断】史料互核：《史记》始皇本纪、李斯列传、陈涉世家、项羽本纪互证二世朝事；《资治通鉴》秦纪沿《史记》编年而损益。胡亥其人记载较为单一（无独立本纪），多经赵高叙事折射，故其"真实意图"多为框架推断，须与史料原文严格区分。
