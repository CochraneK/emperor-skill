# 06 时间线 · 少康（夏·少康，约前20世纪，少康中兴）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **史料门禁**：夏属**传说/半信史**，**一切年代皆为"约"**。少康无同时代纪年；下表年代依《竹书纪年》辑本之干支纪年推数（"元年丙午"），属**后世推算**，仅备参照，不得当作确证。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前21世纪（帝相之时） | 后羿因夏民以代夏政；寒浞杀羿代之；浇灭斟灌、斟鄩，**杀夏后相**（背景） | 夏祀几绝之局自此成；少康日后一切作为皆以"续禹之祀"为题 |
| 约前21世纪末 | 相之妻后缗方娠，**逃出自窦，归于有仍，生少康**（《左传·哀元年》） | 生于亡国之隙，养成"存身先于复国"的底色 |
| 约前21世纪末（少康既长） | 为有仍氏**牧正**；浇使椒求之 | 初识"隐于卑职"可避祸；确立"不入强敌视野"之生存律 |
| 约前20世纪初 | **逃奔有虞，为之庖正**（以除其害）（《左传·哀元年》） | 弃小安、就大隐；卑职自污以换安全空间 |
| 约前20世纪初 | 虞思**妻之以二姚，而邑诸纶**，有田一成、有众一旅（《左传·哀元年》） | 由流亡者转为"有土有民"之据主；确立"最小据点起步"之复国策 |
| 约前20世纪初 | **能布其德，而兆其谋，以收夏众，抚其官职**（《左传·哀元年》） | 确立"以德聚人、以名分结众"的聚人术；复国从个人转为群体事业 |
| 约前20世纪初 | 夏遗臣**伯靡自有鬲氏收二斟之烬，以灭浞而立少康**（《左传·襄四年》） | 学会"借他人之刃"；甘居被迎立之位而不争首功 |
| 约前20世纪初 | **使女艾谍浇，使季杼诱豷**，少康灭浇于过、后杼灭豷于戈（《左传·哀元年、襄四年》） | 定型"先谍后战、分而破之"的用间代战之法 |
| 约前20世纪初 | 夏众灭浞，**奉少康归于夏邑**，诸侯**立为天子**，**复禹之绩，祀夏配天，不失旧物**（《左传·哀元年》） | 确立"以复旧取合法"之执政范式：一切新政皆挂于禹之旧制 |
| 约前20世纪（纪年推算作"元年丙午"） | **帝即位，诸侯来朝，宾虞公**（《竹书纪年》） | 以"朝会与宾礼"确认新秩序；报有虞氏之恩 |
| 约前20世纪（纪年"二年"） | **方夷来宾**（《竹书纪年》/《后汉书·东夷传》注引《纪年》） | 确立"和东夷"之策，为夏中兴之外部环境奠基 |
| 约前20世纪（纪年"三年"） | **复田稷**（《竹书纪年》；互证《国语·周语》"弃稷弗务"） | 以"恢复农官"为中兴之实；治国重心落在农事 |
| 约前20世纪（纪年"十一年"） | **使商侯冥治河**（《竹书纪年》） | 承禹之业而治水；用人于异族（商之先公），显其用人不论亲疏 |
| 约前20世纪（纪年"十八年"） | **迁于原**（《竹书纪年》） | 都城选择随势力扩展而调整；由纶而原，据地渐固 |
| 约前20世纪（纪年"二十一年"） | **陟**（《竹书纪年》）；异说：在位四十六岁（《路史·后纪》十三） | 年数异说并存，如实并列，不伪称定论 |
| 少康之世（约同期） | **封庶子无余于越，以奉守禹之祀**（《史记·越王勾践世家》《吴越春秋》） | 以其一生唯一主线——"恐禹祭之绝祀"——收束其执政 |
| 少康之后 | 子**帝予（杼）**继立；《国语·鲁语》："杼能帅禹者也，故夏后氏报焉。" | 其"复禹"之业由子继之，并由夏后氏世代报祭 |

## 二、史料成书背景与互核

- 【史料原文/一手】《左传·哀公元年》为少康事之**最早、最详**来源（春秋末，伍子胥追述）；《左传·襄公四年》载《夏训》与魏绛语，补"寒浞—后羿—有穷之亡"之背景，两处互校。此为**先秦一手层位**。
- 【史料原文/一手】《史记·吴太伯世家》全录伍子胥谏语，与《左传·哀公元年》异文互证；而**《史记·夏本纪》对少康仅"帝相崩，子帝少康立"一句**，不载寒浞之乱与复国曲折——此为本卷最须并列的一处**史料落差**。
- 【史料原文/一手】《楚辞·离骚》《天问》提供先秦对少康婚娶与用间事的**文学—诘问式**追述，可补细节，然含传说成分。
- 【史料原文/一手】《竹书纪年》（战国魏墓所出，今本为辑本）提供少康一朝的**编年条目**（元年丙午至二十一年陟），是年数之主要依据；然今本真伪有争议，须与《史记》《左传》互核。
- 【史料原文/一手】《国语·周语》（"弃稷弗务"）与《鲁语》（"杼能帅禹者也"）为春秋语文材料，分别与"复田稷""复禹之绩"互证。
- 【史料原文/一手】《史记·越王勾践世家》《吴越春秋》载"封无余于越以奉禹祀"，为少康晚年之举提供最早层位记载（《吴越春秋》为东汉，属后世追述）。
- 【史料原文/一手】考古：二里头文化（约前1750–前1530）、新砦期（约前1850–前1750）、王城岗遗址——为"夏文化"提供**物质线索**，然与少康个人**无直接对应**。
- 【互核结论】少康"生—长—奔虞—据纶—用间—灭过戈—复国—为政"主线在《左传》《史记·吴太伯世家》《竹书纪年》《楚辞》多层记中**方向一致**；唯**三处异说并列**：①《夏本纪》"相崩子少康立"之顺承继统说 vs《左传》亡国复国说；②在位二十一年 vs 四十六年；③少康是否即杜康。
- 【成书背景说明】少康事最早已见于**春秋末**（《左传》），距夏亡逾千年，属**追述性传说**，非同期实录；夏代无自证文字（甲骨文属商代，未及少康）。故本时间线之年代**全为"约"**，皆系后世推算。

## 三、小结

- 一手节点与互核均出《左传》《国语》《楚辞》《史记》《竹书纪年》及二里头/新砦/王城岗考古材料；三处异说如实并列。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
- **史料门禁声明**：少康属**传说/半信史**，材料有限；本卷年代皆带"约"字，**不得伪称一手确证**。
