# 06 时间线 · 夏桀（履癸，夏末代王，约前1650–约前1600）

> 维度定义：即位到崩的编年（上古多为"约前XXXX年"，须带"约"字），含史料成书背景与互核情况。
> **史料门禁：夏属传说/半信史，材料有限。桀无同期文字自证；本时间线的"年"分为两层——① 相对纪年（《竹书纪年》系统所记"帝癸某年"），② 绝对年代（依"夏商周断代工程"夏代约前2070—前1600之框架与"在位约五十年"推定，仅为近似）。两层皆须带"约"字，且异说并存。**

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1700前后（孔甲以来，背景） | 《国语·周语下》"孔甲乱夏，四世而陨"；《史记·夏本纪》"自孔甲以来而诸侯多畔夏" | 桀即位时夏室离心已成定局；其"重振"诉求即由此压力催生 |
| 约前1650（桀元年；《今本竹书纪年》作"元年壬辰"，另有推算为约前1589，见下"异说"） | 帝发崩，子履癸立，是为桀；"桀居斟鄩"（古本《竹书纪年》） | 还都太康旧都，选择"还旧都以振祖业"而非另营新邑，定其执政底色 |
| 约前1650—约前1645（即位初年） | 伐有施，"有施人以妹喜女焉"（《国语·晋语一》）；"筑倾宫，饰瑶台"（古本《竹书纪年》辑本） | 确立"以征伐取资（人/财）"的可复制路径；营建成为其"重振"的可见形式 |
| 约前1640（《今本竹书纪年》系于帝癸十一年） | "夏桀为仍之会，有缗叛之"（《左传·昭公四年》）；遂灭有缗，"桀克有缗以丧其国"（《左传·昭公十一年》） | 首度遭遇会盟场上的公开背弃，并以征伐回应；"胜一役而失诸方国之心"的模式自此固定 |
| 约前1637（《今本竹书纪年》系于帝癸十四年） | 伐岷山，"进女于桀二人，曰琬，曰琰……而弃其元妃于洛，曰末喜氏。末喜氏以与伊尹交，遂以间夏"（古本《竹书纪年》）；《韩非子·难四》"桀索岷山之女而天下离" | 内廷分配失衡，被弃者转为敌方内应；"外部索取→内部裂隙"路径成型 |
| 约前1629（《今本竹书纪年》系于帝癸二十二年） | "乃召汤而囚之夏台"（《史记·夏本纪》；夏台一作钧台，地在阳翟一带） | 已准确识别对手，并完成处置动作——确定性最强的一次决策 |
| 约前1628（《今本竹书纪年》系于帝癸二十三年） | "已而释之"；"汤修德，诸侯皆归汤"（《史记·夏本纪》） | 半处置：既未彻底解决，也未转为同盟；为对手留下复仇记忆，亦为其自身留下"悔"的伏笔 |
| 约前1622—约前1620（《今本竹书纪年》系于帝癸二十八年至三十年） | 昆吾伐商；太史令终古"出其图法，执而泣之……出奔如商"（《吕氏春秋·先识》）；"桀囚而杀之"（关龙逄，见《韩诗外传》卷四）；"瞿山崩"（今本《竹书纪年》） | 掌法典者出走、直谏者见杀，信息通道彻底封闭；此后君臣之间只剩顺诺 |
| 约前1619（《今本竹书纪年》系于帝癸三十一年） | "商自陑征夏邑，克昆吾。大雷雨，战于鸣条。夏师败绩"（今本《竹书纪年》）；《尚书·汤誓》"遂与桀战于鸣条之野"；《史记·殷本纪》"桀败于有娀之虚，桀奔于鸣条" | 战场判定败局；决策空间由"守天下"转为"走与保" |
| 约前1619（其后，同段） | "桀出奔三朡……获桀于焦门，放之于南巢"（今本《竹书纪年》）；古本《竹书纪年》"汤遂灭夏，桀逃南巢氏"；《史记·夏本纪》"桀走鸣条，遂放而死" | 终局：以"逃走—被擒—被放"收束。同期留下唯一自述——"吾悔不遂杀汤于夏台，使至此" |
| 约前1600（框架年代，异说见下） | "汤乃践天子位，代夏朝天下。汤封夏之后，至周封于杞也"（《史记·夏本纪》） | 夏祚终；"桀"自此成为后世"暴君—亡国"的镜鉴原型 |

## 二、异说并存（不强行调和）

1. **元年与在位年数异说**
   - 古本《竹书纪年》辑本仅存"桀居斟鄩""后桀伐岷山……""汤遂灭夏，桀逃南巢氏""自禹至桀十七世，有王与无王，用岁四百七十一年"，**未存桀之元年与在位年数**。
   - 今本《竹书纪年》有"帝癸元年壬辰"及逐年记事（三年筑倾宫、十一年会诸侯于仍、十四年伐岷山、二十二年囚履、二十三年释履、二十八年终古奔商、三十年杀关龙逄/瞿山崩、三十一年鸣条之战）。今本真伪有争议，多数学者视为后世辑补，本 Skill 使用时逐条标注。
   - 流行读物常称桀"在位五十三年"或"五十二年"，属据今本推算，**不可作定论**。
2. **绝对年代异说**
   - "夏商周断代工程"（1996—2000）据文献积年与登封王城岗、禹州瓦店、新密新砦等遗址AMS测年，定夏代约前2070—前1600年；若取桀在位约五十年，则桀约当前1650—前1600年在位。本 Skill 采用此近似框架。
   - 古本《竹书纪年》"自禹至桀十七世……用岁四百七十一年"，与"汤灭夏以至于受，二十九王，用岁四百九十六年"、"自武王灭殷以至幽王，凡二百五十七年"合推，有学者得出夏代约前1994—前1523年（夏商分界前1523年）；亦有取商积年526年而得出夏约前2024—前1553年、或约前2043—前1572年者。
   - 结论：桀之绝对年代在约前1650—前1600（断代工程框架）与约前1589起算（今本《竹书纪年》"元年壬辰"的换算）诸说之间摆动，**本 Skill 一律用"约"**。
3. **终局异说四说并列**
   - ①《史记·夏本纪》："桀走鸣条，遂放而死。"
   - ②古本《竹书纪年》："汤遂灭夏，桀逃南巢氏。"
   - ③《荀子·解蔽》："桀死于亭山。"
   - ④《史记正义》引《淮南子》："汤败桀于历山，与末喜同舟浮江，奔南巢之山而死。"
4. **定都地望异说**
   - 斟鄩地望，学界多系于河南偃师二里头遗址；古本《竹书纪年》"太康居斟鄩，羿亦居之，桀亦居之"与二里头"第二期始为王都、第三期为王都顶峰"的考古分期可相参，但**无同期文字可确证**；另有学者据《左传》《竹书纪年》把夏之重心置于山东（斟鄩在潍坊、有仍之会/有缗在鲁西）一说。

## 三、史料成书背景与互核

- 【史料原文/一手】《史记·夏本纪》为桀事主源，其桀段极简（约五十字），仅载：继统、不务德武伤百姓、囚汤释汤、走鸣条放而死、悔言、汤代夏。**不载**妹喜、酒池、关龙逄、终古。
- 【史料原文/一手】《尚书·汤誓》为商书篇，提供"鸣条之野"的战场名与"时日曷丧"民语；其誓辞立场在汤一侧。
- 【史料原文/一手】古本《竹书纪年》（王国维《古本竹书纪年辑校》辑本，今存条目为类书引文）：提供斟鄩、伐岷山、琬琰、弃元妃、末喜间夏、倾宫瑶台、桀逃南巢氏、夏积年471年。属战国魏史系统，与《史记》多有互异（如"夏年多殷"）。
- 【史料原文/一手】《左传》昭公四年、昭公十一年、宣公三年：提供为仍之会、有缗之叛、克有缗以丧其国、桀有昏德鼎迁于商。
- 【史料原文/一手】《国语·晋语一》《周语下》：提供伐有施、妹喜亡夏、孔甲乱夏四世而陨。
- 【史料原文/一手】二里头遗址（河南偃师）考古报告与测年数据：提供"王都级都邑 + 宫殿 + 青铜作坊"这一可验证层面；一期约前1780—前1708、四期约前1557—前1512（断代工程区间）；2005年后"系列拟合"另得约前1750—前1500。
- 【史料原文/一手】西周中期豳公盨铭"天命禹敷土，墮山濬川"、春秋秦公簋"鼏宅禹迹"、叔夷镈钟"处禹之堵"、清华简《厚父》《四告·四》：证明"禹—夏"观念在西周已流行；**但均未见"桀"名**。
- 【史料原文/二手】《荀子·解蔽》《韩非子·难四》《吕氏春秋·先识/慎大》《韩诗外传》卷二卷四、《新序·刺奢》《淮南子》：提供"末喜/斯观—关龙逄—终古"的贤谗对置、酒池糟堤、日喻、死于亭山、同舟浮江等叙述。
- 【史料原文/一手】《史记》三家注与中华书局点校本校勘记：提供夏台/鸣条/南巢地望与"十七君十四世、四百七十一年"的异说汇总。
- 【互核结论】
  - 三史一致者：桀为履癸、帝发之子、夏末代王；汤伐桀、鸣条之败、夏亡、汤封夏后于杞。
  - 互异者：亡因叙述（《史记》仅"不务德"vs 后世加妹喜/酒池/关龙逄）；终局（放死/逃南巢/死亭山/浮江）；年代与在位年数；定都地望。**均并列保留，不强行调和。**
- 【成书背景说明】桀之全部材料成书年代均晚于事件一千余年至一千五百年以上：最早为春秋《左传》《国语》《论语》，其次战国《孟子》《荀子》《韩非子》《竹书纪年》《吕氏春秋》《天问》，再次西汉《史记》《韩诗外传》《新序》《淮南子》。司马迁据秦记、诸侯史记等成《本纪》，其桀段极简，恰说明西汉时可信材料已极稀薄——后世愈详，正是"层累"之证。

## 四、小结

- 相对纪年（帝癸某年）可核互异之处已逐条标注；绝对年代一律带"约"，并给出至少三种异说。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史料明言；"缺字"一事本身也提示，此人之"思想"当视为**由后世文本反推的模型，而非可核实的心史**。
