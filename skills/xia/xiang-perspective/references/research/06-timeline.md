# 06 时间线 · 夏·相（帝相，仲康之子，约前 19 世纪，传说/半信史）

> 维度定义：即位到崩的编年（上古多为"约前 XXXX 年"，须带"约"字），含史料成书背景与互核情况。
>
> **绝对年代不可定之前提**：夏代无确年可考。本表采两条锚定法并列：(1) **夏商周断代工程**推定夏代始年**公元前 2070 年**、积年**前 2070—前 1600 年**；(2) 考古学**新砦期**（约**公元前 1900—前 1800 年**）被学界推定为"**太康失国—后羿代夏**"阶段之夏文化。帝相处于此二者之间，故本表以**"约前 19 世纪"**为主坐标，具体年份系**据今本《竹书纪年》在位二十八年之相对年数推算所得，属示意，非定点**。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前 19 世纪前段（背景） | 太康失国，"**后羿自鉏迁于穷石，因夏民以代夏政**"（《左传·襄公四年》引《夏训》）；昆弟五人须于洛汭（《史记·夏本纪》） | 帝相尚未即位，夏统已被架空；他后来"守名而不争实"的底色，源自这个"名实已分"的起点 |
| 约前 19 世纪前段（背景） | 仲康立，"羲、和湎淫，废时乱日，胤往征之，作《胤征》"（《史记·夏本纪》）；仲康崩 | 夏廷在帝相之前已无力自振；帝相继承的是一个**只剩名号的王朝** |
| 约前 1870（相元年；今本《竹书纪年》系"元年戊戌"） | **帝相即位，居商丘**（古本《竹书》"后相即位，居商丘"） | 受立于权臣已成之势，即位与东退几乎同时；"**守名—避锋**"基调自此确立 |
| 约前 1870—约前 1862 | 居商丘约八年余 | 远离后羿所据之斟寻（斟鄩），以空间换取不被直接吞并的时间 |
| 约前 1862（相九年；今本） | **相居于斟灌**（古本《竹书》"相居斟灌"） | 移入同姓（姒姓）诸侯之地——"**依同姓以自固**"之策落地，其国防线由城墙变为血缘 |
| 约前 1861 前后 | **寒浞杀后羿**，使其子浇居过、豷居戈（今本《竹书》系"八年，寒浞杀羿，使其子浇居过"；《左传·襄公四年》详载浞"因羿室，生浇及豷"） | 强臣由一代转为二代；夏后之局由"被架空"恶化为"被取代" |
| 约前 1845（相二十六年；今本） | **寒浞使其子浇帅师灭斟灌** | 东方屏障尽失，帝相失去可依之国的第一层 |
| 约前 1844（相二十七年；今本） | 浇伐斟鄩，"**大战于潍，覆其舟，灭之**"（《楚辞·天问》"**覆舟斟寻，何道取之**"即指此役；《左传·哀公元年》作"杀斟灌以伐斟鄩"） | 二斟尽亡，同姓依托彻底崩溃；其"退"已无可再退 |
| 约前 1842（相二十八年；今本） | **寒浞使其子浇弑帝**；"**后缗方娠，逃出自窦，归于有仍**"（《左传·哀公元年》；今本《竹书》"后缗归于有仍"） | 帝相死，夏统中绝；他留给历史的不是遗言，而是一线血脉与一地遗民 |
| 约前 1842 之后 | 后缗生**少康**于有仍；夏臣**靡**奔有鬲氏，"**收二国之烬**"（《左传·襄公四年》） | 复国之业转入下一代与旧臣之手；帝相本人未留下任何指令 |
| 约前 1802 前后（张守节《正义》引皇甫谧《帝王世纪》："帝相被篡，历羿、浞二世，**四十年**"） | **少康与靡灭浞**，立少康，"复禹之绩，祀夏配天，不失旧物"（《左传·哀公元年》）——史称"**少康中兴**" | 帝相之死于此时才被"回填"出意义：他是复国的**前提**，而始终不是复国的**主角** |
| 近现代（考古分期） | **新砦期**（约前 1900—前 1800，以河南新密新砦城址、巩义花地嘴、郑州东赵为代表）被李伯谦等推定为"**太康失国—后羿代夏**"时期之夏文化；其遗存中**突增大量东方（海岱）文化因素** | 帝相之世获得**实物层面的间接对应**；然而**无一件器物、一片文字可系于帝相名下**——考古能证"其时其地有事"，不能证"其人之心" |

## 二、史料成书背景与互核

- 【史料原文/一手】**《史记·夏本纪》**（西汉·司马迁）为夏史主源，然对帝相仅"中康崩，子帝相立。帝相崩，子帝少康立"十字，**未载羿、浞篡夏四十年之事**。此为后世一切争议的起点。
- 【史论/二手】**张守节《史记正义》**（唐）直指此缺："帝相被篡，历羿、浞二世，四十年，而此纪不说，亦马迁所为疏略也"（引皇甫谧《帝王世纪》为据）。**唐人已认定《史记》此处失载。**
- 【史料原文/一手】**《左传》**两处为羿浞之事的最早详细叙述：**襄公四年**魏绛引《夏训》述后羿代夏、寒浞篡羿、浇灭二斟、靡立少康之全链；**哀公元年**伍员述"浇杀斟灌以伐斟鄩，灭夏后相"，并接叙后缗逃窦、少康中兴。**此为帝相结局最具体的先秦记载。**
- 【史料原文/一手】**《楚辞·天问》**"覆舟斟寻，何道取之"、**《离骚》**"浇身被服强圉兮"——战国楚辞以文学形式保存了"浇灭斟鄩、覆其舟"之役与浇之形象，可作旁证。
- 【史料原文/一手·真伪须辨】**《竹书纪年》**系统为帝相提供最完整的编年（居商丘、居斟灌、灭斟灌、弑帝、后缗归有仍）。**然须辨古本/今本**：古本（清·朱右曾《汲冢纪年存真》、王国维《古本竹书纪年辑校》所辑）仅存"后相即位，居商丘""相居斟灌"等残句；**今本为明代辑本，清人及王国维等已辨其为后人缀合增益，其独有之在位二十八年及干支系年，只可作"相对先后"看，不可作定点。**
- 【史料原文/一手】**杜预《春秋左传集解》**僖公三十一年注"相，夏后启之孙，居帝丘"，补出帝相都邑之一；《左传》该年"卫迁于帝丘……卫成公梦康叔曰'相夺予享'"则以春秋人事反证帝丘为帝相故都。
- 【史料原文/一手·考古】**夏商周断代工程**推定夏代始年前 2070 年、积年前 2070—前 1600 年；**新砦期**（约前 1900—前 1800）与**二里头文化时期**（约前 1800—前 1600）构成夏文化主体序列，学界主流认为二里头遗址即文献之"斟鄩"（夏代中晚期都城）。
- 【互核结论】
  - **可互核者**：帝相"受立—东迁—被灭—被弑—后缗逃—少康复国"之事件链，在《左传》襄四年、哀元年与《竹书纪年》系统中**结构一致，可视为同一传说的两条独立记录**（《史记》略去其详）。
  - **不可裁断者（并列不调和）**：(1) **在位年数**：今本《竹书》作二十八年 vs《史记》不记年 vs 古本无年数；(2) **世系写法**：《史记》"中康崩，子帝相立。帝相崩，子帝少康立"呈父子相承之序 vs《左传》《竹书》"羿浞篡夏四十年"之中断叙事——**二者是不同的史源，本 Skill 不强行调和**；(3) **年代归属**：二里头＝斟鄩说 vs 帝相之世属新砦期之考古分期，学界仍无定论；(4) **都邑**：商丘、斟灌、帝丘三地孰为主要都城，文献互有出入。

## 三、小结

- **一手节点与互核**：事件链主干出《左传》《竹书纪年》，旁证出《楚辞》《史记》与杜预、张守节注；考古框架出夏商周断代工程与新砦期、二里头遗址报告。
- **框架推断**：表中"对思维之影响"一栏**全部为基于史事的归纳推断**，非史书明言；"约前××××"之具体年份系据今本《竹书》相对年数推算之示意，**夏代绝对年代学界无定论，本表不作定点**。
- **必须承认者**：帝相在位二十八年（若信今本）而**无一年有可考之自主作为**；其时间线的密度，远低于其后任何一位夏王。**这份"低密度"本身即是他的历史特征。**
