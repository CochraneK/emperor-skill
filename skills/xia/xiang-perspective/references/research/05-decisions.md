# 05 决策记录 · 夏·相（帝相，仲康之子，约前 20 世纪，传说/半信史）

> 维度定义：其征伐、迁都、继统、用人等重大决策及事后评说。
>
> **本份前提**：帝相的决策清单**极短**——史册可考者，主要是**继统（受立）**与**迁都（居商丘—居斟灌—帝丘）**两类，另有一类**"不决策"**（不战、不盟、不降）须一并计入。凡涉其"征伐"者，仅有今本《竹书纪年》"征畎夷""征风夷及黄夷"等零星记载，且属真伪有辨之今本系统，**只能低置信度列入**。所有决策条目均须与"其决策所依赖的实况"合看——因为帝相诸决策的被动性，正是其决策史的本质。

## 一、继统决策：受立于权臣之手（被动继统）

- 【史料原文/一手】《史记·夏本纪》：「中康崩，子帝相立。」——继统本身依"父死子继"之常序，文献无异辞。
- 【史料原文/一手】《左传·襄公四年》魏绛语："昔有夏之方衰也，后羿自鉏迁于穷石，**因夏民以代夏政**。"——帝相之立，正当"后羿代夏"已成事实之后。**他的继统不是"取得权力"，而是"接收一个已被架空的王位"。**
- 【框架推断】**此决策的实质是"接受"而非"选择"**：他既无力拒绝权臣所立之位，亦无实力另起一局。**承认此位，等于承认"我要在这个框架里活下去"；拒绝此位，则连"夏后"之名亦失。**由他终身守"夏后"之号不辍可推，他选择了前者。此为框架推断。
- 【史论/二手】今本《竹书纪年》系其"元年戊戌，帝即位，居商丘"——即位之初即"居商丘"（今河南商丘一带），**离后羿所据之斟寻（斟鄩）向东退避**。若此记载可信，则"即位"与"东迁"几乎是同一动作，**其继统决策自始即含"避"的成分**。

## 二、迁都决策：三迁以避（其决策史的核心）

这是帝相唯一有连续线索的自主决策序列。**每一次迁都，都是在"对手逼近"与"同姓可依"两个约束下做出的。**

**（1）居商丘——即位之初的东退**
- 【史料原文/一手·古本】古本《竹书纪年》："**后相即位，居商丘。**"（今本作"元年戊戌，帝即位，居商丘"）
- 【框架推断】商丘在东、斟寻在西；由西向东，是"退"不是"进"。此退有三重用意（推得）：远后羿之锋、就东夷之地、就同姓之援。**此推断史无明文。**

**（2）居斟灌——约九年后再迁**
- 【史料原文/一手·古本】古本《竹书纪年》："**相居斟灌。**"（今本作"九年，相居于斟灌"）
- 【史料原文/一手】斟灌氏为夏同姓（姒姓）之国，与斟鄩氏并称"二斟"。《左传·襄公四年》"使浇用师，**灭斟灌及斟寻氏**"、哀元年"浇**杀斟灌以伐斟鄩**"，皆以二斟并称，可见其为夏后氏在东方最可依之同姓屏障。
- 【框架推断】**此迁是"退到亲戚家"。**在无兵可战之局中，**依附同姓诸侯是帝相能做的最高级别的"国防"决策**——他的国防线不是城墙，而是血缘。此为据《左传》《竹书》合推，非史书明言其谋。

**（3）居帝丘——最后的据点**
- 【史料原文/一手】杜预《春秋左传集解》僖公三十一年注：「**相，夏后启之孙，居帝丘。**」帝丘在今河南濮阳一带。
- 【史料原文/一手】《左传·僖公三十一年》：「卫迁于帝丘。……卫成公梦康叔曰：'相夺予享。'」——春秋时卫人迁帝丘，梦与"相"争祭祀，说明**帝丘在后世记忆中确属帝相之故都**，其地位之牢固可见。
- 【框架推断】商丘 → 斟灌 → 帝丘，三点皆在豫东—豫东北一线，**构成一条清晰的自保移动路线**。这是一次"不争而走"的决策延续，而非三次孤立的位移。

## 三、"不决策"作为一种决策：不战、不盟、不降

帝相决策史中最重要、也最难证明的一项，是**他始终没有做的那些事**。

- 【框架推断】**不组织可考的反攻**：传世文献中找不到帝相召集诸侯、兴师讨羿或讨浞的任何记载。与之对照，夏初启有"甘之战"、夏末桀有"有娀之虚"之战、其子少康有灭过灭戈之役。**帝相之世，夏后氏无一战可述。**
- 【框架推断】**不向篡统者盟、不与之通使**：后羿"因夏民以代夏政"、寒浞"因羿室"而立，二者皆未闻得帝相的承认或会盟。**"不承认"是他在实力全失之后唯一还能行使的权力。**
- 【框架推断】**不出奔外国以求救**：太康失国是"出奔"（《史记》"太康失国，昆弟五人，须于洛汭"），夏桀亡国是"出奔三朡"。**帝相既不奔，也不降，而是选择留在同姓之地直到被杀。**此为其决策风格中最具张力的一点：他既不认输，也不反抗；**他选择的是"在自家门口待着"。**
- 【框架推断】综上，帝相的"不决策"实为一种低烈度抵抗：**把冲突的烈度压到最低，把时间拉得最长，把复国的希望留给后代。**此为全篇最强的框架推断，须在角色扮演中明示其非史载。

## 四、托嗣：其决策史中唯一"成功"的一项

- 【史料原文/一手】《左传·哀公元年》伍员语："……**灭夏后相**。**后缗方娠，逃出自窦，归于有仍，生少康焉。**"
- 【史料原文/一手·今本】今本《竹书纪年》："二十八年，寒浞使其子浇弑帝。**后缗归于有仍。**"
- 【史料原文/一手】《左传·襄公四年》魏绛语："……**靡自有鬲氏，收二国之烬，以灭浞而立少康。**"
- 【框架推断】帝相之妃后缗（有仍氏之女）在被弑之际怀孕逃归母家，生下少康；夏臣靡则逃奔有鬲氏，收斟灌、斟鄩二国之遗民，最终与少康合力灭浞复国。**帝相本人在其中未留下任何决策指令**——但"复国"这件事终究发生了。**这一项的"成功"须归功于后缗的逃、靡的守、少康的谋，而非帝相的筹画；把功劳全归帝相，是后人的追赠。**此为框架推断，且是**对帝相不利方向的推断**，仍须照实写出。

## 五、事后评说：三重评价并存

- 【史论/二手】**《史记》式评价：不评。** 司马迁以十字了之。**沉默的史笔本身就是一种评价——他认为无可述。**
- 【史论/二手】**张守节式评价：为帝相鸣不平。** 《正义》："帝相被篡，历羿、浞二世，四十年，而此纪不说，亦马迁所为疏略也。"——**过失在史家，不在帝相。**
- 【史论/二手】**通说式评价：帝相是"夏唯一被弑之君"，是夏统中断的承担者。** 后世多以"羿浞乱夏"称此四十年，而以帝相为其轴心人物。
- 【框架推断】**本 Skill 的取舍**：并存三者，不裁断。**帝相究竟是无能之君、是时运不济之君、还是史家失载之君，"材料不够，不能定"。** 本 Skill 只能呈现其决策的"结构"（受立—东迁—不争—待复），不能判定其"质量"。

## 六、小结（一手 vs 框架）

- **一手素材（史料原文）**：继统（《史记·夏本纪》）；迁都（古本《竹书纪年》"居商丘""居斟灌"、杜预注"居帝丘"）；被弑与托嗣（《左传》哀元年"灭夏后相……生少康焉"、襄四年"靡……立少康"、今本《竹书》"后缗归于有仍"）。
- **低置信度条目**：今本《竹书纪年》"征畎夷""征风夷及黄夷""于夷来宾"等——**属真伪有辨之今本系统，且与"帝相无力自主"的整体形象相矛盾，本 Skill 仅列出而不据以立论。**
- **框架推断（逐条已标）**：受立之被动性、三迁之"避—依—守"结构、"不战不盟不降"作为低烈度抵抗、托嗣之成功不应全归帝相。
