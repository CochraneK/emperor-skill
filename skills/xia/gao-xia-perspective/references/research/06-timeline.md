# 06 时间线 · 皋（夏·帝皋／昊／简皋，孔甲之子）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **纪年纪律（须先声明）**：夏代**有世无年**。《夏商周年表》（夏商周断代工程，2000）仅给出夏代整体为**约前2070—前1600**，未给任何单一夏王在位年代。故本表一切年份**一律标"约"**，且不自行推算皋之具体年份。夏史属**传说／半信史，材料有限**。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前17世纪（孔甲之世） | 孔甲继位，"好方鬼神，事淫乱。夏后氏德衰，诸侯畔之"；孔甲元年废豕韦氏，使刘累豢龙 | 皋继位时承的是一个**已被父辈败过的摊子**；"诸侯畔之"是其后一切决策的前提 |
| 约前17世纪（孔甲九年） | 孔甲陟；"殷侯复归于商丘"（商部族重回商丘经营） | 商在东方的复苏与夏室的衰落同步发生；皋所处的窗口期由此开始收缩 |
| 约前17世纪（皋元年） | 《竹书纪年》系"元年庚辰"，帝即位；**使豕韦氏复国**；此后"昆吾、豕韦相继为伯" | 定其执政底色：**以"复"代"革"、以名分假手强藩**——补前任的窟窿，同时让出权力 |
| 约前17世纪（皋在位三年，一说十一年） | "三年，陟"（《竹书纪年》）／"在位十一年"（《通鉴外纪》《路史》《册府元龟》《纲鉴易知录》） | **短祚**。史仅八字"孔甲崩，子帝皋立。帝皋崩，子帝发立"——在位长度虽有异说，"事功记载极薄"则两说一致 |
| 约前17世纪（帝发之世） | 发元年"诸夷宾于王门，再保墉会于上池，诸夷入舞"；发七年陟，"泰山震" | 皋之子一代仍维持东方朝贡与礼乐往来，但天变（泰山震）与边患并见；礼到而令不至 |
| 约前17世纪（桀之世） | "自孔甲以来而诸侯多畔夏"；桀召汤囚于夏台、已而释之；汤伐桀，战于鸣条，桀奔南巢，夏亡 | 皋所处下滑曲线的终点。**孔甲→皋→发→桀**四代，在《夏本纪》中被写成一条因果链 |
| 前628年（春秋·鲁僖公三十二年） | 秦师袭郑，蹇叔哭送，曰"晋人御师必于殽……其南陵，夏后皋之墓也"；次年晋败秦师于殽 | 皋之名因《左传》而成为先秦**最确切的地理坐标**之一；亦载明其为"夏桀之祖父"（杜预注） |
| 战国 | 《国语·郑语》史伯追述"昆吾为夏伯矣"，把昆吾、豕韦列入"五伯"之说 | 皋之"复国—为伯"政策，在战国话语中已成可援引的先例 |
| 1959年（现代） | 徐旭生调查夏墟时专程赴河南三门峡陕州区雁翎关考察"夏后皋墓"；20世纪50—60年代郭沫若、夏鼐认为皋死葬此地之说可信 | 传说中的皋墓进入现代考古视野；但至今**未有发掘证实其为夏代王陵** |
| 1996—2000年（现代） | 夏商周断代工程公布《夏商周年表》：夏代约前2070—前1600，未给单王年代 | 皋之确年**在现有学术条件下不可定**；本 Skill 一切年月皆标"约" |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·夏本纪》（西汉·司马迁，卷二）为皋事主源之一，仅两句世系；其价值在于把皋嵌入"孔甲以来诸侯多畔夏"的下滑叙事。
- 【史料原文/一手】《左传·僖公三十二年》（先秦）为**年代最早、也最确切**的皋之记录，且是唯一给出其实体痕迹（墓址）的先秦文献。杜预（西晋）注："皋，夏桀之祖父。"
- 【史料原文/一手】《今本竹书纪年·帝昊》（题梁沈约注、明范钦订，王国维《疏证》本）给出皋之唯一施政动作"使豕韦氏复国"与"三年陟"。
- 【史料原文/一手】《太平御览》卷八二《皇王部》引《古本竹书纪年》："后昊立三年。（帝皋也。）"——古本与今本在"三年"上互证。
- 【史料原文/一手】《史记索隐》引《世本》"帝皋生发"——以先秦谱牒印证《夏本纪》世系；《史记集解》引《左传》"皋墓在肴南陵"。
- 【史论/二手】《通鉴外纪》（北宋·刘恕）、《路史·后纪》（南宋·罗泌）、《册府元龟》卷一（北宋）、《纲鉴易知录》（清）为皋补出在位年数与元年干支，且**互不相同**（十一年 / 十一年 / 十一年 / 癸酉元年十一年）。
- 【互核结论】**世系一致**（孔甲→皋→发→桀，见《夏本纪》《世本》《竹书纪年》三系）。**在位年数存两说**（三年 / 十一年），**元年干支存三说**（庚辰 / 乙未 / 癸酉）。**墓址一致指向崤山南陵**（《左传》《集解》《括地志》）。
- 【成书背景说明】《史记》成于西汉，距夏已远，所据为《尚书》《世本》及战国传闻；《竹书纪年》出汲冢（西晋太康年间），为战国魏人所记，今本经后人变改（王维《疏证》已辨其非尽汲冢之旧）。**两书对皋之记载都极简，故不能因其"出于古书"即当一手确证。**

## 三、小结

- **一手素材**：孔甲废豕韦氏与皋复豕韦氏（《竹书纪年》两代对照）、殷侯复归商丘（《竹书纪年》孔甲九年）、诸夷宾于王门（《竹书纪年》帝发元年）、诸侯多畔夏与桀亡（《夏本纪》）、皋墓在殽南陵（《左传》《集解》《括地志》）、断代工程年表与雁翎关墓址调查。
- **框架推断**：表内"对思维之影响"一栏全部为基于史事的归纳推断，非史书明言；"皋—发两代不启大衅"亦为推断。
- **纪年纪律复述**：凡本表年月，**皆为"约"**；不得据本表生成任何皋之具体公元年份。
- **排除声明**：本份未引用知乎、微信公众号、百度百科。
