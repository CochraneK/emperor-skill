# 06 时间线 · 夏·杼（帝杼/帝予，少康之子，约前19世纪）

> 维度定义：即位到崩的编年 + 对思维的影响，含史料成书背景与互核情况。
> **本档案性质：夏属传说/半信史，材料有限。** 上古纪年多元确年，本表**一律冠"约"字**。夏商周断代工程仅给出夏代整体范围"约前2070—前1600"（推定值），**未逐王排定绝对年代**；本表所系之年为依通行夏代积年（约四七一年、十七王）与《竹书纪年》辑本条次作出的**推估值**，非确证。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前20世纪（太康—相之世） | 太康失国，后羿代夏；后羿弃武罗、伯因、熊髡、尨圉而用寒浞，终被杀；寒浞因羿室，生浇、豷，灭斟灌、斟寻（背景） | 杼未亲历，然"恃技弃贤者亡、恃诈不德者亦亡"之两重教训，构成其日后"作甲强兵、帅禹立德"两面并行的远因 |
| 约前1950前后 | 后缗逃出自窦，归有仍，生少康 | 杼之出身即"流亡中的夏室"，其思维底色是"复国"而非"守成" |
| 约前1940前后 | 少康奔有虞，虞思妻以二姚，邑诸纶，「有田一成，有众一旅」 | 兵微地寡之局，决定了夏室只能用"谋"——杼"诱豷"之术源出于此 |
| 约前1930前后 | 少康「布其德、兆其谋、收夏众、抚官职」；**使女艾谍浇，使季杼诱豷**，遂灭过、戈，复禹之绩 | 杼由受命副手转为功业当事人；"以诱代攻、以术补兵"之思维定型 |
| 约前1930前后 | 「祀夏配天，不失旧物」——少康复国、夏室祀统重建 | 杼亲历"复国"之艰，亦亲见"祀统"对政权之重；其日后受"报"祭之观念根源于此 |
| 约前19世纪初 | 少康崩，子予（杼）立，居原 | 由复国佐臣转为一国之主；思维重心由"夺回"转为"守住并推远" |
| 约前19世纪中（即位后约五年） | **自原迁于老丘** | 战略重心由豫西东移至豫东平原；思维由"守旧都"转为"移势就敌"，主动经营空间 |
| 约前19世纪中 | **作甲**（《世本·作篇》：「杼作甲」） | 确立"器利先于兵众"的技术优先观；与"诱豷"之术形成"术—器"两翼 |
| 约前19世纪中后 | **征于东海，及三寿，得一狐九尾** | 兵威东及海滨；以征伐与文化祥瑞并施，经营"绍述禹功"的正当性叙事 |
| 约前19世纪末 | 帝杼陟（《竹书纪年》辑本作在位十七年），子帝槐立 | 以"传子无争"完成承业；其东进布局留给下一代兑现 |
| 帝槐之世（约前19世纪末） | 《竹书纪年》辑本载帝槐（帝芬）之世「九夷来御」 | 杼之东征政策结为制度性的东方秩序——**收益在下一代结算** |
| 春秋之世 | 展禽论祀典：「杼能帅禹者也，夏后氏报焉」；《左传》哀公元年、襄公四年两述其"诱豷""灭豷于戈" | 身后被夏人列于三代仅三例的"报"祭之一；其价值判定为"能帅禹"而非"能守成" |
| 战国之世 | 魏史《竹书纪年》系其居原、迁老丘、作甲、征东海、十七年陟诸条 | 由祀典之褒转为编年之载；事迹被系统化，同时亦被纳入后出年表 |
| 西汉 | 《史记·夏本纪》仅存「帝少康崩，子帝予立。帝予崩，子帝槐立」十七字 | 正史对杼严重约省——其"功业"主要靠《左传》《国语》保存，非靠本纪 |
| 现代 | 二里头、王城岗、新砦、瓦店、东下冯等遗址发掘；夏商周断代工程推定夏代为约前2070—前1600 | 考古提供"夏文化"实物链，然**无一件可与"杼"其人确证对应**；甲骨、金文亦无其名 |

## 二、史料成书背景与互核

- 【史料原文/一手】《左传》哀公元年（伍员谏吴王）与襄公四年（魏绛谏晋悼公）为**最早、最系统的夏史追述**，两处互相印证杼"诱豷—灭豷于戈"之功；二文皆春秋时人对夏史的引述，距夏约千年，属"早期追述"而非同时代记录。
- 【史料原文/一手】《国语·鲁语上》展禽论祀典，保存"杼能帅禹者也，夏后氏报焉"一语，是**唯一一条对杼的正式价值判定**，出自春秋祀典系统。
- 【史料原文/一手·辑佚】《世本·作篇》「杼作甲」，原书已佚，经辑本与《史记索隐》征引而得；属先秦文献之辑佚，可信度较高而字句存疑。
- 【史料原文/一手】《史记·夏本纪》提供世系（少康→予→槐）与"帝予"之名，虽是正史，然于杼仅十七字，**信息量低于《左传》《国语》**。
- 【史料原文/一手·辑佚/文本警示】《竹书纪年》之"居原、迁老丘、作甲、征东海得九尾狐、十七年陟"诸条，为**最重要的行为细节来源**；然古本已佚、今本多疑为后人辑补或伪托（王国维《今本竹书纪年疏证》证其伪），所引多出《太平御览》卷八十二等类书。**属"战国史料之辑佚引文"，非同时代确证。**
- 【史论/二手】《帝王世纪》（皇甫谧）、《路史》（罗泌）、《括地志》（唐初）等后世书，增益演绎明显，仅作"后世如何想象杼"之参照，不取为事实源。
- 【互核结论】① 杼之名号：《史记》"予"、《左传》"季杼/后杼"、《世本》"杼/季伫"、《竹书纪年》"杼/宁"——**异写并存，本档案不调和**。② 杼之地位：《左传》"灭豷于戈"、《国语》"报焉"、《世本》"作甲"、《竹书纪年》"迁老丘、征东海"——**四系文献互证其"武功—承禹"之形象一致**。③ 杼之年数：仅《竹书纪年》一说（十七年），无他证，标为待核。
- 【成书背景说明】司马迁据《夏书》类文献与春秋战国追述成《夏本纪》，于无誓诰之夏王一律约省为世系；故"本纪简略"≠"其人无事"，而是**文体与材料所限**。

## 三、小结

- **一手节点与互核**：皆出《左传》《国语》《世本》《史记·夏本纪》《竹书纪年》辑本；名号与年数之异说如实并列。
- **框架推断**：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
- **纪年声明**：全表年代皆冠"约"字，为推定值；夏代绝对年代无确证底本。
