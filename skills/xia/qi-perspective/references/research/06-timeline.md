# 06 时间线 · 启（夏后帝启，约前2057–约前2038，禹之子）

> 维度定义：即位到崩的编年。
> **纪年门禁**：夏代绝对年代学界无定论。本表年份采夏商周断代工程推定框架（夏代始年约前2070，夏商分界约前1600）并配以团队约定刻度，**一律冠"约"字**，仅表相对先后，不作定点。启之在位年数有异说：今本《竹书纪年》作"十六年，陟"，皇甫谧《帝王世纪》一系作九年，另有二十九年、三十九年等说（皆后世编年）。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前2070（背景） | 禹受舜禅、夏后氏立国；"禹会诸侯于涂山，执玉帛者万国"一类会盟传统形成（《左传》哀公七年所引） | 启所继承的不只是一个"位"，而是一套已经用会盟与治水组织起来的广域秩序——这是"家天下"得以成立的物质前提 |
| 约前2060前后（背景） | 禹末之政局：授政于益，而"以启人为吏""势重尽在启"（《韩非子·外储说右下》）；一说"禹荐益于天，七年"（《孟子·万章上》） | 启所面对的接班格局从一开始就对他有利；其"受立"是结构性的结果，非孤身的夺权 |
| 约前2057 | 禹崩；三年之丧毕（《孟子》说），诸侯/朝觐讼狱者/讴歌者皆去益而就启——"吾君帝禹之子也"；启即天子位，是为夏后帝启（《史记·夏本纪》《孟子·万章上》） | 承统的合法性第一次由"贤"转到"子"：名分自此重于德行，这一转向是启全部执政逻辑的起点 |
| 约前2057（元年） | 帝即位于夏邑，大飨诸侯于钧台，诸侯从（今本《竹书纪年》）；《左传·昭公四年》追引"夏启有钧台之享" | 以仪式把"服从"变成可见之事：新政权首先需要的不是政令而是登场 |
| 约前2057–前2055（异说：益启之争） | 一说"益干启位，启杀之"（《古本竹书纪年》）；一说"启与友党攻益而夺之天下"（《韩非子》《战国策》）——与上条和平受立之说并存 | 同一件事三说并传，使"启之合法性究竟来自何处"成为他一生无法自证的问题；本 Skill 三说并列，不裁断 |
| 约前2056–约前2050 | 有扈氏不服，启伐之，大战于甘；将战作《甘誓》；遂灭有扈氏，天下咸朝（《史记·夏本纪》《尚书·甘誓》） | 以"恭行天之罚"为内战命名：此后"不服"不再是政治分歧，而是逆天——秩序由此做实，谈判余地亦由此消失 |
| 约前2048（十年） | 帝巡狩，舞九韶于大穆之野（今本《竹书纪年》）；神话层则作"开上三嫔于天，得《九辩》与《九歌》以下"（《山海经·大荒西经》） | 王权被挂上"通天"的背书：权威的来源从"天命所授"进一步变为"天物所取"，其文化资本亦成后世"纵乐"之口实 |
| 约前2047（十一年） | 放王季子武观于西河（今本《竹书纪年》） | 世袭制的第一笔副作用在内宅出现：位可传子，则诸子皆有份；启的处置是"移开"，而非"定分" |
| 约前2043（十五年） | 武观以西河叛；彭伯寿帅师征西河，武观来归（今本《竹书纪年》） | 流放之地成了叛乱基地，证明"移开矛盾"只能延迟冲突；对内无对话的执政方式在此显出代价 |
| 约前2040前后 | 墨子所见《武观》佚篇以"启乃淫溢康乐……天用弗式"为篇首之戒（《墨子·非乐上》引）；屈原《离骚》"启《九辩》与《九歌》兮，夏康娱以自纵。不顾难以图后兮，五子用失乎家巷" | 至少在先秦的两种传本中，启已从开国者变为"纵乐失度"的教材；其文化功业与道德罪证系于同一事 |
| 约前2038 | 启崩（今本《竹书纪年》作"十六年，陟"，另有在位九年、二十九年、三十九年等异说）；子帝太康立（《史记·夏本纪》） | 传子之制自此成为常例：启以"吾君之子"受位，又用同一原则授位——规则的第一次代际付账落在太康身上 |
| 其后（背景·启之决策的长程后果） | 太康失国，有穷后羿因夏民以代夏政；夏祚中断，至少康乃复（《史记·夏本纪》《左传·襄公四年》所引《夏训》） | 家天下并未带来稳定，只换了一种争夺的场域：从"异姓之争"变为"同姓内乱"（武观之于启，即其首例） |
| 后世（评价层） | 《礼记·礼运》以"天下为家"系于禹启之变；《孟子》以启为"贤，能敬承继禹之道"；《淮南子·齐俗训》以有扈氏为"知义而不知宜"；历代论者或以"定一统"誉之，或以"公天下之终"讥之 | 启成为两千年"权力交接正当性"讨论的公共案例，其形象随需要而被重述——本 Skill 存三说而不调和 |

## 纪年与史料说明

- 上述"约前××××"仅表相对先后与大致量级，**不作定点**。夏代王年无当时文字自证（二里头等遗址未出可解读之文书），一切年代皆为后世推定。
- 启之在位年数异说：今本《竹书纪年》"十六年，陟"；皇甫谧《帝王世纪》一系"在位九年"；另有二十九年、三十九年等说。本表取团队约定刻度"约前2057–约前2038"，仅作区间示意，不代表考订结论。
- 事件排序亦存异说：钧台之享与伐有扈氏之先后，不同辑本系年不一（有以钧台为元年、伐有扈氏为二年者，亦有反之者）；本表按"即位—会盟—征伐"之序排列，属叙述便利，非考订结论。
- 武观之乱系年取今本《竹书纪年》"十一年放—十五年叛"之说；今本《纪年》之真伪与系年，学界有争议，此处仅作一说记录。
- **传说/半信史声明**：夏属传说/半信史，材料有限；本表所据《史记·夏本纪》《尚书·甘誓》《竹书纪年》《孟子》《韩非子》《山海经》《墨子》《离骚》《淮南子》皆经后人转写或引述，二里头/王城岗/新砦等考古材料与启其人之间无直接文字对应，本底稿不伪称"一手确证"。
