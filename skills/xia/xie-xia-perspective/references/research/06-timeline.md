# 06 时间线 · 帝泄（夏·帝泄，芒之子，约前1903–约前1884）

> 维度定义：自即位到崩的编年。
> **门禁声明（记年纪律）**：夏属传说 / 半信史，材料有限，**其绝对年代不可确证**。本份采取三层标注：（一）**《竹书纪年》自身的在位年序**（可靠于相对先后，不可靠于绝对年代）；（二）**任务书 / 断代框架的近似年代**（一律带"约"字）；（三）**异说并列**，凡他书异文均于当行注出，不调和。
> 本份的"时间"列以《纪年》位序为主，绝对年代一律作"约前 19 世纪"级的近似；凡精确到年的数字，仅表示按其框架的推算，非确证。

## 二、帝泄之世（编年）

| 时间 | 事件 | 对思维的影响 |
|---|---|---|
| **约前 1903（帝泄元年辛未）** | "元年辛未，帝即位。"（今本《竹书纪年》）帝泄以帝芒之子即位，夏世系无失国、无复位、无内乱之记。 | 即位即承槐—芒两代所经营的"九夷来御—宾于河"格局；无待解决的合法性危机，是本朝"守成"基调的起点。 |
| **约前 1892 前后（十二年）** | "殷侯子亥宾于有易，有易杀而放之。"（今本《竹书纪年》）附注并载："殷侯子亥宾于有易而淫焉。有易之君绵臣杀而放之。"（《山海经·大荒东经》郭璞注引古本《竹书》文同） | 夏室在句中不作主语、不出兵、不遣使。此后夏室对北方属邦事务采取"不载即不干预"的处理，成为本朝对外纪录的常态。 |
| **约前 1888 前后（十六年）** | "殷侯微以河伯之师伐有易，杀其君绵臣。"（今本《竹书纪年》）——上甲微借河伯之师为父复仇，灭有易。 | 河伯之师本为芒之世"以玄珪宾于河"所结的盟好；至是盟军被殷人所借。夏室在句中仍非主语。属邦在夏室不介入的空档中完成"中衰—复仇—复兴"的完整循环。 |
| **约前 1883 前后（二十一年）** | "二十一年，命畎夷、白夷、玄夷、风夷、赤夷、黄夷。"（今本《竹书纪年》；《后汉书·东夷传》注引古本《纪年》末名为"阳夷"）《后汉书·东夷列传》述其义："至于后泄，始加爵命，由是服从。" | 本朝唯一可指认的主动施政：以"授名"替代"出兵"。执政中后期方行此策，前二十年（含殷事两件）皆付诸记录而不介入。 |
| **约前 1884–约前 1879（二十五年·陟）** | "二十五年，陟。"（今本《竹书纪年》）\[异说\]《路史·后纪》十三注引《纪年》作"二十一"；《太平御览》卷八十二引《帝王世纪》"帝泄在位十六年"，刘恕《通鉴外纪》从之；《路史》本文"帝泄二十六岁陟"，罗泌自注斥《世纪》《年代历》《纪年》三说"皆非"。 | 在位年数四说并存（二十五 / 二十一 / 十六 / 二十六），故其终年只能是区间而非定点。本包 frontmatter 取任务书框架"约前 1903–约前 1884"，与《纪年》"二十五年"说（→约前 1879）并列不调和。 |
| **其后** | 《史记·夏本纪》："帝泄崩，子帝不降立。"今本《竹书纪年》："（帝不降）六年，伐九苑"；"五十九年，逊位于弟扃"，附注"三代之世内禅，惟不降实有圣德"；"（帝扃）十年，帝不降陟"；帝廑"元年己未，帝即位，居西河"；帝孔甲"元年乙巳，帝即位，居西河"，"废豕韦氏，使刘累豢龙"。 | 帝泄留下两个儿子（不降、扃），两支互让、四代之后归于不降之子孔甲；《史记》记孔甲"好方鬼神，事淫乱。夏后氏德衰，诸侯畔之"，《国语·周语下》"孔甲乱夏，四世而陨"由是起算。本包不对这条跨四代的链条作归因断言。 |

## 三、"绝对年代"一节的矛盾（如实并列）

- 【框架推断】依任务书与断代框架的夏积年向下分配，帝泄（禹以下第十王）约在前 1903—前 1884 之间；若依《今本竹书纪年》"二十五年陟"，则约在前 1903—前 1879 之间。
- 【框架推断】**与考古分期的张力**：二里头遗址的年代上限约在前 1780（《夏商周断代工程》框架），而帝泄之世落在其前约一百年。因此（甲）若采"夏前 2070—前 1600"框架，帝泄之世应对应新砦期 / 河南龙山晚期；（乙）若坚持"二里头全为夏都"，则夏代积年须大幅压缩，帝泄的年代随之整体下移。两读并存，本包不调和。
- 【框架推断】干支记年（元年辛未）属后世纪年系统所加，不能据以定点；本包不用干支作任何绝对纪年的推算依据。

## 四、帝泄纪中唯一被外部材料检验的两条

- 【史料原文/一手（出土实物）】甲骨卜辞中"王亥""上甲""河"受隆重之祭："贞：侑于王亥惟三百牛"（《甲骨文合集》14724）；"甲辰卜，㱿贞：来辛亥燎于王亥三十牛"（《甲骨文合集》14733）；"燎于河、王亥、上甲十牛，卯十牢"（《甲骨文合集》）；《小屯南地甲骨》"辛巳卜，贞，来辛卯河十牛，卯十牢；王亥燎十牛，卯十牢；上甲燎十牛，卯十牢"。
- 【框架推断】帝泄之世的两条殷事，其人物（王亥、上甲微、河伯）经甲骨文与《天问》《山海经》《世本》互证为真（王国维《殷卜辞中所见先公先王考》，1917）；**但甲骨文未确证帝泄其人，也未直接确证"有易杀王亥""上甲微伐有易"二事**。故本份只能作最低判断：帝泄纪在其可检验处可靠，不等于帝泄其人其世皆可靠。

## 五、小结（一手 vs 框架）

- 一手素材（编年与事件）：《史记·夏本纪》世系链；《竹书纪年》帝泄五条、帝芒四条、帝芬六条、帝不降 / 帝扃 / 帝廑 / 帝孔甲诸条；《山海经·大荒东经》本文与郭璞注引古本《竹书》；《后汉书·东夷列传》三段式；《太平御览》引《帝王世纪》、《路史·后纪》、《通鉴外纪》异说；《甲骨文合集》《小屯南地甲骨》相关卜辞；《夏商周断代工程》报告与二里头考古报告。以上构成全部可核验基底，占比明显过半。
- 框架推断：绝对年代的分配、与二里头分期的张力、"可检验处可靠"的最低判断，均由材料对读推得，逐条标注，未伪称史载原话。
- 存疑不决：在位年数（二十五 / 二十一 / 十六 / 二十六）、绝对年代（约前 1884 / 约前 1879，及更大幅度的下移说）、帝泄之世与考古分期的对应、干支记年的可用性 —— 四组异说并列，本包不强行调和。
