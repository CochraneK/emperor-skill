# 05 决策记录 · 帝泄（夏·帝泄，芒之子，约前1903–约前1884）

> 维度定义：其征伐、迁都、继统、用人、外交等重大决策及事后评说。
> **门禁声明：帝泄名下可考的"决策"只有一条有明确动作（二十一年"命六夷"），另有三条须由"缺席"与"后果"反推（不介入殷事、不营都、继统安排）。** 本份把"可考决策"与"反推决策"严格分节，且反推者一律标为框架推断。
> **史料门禁提示：夏属传说 / 半信史，材料有限。** 下列各条不伪称"一手确证"。

## 一、可考决策一：二十一年"命六夷"——以授名替代征伐

- 【史料原文/一手】今本《竹书纪年》："二十一年，命畎夷、白夷、玄夷、风夷、赤夷、黄夷。"（《后汉书·东夷传》注引《纪年》末名为"阳夷"。）
- 【史料原文/一手】《后汉书·东夷列传》："及后相即位，乃征畎夷，七年然后来宾。至于后泄，始加爵命，由是服从。"
- 【框架推断】决策内容可辨者为三点：（1）**对象**——六支东方夷人（畎、白、玄、风、赤、黄/阳）；（2）**手段**——"命"，即授予名分 / 位号，而非出兵；（3）**时点**——在位第二十一年，即执政中后期，非即位之初。
- 【框架推断】与前任对照：帝相的处理方式是"征畎夷，七年然后来宾"——用兵七年才换来一次来朝；帝泄的处理方式是"命"——一次授名换取"服从"。**这是一次工具替换**：从"以兵致服"改为"以名系人"。其成本结构完全不同：出兵是一次性高成本、可逆性差；授名是低成本、可复制、依赖对方承认。
- 【史论/二手】事后评说见《后汉书》"由是服从"（东汉后史家判语）；清人徐文靖《竹书统笺》引《周礼》师氏"四夷之隶……守王之门外"，疑"命夷"或涉夷人充宿卫。徐说为补说，非史实。
- 【框架推断】决策的风险未被任何文献讨论：**授名政治的天花板是"授名者的兵威一旦贬值，名分随之贬值"。** 帝泄之后三代（不降、扃、廑），《纪年》再无一次"命"的记录；至孔甲一代，只见"废豕韦氏""好事鬼神"。《国语·周语下》"孔甲乱夏，四世而陨"即由此段起算。本包把这条视为该决策的**长程代价**，如实并列。

## 二、可考决策二（以"不记载"形式留痕）：不介入殷—有易之争

- 【史料原文/一手】今本《竹书纪年》："十二年，殷侯子亥宾于有易，有易杀而放之。""十六年，殷侯微以河伯之师伐有易，杀其君绵臣。"
- 【史料原文/一手】《山海经·大荒东经》郭璞注引古本《竹书》："殷王子亥宾于有易而淫焉，有易之君绵臣杀而放之。是故殷主甲微假师于河伯，以伐有易，灭之，遂杀其君绵臣也。"
- 【框架推断】两件事都发生在帝泄在位期间，且夏室在两件事的句法里都不是主语：没有"夏使……""请于夏""夏师……"的任何界面动作。可推的决策形态有两种，史料不足以裁决：
  - **读法甲（决策不介入）**：殷事属属邦自治，夏室按惯例不介入；纪年照录而不评断，说明当时不视为夏室之事。
  - **读法乙（无力介入）**：殷地在河北，河伯之师可至，夏师来路与补给不明；"不载"或即"不能"。
- 【框架推断】**两读并列，不调和。** 但从决策研究角度可指出一点：无论出于何种原因，其后果是**商族在夏室不介入的空档中完成了"中衰—复仇—复兴"的完整循环**（《国语·鲁语上》"上甲微能帅契者也，故殷人报焉"）。夏室未从中获得任何可记的收益，也未付出任何可记的成本。
- 【框架推断】与决策一合并看，可辨出一条一致的取向：**帝泄一朝对东方用"名"（命六夷），对北方用"不介入"（殷事）——即全面回避用兵。** 这是本包"守成"判断的最实质依据；但它同时也可能是"无力用兵"的另一种写法，本包两存。

## 三、反推决策三：不营都、不迁都

- 【框架推断】帝泄名下无任何都邑记述（今本《纪年》帝泄五条无一处涉及居地）。对照：其孙帝廑"元年己未，帝即位，居西河"，其曾孙孔甲"元年乙巳，帝即位，居西河"，其父帝芒无居地记录，其祖帝芬无居地记录，而其父之世有"三十三年，商侯迁于殷"。
- 【框架推断】可推者只是"未发生可记的都邑变动"，不能推为"有意不迁"。
- 【框架推断】此条的意义在于**排除一个常见误解**：夏代自太康失国、少康中兴之后，都邑并非频繁迁徙（"居原""迁于老丘""居西河"分别见于杼、廑、孔甲诸世）；帝泄之世无都邑变动，与其"守成"的取向相容，但不构成独立证据。

## 四、反推决策四：继统安排——两个儿子与两条线

- 【史料原文/一手】《史记·夏本纪》："帝泄崩，子帝不降立。帝不降崩，弟帝扃立。帝扃崩，子帝廑立。帝廑崩，立帝不降之子孔甲，是为帝孔甲。"
- 【史料原文/一手】今本《竹书纪年》："（帝不降）五十九年，逊位于弟扃。"附注："三代之世内禅，惟不降实有圣德。"又："（帝扃）十年，帝不降陟。"
- 【史论/二手】徐文靖《竹书统笺》据《竹书》纠《史记》："《夏本纪》云帝不降崩弟帝扃立，今据《竹书》，不降让位于弟，后十年始崩，是史误也。"
- 【框架推断】帝泄至少留下两个儿子：不降（继位，在位五十九年后逊位于弟）、扃（受禅，在位十八年，其中十年与不降并存）。继统链条此后是：不降 → 扃 → 廑（扃之子） → 孔甲（不降之子，即回到不降系）。
- 【框架推断】把这条链读作"决策"，须极谨慎：**逊位是帝不降自己的决定，不是帝泄所命**；但"两子皆具资格"这一格局是帝泄留下的。可辨的后果有两点：（一）夏史中出现了一次罕见的"内禅"，并被后世特加称许（"惟不降实有圣德"）；（二）四代之后，帝位回到不降系，而回归者正是《史记》所记"好方鬼神，事淫乱。夏后氏德衰，诸侯畔之"的孔甲，《国语·周语下》所谓"孔甲乱夏，四世而陨"由是起算。
- 【框架推断】**归因必须止于此**：把"孔甲乱夏"回溯归因于帝泄的继统安排，是跨越四代三传的长程倒推，中间变量过多，本包不作此断言。本包只如实指出这一格局的存在与其后事，让矛盾并列。

## 五、决策风格的可辨特征（与前王对照）

| 决策面 | 帝芬（祖） | 帝芒（父） | **帝泄** | 帝不降（子） | 帝孔甲（曾孙） |
|---|---|---|---|---|---|
| 都邑 | 无记 | 无记 | **无记** | 无记 | 居西河 |
| 征伐 | 无 | 无 | **无** | 伐九苑 | 无（畋于萯山） |
| 兴作 | 作圜土 | 无 | **无** | 无 | 作东音 |
| 对外 | 九夷来御 | 以玄珪宾于河、东狩于海 | **命六夷** | 无 | 无 |
| 分封 / 废置 | 封昆吾氏子于有苏 | 商侯迁于殷（他者动作） | **无** | 殷灭皮氏（他者动作） | 废豕韦氏 |

- 【框架推断】表中最突出的不是"帝泄做了什么"，而是**"除'命'之外什么都没记"**。其后任者中，不降有"伐九苑"、孔甲有"居西河 / 作东音 / 废豕韦氏"，皆属可指认的"作为"。帝泄一代的施政动作类别，是夏室由"作"（芬）与"宾"（芒）转向"命"，再由"命"转向"废 / 居 / 作"（孔甲）之间的一环。
- 【框架推断】由此可提出一个本包仅作提示、不作断论的读法：**"命"很可能是夏室在军事半径收缩后所选的中低成本对外工具**；它见效于记录（"由是服从"），但它的效力不以夏室可控的方式折旧——一旦夏室不再有可授之爵，这套工具就失效了。

## 六、小结（一手 vs 框架）

- 一手素材（决策与记录）：《竹书纪年》帝泄五条事目及其附注、帝不降"逊位于弟扃"、帝廑"居西河"、帝孔甲"居西河""废豕韦氏"；《史记·夏本纪》世系链与"孔甲……夏后氏德衰，诸侯畔之"；《后汉书·东夷列传》三段式；《山海经·大荒东经》注引古本《竹书》；《国语·鲁语上》《周语下》；《竹书统笺》引文。以上构成全部可核验基底，占比明显过半。
- 框架推断：本份第二至第五节的四条"反推决策"、决策风格对照表、"名分工具折旧"的读法、"夏室未从中获得可记收益"的判断，均由史文推得，逐条标注，未伪称史载原话。
- 不作断言者：把"孔甲乱夏"归因于帝泄的继统安排（长程倒推，变量过多）；把"不介入殷事"定为主动决策（与"无力干预"不可分辨）。
