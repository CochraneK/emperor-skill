# 06 时间线 · 帝槐（夏·帝芬，杼之子，约前19世纪在位）

> 维度定义：即位到崩的编年，含史料成书背景与互核情况。
> **史料门禁提示：夏属传说 / 半信史，材料有限。** 上古纪年多属后世推算，本份所有西元年代**一律带"约"字**，并标注其推算依据；凡干支系年（"元年戊子"）说明其出自后世历术系统，不作确证。

## 一、年代基准说明（先读）

- 【框架推断】《竹书纪年》帝芬纪以"帝芬N年"记时（元年、三年、十六年、三十三年、三十六年、四十四年），"元年戊子"之干支则属后世历术配合所得，非战国原文原貌。故本份以"帝芬N年"为**原始时间刻度**，西元年代为**推算换算值**。
- 【框架推断】推算路径：夏商周断代工程定夏代为约前2070–前1600 年（积年约470 年）；依《纪年》世系与各王在位年数自上而下分配，帝芬之世落在约前19 世纪。以"四十四年"说换算，帝芬元年约当前1833 年、末年约当前1790 年。
- 【史料原文/一手·异说】《帝王世纪》作"在位二十六年"，《路史》另记"四十有六岁"。若取二十六年说，其世相应后移，约当前19 世纪中后期。**本份主干采四十四年说，异说并记。**

## 二、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 帝杼五年前后（背景，约前1850 前后） | 其父帝杼自原迁都老丘（《纪年》杼纪"五年，自原迁于老丘"） | 帝槐嗣位时都邑已定、根基已固，"不迁都"成为其执政的默认前提 |
| 帝杼八年前后（背景） | 帝杼"征于东海及三寿，得一狐九尾"（《海外东经》注引《汲郡竹书》）；《鲁语》评"杼能帅禹者也，故夏后氏报焉" | 父辈以征伐与"帅禹"立威；帝槐承其武备之果，转而以"来服"为其执政形态——文武两代的对照自此形成 |
| 帝杼十七年（约前1833） | 帝杼陟（《纪年》杼纪"十七年，陟"），帝槐即位，**不记迁居**（徐文靖笺"当亦嗣父居老丘也"） | 确立"不改先制"的第一决策，守成底色定型 |
| 帝芬三年（约前1831） | **九夷来御**（《纪年》；《后汉书·东夷传》注引同） | 执政第三年即获外部承认，其"以服代灭"的边界观在早期即得验证，此后近四十年的外部路线基本未再变动 |
| 帝芬十六年（约前1818） | **洛伯用与河伯冯夷斗**（《纪年》；《水经·洛水注》引同）；《归藏》载河伯卜战于昆吾，占曰不吉 | 王畿之侧的方国冲突而不见夏廷裁断；"克制"与"失位"两种读法由此句并出，成为其执政记录中最大的一处歧义 |
| 帝芬三十三年（约前1801） | **封昆吾氏子于有苏**（《纪年》；《国语》郑语"己姓，昆吾、苏、顾、温、董"） | 以旧族子弟据新地，形成"据点—网络"式的长程布局；此支存续至商末，为四十四年中影响最久的一项安排 |
| 帝芬三十六年（约前1798；一作二十六年） | **作圜土**（《纪年》；《周礼》郑注"圜土者，狱城也"；徐文靖笺疑即夏台） | 由人治转向常设制度：惩戒成为可反复运行的场所与流程；其"内生确定性"的制度面由此确立 |
| 帝芬四十四年（约前1790；一作二十六年） | 帝芬**陟**，子帝芒立（《史记·夏本纪》"帝槐崩，子帝芒立"；《纪年》芒纪"元年壬申，帝即位，以玄珪宾于河"） | 传承平稳、无篡弑之争；其子继其河洛路线（宾祭于河），守成路线延续至下一代 |

## 三、史料成书背景与互核

- 【史料原文/一手】《史记·夏本纪》（西汉·司马迁）：帝槐记载仅两句世系（"帝予崩，子帝槐立。帝槐崩，子帝芒立"）与一个"槐"字之名。司马迁所据为秦记及先秦旧闻，其所以只留世系，反映西汉时夏代中期事迹已无可据。
- 【史料原文/一手】《竹书纪年》（战国魏国编年史，今本 / 古本问题见下）：帝芬名下六条事目，是本维度的主源。其中三条另有他书引文可互核：三年"九夷来御"（《后汉书·东夷传》注引、《通鉴外纪》《路史·后纪》引）、十六年"洛伯用与河伯冯夷斗"（《水经·洛水注》引）、四十四年"后芬立四十四年"（《太平御览》卷八十二引）。
- 【史论/二手·今本古本问题】《竹书纪年》有古本（汲冢出土，已佚，赖唐宋类书与注疏引存）与今本（明代重出，学界多疑为辑补）之别。方诗铭、王修龄《竹书纪年辑证》逐条标注佚文出处。**本包对帝芬六条的引用，凡有唐宋引文可核者以引文为准（三年、十六年、四十四年三条）；其余三条（元年、三十三年、三十六年）据今本系统，标为"今本所记"，不作确证。**
- 【史论/二手】《世本》（先秦世系书，辑本）：作"帝芬"，与《纪年》同，与《史记》之"槐"异写。
- 【史论/二手】《帝王世纪》（魏晋·皇甫谧）："帝芬，一名帝槐，或曰祖武，在位二十六年"——名号与年数双异说的出处。
- 【史论/二手】《竹书统笺》（清·徐文靖）、（《竹书纪年义证》（清·雷学淇）：帝芬条下笺证最详，为"嗣居老丘""来御之义""圜土即夏台"三处关键推断之所出。
- 【考古/一手】二里头遗址分期与碳十四测年、新砦期遗存、荥阳大师姑城址：提供夏中晚期的物质文化框架；与帝槐之世的对应为年代学推断（见 04 篇第六节）。
- 【互核结论】帝槐之"即位—传子芒"在《史记》《世本》《竹书纪年》三系一致，无争议；其"事迹"则仅《纪年》一系独有，无第二源可校——**这是本包最需要如实说明的一点：其事目为单源，且该源本身存在今本 / 古本之争。**
- 【争议并列】名号（槐 / 芬 / 芬发 / 祖武）、在位年数（四十四 / 二十六 / 四十六）、圜土系年（三十六 / 二十六年）、九夷地望与"来御"之义（三说）、洛伯河伯之神人二说、老丘地望（陈留 / 濮阳）——六组异说并列，不强行调和。

## 四、时间线的解释学说明

- 【框架推断】帝槐时间线的形态特征：**跨度长（四十余年）而节点少（六条）**。每一节点之间平均间隔七至十年，中间为空白。
- 【框架推断】这一形态导致两种相反的读法，本包并列保留：
  - 读法甲：其世无事，故无记——守成之世以"无大事"为内容，"不出事"即是成果。
  - 读法乙：其世有事而材料亡佚——《纪年》对夏中期诸王的记载皆简，帝槐并非特殊。
  **两读法不可由现有材料判定；本包不作确定断言。**

## 五、小结（一手 vs 框架）

- 一手节点：《竹书纪年》帝芬六条（其中三条有唐宋引文互核）、《史记·夏本纪》世系两句、《国语》郑语、《归藏》佚文、《穆天子传》郭注、《周礼》郑注、二里头与新砦与大师姑考古材料。
- 框架推断：全部西元系年（换算值）、各节点"对思维之影响"一栏、时间线形态的解读，均为本包归纳推断，非史书明言。
- 年代性质声明：**帝槐之世属传说 / 半信史，其编年系由后世文献串联与推算而得，不存在同期自证文字（无甲骨卜辞、无同期金文可系于其名）。** 本份所给年代仅供框架参照。
