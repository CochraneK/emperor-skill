# 06 时间线 · 发（夏·帝发／后发，皋之子，桀之父，约前1665–约前1650）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **纪年声明**：夏史属**传说／半信史，材料有限**；发之年代**无定论**，以下一律冠"约"字。异说并列，不调和。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1705—约前1665（孔甲、皋两朝；具体年数异说，见三） | 孔甲"好方鬼神、事淫乱，诸侯化之，夏政始衰"（《史记》论桀段／《今本竹书纪年》孔甲条）；皋即位即"使豕韦氏复国"以修人事 | 发承两朝之局：王位在而威望已削，"诸侯多畔夏"的非始于其手 |
| 约前1665（今本《竹书纪年》系于帝发元年乙酉；异说见三） | 皋崩，子发立（《史记·夏本纪》"帝皋崩，子帝发立"）；仍居西河（据廑、孔甲"居西河"推定，非明记） | 顺位继统、不变都邑——"受之而不言"的基调自此定 |
| 约前1665（元年） | "诸侯宾于王门，再保墉，会于上池，诸夷入舞"（今本《竹书纪年》；古本作"诸夷宾于王门，再保庸会于上池"） | 确立"以宾礼与乐舞维系远人"的邦交方式：不责贡、不示威，只求相会 |
| 约前1665—约前1650（元年之后的六年） | 文献**无一字**记载 | 材料空白本身即其"少事之君"的处境：无可称述，亦无可归责 |
| 约前1651（今本系于七年） | "七年，陟。泰山震。"（今本《竹书纪年》） | 短祚骤止，附记一次地动而无解释——留白最大处 |
| 约前1650（其后即桀元年） | "帝发崩，子帝履癸立，是为桀"（《史记》）；桀"居斟鄩"（今本系于帝癸元年壬辰） | 传嗣之果落地：都邑由西河迁斟鄩；夏亡的叙事自下一代展开 |
| 约前1600（框架年代；异说见三） | 鸣条之战，夏师败绩，桀放于南巢，汤代夏（《史记·夏本纪》、古本《竹书纪年》） | 发被回溯为"末代前夕"的一环：其传嗣决策在后果层被反复追评 |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·夏本纪》（西汉·司马迁）为发事主源，然**仅十五字**：「帝皋崩，子帝发立。帝发崩，子帝履癸立，是为桀。」无言行、无纪年、无评语。
- 【史料原文/一手】《今本竹书纪年·帝发》（梁沈约附注本系统，明范钦订本，清徐文靖统笺）给出较详条目：异名（一名后敬，或曰发惠）→ 元年乙酉即位 → 朝会记事 → 七年陟·泰山震。
- 【史料原文/一手】古本《竹书纪年》（《太平御览》卷八二引）仅存朝会一句，无年数与陟年；与今本互证而更简。辑校诸家（朱右曾《存真》、王国维《辑校》、范祥雍《订补》、方诗铭王修龄《辑证》）对"再／冉""保庸／保墉"有异读。
- 【史料原文/一手】《史记·夏本纪》索隐引《世本》：「帝皋生发及桀。」——与《史记》"桀为发之子"异。**世系异说并列，本 Skill 依《史记》主流，不调和。**
- 【史论/二手】清·徐文靖《竹书纪年统笺》释"泰山震"为"将有代起而王者"之兆——清代注家的灾异解读，属注疏层。
- 【史论/二手】《夏商周断代工程 1996—2000 年阶段成果报告：简本》及《夏商周年表》：夏代约前 2070—前 1600，十七王（禹……皋、发、桀）**不分列年代**。
- 【史料原文/一手（考古实物）】二里头遗址发掘与测年（一至四期约前 1880—前 1520，或经"系列拟合"压缩至约前 1750—前 1500）：王都级宫殿、铸铜作坊、玉器青铜器；学界争议仍在"夏都或商都""夏商分界落于三期或四期"。**至今未出可确证王名的文字材料，故不得称发之"一手确证"。**
- 【互核结论】发之"继统—受朝—短祚—传桀"四节点，在《史记》《竹书纪年》（古本／今本）三种材料中方向一致；唯**年数（三年／七年／十一年／十七年／十九年）、都邑（西河／斟鄩）、世系（桀为子／为弟）**三处异说并存。
- 【成书背景说明】今本《竹书纪年》之真伪与成书年代**学术上有争议**（多数学者视为后出辑补，含梁沈约注、明清刊刻层累），故其干支与年数**不可当作战国原始记录**；凡引用均标明"今本，须标注"。

## 三、异说并列（不调和）

1. **在位年数**：今本《竹书纪年》作"七年，陟"；《通鉴外纪》《路史》《帝王世纪》一系与近世读本另推作"十一年／十七年／十九年／十四年"不等。本 Skill 取"约七年"为叙事框架，其余异说并列。
2. **年代框架**：断代工程取夏约前 2070—前 1600；另有依古本《竹书纪年》"自禹至桀十七世……用岁四百七十一年"推出的约前 1994—前 1523、约前 2024—前 1553，以及约前 1572 为夏商分界诸说。故发之绝对年代本质上不可定，本 Skill 一律用"约"。
3. **都邑**：发之都，文献无明记；依廑、孔甲"居西河"推为西河；桀则"居斟鄩"。近世读物称发迁斟鄩／渑池者，无先秦两汉依据，属二手推测。
4. **世系**：桀为发之子（《史记》）／桀与发同为皋之子（《世本》引）。两说并列。

## 四、小结

- 一手节点均出《史记·夏本纪》、《今本竹书纪年·帝发》条、《太平御览》引古本《竹书纪年》、二里头考古与测年实物；年数、都邑、世系异说如实并列。
- 框架推断：表中"对思维之影响"一栏与"仍居西河"之推定，均为据史事与邻王条目的归纳推断，非史书明言。
- **本份全部年代均冠"约"字；夏史属传说／半信史，材料有限，不得作精确纪年使用。**
