# 06 时间线 · 武丁（商·高宗，约前1250–约前1192在位）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
>
> 门禁提示：商属**半信史**。武丁一朝虽因甲骨文而材料最厚，然其绝对年代仍由多重推算得之，**凡系年一律带「约」字**；异说并列，不取一说为定。

## 一、年代基准（先说清楚依据，再排表）

- 【史论/二手】**《尚书·无逸》**：「肆高宗之享国五十有九年。」——在位年数之唯一早期依据（西周文献）。
- 【史论/二手】**夏商周断代工程（1996–2000）**：以宾组卜辞五次月食（癸未夕前1201、甲午夕前1198、己未夕向庚申前1192、壬申夕前1189、乙酉夕前1181）作天文回推，得两案：**约前1250–前1192** 或 **约前1239–前1181**。
- 【史论/二手】**另有异说**：据历组卜辞庚辰日食与分期，主张武丁元年约在前1259年、祖庚元年不晚于前1198年。
- 【框架推断】本文表中「约前XXXX」按前1250–前1192一案折算，仅示先后关系；凡与他案冲突处不改数，读者宜视其为序列而非绝对年份。

## 二、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1250（异说约前1239／前1259） | 小乙崩，子武丁立（《史记·殷本纪》：「帝小乙崩，子帝武丁立。帝武丁即位，思复兴殷，而未得其佐」） | 起点是「未得其佐」——其执政的第一命题不是如何扩张，而是如何找到能办事的人 |
| 约前1250–前1247 | 三年不言，政事决定于冢宰，以观国风；卿士患「无所禀令」，武丁作书曰「以余正四方，余恐德之不类，兹故不言」（《史记》／《国语·楚语上》） | 养成「先观后动、以不足自处」的姿态；同时形成「委政而不停摆」的处置方式 |
| 约前1247 | 夜梦得圣人，使百工营求之野，得说于傅险（时为胥靡，筑于傅险），举以为相，殷国大治，号曰傅说（《史记》） | 确认「以神意破常规」可用；「举贤于微」成为其用人范式 |
| 约前1247以后 | 命傅说「朝夕规谏」「朝夕规诲箴谏」，且曰「必交修余，无余弃也」（《国语·楚语上》） | 把纳谏制度化的自觉：预设君主会「荒失遗忘」，故将纠错外置于臣 |
| 约前1247–前1200年间 | 连年处置边患：《合集》6057 记土方「征于我东鄙，𢦔二邑」、工方「亦侵我西鄙田」，王占曰「有祟，其有来艰」而后验；《合集》6409「共人五千征土方」；《合集》6412「呼妇好伐土方」 | 「情报—占断—征发」链条定型；对边患取绝对优势一次压服的取向 |
| 约前1226（今本《竹书纪年》系于二十五年，**待核**） | 「王子孝己卒于野」（今本《竹书纪年》所载） | 若可信，则其继嗣安排曾遭挫折；惟此条系年与人物身份均有异说（《史记》中「祖己」为臣），仅列为存疑节点 |
| 系年不详（今本《竹书纪年》系于二十九年，**待核**） | 祭成汤之明日，「有飞雉登鼎耳而呴」，武丁惧；祖己训以「王勿忧，先修政事」，武丁修政行德，天下咸驩，殷道复兴（《史记·殷本纪》／《尚书·高宗肜日》） | 形成「以德应妖」的处置范式（与先祖太戊闻祥桑谷而修德同构）；异象被转化为施政调整的触发点 |
| 约前1219（今本《竹书纪年》三十二年） | 「伐鬼方，次于荆」（《竹书纪年》） | 战事进入持久消耗；「次于」显示以驻守换取时间 |
| 约前1217（今本《竹书纪年》三十四年） | 「王师克鬼方，氐羌来宾」（《竹书纪年》）；《周易·既济》「高宗伐鬼方，三年克之」（另说此役属帝乙时，见 04 篇争议 1） | 形成「难事以三年为期、不轻弃」的经验；西北方向之稳定成为中兴题面之一 |
| 约前1200年前后 | 妇好卒，葬于宫室区旁池苑之畔，墓上建享堂；卜辞中有为其疾病、生育之占问（《合集》709正「妇好𠬪凡有疾」、14002正「妇好娩，嘉」）；其墓于 1976 年发掘（小屯M5） | 显示其「祀戎同托一人」的用人配置之实况；亦显示王对至亲之事的占问密度与政务等量 |
| 约前1192（五十九年） | 武丁陟（今本《竹书纪年》「五十九年，陟」）；子祖庚立；祖己立其庙为高宗，作《高宗肜日》及《训》（《史记·殷本纪》） | 「高宗」为身后之号，非生前自称；其「中兴」定位自此进入王室祭祀与文献传承 |

## 三、史料成书背景与互核

- 【史料原文/一手】《尚书·无逸》：西周早期文本，最早评武丁者；《尚书·高宗肜日》：今文尚书篇目，记祖己训王。
- 【史料原文/一手】《国语·楚语上》：春秋史料，白公子张引武丁事，保存《说命》类佚文中最长的一段武丁自语。
- 【史料原文/一手】《史记·殷本纪》：西汉司马迁撰，采《书》《诗》及秦记；「太史公曰」自言「自成汤以来，采于《书》《诗》」。
- 【史料原文/一手】殷墟甲骨宾组卜辞（《甲骨文合集》1／6057／6409／6412／6480／14002／13926 等）与妇好墓（小屯M5）考古报告：同时代之实物与王言，为武丁断代与史事之最硬证据。
- 【史论/二手】《周易》爻辞、「今本《竹书纪年》」诸条、伪《古文尚书·说命》、历代注疏、断代工程诸说。
- 【互核结论】「三年不言—举傅说—征土方工方—伐鬼方—以妇好领军—雉雊修政—在位五十九年—立庙高宗」之主链，在《无逸》《国语》《史记》《周易》《竹书纪年》与卜辞、考古材料间可相互支撑；**绝对年代、鬼方归属、祖己身份、妇好军权高下四项存异说，并列不调停。**
- 【成书背景说明】今本《竹书纪年》为战国魏墓所出纪年之流传本，经后人整理，其商王年数条目可参不可尽信；本文凡引之条均标「今本《竹书纪年》」并注「待核」。
- 【原拓未核说明】甲骨片号依二次转引核对，未见原拓；释文从学界通行读法。

## 四、小结

- 一手节点：即位、三年不言、举傅说、命朝夕规谏、征土方工方、伐鬼方、妇好在位与卒、雉雊修政、五十九年陟、立庙高宗。
