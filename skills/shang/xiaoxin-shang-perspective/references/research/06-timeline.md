# 06 时间线 · 小辛（商王小辛，约前1287–约前1267，盘庚之弟）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **史料门禁声明**：商史属**半信史**，上古纪年多为"约前XXXX年"之说，异说并存；本文件所有绝对年代仅供参照，**不具断代意义**。
> **系年方法说明**：今本《竹书纪年》所载干支自成体系（盘庚元年丙寅、小辛元年甲午、小乙元年丁酉），按其自洽推算，小辛元年约当前1287年，三年陟约当前1285年；而《太平御览》八十三引《史记》作"小辛在位二十一年"，则崩年约当前1267年。夏商周断代工程定盘庚迁殷约前1300年、武丁约前1250—前1192年，与今本干支体系不合。**故本 Skill 取宽区间"约前1287—约前1267"，两说并存。**

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1315（盘庚元年丙寅） | 盘庚即位，居奄（背景） | 小辛尚未登场；"迁都"成为此后整个家族的政治母题 |
| 约前1301（盘庚十四年） | 盘庚"自奄迁于北蒙，曰殷"（《竹书纪年》），行汤之政，殷道复兴，诸侯来朝（背景） | 小辛所继承的是一次**刚完成、且已见效**的巨变；这决定了他"以不改继大改"的执政底色 |
| 约前1288 | 盘庚崩；弟小辛立（背景起点） | 小辛的王位合法性主要来自兄长之功业，而非自身功业——其思维底色之一即"借来的合法性" |
| 约前1287（小辛元年甲午） | 王即位，**居殷**（《竹书纪年》） | 其唯一有记载的施政事实：不徙都。确立"守成不动"为执政原则 |
| 约前1287—约前1267（在位期间） | "帝小辛立，**殷复衰**"；"百姓思盘庚，乃作《盘庚》三篇"（《殷本纪》） | 现实下滑与对前任的追忆同时发生；其思维处境是**被前任标尺衡量的在位者** |
| 在位期间 | 卜辞中"颂王/王颂"名下贞问：来女、进龟、告祭、贞祟、受享（一期卜辞，释读有争议） | 王权落点在祭祀与安危的具体事务上，呈"祭司式的王"面貌，与盘庚"政治家的王"对照 |
| 约前1285 或 约前1267 | 小辛崩（《竹书纪年》"三年，陟"／《御览》引《史记》"二十一年"，异说并列）；弟小乙立（《殷本纪》） | 传位平稳、未启争端；其历史位置最终由"传给谁"而非"做了什么"决定 |
| 约前1284—约前1275 | 小乙朝：六年"命世子武丁居于河，学于甘盘"（《竹书纪年》） | 小辛之死把王朝交给了准备最充分的下一代支系；"复兴"的准备在别人的朝代完成 |
| 约前1274 或 约前1250（异说） | 武丁即位，"思复兴殷，而未得其佐"，三年不言，后举傅说为相，殷道复兴（《殷本纪》） | 小辛夹在盘庚与武丁两个高点之间，"复衰"一语遂成其全部叙事 |
| 武丁朝及以后 | 小辛在武丁卜辞中多称"**父辛**"，在二期、五期周祭卜辞中称"**小辛**"，入祀谱受祭 | 殷人以祭祀给予的承认，比《殷本纪》的"殷复衰"更中性；其名在祀谱中与其兄盘庚、其弟小乙并列 |
| 约前1046 | 商亡（现代学界多主此说） | 其"居殷不改"的成果被完整继承：王国维谓"盘庚以后，帝乙以前，皆宅殷虚" |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》为小辛事**主源**，但其记载仅两句：世系句 + "殷复衰／百姓思盘庚"句，**无言行、无举措、无专评**。
- 【史料原文/一手】今本《竹书纪年》补"名颂、元年甲午、居殷、三年陟"四点；《太平御览》八十三引《史记》与《外纪》《通志》则作"在位二十一年"——**在位年数三说（三年／二十一年）并存，不调和**。
- 【史料原文/一手】《尚书》序与司马贞《史记索隐》就《盘庚》三篇的成篇时点提出异议（《索隐》直指司马迁"不见古文"而误系）——**小辛名下唯一的文本事件因而存疑，本 Skill 并列保存**。
- 【史料原文/一手·出土】甲骨卜辞以"父辛""小辛"之名与盘庚、小乙连书，**世系互证《殷本纪》"无一先后陵乱者"**（罗振玉、王国维）；小辛入二期、五期周祭祀谱。
- 【史论/二手·争议】武丁以前卜辞是否存在，学界分歧：董作宾以月食定《甲》1289属小辛十年；刘一曼列出一批早于武丁的刻辞；吴俊德则主张盘庚至小乙三朝"卜用之后并无契刻卜辞的习惯"，诸说缺坚实佐证；目前出土甲骨中可确定的最早卜辞出自武丁时期。**故小辛的"一手实物证据"本身处在争议中，本 Skill 如实标注，不据以立论。**
- 【史论/二手·年代】夏商周断代工程定盘庚迁殷约前1300、武丁约前1250—前1192，未为小辛单列绝对年代；本文件年代一栏取约数。
- 【互核结论】"盘庚—小辛—小乙—武丁"之**世系与继位顺序**在《殷本纪》、今本《竹书纪年》、甲骨卜辞三方一致；**在位年数**（三年／二十一年）与**《盘庚》系年**（盘庚自作／小辛之世所编）两处存异说，并列不调和。

## 三、小结

- 一手节点（世系、"殷复衰"、居殷、名颂、崩继、周祭、卜辞庙号）均可核；异说如实并列。
- 表格中"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
- **须诚实承认**：小辛时间线是**上古纪年最不确定的一类**——绝对年代靠干支自洽推算与宽区间估计，在位年数差七倍，个人事迹几近于无。
