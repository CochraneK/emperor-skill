# 06 时间线 · 商汤（成汤/天乙/大乙，商朝开国之君）

> 维度定义：即位到崩的编年 + 对思维的影响，含史料成书背景与互核情况。
> **上古纪年多不可确考**：以下凡具体年代一律带"约"字；灭夏年代取夏商周断代工程推定之约前1600年，属框架值而非定论。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前21世纪（传说/半信史） | 契佐禹治水有功，舜命为司徒、敬敷五教、封于商，赐姓子氏 | 商族"以教化为职、以治水为功"的祖训成为汤"以宽治民"的远源（传说，材料有限） |
| 约前17–前16世纪（传世） | 自契至汤八迁；天乙立，是为成汤，始居亳，从先王居，作《帝诰》 | "迁都以就势"成为商族常态；居亳即择天下之中、接续祖业以图夏 |
| 约前16世纪初 | 葛伯不祀、仇饷杀童子；汤始伐之，作《汤征》 | 首战选"罪小而明"者，确立"伐罪不伐强、由小及大"的路线 |
| 约前16世纪初（灭夏前） | 伊尹以媵臣负鼎说汤，或曰汤五聘乃往；汤举任以国政 | 得一人而知夏之虚实；"不避出身、屡聘不倦"从此成为其决策签名 |
| 约前16世纪初（灭夏前） | 伊尹去汤适夏，丑其政而复归亳（作《女鸠》《女房》） | 敌情内线贯通；亦验证汤容人往返而不疑之气量 |
| 约前16世纪初（灭夏前） | 汤出见野张网四面，去其三面；诸侯闻之曰"汤德至矣，及禽兽" | 确认"可被转述的行为"比宣说更能换取诸侯向心力 |
| 约前1600 | 兴师率诸侯，伊尹从汤，汤自把钺伐昆吾，遂伐桀；战于鸣条，夏师败绩，桀奔南巢 | "代天行罚"叙事落地；但以臣放君之实，埋下"惭德"之结 |
| 约前1600（克夏后） | 欲迁夏社不可，作《夏社》；还亳作《汤诰》令诸侯；改正朔、易服色、上白、朝会以昼 | 由"征伐者"转为"为政者"：用制度与治绩接替军事叙事 |
| 约前1600后（立国后某年） | 大旱五年不收，汤以身祷于桑林，翦发磨手以身为牺牲；传"民悦雨至" | "罪在朕躬、以身代民"的担责范式成其德性资本，亦为后世君德标杆 |
| 约前1580（汤崩） | 太子太丁未立而卒；立太丁弟外丙，三年崩；立中壬，四年崩；伊尹立太丁之子太甲 | 继统规则未定，直接引出"伊尹放太甲"之变，反衬汤朝"人主—贤相"结构之脆弱 |
| 约前13–前11世纪（殷墟） | 卜辞屡祭"大乙/成唐"，列周祭直系先王首位 | 汤被制度化神化为"受命之祖"，其天命叙事成为商王朝合法性的基石 |
| 约前11世纪后（商亡后） | 《商颂》追述"古帝命武汤，正域彼四方"；春秋叔夷镈铭称"虩虩成唐……翦伐夏后，伊小臣唯辅" | 汤形象在旧族记忆中凝定为"受命—伐夏—得辅"三位一体，个人性格被抽薄为符号 |

## 二、史料成书背景与互核

- 【史料原文/一手】《尚书·汤誓》为最接近当事的文本，然今文《汤誓》之写定年代有商初口传、西周写定等说；《汤诰》《汤征》今文已亡，仅存伪古文与《殷本纪》引语。
- 【史料原文/一手】《史记·殷本纪》（西汉·司马迁）为汤事主源，其据《商书》《世本》等熔铸，叙事脉络为：契—八迁—居亳—伐葛—得伊尹—网开三面—伐昆吾伐桀—鸣条—践位—汤诰—改朔—崩—继统。
- 【史料原文/一手】《竹书纪年》（战国魏史，今存辑本）提供另一套系年与"汤有七名而九征"之说，可作互校。
- 【史料原文/一手】《诗经·商颂》（宋人祭祖乐歌）、叔夷镈铭（春秋齐器）为商后裔记忆的独立旁证。
- 【史料原文/一手】殷墟卜辞"大乙/成唐"仅为名号与祭祀记录，**不能提供任何言行细节**，但其存在证明汤为真实受祭祖先，而非后世凭空构造。
- 【考古/实物】偃师商城、郑州商城、二里头遗址构成"夏商更替"的考古背景；夏商周断代工程推定灭夏约前1600年。
- 【互核结论】"伐葛—得伊尹—伐桀—鸣条—践位—汤诰"主线在《殷本纪》《孟子》《墨子》《吕览》《商颂》中大体一致；**唯一系统性分歧在年数、地望与名号**（亳三说、鸣条三说、在位年数数说、名号七说），本 Skill 全部保留并列，不强行调和。

## 三、小结

- 一手节点与互核来源：《尚书》各篇、《史记·殷本纪》《竹书纪年》《商颂》、叔夷镈铭、卜辞、相关考古报告。
- 传述：桑林祷辞（《吕览》《墨子》《论语》引）。
- 框架推断：表中"对思维之影响"一栏为基于史事的归纳推断，非史书明言；具体年代除断代工程推定值外均为"约"值。
