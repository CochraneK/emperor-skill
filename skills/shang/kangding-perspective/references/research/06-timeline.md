# 06 时间线 · 康丁（商·康丁，约前12世纪）

> 维度定义：即位到崩的编年（上古多为"约前XXXX年"，须带"约"字）。
> **纪年说明**：商晚期诸王之绝对年代学界无定论。夏商周断代工程所颁商后期年表与诸家推算互异；康丁（《史记》作"庚丁"）之在位年数，今本《竹书纪年》一类作八年，另有他说。故本表一律以"约前12世纪"表相对先后，不作定点，凡具体年份皆为不可据之参考。

## 一、其世系位次（据《史记·殷本纪》）

- 父：祖甲（《殷本纪》"帝祖庚崩，弟祖甲立，是为帝甲"；同篇"帝甲淫乱，殷复衰"）
- 兄：廪辛（《殷本纪》"帝甲崩，子帝廪辛立"）
- 本人：康丁（《殷本纪》作"庚丁"；甲骨卜辞作"康丁"，周祭卜辞或称"康祖丁"）
- 子：武乙（《殷本纪》"帝庚丁崩，子帝武乙立。殷复去亳，徙河北"）
- 继统方式：兄终弟及（弟继兄位），再传子（父死子继）

## 二、编年表

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前13世纪末 | 武丁之世，商势极盛；周祭制度在此前后逐步完备（背景） | "王统即祀典之序"的底色由武丁至祖甲一路定下，成为康丁所守之绳 |
| 约前12世纪 | 祖甲立（《殷本纪》"是为帝甲"）；同篇又云"帝甲淫乱，殷复衰" | "衰势自父而起"成为其承继之局：接手时已知此盘无增量 |
| 约前12世纪 | 祖甲崩，子廪辛立（《殷本纪》"帝甲崩，子帝廪辛立"） | 继统先走一步"父死子继"，康丁之承位尚在其次 |
| 约前12世纪 | 廪辛崩，弟庚丁（甲骨作"康丁"，名嚣）立，都于殷 | 位出旁系；"以主祭自证、以守序立足"的模式自此确立 |
| 康丁在位前期 | 周祭不辍；依日名轮祭先王先妣，五祀一周；卜辞以"兄辛"祀廪辛、"父甲"祀祖甲之说（甲骨学界通说） | 以称谓与祀典把自己钉回直系序列；合法性由仪式给出 |
| 康丁在位期间 | 西土用兵不止：有"王叀令五族戍羌"之辞（《合集》28053，转引）；"戍屰……五族其雉王众"之辞（《合集》26879，转引）；俘获献祭之辞（《合集》26925，转引） | 形成"以戍代战"的军事样态：不求一战而胜，只求战线不溃、王众不失 |
| 康丁在位期间 | 卜辞多见"王其田，往来亡灾"之贞；学界多据卜辞论晚商王室有以殷为中心的田猎区（陈梦家《殷墟卜辞综述》可参） | 以巡行兼习武，构成周期性的、可重复的年度节拍 |
| 康丁在位期间 | 卜辞中"受年""其雨"与戍、祀并行；旬首必贞"旬亡祸" | 时间感为循环而非线性；确定性安放于程序，不确定性交给占卜 |
| 康丁之世 | 无迁都、无改制、无大役之记（与同篇系于武乙之"殷复去亳，徙河北"相对照） | 以"不改"渡过衰世；代价是未决问题被整笔留给下一代 |
| 康丁崩 | 子武乙立；晚商继统复归父死子继 | 把继承序列拉直，减少下一代争夺位的口实；但稳不住整条曲线 |
| 其后（武乙之世） | 武乙为偶人谓天神、与之博而僇辱之；为革囊盛血而射之，命曰"射天"；猎于河渭之间，暴雷震死（《殷本纪》） | 康丁之"不改"之后续；商势愈下，西土周人渐起 |
| 其后（约百年） | 商亡于牧野；《尚书·牧誓》所列反商西土联军中有"羌" | "戍羌而未服羌"之局在此收官：定得住边界，定不住时间 |
| 后世 | 自罗振玉、王国维以卜辞校《殷本纪》以来，学界通以"庚丁"为"康丁"之讹；董作宾甲骨五期断代将廪辛、康丁合为"第三期" | 其名由地下之辞改正于纸上之史；其"世"因卜辞与考古而可考，其"人"则仍无可考 |

## 三、若干须保留的异说

- **名号**：《殷本纪》"庚丁"／卜辞"康丁"（周祭卜辞"康祖丁"）。本 Skill 双标并存，正文以"康丁"为主、注明本纪作"庚丁"。
- **位次**：康丁在商王序列中的位次，诸家年表作第25、26、27位不一；本 Skill 不用序号，只言"继廪辛而立、传位于武乙"。
- **在位年数**：今本《竹书纪年》一类作八年，另有他说；诸家所给绝对年代（如前1152—前1145一类）互异，不可据。
- **"帝甲"之所指**：《国语·周语下》"帝甲乱之，七世而亡"，自祖甲数至帝辛适为七世，本 Skill 从《殷本纪》以"帝甲"为祖甲；古注另有一路不以"帝甲"为祖甲，异说并存，不调和。
- **迁都之记**：本纪系"殷复去亳，徙河北"于武乙之下，与《史记正义》引《竹书纪年》"自盘庚徙殷至纣之灭更不迁都"相抵牾。本 Skill 仅取"康丁之世未有迁都之记"这一共同点。
- **卜辞辞例归属**：部分戍羌辞例（如《合集》28053）系于廪辛抑或康丁，学界有出入；本 Skill 统称"廪辛康丁时期卜辞"以避险。
- **周之兴起之系年**：古公亶父去豳迁岐、周势渐长，学界系年参差，或系于祖甲以后、或系于武乙前后；本 Skill 不据以定康丁之世的具体事件。

## 四、小结（一手 vs 框架）

- 一手素材（史料原文/甲骨）：世系位次与继统方式（《殷本纪》）、"帝甲淫乱，殷复衰"（《殷本纪》）、"七世而亡"（《国语》）、戍羌与田猎卜辞辞例（转引）、武乙之"射天"与震死（《殷本纪》）、羌入牧野联军（《尚书·牧誓》）、卜辞校"庚丁"为"康丁"之考订。
- 框架推断：表中"对思维的影响"一栏全部为据史料推得之解释，非史书明言；凡无明文者（如田猎区之性质、不迁都之动机）均已标注推断或二手依据。
- 排除声明：未引用知乎／微信公众号／百度百科；凡网络与百科类页面所给出的康丁具体年份（如"前1152—前1145年"）与在位年数，本表不采为定点依据，仅作为"诸家异说之一"列于第三节。
