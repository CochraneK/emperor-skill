# 06 时间线 · 南庚（商王南庚，名更，约前14世纪末在位）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **前注（门禁）**：商属**传说/半信史**，商中期王年学界无定论（夏商周断代工程未颁商前期王年表）。下表绝对年代一律冠"约"，仅示相对先后，**不作定点**。南庚在位年数有三说（六年／二十五年／二十九年，详见 04-external-views），本表按《竹书纪年》今本"六年"之序排列。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前14世纪中（背景） | 祖乙迁庇、城庇；祖辛、开甲（沃甲）、祖丁相继"居庇"，庇为都约四十七年（《竹书纪年》、徐文靖《统笺》） | 南庚接手的是一个**经营近半世纪的旧中心**；"守旧都"成为其默认起点 |
| 约前14世纪末（背景） | 中丁以来"废適而更立诸弟子，弟子或争相代立，比九世乱，于是诸侯莫朝"（《殷本纪》） | 承统之序已乱；**位子的合法性成为首要问题**，而非业绩问题 |
| 约前14世纪末（即位前） | 祖丁崩，王族争立，南庚（沃甲之子、祖丁堂弟）得立（《殷本纪》） | 以旁系承统，"自证正统"的需求贯穿其一朝 |
| 约前14世纪末（元年丙辰） | 王即位，**居庇**——承四十七年之旧都，未即迁（《竹书纪年》） | 决策节奏确立为"**先观察、后动作**"：接手旧盘三年而后弃 |
| 约前14世纪末（三年） | **迁于奄**（古本辑文"南庚更自庇迁于奄"，《太平御览》卷八三引；《路史·国名纪》"后阳甲居之，商奄也"） | 一朝唯一可考之行动落地；思维由"守成"转为"另立中心"——**以空间换格局** |
| 约前14世纪末（六年） | 陟。祖丁之子阳甲继位（《殷本纪》"帝南庚崩，立帝祖丁之子阳甲"） | "沃甲—南庚"一系到此为止；其"自证正统"的努力未能越过一代 |
| 其后（同期评价） | "祖辛—祖丁—阳甲"一系取代"沃甲—南庚"一系为**直系**；羌甲（沃甲）在后期黄组卜辞中由直系改为**旁系**先王受祭 | 身后地位不由功业决定，而由"有无子孙继位为王"决定 |
| 其后（阳甲朝） | 阳甲"即位，居奄。三年，西征丹山戎。四年，陟"（《竹书纪年》） | 南庚所迁之奄被继承；其未做之事（征伐）由其继任者补上 |
| 其后（盘庚朝） | 盘庚元年"居奄"；十四年"自奄迁于北蒙，曰殷"（《竹书纪年》） | 南庚之奄为三代之都而终弃：其迁都在王朝尺度上是**过渡，而非终局** |
| 其后（武丁朝，约前13世纪中） | 卜辞中常祀南庚：安阳博物馆藏「受年」骨"贞勿侑于南庚"；《合集》01823正"南庚（害）王"与羌甲、父壬并卜；《合集》01822正"惟南庚/不惟南庚"等 | 在殷人祖灵体系中**未被除名**——这是南庚身后最持久、也最确凿的"位置" |
| 其后（晚商周祭定型） | 甲骨祀谱中南庚为**第16位**商王，《殷本纪》列为**第18位**（中壬、沃丁不见于甲骨文）；其名入祀谱而一系未续为直系 | "入谱"只证被承认，"降格"则由继承链决定——两条并观，方见其全貌 |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》（西汉·司马迁，卷三）为南庚事主源之一，记其继统与崩继，并以前后文给出"九世之乱"的总体框架；然**于其一朝只有两句**，不含任何其言、其政。
- 【史料原文/一手】《竹书纪年》（战国魏襄王墓所出，古本已佚，有辑本；今本二卷为明人所出）为南庚事之主要编年来源："南庚，名更。元年丙辰，王即位，居庇。三年，迁于奄。六年，陟。"古本佚文经《太平御览》卷八十三引作"南庚更自庇迁于奄"，与今本互证。
- 【注疏/近一手】清·徐文靖《竹书纪年统笺》、清·陈逢衡《竹书纪年集成》汇校《纪年》诸本，并引《皇极经世》《资治通鉴前编》之异年；其"祖乙二年迁庇至南庚二年共四十七年居庇"之说，为本卷"庇为四十七年之都"所本。
- 【注疏/二手】南宋·罗泌《路史·国名纪》"南庚更自庇迁奄，后阳甲居之，商奄也"；清·徐文靖考"奄"即鲁国、"商奄"之名因商王迁此而得（引《左传》昭四年"因商奄之民，命以伯禽"）。
- 【史料原文/一手·同时代】殷墟甲骨卜辞为**唯一的同时代第一手材料**，但属武丁以降（约前13世纪起），距南庚之世已逾百年；其中南庚只作**受祭对象**出现，可证其"在祀典"，**不可证其迁都、其政绩**（据《甲骨文合集》01822正、01823正、00721正、01772正、05658正，及安阳博物馆藏「受年」刻辞卜骨）。
- 【互核结论】三事可信度最高且诸源一致：①**名"更"**；②**居庇而后迁奄**；③**其后由祖丁之子阳甲继位**。至于①在位年数（六年／二十五年／二十九年）、②元祀干支（丙辰／戊辰）、③迁都原因、④是否逊位或夺位——**诸说并列，本 Skill 不裁断**。
- 【成书背景说明】《殷本纪》据先秦旧史与《世本》系统熔铸而成，其世系与甲骨祀谱大体相合而位次有差；《竹书纪年》为战国魏人所编的编年系统，商中期部分有整饬化的干支纪年（今本尤然），可作相对先后之参照，不宜作绝对年代之依据。

## 三、小结

- 一手节点（名、居庇、迁奄、六年陟、以堂弟承统、身后归祖丁一系）皆出《殷本纪》《竹书纪年》及甲骨卜辞；异说如实并列。
- 框架推断：表中"对思维之影响"一栏均为基于史事的归纳推断，非史书明言；凡涉动机、心境、判断者一律属推断。
- **材料限度之声明**：南庚名下**无一句其言、无一条其政（迁都除外）、无一件金文可指**；本时间线不填补、不设想。
