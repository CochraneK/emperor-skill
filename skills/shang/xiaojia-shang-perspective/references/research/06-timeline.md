# 06 时间线 · 小甲（商·第七王，约前16—前15世纪）

> 维度定义：即位到崩的编年。上古多为"约前XXXX年"，须带"约"字。
> **本文件的首要结论是：小甲的绝对年代不可确考。** 商代前期的公历纪年整体无定论（夏商周断代工程所定商前期框架为约前1600—前1300），加之小甲在位年数有 17／36／57 三说，故下文一律以"**约**"领起，并给区间而不给单一年份。表中"时间"列凡作"约前N世纪"者，皆为**推断性坐标**，非确切纪年。

## 一、小甲本人编年

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前16世纪（商前期，当太甲—太戊之间） | 太庚（《竹书》作"小庚"）崩。**小甲即位**，是为商第七王（汤—外丙—中壬—太甲—沃丁—太庚—小甲）。【一手：《殷本纪》"帝太庚崩，子帝小甲立"；《今本竹书纪年》"小甲名高。元年丁巳，王即位，居亳"】 | 承太甲"太宗"、沃丁、太庚三代之后的守成之局；其名下起点即"受位于无事之时" |
| 约前16—前15世纪（小甲元年起） | **居亳**，不改都、不迁邑。【一手（后世辑本）：《今本竹书纪年》】 | 确立"以不动为治"的底色；与前后的太庚、雍己、太戊同处"亳都"序列，直到仲丁才"自亳迁于嚣" |
| 约前16—前15世纪（在位期间） | **史不著一事**：无征伐、无命卿士、无兴作、无盟会之记载。【一手：《殷本纪》小甲条；《今本竹书纪年》小甲条】 | 其"执政逻辑"只能在史料空白中反推，且反推结论须标为框架推断 |
| 约在位末年前后（晚商追记） | 后世商王（周祭制度成于祖甲—帝辛之世）将小甲列入周祭受祭先王谱，**为旁系先王（无先妣配偶同祭）**。【一手·考古：周祭卜辞；常玉芝《商代周祭制度》世次表】 | 身后位分"降格"：因其无子继位为王故入旁系——后人对其历史位置的判定，与其生前事迹无关 |
| 约前16—前15世纪（在位十七年／异说三十六年／五十七年后） | **小甲崩（"陟"）**，弟雍己立。【一手：《殷本纪》"帝小甲崩，弟雍己立，是为帝雍己"；《今本竹书纪年》"十七年，陟"】 | 继统由"父死子继"转为"兄终弟及"；其身后即《殷本纪》所记"殷道衰，诸侯或不至" |
| 紧接其后 | 《殷本纪》于"帝小甲崩，弟雍己立，是为帝雍己"之后紧书："**殷道衰，诸侯或不至。**"（**原文无"帝某之时"限语**，故段界两分：可作收束小甲纪事，亦可作开启雍己纪事）【一手：《殷本纪》】 | 史笔把"衰"的起点放在小甲—雍己之际；此九字成为小甲名下最重的历史评价，且**并非他本人的言行所致**（本纪未载其致衰之事） |
| 紧接其后 | 雍己崩，**弟太戊立**；太戊用伊陟、臣扈，遇"祥桑谷共生於朝"而问政修德，"**殷复兴，诸侯归之，故称中宗**"。【一手：《殷本纪》】 | 衰势的逆转不发生在小甲朝，而发生在下一代——他的"问题"由后人作答 |

## 二、与小甲相关的"后世时间坐标"（决定他如何被记住）

| 时间 | 事件 | 对小甲历史形象的影响 |
|------|------|----------------------|
| 约前1300（盘庚十四年前后） | 盘庚"自奄迁于北蒙，曰殷"（殷墟），商代进入晚商。【一手（后世辑本）：《今本竹书纪年》；一手：《殷本纪》"盘庚渡河南，复居成汤之故居，乃五迁"】 | 商前期（含小甲）自此再无都邑遗存可寻，其史料命运在此定格 |
| 约前1250—前1046（武丁至帝辛） | 殷墟卜辞大量产生（今存十余万片），其中周祭卜辞见"小甲"受祭。【一手·考古：殷墟甲骨；《甲骨文合集》所收周祭卜辞】 | 这是小甲"存在过"的**唯一同时代物质痕迹**，且仅为祭祀记录 |
| 约前1046（周初） | 商亡。此后商史靠周人及后世的追述与残卷流传。【史论/二手】 | 小甲一代之政事，大概率在商末周初即已散佚 |
| 前2世纪（西汉前期） | 司马迁撰《史记·殷本纪》，据"秦记"与商史残卷排比商王世系；小甲仅得两句世系衔接，其后紧书"殷道衰，诸侯或不至"（无限语、两读并存）。**同书《三代世表》却作"帝小甲，太庚弟也"**（徐广《集解》引），世系自相异。【一手/注疏】 | 他在正史中的全部形象，就此定型为"两句世系＋其后一句衰评" |
| 约前299—前257年间（战国魏） | 《竹书纪年》成书，记小甲"名高、居亳、十七年陟"（西晋太康二年即公元281年出自汲冢）。【一手（后世出土文献）】 | 补出私名与都邑，但仍是极简小传 |
| 281（西晋太康二年） | 汲冢出土《竹书纪年》，经荀勖、和峤等整理传世。【一手·考古/文献学】 | 现存关于小甲最早的成文记载来源之一 |
| 1917 | 王国维撰《殷卜辞中所见先公先王考》及《续考》，以卜辞校《殷本纪》，证商世系大体可信并订正部分次序。【二手：现代学术研究】 | 商王世系（含小甲）由"传世文献"升为"二重证据"，但**所校订者多为先公与个别次序，于小甲本人的事迹全无补益** |
| 20世纪—今 | 陈梦家据卜辞祭序把世系校为"小甲—大戊—雍己—中丁"；中国社科院《商代王位继承制的特质》谓大戊"为雍己次兄、小甲次弟"；侯乃峰则主张祭序≠世系次序，反对此校正。**两说未定。**【二手：现代学术争论】 | "小甲与太戊、雍己孰先孰后"至今无定论，其历史坐标仍带问号 |
| 1996—2000 | 夏商周断代工程公布商前期框架约前1600—前1300。【二手：现代学术工程】 | 为小甲提供"约前16—前15世纪"的粗坐标，仍不能精确到年 |
| 迄今 | **无任何一处考古遗址可与"小甲"直接对应**；其所"居"之"亳"（偃师商城说／郑州商城说／内黄等说）学界聚讼未定。【二手：考古学争议】 | 他的考古存在度，等于周祭谱上的一个名字 |

## 四、小结（一手 vs 框架）与排除声明

- 一手素材（史料原文/出土文献/考古）：《史记·殷本纪》小甲条及商代前期诸王纪事；《今本竹书纪年》小甲条与盘庚迁殷条；《史记集解》引徐广引《三代世表》；《太平御览》卷八十三引《纪年》《史记》；《竹书纪年》汲冢出土（281）之文献学事实；殷墟周祭卜辞及《甲骨文合集》所收卜辞；常玉芝《商代周祭制度》所据周祭资料。占本文件证据之主。
- 二手材料：清·徐文靖《竹书统笺》卷五——"史记曰雍巳之时殷道衰诸侯或不至"（殷道衰系于雍己之注疏读法）、"小庚小甲雍巳元年即位皆不言命卿士者并咎单为相也"（用人注疏推断），均标【史论/二手·清人注疏】；陈梦家据卜辞祭序校世系之说、侯乃峰之反论、夏商周断代工程年代框架、通俗年表——见 04 号文件。
- 框架推断："约前16—前15世纪"之粗坐标、"以守代拓""身后降格"等对思维影响之列注、以及由事实反推的因果，均为框架推断，已逐项标注。**表内"对思维的影响"一栏系据史料推得，非史料原文。**
- 排除声明：未引用知乎／微信公众号／百度百科；凡网络通俗年表所给"小甲 前1516—前1499"之类精确年份，本包不作为纪年依据。
