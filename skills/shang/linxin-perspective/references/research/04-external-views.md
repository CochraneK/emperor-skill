# 04 · 他者视角：史评、注疏异说与学界争议（廪辛）

> 调研目标：汇集「他人如何看廪辛」——后世史评与史论、注疏与名号异说、甲骨学与考古学界的考订与争议。廪辛本人材料极稀，**故他者视角在其身上所占比重反比一般帝王为大**：其「是否存在」「是否有其位」「何以不入祀谱」，皆由他者之论定。

## 一、史评与史论

### 1. 本纪的「结构性沉默」——最重的史评
- 《史记·殷本纪》于廪辛仅「帝甲崩，子帝廩辛立。帝廩辛崩，弟庚丁立，是為帝庚丁」两句【一手：《史记·殷本纪》卷三】。**无一字评价、无一事记述**——这种沉默本身即是史家态度：在司马迁的殷商叙事中，廪辛是一个「序中之人」，非「事中之人」。
- 前后文之时代判语：紧接其前有「帝甲淫亂，殷復衰」，其后有「殷復去亳，徙河北」（武乙时）【一手：同上】。**廪辛被夹在一个被判定为「衰」的时段之中**，虽未被直接贬斥，却无从脱出这一叙述框架。

### 2. 先秦文献对晚商王统的两种相反之调
- **褒调**：《尚书·周书·无逸》载周公语：「其在祖甲，不义惟王，旧为小人。作其即位，爰知小人之依，能保惠于庶民，不敢侮鳏寡。肆祖甲之享国三十有三年。」同篇又曰：「自殷王中宗、及高宗、及祖甲，及我周文王，兹四人迪哲。」——以祖甲与中宗太戊、高宗武丁、周文王并列，**祖甲入「三宗／四人迪哲」之列**【一手：《尚书·无逸》】。
- **贬调**：《国语·周语下》：「玄王勤商，十有四世而兴；帝甲乱之，七世而陨。」——以帝甲（祖甲）为殷衰之转捩点【一手：《国语·周语下》】。
- **汉人承贬调**：《史记·殷本纪》「帝甲淫亂，殷復衰」【一手：《史记》】。
- **张力**：**同一祖甲，而《无逸》褒之、《国语》贬之，二说皆有一手之据**。廪辛为祖甲之子、承其政者，故这一褒贬之争直接落于其身；本 Skill 两存之，不调和不作结。
- **注疏异说**：《无逸》之「祖甲」所指，旧有两说——郑玄、马融以之为武丁之子帝甲（即祖甲），亦有说为太甲者；此为注疏史上之异说，本 Skill 并列不决【二手：注疏异说】。

- **辨析**：「廩」「冯」「凭」或为音假；「祖辛」「兄辛」「父辛」为庙号与亲属称谓两个层次之别。**异文之产生或为繁体简体、或为音假音变、或为形讹**【二手：甲骨学界对「人名今古异字」之通说】；孰为原文，本 Skill 并列不决。
- **或谓其「名先」、姓子**：此说多见于晚出之书与今人通俗叙述，**未见于先秦两汉核心文献**，本 Skill 标为存疑【待考】。

## 三、甲骨学界的考订与争议

### 1. 廪辛「是否存在」之争（核心争议）
- **质疑方**：廪辛不见于周祭卜辞（遍祀商先王的固定祀典）。有学者据此推断，「中壬、沃丁、廩辛」三王「可能并不存在，或未曾即位为王，或其继位不合法统」，故被摒弃于周祭制度之外【二手：转述质疑方之说】。
- **驳论方**：《史记·殷本纪》「廩辛为祖甲之子、康丁之兄，曾即位为王，文献言之凿凿，是无可疑」；且「我们今天不能看到全部甲骨卜辞，所以不能据此得出殷无廩辛的结论」；甲骨文三、四期之「祖辛」「兄辛」极有可能就是廩辛【二手：《商王廩辛何以未入周祭祀谱》】。
- **关键证据**：
  - 《合集》27364「鬯祖丁，父甲。[父]甲以兄辛」——陈梦家释「此『父甲』是廩辛、康丁之所以称祖甲，此『兄辛』是康丁所以称廩辛」，「这一证据非常有力，涉及祖丁（武丁）、父甲（祖甲）等亲属关系，**不容别作解释**」【二手：陈梦家《殷墟卜辞综述》，转引】。
  - 《殷契粹编》341「辛亥卜，其侑歲于三祖辛」——郭沫若考释「此三祖辛當是廩辛，其前有祖辛、小辛，此居第三位也」【二手：郭沫若考释，转引】。
  - 董作宾：廪辛在康丁卜辞中被称为「兄辛」，在武乙时被称为「父辛」【二手：董作宾《五十年考订殷世系的检讨》】。
- **本 Skill 立场**：**两说并列，不替任何一方作结**；据《合集》27364 之亲属关系可证其人实有，然其即位之「合法性」在史料上无从确证，亦不伪称「一手确证」。

### 2. 「何以不入周祭」二解
- **旧解（位不正）**：见上。
- **新解（庙号日干受限）**：先王庙号干支早已确定，而周祭「始于祖甲而完备于乙辛之时，是后世人为设计的」；欲使周祭次序既与庙号日干吻合、又与即位次序吻合，「事实上是有困难的」——「最有说服力的例证，就是周祭祀谱无法安排廩辛的位置，致使廩辛被置于谱外」【二手：《商王廩辛何以未入周祭祀谱》《商代王位继承制的特质》】。
- **附带之谨慎**：有学者提醒「甲骨卜辞今已发现十余万片，看似数量庞大，具体到某些细节问题，资料仍显不足，是以**说有易，说无难**」；「商代周祭制度的研究，有些问题并不十分清楚，据以考史亦须审慎」【二手：同上】。

### 3. 周祭制度与商王世系研究之脉络（他人之成果，廪辛为其中一例）
- **董作宾**：最早发现商代周期性祭祀制度，称「五祀统」【二手】。
- **陈梦家**：据其周而复始之特点命名为「周祭」，为学界广泛接受；并以卜辞亲称考订廪辛之实有【二手】。
- **常玉芝《商代周祭制度》、许进雄《殷卜辞中五种祭祀的研究》**：系统整理周祭祀周【二手】。
- **王国维《殷卜辞中所见殷先公先王考》**：以卜辞校《殷本纪》世系之始，为后世方法之基【二手】。
- **黄铭崇**：《甲骨文、金文所见以十日命名者的继统「区别字」》（《中央研究院历史语言研究所集刊》76-4，2005）及甲骨学专著《殷契释亲》「商代的世（嗣）系及王统」章，列《殷本纪》有而卜辞未见之三王为仲壬、沃丁、廩辛，并整理商王名号、位序、分组、承继之表【二手】。

### 4. 张光直「十世系（乙丁制）」说——涉及廪辛世次之学界悬案
- **张光直《商王庙号新考》（1963）**：主张商王庙号有隔代同组现象，分A（甲、乙、戊、己）与B（丙、丁、壬、癸）两组隔代交替，王位在十个以天干为代表之世系中传承，**两代商王间之关系为舅甥，非父子**；并以之拟周代「昭穆」【二手：张光直说】。
- **质疑方**：学者力证商王室自始出自一姓族级血亲组织，「只要证明商王室从上甲至帝辛代代之间为生身父子关系，便是证明商王室乃系一父系世（嗣）系，同时也证伪了商王室十世（嗣）系说」【二手：《殷契释亲》章】。
- **本 Skill 立场**：此为学界悬案，**涉及廪辛之世次与继统性质，本 Skill 两存之，不采其一为正文立论根基**。

## 四、考古与实物层面

- **殷墟甲骨**：《合集》27364（康丁之世）等片为廪辛名下最直接之同时代实物证据【一手：卜辞】。
- **晚商金文**：用于校核文献与卜辞中之王名（如「帝乙名见于晚商金文」一类的比证），然未见与廪辛直接相关之铭文【一手：金文通例，逐器未核】。
- **殷墟王陵与祭祀遗存**：晚商王都及王陵区之发掘，提供廪辛所处时代之物质背景；**但无任何可指认属于廪辛之陵墓、器物或文字**，此为本人物「考古层面之空白」【一手：殷墟考古报告；空白之判定属框架推断】。
- **说明**：凡网络百科类条目所载廪辛「征羌方」「征调卫、虎、受等部族」「射杀蚕丛氏首领」等战争叙述，**未见于学刊与甲骨著录，本 Skill 一概不采为据**。
