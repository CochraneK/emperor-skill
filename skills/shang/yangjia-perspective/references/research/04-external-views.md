# 04 他者视角 · 阳甲（商王阳甲，一名和甲/和）

> 维度定义：后世史评/史论、注疏异说、考古与学界争议。
> **前注（门禁）**：商属**传说/半信史**，材料有限。阳甲是商王中**史料最少者之一**，其"他者视角"有一个极特殊之处：**后世于他几乎无评**——既无贾谊《过秦论》式的史论，亦无《尚书》式的褒贬，所存者多为**名号异释、年数异说、与"九世之乱"的定性之争**。本卷据实收录，凡矛盾并存者**不强行调和**。

## 一、最早的"他者"：司马迁之断——"帝阳甲之时，殷衰"

- 【史料原文/一手】《史记·殷本纪》："帝南庚崩，立帝祖丁之子阳甲，是为帝阳甲。**帝阳甲之时，殷衰。**"
- 【史料原文/一手】《殷本纪》定其由来："自中丁以来，废適而更立诸弟子，弟子或争相代立，**比九世乱**，于是**诸侯莫朝**。"
- 【史论/二手】此为史迁对阳甲一朝的**全部评价**：不复述其功过、不辨其是非，只以"殷衰"二字作结，并将其置于"九世"积乱之末。**在《史记》的叙事结构中，阳甲的"角色"是"衰之见底者"**，而非"衰之作者"。这是关于阳甲最早也最有力的"他者定义"。

## 二、纪年与在位年数：三说并立，不可调和

- 【史料原文/一手】《竹书纪年》（今本）："阳甲……**四年，陟。**"（元年壬戌即位，四年崩）
- 【史料原文/一手】《太平御览》卷八十三引《史记》："**阳甲在位十七年。**"
- 【史料原文/一手】《皇极经世》（《外纪》）："**七年**"；又引《帝王本纪》云"**十七年**"。
- 【框架推断】同一王，三说（4／7／17）并立。本 Skill **保留矛盾，不强行调和**，亦不据任一说推算其在位年代；文中凡涉年数，皆标"约"字并注异说。（详见 06 卷。）
- 【史论/二手】须注意："陟"在殷人用语中为"升天"之讳辞，甲骨与《纪年》习用；《御览》所引《史记》之"在位十七年"与今本《史记·殷本纪》不载在位年数，故其"十七年"恐非《殷本纪》原文，来源存疑——此系本 Skill 之校记，非定论。

## 三、名号之辨："和甲"、"羊甲"、"象甲"、"兔甲"——异释四出

- 【史料原文/一手】《山海经·大荒北经》郭璞注引古本《竹书》："**和甲西征，得一丹山。**" —— 古本作"和甲"。
- 【史料原文/一手】今本《竹书纪年》："阳甲（**一名和甲**）名和。"
- 【史论/二手】**王国维**《今本竹书纪年疏证》："隶书'和'、'祖'二字形相近，**和甲疑即祖甲之讹**。" —— 王说据此将"西征得丹山"之事**改系于祖甲**（《辑校》即列祖甲下）。
- 【史论/二手】**杨树达**《积微居甲文说》驳王说："'和甲'之称，与《吕氏春秋》称河亶甲为'整甲'者辞例同，**非后人所能杜撰**，此可证今本《纪年》阳甲名和之说为可信。"斥王说为"**武断甚矣**"。（《积微居甲文说》卷下）
- 【史论/二手】**郭沫若**《卜辞通纂》以卜辞字形立说："象、○与阳同部，则**象甲若○甲即阳甲矣**。" —— 由字形求其实。
- 【史论/二手】卜辞中该王庙号的**隶释本身**即有多说：或释"羊甲"、或释"象甲"、或释"兔甲"、或释"喙甲"，学界至今无一致隶定。
- 【框架推断】**此三说对峙，正是关于阳甲的"学术对话"之全部**：一疑其名之伪（王），一信其名之真（杨），一由字形求其实（郭）。三说皆非铁证——王说纯据形近、杨说据辞例而辞例亦可反、郭说所隶之字本有异释。本 Skill **并陈不裁**，凡称其名，写作"阳甲（一名和甲；异说见 04 卷）"。

## 四、卜辞与《殷本纪》的对勘：世系获证，阳甲在其列

- 【史论/二手】**王国维**《殷卜辞中所见先公先王考》《续考》：以卜辞祭祖谱系与《殷本纪》对勘，证《世本》《史记》所载商先公先王名号次序**基本可信**，仅个别名号与次序有误。此为中国上古史研究之里程碑，也是商由"传说"转入"信史"的关键一步。
- 【史论/二手】经此对勘，**"汤—大甲—大戊—中丁—外壬—河亶甲—祖乙—祖辛—沃甲—祖丁—南庚—阳甲—盘庚"** 一系在甲骨（周祭卜辞）中大体有对应记录；阳甲之名**在卜辞祭祀体系中占有一席**。
- 【史论/二手】**李济**之评（转述）：甲骨文对司马迁排定的继承秩序予以**强力证实**，仅少数名号需修正，**无核心内容可删改**——此论坐实《史记》为经得起考古检验的"实录"。
- 【史论/二手】（须一并记录之异说）有学者主张 **祖乙应为仲丁之子，而非《殷本纪》所记河亶甲之子**。此类世次差池提示：即便在"九世"这一段，文献与卜辞亦非处处吻合。本 Skill 保留此异说不裁。
- 【框架推断】由此可推一个对阳甲极重要的"他者视角"：**在商人的祀典中，阳甲未被除名**。史家说他"殷衰"，商人却仍以先王之礼祀他——**"史评"与"祀典"的两种他者眼光，对阳甲给出了不同的待遇**。此为本 Skill 之综合推断，非某家明言。

## 五、学术争议核心："九世之乱"是"乱"还是"制"？

- 【史料原文/一手】《殷本纪》："自中丁以来，**废適而更立诸弟子，弟子或争相代立，比九世乱**。"
- 【史论/二手】**传统读法**：以"废適立弟"为乱源，视中丁至阳甲九世为**继承失序、兄弟相争、诸侯离心**的衰世；阳甲即此衰世之末君。
- 【史论/二手】**质疑读法**（现代学界主流倾向之一）：商代王位继承本为"**父死子继**"与"**兄终弟及**"并行之制（商前期尤多兄弟相继），"九世"间王之更迭**未必尽是"争相代立"之乱**；司马迁以周制（嫡长继承）之眼观商制，遂以"废適"为病。**"乱"或为后人之定性，而非当时之实况。**
- 【史论/二手】**中间读法**：制虽容兄终弟及，然中丁以降**继统频易、都邑屡迁、诸侯莫朝**，三者叠加即为实际之衰——不必以"制度"为"乱"脱责，亦不必以"乱"尽归诸人之争。
- 【框架推断】此争议对阳甲之评价影响极大：**若从传统读法，阳甲是"九世乱"之末环，承其衰名；若从质疑读法，阳甲不过是在既定继统之制下依例受立之一王，"殷衰"之责不在其身。** 本 Skill **并陈两读，不替阳甲定罪，亦不为阳甲开脱**。

## 六、考古视角：都邑屡迁与"九世之乱"的物证（及争议）

- 【史料原文/一手】《竹书纪年》系联：河亶甲"自嚣迁于相" → 祖乙"自相迁于耿""自耿迁于庇" → 南庚"自庇迁于奄" → 阳甲"居奄"（不迁）→ 盘庚"自奄迁于北蒙，曰殷"。
- 【史论/二手】**郑州商城**、**小双桥遗址**（学界多以为即仲丁之隞都）、**洹北商城**（学界多以为盘庚迁殷之初都，或谓河亶甲所居）等遗存，被广泛用于讨论商前期的都邑转移；**偃师商城**亦在其列。
- 【史论/二手】**殷墟**（安阳小屯）自盘庚迁殷至纣之灭，为商后期都城，出土甲骨为其王室档案——**阳甲之世不在殷墟之列**（阳甲居奄，盘庚方迁殷）。
- 【史论/二手】关于商前期**何以屡迁**，学界有"水患说""政治斗争说""游农说""去奢行俭说"等，**无定论**。以之解"九世之乱"，各家所据器物层位与文献纪年尚未能严丝合缝地对应。
- 【框架推断】**诚实提示**：**考古学至今未出任何一处可确指为"阳甲之世"或"阳甲之奄都"的实证**。"奄"之地望（多说在今山东曲阜一带）亦为后世文献推考，非考古确证。凡此**不得伪称"考古确证"**。

## 七、后世的"无评"——一种特殊的他者视角

- 【框架推断】阳甲在先秦两汉以下之史论、政论、诗文中**几无出场**：既无"殷有三仁"式的道德评断（其时不属纣世），亦无"太甲悔过""盘庚中兴"式的榜样叙事。
- 【框架推断】其被提及，多是在**商王世系表**中占一行、在"九世之乱"的一段话里作结。**"被列表而不被评论"**，是阳甲所受的最主要他者待遇。
- 【史论/二手】现代普及读物中"阳甲"多被简述为"南庚之侄、盘庚之兄、殷衰之君"，**基本是《殷本纪》与《竹书纪年》的复述，未增新材料**；凡此类读物皆属二手，本 Skill 仅作背景参照，不取为事实源。

## 八、小结（一手 vs 框架）

- **一手素材**：《殷本纪》"殷衰""九世乱""诸侯莫朝"之原文；《竹书纪年》阳甲四条及河亶甲/祖乙/南庚/盘庚迁都条；《山海经》郭注所引古本《竹书》；《太平御览》所引异说之年数。以上皆为本卷所据之原始文献。
- **二手素材（史论/学术）**：王国维、杨树达、郭沫若、李济及甲骨学界诸说；考古学界关于商前期都邑与"屡迁"成因诸说。**本卷已逐条标"史论/二手"。**
- **框架推断**：①"史评与祀典两种眼光不同"；②"九世之乱"两读对阳甲评价之影响；③"被列表而不被评论"。三项皆为本 Skill 之综合推断。
- **矛盾保留**：在位年数（4／7／17）、名号（阳甲／和甲／羊甲／象甲／兔甲）、"九世之乱"之性质（乱／制／折中）、祖乙之父（河亶甲／仲丁）——**四组矛盾一律并列，不调和。**
