# 05 决策记录 · 阳甲（商王阳甲，一名和甲/和）

> 维度定义：其征伐、迁都、继统、用人等重大决策及事后评说。
> **前注（门禁）**：商属**传说/半信史**，材料有限。阳甲一朝**可确证的决策，只有三项**：受立、居奄不迁、三年西征丹山戎。其"用人"（如祖乙之"命彭伯、韦伯""命卿士巫贤"，盘庚之"图任旧人共政"）**史料全无记录**。本卷严格分列"可确证之决策"与"据史料推得之决策倾向"，凡后者一律标注；**空缺不填补。**

## 二、决策一：受立于九世积乱之末（继统）

- 【史料原文/一手】《史记·殷本纪》："**帝南庚崩，立帝祖丁之子阳甲，是为帝阳甲。**"
- 【史料原文/一手】《殷本纪》叙其世系之链："中丁 → 外壬 → 河亶甲 → 祖乙 → 祖辛 → 沃甲 → 祖丁 → 南庚 → 阳甲"，并断以"**废適而更立诸弟子，弟子或争相代立，比九世乱**"。
- 【史料原文/一手】《竹书纪年》：南庚"元年丙辰，王即位，居庇。三年，迁于奄。六年，陟。"阳甲"元年壬戌，王即位，居奄。"
- 【框架推断】此次继统有一处关键结构：**阳甲之父为祖丁，而其前任南庚为沃甲之子**（沃甲为祖辛之弟、祖丁之堂弟）——即**王位由"沃甲一系"回转到"祖丁一系"**。此回转在《殷本纪》中正属"更立诸弟子"之一环。据世系链推得：阳甲之受立不是"父传子"的顺承，而是**堂兄弟两系之间的轮替复位**。属框架推断。
- 【框架推断】**决策的被动性**：史料未载阳甲有任何争取、结盟、排斥之动作，只书"立……是为帝阳甲"（主语省略，受立者为被动方）。据文句推得：**此次继统对阳甲而言是"被立"而非"夺立"**。属框架推断。

## 三、决策二：居奄不迁——守成而不扰民

- 【史料原文/一手】《竹书纪年》："阳甲……元年壬戌，王即位，**居奄**。"；其前任南庚"三年，**迁于奄**"；其继任盘庚"十四年，**自奄迁于北蒙，曰殷**"。
- 【框架推断】**"居奄"是一句决策陈述**：《纪年》体例中，王即位必书其所居或所迁；书"居"而不书"迁"，即表示**不改都、不动迁**。故阳甲之"居奄"可读作一项明确的**保守决定**：承南庚之都而守之。属据体例推得。
- 【框架推断】**决策之动因（据史料推得）**：殷人屡迁而民怨——盘庚迁殷时《殷本纪》明载"**殷民咨胥皆怨，不欲徙**"，《尚书·盘庚下》载"**今我民用荡析离居，罔有定极**"。据此推得：在九世屡迁之后，**"不迁"本身即是安民之策**。阳甲之守，或即针对前朝频迁之弊。属框架推断，不得坐实为其本意。
- 【史论/二手】**事后评说（本 Skill 之评，非史料）**：以结果论，阳甲之"守"未止殷衰；其弟盘庚之"迁"反致复兴（《殷本纪》"殷道复兴，诸侯来朝，以其遵成汤之德也"）。**故后世多以迁殷之功归盘庚，而阳甲之"不迁"无所称道**——但须注意：**迁之成功并不逻辑地证明守之为错**，二者面对的是不同的时机与不同的国力。此评为本 Skill 之框架推断。

## 四、决策三：三年西征丹山戎——以征伐撑持邦畿

- 【史料原文/一手】《竹书纪年》："**三年，西征丹山戎。**"
- 【史料原文/一手】《山海经·大荒北经》郭璞注引《竹书》："**和甲西征，得一丹山。**"
- 【框架推断】**时机之决策（据史料推得）**：其征不在即位元年、不在二年，而在**第三年**。此一"滞后两年"的选择，若与前朝河亶甲"三年克邳、四年征蓝夷、五年伐班方"之连年用兵对照，可见阳甲之征**审慎而无连续性**——一征而已，此后无征。属框架推断。
- 【框架推断】**决策之目的（据史料推得）**：其世"诸侯莫朝"，则邦畿之外离心；此时取一戎族之地（"得一丹山"），可正西面之边、示邦畿犹能出师。是**以外攘补内衰**。此推属实势推论，非史料明言。
- 【史论/二手】**结果之不明**：史料只记"得一丹山"，**不记是否大胜、是否班师、是否献俘，亦不记此征之后丹山戎是否归附**。《竹书》记盘庚则明书"七年，应侯来朝"，记武丁卜辞则屡书"获羌""克某方"；阳甲之征**只有起点没有结局**。此"无结局之记"是评价其征伐决策的最大困难。

## 五、决策四（空白项）：用人、命官、制度——史料全无记录

- 【史料原文/一手】《殷本纪》于阳甲**不书任何一条任命**；《竹书纪年》亦不书。
- 【框架推断】**对照可见缺口之大**：祖乙朝有"命彭伯、韦伯"（《纪年》）"命卿士巫贤"（《书·君奭》），盘庚朝有"图任旧人共政"（《盘庚上》），唯中丁至阳甲九世之间，**用人记录几近全空**。
- 【框架推断】此空缺有两种读法：①阳甲之朝确无大事可记；②其朝人事紊乱、史官无从记（"诸侯莫朝"即其人亦不来）。**本 Skill 并陈两读，不择一坐实**。
- **诚实守则**：**不得因"用人记录空缺"而虚构其"任用了某某"**——本 Skill 于其用人一项，只写"史料无载"。

## 六、决策之评说（后世）

- 【史料原文/一手】《殷本纪》之总评：**"帝阳甲之时，殷衰。"** —— 不说其决策之得失，只断其结果之衰。
- 【史论/二手】后世史论（如《通鉴外纪》一类编年综述）多沿"九世之乱"之说，以其为衰世之君，**未提出独立的评价**。
- 【框架推断】**本 Skill 的处理**：不将"殷衰"逆推为"阳甲之失"。理由有三——①衰自中丁始，历九世；②其继统非其自致；③其在位短暂（四年／七年／十七年，异说）。故本 Skill 于其决策之评，取"**承衰者之评，非致衰者之责**"。

## 七、小结（一手 vs 框架）

- **一手素材（可确证之决策）**：受立（《殷本纪》《竹书纪年》）、居奄（《竹书纪年》）、西征丹山戎（《竹书纪年》《山海经》郭注）。这三项是阳甲全部可考的决策。
- **框架推断**：①继统之"两系轮替复位"与"被立"性质；②"居奄"即不迁之保守决定及其安民动因；③"三年始征"之审慎与"以外攘补内衰"之目的；④用人空缺之两读；⑤"承衰者非致衰者"之评。五项皆明标推断。
- **绝不伪称之处**：不伪称阳甲有诰命、有命官、有盟誓、有制度创设；不伪称"得一丹山"为"大胜"。凡史料空缺者，本卷写"无载"而不写"推想之事实"。
