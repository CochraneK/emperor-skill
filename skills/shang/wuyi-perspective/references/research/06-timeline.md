# 06 时间线 · 商·武乙（子瞿，约前1147–约前1113 在位，晚商）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **商属传说/半信史，材料有限。** 武乙之世距今约三千一百年，绝对年代不可确考：以下凡作年者一律冠"约"，并以夏商周断代工程的推定为坐标，异说并列。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1147（前） | 武丁—祖庚—祖甲—廪辛—康丁相继；祖甲立周祭之制，祭祀由繁乱走向程式化；廪辛、康丁之世征伐渐少，王权与巫祝张力显现（背景） | 武乙所承之局：祭祀已僵化为程序，神意解释权回升至巫祝之手——其"射天"所对之靶，正是在这一段被立起来的 |
| 约前1147 | 康丁崩，子武乙即位（"帝庚丁崩，子帝武乙立"）。【异说】夏商周断代工程定其元年在约前1147 | 继统为父子相传，商王正统未断；此点决定其改革不必以夺位为代价，可直接动作 |
| 约前1147（即位后） | "殷复去亳，徙河北"——迁都，且史料未存告谕之辞 | 开局即动空间：先换场域再换规则。养成"先行后告、以既成事实代替说服"的执政习惯 |
| 约前1147–约前1113 之间（具体年无载） | "为偶人，谓之天神。与之博，令人为行。天神不胜，乃僇辱之。为革囊，盛血，卬而射之，命曰'射天'。" | 以最低成本的公开象征行动挑战神权解释体系；由"代理神意者本是人"推到极致——他亲手替神落了子，也亲手射了神 |
| 约前1114（三十四年） | 【辑本】"周王季历来朝，武乙赐地三十里，玉十瑴，马八匹。" | 以地、玉、马换取西方屏藩的名分效忠；确立"以给予代征伐"的对外模式 |
| 约前1113（三十五年） | 【辑本】"周王季伐西落鬼戎，俘二十翟王。"——商不劳师而得西陲之安 | 外包防务在短期内奏效；此模式之长期代价（受赐者坐大）在季历、姬昌两代后方显，武乙未见其果 |
| 武乙之世（约前1147–约前1113，具体年无载） | 【史论/二手】东方失控：《后汉书·东夷列传》"武乙衰敝，东夷寖盛，遂分迁淮、岱，渐居中土" | 西以赐、东以让，同一盘面上"用最小代价换一时之安"；也埋下商末两线受敌之势 |
| 约前1113 | "武乙猎于河渭之间，暴雷，武乙震死。"子太丁（文丁）立 | 死于西陲边地。死因史无定说（天罚/意外/战死/病死），而后世以"天罚"覆盖之——其一生最重的一课由此而来：解释权不在他手里 |
| 约前1113 之后 | 文丁及其后王将武乙纳入周祭王名序列，配妣戊、妣癸等受祭；"武乙"庙号由此确立 | 生前的挑战者被身后的祭祀制度收编：正统接纳了他，但接纳的方式是把他变成名单上的一个名字 |
| 约前1100 前后 | 文丁杀季历（一说囚死），商周由盟友转为仇敌；其后帝乙嫁女于姬昌、帝辛亡于牧野 | 武乙"赐地养周"之策的长期后果在此时兑现——西陲屏藩成为代商者 |
| 西汉 | 司马迁据《尚书》《诗经》及旧史作《殷本纪》，于武乙仅数十言，"帝武乙无道"四字定评 | "无道"叙事定型约一千年后，其人再无翻案材料可言；后世所有争论都在这一句之下展开 |
| 唐—清 | 司马贞《索隐》述赞"武乙无道，祸因射天"；三家注训释字词；晚清以来甲骨出土、殷墟发掘，武乙之名重现于周祭卜辞 | 评价与证据从此分道：道德定评继续流传，而王世、庙号、祭祀规模由甲骨另立一套证据体系 |

## 二、绝对年代与异说

- 【史论/二手】夏商周断代工程《1996–2000年阶段成果报告》（简本）将武乙定于约前1147–约前1113，在位约三十五年。此为现代推定，非当时实录；甲骨、金文中无绝对纪年可与之直接校准。
- 【史料原文/一手·辑本】古本《竹书纪年》辑本记武乙"即位，居殷"，并载"三十四年"周王季历朝、"三十五年"伐西落鬼戎——其三十四/三十五年之说，与断代工程所定三十余年在位大体相容，可作互核之参考，然不得视为精确编年。
- 【存疑并列】古本《竹书纪年》原书已佚，今存唯辑本；今本《竹书纪年》为后世辑缀，掺杂增窜，凡今本独有的武乙事（如"命周公亶父赐以岐邑"）须标疑使用。
- 【存疑并列】甲骨第四期（武乙、文丁）之王世归属，存在"历组卜辞断代"之争（李学勤等主张其上限可至武丁晚期至祖庚），故凡以甲骨系武乙之世者，皆带此一层不确定性。

## 三、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》为武乙事之唯一主源，且为孤证性质：射天、迁都、震死三事皆出此一篇，篇外无平行叙事可校。司马迁自述其作殷史"采于书诗"，即取《尚书》《诗经》及旧史；武乙之世已无从《尚书》取文（晚商诰命无存），故其记述**细密而单薄**——细节愈具体（偶人、革囊、盛血），可校验性愈低。
- 【史料原文/一手】《后汉书·东夷列传》提供一条独立的东方形势记录，与《殷本纪》所记无重叠，可作其治世背景之侧证。
- 【史料原文/一手·甲骨】殷墟出土第四期卜辞与周祭卜辞，是唯一**与《史记》无关的当代实物证据**：它所证的不是"射天"，而是"武乙确为一王之庙号、确入商王祭序、其世的卜事确有变化"。史书记其恶，甲骨记其位。
- 【史料原文/一手·考古】殷墟西北冈王陵区大墓与人牲祭祀坑的发掘，为晚商王权、祭祀规模提供实物背景；然大墓墓主多不可确指，不能径指武乙之墓。
- 【互核结论】可互核者仅三项：其一，武乙为商王之事实（《殷本纪》与周祭卜辞一致）；其二，其世之祭祀与卜事规模处于下降趋势（甲骨与考古一致，非其一人的功过）；其三，其西方有周人崛起（《竹书纪年》辑本、《后汉书·西羌传》系统与西周金文所述先周世系可相参）。至于射天之细节与死因，**无互核材料**，只能作单源记述看待。

## 四、小结（一手 vs 框架）

- **一手素材（史料原文/原话）**：《殷本纪》武乙三事与世系；古本《竹书纪年》辑本二条；《后汉书·东夷列传》一条；第四期卜辞、周祭卜辞、殷墟王陵区考古。占比过半。
- **框架推断**：各节点"对思维之影响"一栏、以三十年为一生的战略视野评其"西赐东让"、以身后庙号反观其正统地位——皆为基于史事的归纳推断，非史书明言。
- **诚实说明**：本维度**绝对年代全部为推定值**，一律冠"约"；武乙一生中除即位、迁都、（约）三十四至三十五年二事与震死外，其余年份无从系属。商属传说/半信史，材料有限，凡此已如实标注。
