# 06 时间线 · 沃甲（商·第15/16任王，九世之乱第六王）

> 维度定义：即位到崩的编年。
> **纪年纪律**：商代中期**无确切绝对年代**，本表**所有年份一律冠"约"字**，且不掩盖异说。凡本表所载年代，均为**现代学者的推定方案**（主要参照《竹书纪年》辑本与《太平御览》等所引系统的在位年数，及夏商周断代工程对商后期的定位），**不是史料原文的年数，更不是当时的纪年**。

## 一、在位前后的编年（本表主体）

| 约纪年 | 事件 | 史料性质 | 对思维的影响 |
|------|------|------|------|
| 约前14世纪末以前 | 中丁迁隞，弟外壬立；外壬崩，弟河亶甲立，"殷复衰"；河亶甲崩，子祖乙立，"殷复兴。巫贤任职" | 【史料原文/一手】《史记·殷本纪》 | 乱局自中丁起；沃甲之父祖乙是九世之乱中唯一有"复兴"字样的一代——**父辈的复兴是他继承的包袱也是他的底气** |
| 约前14世纪 | 祖乙崩，子祖辛立（《竹书纪年》辑本：名旦，"王即位居庇"） | 【史料原文/一手】《殷本纪》《竹书纪年》辑本 | 都邑在庇，为其弟沃甲所续居；**兄长的都邑就是他的都邑** |
| **约前1356**（异说：约前1490） | **祖辛崩，弟沃甲立，是为帝沃甲**——以"弟及"承兄之位 | 【史料原文/一手】《殷本纪》 | **受位方式决定其全部执政姿态**：他的一切合法性来自"序"，不来自"功"，故此生须守住"序" |
| 约前1356 起 | 《竹书纪年》辑本："王即位居庇"——**续居旧都，未营新邑** | 【史料原文/一手·辑本】 | 在九世之乱四迁其都的链条上，沃甲之世是一处停顿；"不动"成为他最可辨的行事特征 |
| 约前1356–约前1336 之间 | 其世无征伐、无叛乱、无灾异、无任职之人被记 | 【史料原文/一手】《殷本纪》沃甲条仅二十余字 | **叙述空白即其执政记录**；在"诸侯莫朝"的天下里，他维持着一个不被朝见的王位 |
| **约前1336**（异说：约前1466） | **帝沃甲崩，立沃甲兄祖辛之子祖丁**——传位于兄之子，不传己子 | 【史料原文/一手】《殷本纪》 | **其执政逻辑的落点**：依序不依亲。这是他唯一有明文的重大决定 |
| 约前1336–约前1327 | 祖丁立（《竹书纪年》辑本：名新，"王即位居庇"，九年陟；异说三十二年） | 【史料原文/一手】《殷本纪》《竹书纪年》辑本 | 即位者是其侄；沃甲一房暂时退居次位 |
| 约前1327 | **帝祖丁崩，立弟沃甲之子南庚**——王位回到沃甲一房 | 【史料原文/一手】《殷本纪》 | **"还位"未使自己一房出局**；交叉轮流逻辑确立，沃甲之子即其实例 |
| 约前1327–约前1321 | 南庚之世，"三年迁于奄"（今山东曲阜一带），殷道再衰 | 【史料原文/一手】《殷本纪》《竹书纪年》辑本 | 沃甲"不迁"的一次反向验证：其子一迁，衰势复现 |
| 约前1321–约前1314 | 南庚崩，立祖丁之子阳甲，"帝阳甲之时，殷衰"；自中丁以来"比九世乱，于是诸侯莫朝" | 【史料原文/一手】《殷本纪》 | **九世之乱至此收束**；沃甲正在这九王之中段——他不是乱的原因，也非乱的终结者 |
| 约前1314 起 | 阳甲崩，弟盘庚立；盘庚渡河南，复居成汤之故居，"殷道复兴" | 【史料原文/一手】《殷本纪》《尚书·盘庚》 | 沃甲的侄孙终结了这场乱；**乱世的结束发生在下一代，不在他手上** |

## 二、身后（材料层的时间线，与本人无关但决定我们如何知道沃甲）

| 约纪年 | 事件 | 史料性质 |
|------|------|------|
| 约前13世纪（盘庚迁殷后） | 殷墟成为晚商都邑；**现存有字卜辞最早不过武丁前后**，故沃甲生前无同时代文字 | 【一手·考古与甲骨学】董作宾五期断代 |
| 约前12–前11世纪（武丁至帝辛） | 黄组周祭卜辞按旬日之序祭祀先王，**"羌甲"列于祖辛之后、祖丁之前**；其直系/旁系规格随各王世变动 | 【一手·甲骨文】《甲骨文合集》周祭卜辞；【二手】常玉芝《商代周祭制度》等 |
| 约前11世纪 | 商亡于周；甲骨卜辞与王室档案散落 | 【一手·考古】殷墟地层 |
| 西汉 | 《史记·殷本纪》以二十余字记沃甲，并作"比九世乱"总断 | 【一手】司马迁《史记》 |
| 西汉以前（成书早于汉） | 《世本》作"开甲"；《竹书纪年》作"开甲"，记名"踰（逾）"、"居庇"、"五年陟" | 【一手·旧籍与辑本】《世本》《竹书纪年》（今存辑本） |
| 唐 | 《史记索隐》引《世本》"系本作'开甲'也"；《尚书正义》系统另有"开甲为祖辛之子"之说 | 【一手·注家】司马贞《索隐》、孔颖达《正义》 |
| 宋 | 薛尚功《历代钟鼎彝器款识法帖》著录"祖辛卣"，按语称"祖辛，沃甲之兄，祖丁之父也" | 【一手·金文著录】薛尚功 |
| 清 | 《竹书纪年》诸家统笺、志疑指出"疑'沃'字非"，并直言世系异说"无从参考" | 【一手·清人按语】《竹书纪年集成》所收 |
| 1917 前后 | 王国维《殷卜辞中所见先公先王考》以卜辞勘验《殷本纪》世系，商王世次大体可信；《殷周制度论》统计"以弟继兄者凡十四帝"，沃甲为其中之一 | 【二手】王国维两种 |
| 1945 起 | 董作宾《殷历谱》创立周祭卜甲复原法；陈梦家、岛邦男、许进雄继之，常玉芝《商代周祭制度》集大成——羌甲祀序得以定位 | 【二手】历代甲骨学著作 |
| 1996–2000 | 夏商周断代工程推定盘庚迁殷约前1300年、武丁约前1250–前1192年；**商代中期（含沃甲）仍无确切绝对年代** | 【二手】断代工程报告 |
| 2021 | 杜勇、李玲玲《商代王位继承制的特质》指出"九世之乱"实即"九王之乱"，并强调商代中期世次"总体上仍须以《史记·殷本纪》为据" | 【二手】《史学集刊》2021 年 2 期 |

## 四、小结（一手 vs 框架）

- **一手素材**：《殷本纪》沃甲条与其前后诸王条、《竹书纪年》辑本、《世本》佚文（经《索隐》引）、《甲骨文合集》周祭卜辞、殷墟考古的**分期框架**。**本表所有"约前"年份均为现代推定，非一手记载。**
- **框架推断**："叙述空白即执政记录""还位未出局""不迁都的反向验证"等评注为框架推断，已随行标注。
- **性质警示**：**夏商属传说/半信史，材料有限。** 商代中期无确切年代，任何"前XXXX年"都只是便利性坐标；不得据本表任一数字声称"确证"。
