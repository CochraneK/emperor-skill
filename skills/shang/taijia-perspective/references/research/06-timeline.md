# 06 时间线 · 太甲（商·太宗，约前16世纪）

> 维度定义：即位到崩的编年（上古多为"约前XXXX年"，须带"约"字）+ 对思维的影响，含史料成书背景与互核情况。
> **年代声明**：商前期各王之绝对年代学界无定论，夏商周断代工程所颁年表止于商后期（武丁以下），未颁商前期王年。《殷本纪》不载太甲在位年数，《竹书纪年》系统所记亦有出入。下表年份一律取"约"，仅示相对先后，**不作定点**。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1600 | 成汤灭夏立商（背景） | 其全部合法性来源"汤法"由此确立 |
| 约前1580 | 汤崩；太子太丁早卒未立，太丁之弟外丙立（约三年） | 继统之序本非"父死子继"；汤法之权威自此由辅臣伊尹守护 |
| 约前1577 | 外丙崩，其弟中壬立（约四年） | 王位在两代之间流动，"承统须自证"之底色加深 |
| 约前1573 | 中壬崩，伊尹立太丁之子太甲为帝。太甲元年，伊尹作《伊训》《肆命》《徂后》 | 即位即受师保之训，认知底色为"居位须受训导"而非"居位即有权" |
| 约前1570（立三年） | 太甲不明、暴虐、不遵汤法、乱德；伊尹放之于桐宫 | 首度因失德失位；"汤法即合法性"自此成为其核心命题 |
| 约前1570–约前1567 | 伊尹摄行政当国，以朝诸侯 | 亲见"权柄可离开王身而独立运转"，对权柄之可让可还获得切身体认 |
| 约前1567（居桐三年内） | 太甲悔过自责、反善；据《孟子》"自怨自艾，于桐处仁迁义，以听伊尹之训己" | 完成自我重置：复活之路不在夺权，而在换人 |
| 约前1567（一说放后七年，见《竹书纪年》异说） | 伊尹以冕服迎太甲归于亳，授之政；太甲修德，诸侯咸归殷，百姓以宁；伊尹作《太甲训》三篇，褒之，称"太宗" | "修德—归服"因果被确认，定下"守成即修德"之执政观；获庙号"太宗" |
| 其后 | 太宗崩，子沃丁立 | "失位—悔过—复位"成商史中唯一范式，为后世所引 |
| 异说（《竹书纪年》） | 伊尹放太甲于桐而自立；太甲七年潜出桐宫，杀伊尹，乃立其子伊陟、伊奋，复其父田宅而中分之 | 若此说成立，"悔过复位"即"隐忍复辟"；两说并存，本 Skill 不调和、不裁断 |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》（西汉·司马迁）：太甲事之主源。叙其世系、受立、被放、摄政、悔过、复位、称宗，脉络完整但极简（百余字）。
- 【史料原文/一手·先秦】《孟子·万章上》（战国）：早于《史记》，为"悔过复位"一路之最早来源；且提供《殷本纪》所无之细节（"自怨自艾""处仁迁义""听伊尹之训"）。
- 【史料原文/一手·先秦】《尚书·君奭》（今文尚书）：周公历数商贤佐，特举"在太甲，时则有若保衡"，为最早的太甲朝旁证。
- 【史料原文/伪古文】《尚书·太甲》上中下（东晋梅赜本）：提供大量细节，然经清儒（阎若璩等）考定为魏晋人所造；其中"天作孽"句因《孟子·公孙丑上》引用、《礼记·缁衣》所引"毋越厥命以自覆"句，可溯先秦。
- 【史料原文/异说】《竹书纪年》（战国魏襄王墓所出，古本）：与《史记》一路彻底冲突，记伊尹自立、太甲杀伊尹。
- 【甲骨/一手】殷墟周祭卜辞"大甲"辞例：与《殷本纪》世系互核相合。
- 【互核结论】**世系**：太甲为汤之孙、太丁之子（《殷本纪》《孟子》《竹书纪年》一致；甲骨卜辞"大甲"受祭亦可佐其存在）。**事功**：《史记》一路的"悔过复位"与《竹书纪年》一路的"潜出杀尹"，自战国以来两说并存，无法互核裁定。**年代**：无定论，本表年份仅示相对先后。
- 【成书背景说明】太甲距司马迁约一千五百年，司马迁所据当为商代流传之史料与战国旧说；其叙事之完整性并不等于其记载之确切，凡涉细节当以"传说/半信史"视之。

## 三、小结

- 一手节点与互核出《史记·殷本纪》《孟子》《尚书·君奭》《竹书纪年》及甲骨卜辞；两说冲突如实并列，不裁断。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
- **传说/半信史声明**：太甲一生无同时代文书为其佐证；甲骨只证其入祀典，不证其事。本表不伪称一手确证。
