# 06 时间线 · 商太戊（大戊，商·中宗，约前16世纪末–约前15世纪中叶）

> 维度定义：即位到崩的编年（上古多为"约前XXXX年"，须带"约"字），含史料成书背景与互核情况。
> **史料门禁：商属传说/半信史，材料有限。本时间线的"年"分两层——① 相对纪年（《竹书纪年》系统所记"大戊某年"），② 绝对年代（据"夏商周断代工程"商始年约前1600 之框架，并据今本《竹书纪年》一系所记太戊之前诸王在位年数合计推拟）。两层皆须带"约"字；商前期王年学界无定论，断代工程未颁商前期王年，本表不作定点。**
> **另须先记一条：太戊名下无一处"某某年"的确记。** 今本《竹书纪年》一系有其"元年丙戌"与"七十五年陟"之文，惟今本真伪有争议，使用时逐条标注。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前16世纪末（背景） | 帝小甲崩，弟雍己立（《殷本纪》）。雍己之世：**"殷道衰，诸侯或不至"** | 即位时面对的"衰"不是叛乱而是缺席——权威的流失。这决定了其执政的用力方向是"复位份"而非"平叛乱" |
| 约前16世纪末（元年，今本《竹书纪年》一系作"大戊元年丙戌"，推拟，非定论） | "帝雍己崩，弟太戊立，是为帝太戊"（《殷本纪》）——以**兄终弟及**承统 | 继统非常序，合法性需自证；此为"以德自证"路线之所以必要的处境 |
| 约前16世纪末（即位之始，即《殷本纪》所记其第一个动作） | **"帝太戊立伊陟为相"**（《殷本纪》）；《尚书·君奭》另记其朝有"伊陟、臣扈""巫咸" | **先定人、后定策**——修德之所以能成为国策，前提是提出修德的人已在相位上 |
| 约前16世纪末（立相之后，桑谷之变） | "亳有祥桑榖共生于朝，一暮大拱。帝太戊惧，问伊陟。伊陟曰：'臣闻妖不胜德，帝之政其有阙与？帝其修德。'太戊从之，而祥桑枯死而去"（《殷本纪》） | 确立核心心智：**把天变读成"政阙"，把异象处理成内政自查**；关键在于问相不问巫 |
| 约前16世纪末（桑谷事后） | "伊陟赞言于巫咸。巫咸治王家有成，作《咸艾》，作《太戊》"（《殷本纪》）；《封禅书》："太戊修德，桑谷死。伊陟赞巫咸，巫咸之兴自此始" | 中兴的落地环节：由"个人修德"转为**"治王家"的组织性治理**；并留下文本（皆亡佚） |
| 约前16世纪末（其后） | "帝太戊赞伊陟于庙，言弗臣，伊陟让，作《原命》"（《殷本纪》） | 荣誉分配：公开把中兴之功记给相，降低功高震主之险，亦等于君自认"中兴非一人之力" |
| 约前16世纪末—约前15世纪中叶（古本《竹书纪年》辑本系于桑谷之后"三年"） | "大戊遇祥桑，侧身修行。三年之后，远方慕明德，**重译而至者七十六国**。商道复兴，庙为中宗"（《太平御览》引古本《竹书纪年》辑本） | 修德的可见产出被记为"远方来归"（转译数重而来），而非"征服"；**其治绩的口径是"归"不是"克"** |
| 约前15世纪中叶（在位七十五年，见《尚书·无逸》） | 《尚书·无逸》："昔在殷王中宗，严恭寅畏，天命自度，治民祇惧，不敢荒宁。**肆中宗之享国七十有五年。**"《殷本纪》："**殷复兴，诸侯归之，故称中宗**" | 先秦材料给的标签是"不敢荒宁"，西汉材料给的标签是"复兴—归之—称中宗"；**两个标签不是一回事**，本 Skill 并列使用 |
| 约前15世纪中叶（其后） | "帝太戊崩，子帝中丁立"（《殷本纪》）——位子交回"父死子继"一系 | 中兴有果而未固化：交接未立成规矩 |
| 约前15世纪中叶以降（身后） | "自中丁以来，废适而更立诸弟子，弟子或争相代立，**比九世乱**，于是诸侯莫朝"（《殷本纪》） | "诸侯归之"与"诸侯莫朝"构成前后对照；此为评价太戊"中兴是否成功"的关键证据，两读并存 |
| 商后期（殷墟时期） | 殷墟周祭卜辞中以"大戊"为受祭之直系先王；另有"中宗"之称的辞例（学界多以为指祖乙） | 卜辞证"有其人、在其祀典"；**不能证祥桑、伊陟、巫咸之事，亦不能证"中宗"之号属大戊** |

## 二、异说并存（不强行调和）

1. **"中宗"归属异说**
   - 《尚书·无逸》仅称"殷王中宗"，未点名；伪孔传注"中宗，太戊也"，《史记·殷本纪》循此系于太戊。
   - 殷墟卜辞中"中宗"之称的辞例，学界多以为指**祖乙**；亦有主张指大戊者。**两说并存，本 Skill 不裁断。**
2. **在位年数与纪年异说**
   - 《尚书·无逸》："肆中宗之享国七十有五年"——**此说最早**，出先秦今文《尚书》。
   - 《史记·殷本纪》记其称中宗，**不载在位年数**。
   - 今本《竹书纪年》一系有"大戊元年丙戌""七十五年陟"，其数值与《无逸》相合，惟今本真伪有争议（多数学者视为后世辑补）。
   - 古本《竹书纪年》辑本仅存"大戊遇祥桑……三年之后……七十六国……庙为中宗"，**不载其元年与在位年数**。
3. **绝对年代推拟（须带"约"，且明标为推拟）**
   - "夏商周断代工程"定商代为约前1600—前1046，**未颁商前期逐王王年**。
   - 若以商始年约前1600、并据今本《竹书纪年》一系所记太戊之前诸王（外丙、仲壬、太甲、沃丁、太庚、小甲、雍己）之在位年数合计推之，则太戊之立约在前16世纪末，在位七十五年之末约在前15世纪中叶。**此为本 Skill 的推拟框架，非定论。**
   - 故本表一律用"约前16世纪末—约前15世纪中叶"表述，不作定点。
4. **世系与兄弟次序异说**
   - 《殷本纪》：太庚崩，子小甲立；小甲崩，弟雍己立；雍己崩，弟太戊立（太戊为太庚之子、小甲与雍己之弟）。
   - 卜辞周祭之直系序列（大庚—小甲—大戊—中丁一路）与之大体相参，惟个别王之地位与次序仍有讨论。**并列保留。**
5. **"中丁"之身份**
   - 《殷本纪》："帝太戊崩，子帝中丁立。"（中丁为太戊之子）
   - 九世之乱的起点即自中丁始（"自中丁以来，废适而更立诸弟子……比九世乱"）。本 Skill 依《殷本纪》，异说不另立。

## 三、史料成书背景与互核

- 【史料原文/一手】《尚书·无逸》（今文《尚书》，周书）——最早给出"殷王中宗""不敢荒宁""享国七十有五年"。**性质为周公对成王的告诫，中宗是论据，非对话者。**
- 【史料原文/一手】《尚书·君奭》（今文《尚书》）——最早给出太戊朝佐臣名单："在大戊，时则有若伊陟、臣扈，格于上帝；巫咸乂王家。"**早于《史记》数百年，是太戊用人格局最硬的文献依据。**
- 【史料原文/一手】《尚书序》（《书序》）——记"伊陟相大戊，亳有祥桑榖共生于朝"，并记《咸乂》四篇、《伊陟》《原命》之作。**其篇名归属与《殷本纪》互异。**
- 【史料原文/一手】《史记·殷本纪》（卷三，西汉·司马迁）——太戊事之主源，约一百二十字，给出完整叙事链：继统→立相→桑谷→妖不胜德→从之→赞巫咸→治王家有成→赞伊陟于庙→殷复兴、诸侯归之、称中宗→崩、中丁立→九世之乱。**全部用动作动词，无一句直引其言。**
- 【史料原文/一手】《史记·封禅书》（卷二十八，西汉）——"太戊修德，桑谷死。伊陟赞巫咸，巫咸之兴自此始。"提供"巫统之源"这一另一落点。
- 【史料原文/一手】古本《竹书纪年》辑本（王国维《古本竹书纪年辑校》；《太平御览》引）——"大戊遇祥桑，侧身修行。三年之后，远方慕明德，重译而至者七十六国。商道复兴，庙为中宗。"属战国魏史系统。
- 【史料原文/一手】今本《竹书纪年》——"大戊，名密""元年丙戌""七十五年陟"（今本真伪有争议，逐条标注）。
- 【甲骨/一手】殷墟周祭卜辞（《甲骨文合集》相关著录）中"大戊"受祭之辞例——证其为商王室承认的直系先王；另有"中宗"之称的辞例（多以为指祖乙）。
- 【史料原文/一手】《史记》三家注（裴骃集解、司马贞索隐、张守节正义）——"赞""言弗臣"字义、伊陟为伊尹之子说、篇名异说之校。
- 【史论/二手】《山海经·大荒西经》十巫、《楚辞·离骚》"巫咸将夕降兮"、《吕氏春秋·勿躬》"巫咸作筮"、《世本》——巫咸在异系文本中的神话化。
- 【互核结论】
  - 各源一致者：太戊为雍己之弟、继衰局而立；用伊陟（及臣扈、巫咸）；有桑谷之变与"修德"之应；"殷复兴、诸侯归之、称中宗"。
  - 互异者：**"中宗"之归属**（大戊/祖乙）、**在位年数之记载系统**（《无逸》有、《殷本纪》无、今本《纪年》有）、**篇名归属**（《殷本纪》vs《书序》）、**巫咸之身份**（官员/神巫）、**中兴之效**（誉/疑）。**均并列保留，不强行调和。**
- 【成书背景说明】太戊之全部材料均晚于事件：最早为周初《尚书·无逸》《君奭》（追述商史以论周政），其次战国《竹书纪年》一系，再次西汉《史记》。**《殷本纪》记其行事仅约一百二十字，且不载其在位年数**——恰说明西汉时关于太戊的可信材料已极稀薄。甲骨能补的只有"其在祀典"这一层。

## 四、小结

- 相对纪年（大戊元年、七十五年）与绝对年代（约前16世纪末—约前15世纪中叶）皆已逐条标注来源与推拟性质；绝对年代一律带"约"。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史料明言；"其言阙如"这一事实本身即提示，此人之"思想"当视为**由后世文本与他人的追述反推的模型，而非可核实的心史**。
