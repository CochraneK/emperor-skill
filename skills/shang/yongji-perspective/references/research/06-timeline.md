# 06 时间线 · 雍己（商·第八王，约前16世纪）

> 维度定义：关键节点表 + 对思维的影响，含史料成书背景与互核情况。
> **纪年声明**：商代前期（盘庚迁殷以前）无绝对纪年，今所通行者皆为后人推算，异说纷纭。故本表一律冠"约"字，且以**相对次第**（谁先谁后、承谁传谁）为主，绝对年代一律从略，不伪称精确。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前16世纪（背景） | 成汤灭夏建商；自汤至雍己之世，商行"节用宽民、以德治商"之政，历百余年相对稳定（《殷本纪》叙世系；"节用宽民"为后世概述性表述） | 雍己一生处于王朝的"长和平期"末段——其衰落不是在危机中发生，而是在顺境中积累 |
| 约前16世纪（背景） | 太甲经伊尹放桐宫而后复位，修德，"诸侯咸归殷，百姓以宁"，称太宗（《殷本纪》） | 商第一次中兴在其前代已完成；"中兴"之后如何守成，是他这一代的前提 |
| 约前16世纪（背景） | 沃丁、太庚相继立；沃丁之世伊尹卒，咎单作《沃丁》训王（《殷本纪》《尚书序》） | 开国辅政传统在其前代已告一段落，"师保型强臣"不再，君主须自立 |
| 约前16世纪 | 太庚崩，子小甲立（《殷本纪》；另有世系异说）。现代商史研究以"小甲时期开始商王朝的第一次衰败"表述之 | 衰象在其兄之世已萌；他所承者不是高峰，而是一个正在下沉的局面 |
| 约前16世纪 | 小甲崩，弟雍己立（《殷本纪》）。一说太戊先于雍己即位、雍己所继者为兄太戊（常玉芝等据周祭卜辞复原次序） | 继统链条本身即有异说——其"位从何来"在史料中都不确定，这构成他处境的第一重不确定 |
| 约前16世纪（在位期） | "帝雍己之时，殷道衰，诸侯或不至。"（《殷本纪》）——史料对他全部执政期的唯一记录 | 他留下的不是事件而是一个判断；对在位者而言，最难受的正是"没有可指之事，却已有定论" |
| 约前16世纪 | "帝雍己崩，弟太戊立，是为帝太戊。"（《殷本纪》） | 传位是其史料中的最后一条；据卜辞异说，此条次序亦当存疑 |
| 约前16世纪（其后） | 太戊立伊陟为相；有祥桑谷共生于朝之灾异，太戊惧、问伊陟，伊陟"妖不胜德"，太戊修德而祥桑枯死；巫咸治王家有成。"殷复兴，诸侯归之，故称中宗"（《殷本纪》） | 衰与兴紧相衔接——他的失败成了下一代中兴的直接教材 |
| 殷墟期（其后数代） | 周祭卜辞将雍己列入受祭先王，与"小甲、大戊"同旬（据常玉芝《商代周祭制度》复原先王名录） | 制度上他被接纳为一代王，但列入的位次在直系主轴之外（旁系先王） |
| 后世 | 《太平御览》系统与今本《竹书纪年》系统作在位十二年；《资治通鉴外纪》《通志》系统作十七年；另有十三年之说 | 其"个人信息"仅剩名与年数二项，且二项皆无定说 |
| 近现代 | 王国维《殷周制度论》立"商以弟及为主"之继统框架；常玉芝《商代周祭制度》据残辞互补复原周祭谱，谓太戊先于雍己继位；学界据此修正《殷本纪》世次 | 他的位次由"史书定案"变为"史料争议"，其史料形象至今未定 |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》（西汉·司马迁）为雍己事之唯一传世主源，文字仅三句。司马迁据《秦记》以外的诸侯史记与上古传说熔铸而成，商前期部分（盘庚以前）所据多为传世谱牒与旧说，非同期实录。
- 【史料原文/一手】《史记·三代世表》系统另存世系排列，与《殷本纪》互有异同，是世次讨论的另一支文本文献。
- 【甲骨/一手】殷墟出土周祭卜辞（《甲骨文合集》等著录）以王室祀典形式保存先王名录与祭序，为**独立于传世文献的第二套证据**；常玉芝《商代周祭制度》、董作宾《殷历谱》、陈梦家《殷墟卜辞综述》等为甲骨材料之整理与复原（近一手研究）。
- 【史料原文/一手】《竹书纪年》（战国魏墓所出，今存者为辑本）与《太平御览》《资治通鉴外纪》《通志》等，构成其名号与在位年数的另一支记载；今本《竹书纪年》系宋以后辑补，王国维《今本竹书纪年疏证》逐条辨其来历。
- 【互核结论】雍己之**存在**（确为一代商王）由"《殷本纪》世系 + 周祭卜辞受祭名录"双重支持，可靠性较高；其**具体世次**（继小甲还是继太戊）在传世文献与卜辞之间存在冲突，学界至今无定论；其**事迹**（除"殷道衰"一句外）两套材料皆无；其**名与年数**仅见于后世辑本与类书，可靠性最低。四个层次的可靠性依次递减，使用时须分层对待。
- 【证据限度声明】卜辞属殷墟期（盘庚迁殷以后）材料，与雍己之世相隔数代；其所反映者主要是**后世的祭祀制度**（即后人如何承认他），不能直接视为其生前实况。

## 三、小结

- 一手节点：《殷本纪》三条（继统、衰局、传位）；周祭卜辞受祭名录；《三代世表》世系排列。
- 二手／史论：在位年数异说（十二／十三／十七年）；今本《竹书纪年》系统之名号与"都亳"说（不作一手据）。
- 框架推断：各节点"对思维之影响"一栏，以及"衰象在其前代已萌""长和平期末段"等历史氛围描述，均为基于史事的归纳推断，非史书明言。
- **传说/半信史声明**：商代前期属传说／半信史，纪年无定说，世次有争议，记事极简；本表之"约前16世纪"只是大致区间，不代表可考的绝对年代。
