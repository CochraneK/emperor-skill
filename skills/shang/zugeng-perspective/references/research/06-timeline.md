# 06 时间线 · 商·祖庚（武丁之子，约前1191–约前1189 在位）

> 维度定义：即位到崩的编年。
> **史料门禁提示**：商属传说/半信史，祖庚一代尤甚——**正史无任何绝对纪年，所有年份均带"约"字**，且诸说并出。本条时间线以夏商周断代工程《夏商周年表》（2000）为骨架，以《史记·殷本纪》、今本《竹书纪年》为文本依据，异说并列保留。

## 一、年代框架与异说

- 【史论/二手·夏商周断代工程】《夏商周年表》（2000）：武丁 **前1250—前1192（在位59年）**；其后**祖庚、祖甲、廪辛、康丁四王合并置于前1191—前1148**，未单列祖庚年数。
- 【史论/二手】学者的疏证性修正给出不同结果：有作**祖庚前1191—前1189（约三年）**者，有作**前1200—前1190（十一年）**者。
- 【史论/二手·今本《竹书纪年》】"祖庚，名曜。元年丙午，王即位，居殷，作《高宗之训》。**十一年，陟**。" 同条注：**按《通志》作在位七年**。
- 【史论/二手·邵雍《皇极经世》（蔡沈《书经集传》引）】"高宗五十九年、**祖庚七年**、祖甲三十三年，世次历年皆与书合。"
- 【框架推断】**结论：祖庚在位年数有三年、七年、十一年三说，无一手确证**。本 Skill 的 frontmatter 采用"约前1191–约前1189"（断代工程区间内的通行为三年之分配），并在正文中明示异说，不伪称定论。
- 【框架推断】须知**今本《竹书纪年》为后世辑本**（其真伪与文字可靠性学界有争议），古本《竹书纪年》仅存辑佚；上述年数皆**不可视为确证**。

## 二、编年表

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1250—约前1192 | 武丁在位五十九年：傅说为相、殷道复兴、四方征伐（土方/羌方/鬼方）、妇好为将、武丁朝卜辞（宾组）极盛（前史） | 父王功业过于巨大，形成"不可超越的参照系"；祖庚的一切合法性都从此派生 |
| 约前1192 前 | 武丁欲废长子祖庚、立贤子祖甲；祖甲以"废长立少不义"而逃于民间（马融、郑玄注《无逸》说，异说） | 继位前即已置身一场自己无法参与的安排之中，奠定"接受安排、不争不辩"的底色 |
| 约前1192 前 | 武丁惑后妻之言，放长子孝己，孝己（祖己）废不得立（《帝王世纪》《孔子家语》说，王国维引） | 父王的另一次错误，为祖庚即位后"还兄之冤"预留了动作空间 |
| 约前1192 前 | 武丁祭成汤，有飞雉登鼎耳而呴，祖己训王（《史记·殷本纪》旧说；王国维新说以此事系于祖庚朝） | "祥雉—修德"故事在旧说与新说之间的迁移，成为祖庚形象的关键变量 |
| 约前1192 | **武丁崩，祖庚立**（《史记·殷本纪》："帝武丁崩，子帝祖庚立。"） | 以长继位，合法性来自制度而非功业；自觉处于"守"的位置 |
| 约前1191 元年 | 王即位，**居殷**，不迁都（今本《竹书纪年》：元年丙午，王即位，居殷） | 选择不重启政治重组，完整继承既有格局；"承接而不改动"成为执政基调 |
| 约前1191 | **立武丁之庙为高宗**，尊号"高宗"，隆其祀（《史记·殷本纪》系于祖庚之世） | 毕生最核心的决策：以父之名立己之位；把合法性寄存于宗庙而非自身 |
| 约前1191 | 祖己（孝己）"嘉武丁之以祥雉为德"，作《高宗肜日》及《训》（《史记·殷本纪》）；今本《竹书纪年》则系《高宗之训》于祖庚名下 | 《高宗之训》作者两说相抵，文献归属本身即不稳固；祖庚之名下始终缺少可确证的文本 |
| 约前1191 | 若从王国维说：《高宗肜日》为"祖庚祭高宗之庙"而作，训辞核心为"**典祀无丰于昵**" | 祖庚"厚祭其父"的路线在制度层面受到内部制约；接受规谏而不辩驳 |
| 约前1191 | 若从王国维说：**祖庚之世还兄长孝己（祖己）之位**，孝己得入受祭序列（卜辞"王宾祖己"） | 本朝唯一带个人意志的决策——不是继承，而是修正父王的一桩冤案 |
| 约前1190—约前1189 | 出组卜辞（贞人"出"为代表，陈梦家定为祖庚、祖甲时期）持续记录卜旬、祭祀、"王占曰"断辞 | 王的意志经占卜程序分泌为极简裁决语；其"言"全部投向神与祖，不投向自身 |
| 约前1190—约前1189 | 对外军事显著收缩，卜辞中征伐类内容占比下降、祭祀类上升（倾向性判断，受历组归属争议影响） | 不主动开衅、不向外投注，把资源集中在内部秩序与祀典 |
| 约前1190—约前1189 | "后母戊"大方鼎或铸于此期——为祭祀母亲（武丁之妻妇妌，庙号"戊"）而作（国家文物主管部门说明：祖庚或祖甲为祭母铸造；另有文丁说，归属存疑） | 物质资源同样投向先人而非自身；"表达"继续以供奉的形式出现 |
| 约前1189 | **祖庚崩，弟祖甲立，是为帝甲**（《史记·殷本纪》） | 兄终弟及，平静无争；顺殷制而不立新制 |
| 约前1189 后 | 《史记》："帝甲淫乱，殷复衰。" 而《尚书·无逸》周公却列祖甲为殷之贤王四人之一（中宗、高宗、祖甲、周文王），**独遗祖庚** | 祖庚的历史位置完全取决于对祖甲的褒贬；在周人的殷鉴谱系中他彻底落空 |
| 约前1189 后 | 殷商进入祖甲—廪辛—康丁—武乙—文丁—帝乙—帝辛的下降通道，至前1046 为周所灭 | 祖庚由此被后世定位为"盛世最后一位守成者/衰世之前的过渡君主"——一个夹在两段叙事之间的连接件 |
| 1933 及以后 | 董作宾《甲骨文断代研究例》以"五期分法"将祖庚、祖甲合为第二期；陈梦家《殷虚卜辞综述》以贞人系联提出"出组"，并将"祖庚卜辞"单列；李学勤提出"先分类后断代"与"两系说"，历组归属之争牵动祖庚材料边界 | 祖庚在二十世纪被甲骨学"重新发现"，但其材料的独立边界至今仍在争论之中 |
| 1939 | "后母戊"鼎（旧称司母戊鼎）出土于安阳武官村 | 与祖庚之世相关的重器，其归属仍存三说 |
| 2000 | 夏商周断代工程《夏商周年表》公布，祖庚未获单列纪年 | 连年代学都无法为祖庚划出独立区间——其历史存在感的最后一重注脚 |

## 三、世系位置（两说并列，不强行调和）

- 【史料原文/一手·《史记·殷本纪》】小乙 → **武丁（高宗）** → **祖庚** → 祖甲（帝甲） → 廪辛 → 庚丁 → 武乙 → 太丁（文丁） → 帝乙 → 帝辛（纣）。
- 【框架推断】祖庚为**武丁之子、祖甲之兄**，两《本纪》与《无逸》郑玄注一致。
- 【史论/二手·异说】《尚书·无逸》"其在祖甲"之"祖甲"，孔安国、王肃一派释为"汤孙太甲"，则《无逸》所举非武丁之子帝甲。司马贞《索隐》以"《纪年》太甲唯得十二年，此云祖甲享国三十三年"驳之，定其为帝甲。**此异说不影响祖庚的世系位置，但影响对"祖庚之后是贤君还是昏君"的判断，故并列保留。**
- 【框架推断】另有旁支信息：《帝王世纪》《孔子家语》载武丁长子孝己（即王国维所定之祖己）被放而死，未继位。若从王国维说，则祖庚尚有兄孝己一位，位序在祖庚之前而不曾为王。

## 四、崩后与身后

- 【史料原文/一手】《史记·殷本纪》："帝祖庚崩，弟祖甲立，是为帝甲。帝甲淫乱，殷复衰。"
- 【框架推断】祖庚身后无谥、无专门史评、无独立纪年，其名仅以"武丁之子""祖甲之兄"两种关系存在于史册。**在殷商后期诸王中，他是唯一一位既无褒、也无贬、亦无事迹可述的君主。**
- 【框架推断】其可继承的"遗产"只有两项：一是"**高宗**"这个庙号——被沿用三千年；二是《高宗肜日》这篇训辞——成为西周政治教材。**两者都不是他自己的话。**

## 五、小结（一手 vs 框架）

- 一手素材（史料原文）：《史记·殷本纪》两句本纪文、《尚书·无逸》《高宗肜日》文本、今本《竹书纪年》祖庚条、出组卜辞、后母戊鼎器铭。
- 史论/二手：夏商周断代工程《夏商周年表》、邵雍《皇极经世》、《通志》、马融与郑玄注、孔安国与王肃注、司马贞《索隐》、蔡沈《书经集传》、《帝王世纪》、《孔子家语》、王国维《高宗肜日说》、董作宾与陈梦家与李学勤之断代学说。
- 框架推断：全部"对思维的影响"一栏及年代分配结论，均属推断，已逐条标注。
- 重要提示：**上古纪年无绝对定论**。本时间线中"约前XXXX年"字样均为推定值，凡遇精确到具体年份的表述，皆应回到断代工程年表与《竹书纪年》异说互校。
