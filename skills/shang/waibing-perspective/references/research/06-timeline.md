# 06 时间线 · 外丙（商·第二代王，约前16世纪）

> 维度定义：即位到崩的编年（上古多为"约前XXXX年"，须带"约"字）。
> **绝对年代无法定点。** 商前期诸王的绝对年代学界无定论，夏商周断代工程未颁商前期王年。本底稿因此采取两条办法：①与《竹书纪年》自身的历日干支系统（下文"竹书纪年系统"）为准，排出**相对先后**；②凡涉公历年份，一律冠"约"字并只作约略示意，不作定点。凡有异说处逐处并列。

## 一、可用的两套时间坐标

- 【史料原文/一手】《竹书纪年》干支系统：成汤"十八年癸亥，王即位，居亳……二十九年，陟"→ 外丙"元年乙亥，王即位……二年，陟"→ 仲壬"元年丁丑，王即位……四年，陟"→ 太甲"元年辛巳，王即位……十二年，陟"。（癸亥→乙亥→丁丑→辛巳，干支首尾相续，故其系统内部自洽。）
- 【史论/二手】《竹书统笺》据干支推算："己亥误，当是乙亥。汤十八年为癸亥，二十九年为甲戌，则外丙元乙亥。"——即汤崩于甲戌，外丙元年即乙亥，与其"元年乙亥"相合。此为注家之历日校算，可作旁证。
- 【史论/二手】《竹书统笺》又据《大衍历》推"太甲二年壬午"，谓与《竹书》太甲元年辛巳相合，可证其干支链内部一致。
- 【框架推断】公历换算无法确定：商建国之绝对年代通行约前1600年（仅约数），汤在位二十九年之说又出自《竹书纪年》一路，故由此上推所得之外丙年代误差可达数十年。**本包 frontmatter 所标「约前1580–约前1577」，系以《竹书纪年》干支相对序为骨、并以下一位商王中壬之推拟起点（约前1577）回推锚定所得；区间宽度径取所引异说之上限（三年），而不取《竹书》之二年说，故于《史记》《竹书》两说皆能容纳。此仅示相对先后，非定点。**本底稿表中凡列"约前××世纪"字样者，亦只表示"在汤之后、太甲之前"的相对位置。属纪年限度声明。

## 二、时间线（相对编年）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前16世纪（竹书：汤十八年癸亥） | 成汤灭夏立商，即位居亳；始屋夏社（《竹书纪年》） | 背景：外丙日后所守之"旧章"，即此一朝所立 |
| 约前16世纪（汤十九至二十九年） | 汤之世：大旱数年—祷于桑林而雨—作《大濩乐》—初巡狩、定献令—迁九鼎于商邑（《竹书纪年》） | 背景：汤朝以密集的立法、禳灾、制礼动作立国；外丙所承者即此套制度 |
| 汤崩之前（史载时点不明，在汤崩前） | 太子太丁未立而卒（《史记·殷本纪》） | 继统之序被迫改由"弟及"；外丙之全部处境自此事开始 |
| 约前16世纪（竹书：汤二十九年甲戌） | 汤崩；"于是乃立太丁之弟外丙，是为帝外丙"（《史记》）；《竹书》系之为"二十九年，陟" | "乃立"而非"自立"——其位由序来，非由力争；认知底色为"承接"而非"开创" |
| 约前16世纪（竹书：外丙元年乙亥） | 王即位，居亳，命卿士伊尹（《竹书纪年》）；《古今图书集成》引同 | 三项制度性动作同时完成：定位（即位）、定都（不改汤之居）、定人（续任旧辅）；"不折腾"自此成其全部执政方式 |
| 外丙元年至崩之间 | 同期无征伐、无迁都、无改制、无作诰、无祷祭之记（《史记》《竹书纪年》两书共同沉默） | 低干预执政观；以"无事"为治，亦以"无事"为史所略 |
| 约前16世纪（竹书：二年；《史记》：三年） | 外丙陟（《竹书纪年》"二年，陟"；《史记》"即位三年，崩"）；两说并存 | 短祚；"守成"来不及兑现为业绩，"在位"本身反成后世争论之题 |
| 崩后 | "立外丙之弟中壬，是为帝中壬"（《史记》）；仲壬元年丁丑即位，居亳，命卿士伊尹，四年陟（《竹书纪年》） | 兄终弟及之序继续；外丙为其首位践行者，非其终结者 |
| 仲壬崩后 | "伊尹乃立太丁之子太甲"（《史记》） | 序返于嫡；外丙一系（无子为王）自此退出主轴，入旁系 |
| 太甲朝（约在其后数十年内） | 太甲立三年不明、暴虐、不遵汤法、乱德；伊尹放之于桐宫；伊尹摄政当国；三年后迎归授政 | 外丙、仲壬两朝所积累的元老权力，在太甲朝显露为"可以放一位王"；此后果非外丙所能预见 |
| 太甲朝之后 | 伊尹卒于沃丁之世，"既葬伊尹于亳，咎单遂训伊尹事，作《沃丁》"（《史记》） | "命卿士伊尹"之格局自此终结，商初辅臣政治告一段落 |
| 商末（殷墟晚期） | 周祭卜辞以"卜丙"致祭，祭序为"大乙—大丁—大甲—卜丙—大庚"；外丙无子为王，属旁系先王（《甲骨文合集》35406 等） | 以祀定位：其名在祀典中被郑重保留，而不在史叙中被铺陈 |
| 汉以后 | 《尚书序》《三统历》一路径以"成汤既没，太甲元年"为说，不载外丙、仲壬（见 04 底稿） | 其"在位"本身成为文献学悬案；本 Skill 并列两派，不裁断 |

## 三、异说与不可定点之处（不调和并列）

1. **在位年数**：《竹书纪年》"二年，陟"与《孟子·万章上》"外丙二年"相合，赵岐注从之；《史记·殷本纪》作"即位三年"。程颐另以"二年"为年岁而非年数（"外丙方二岁"）。四说并存，本底稿不裁断。
2. **是否真曾即位**：《尚书序》《汉书·律历志》所引《三统历》一路不载外丙、仲壬，径书汤崩而太甲即位；《史记》《竹书纪年》《孟子》一路则记二王在位。两派自汉至晋并存。
3. **其位次**：卜辞周祭祭序"大乙—大丁—大甲—卜丙—大庚"以卜丙列于大甲之后，与《史记》"外丙在太甲之前"不合。学界有"祭序即即位序"（陈梦家一路）与"祭序不必等于即位序"（王玉哲、裘锡圭、葛英会、侯乃峰一路）两方之争。本 Skill 不裁断，凡涉其位次皆标争议。
4. **公历年代**：商前期王年学界无定论，夏商周断代工程未颁商前期王年。本底稿所列"约前16世纪"仅为相对位置之示意。

## 四、小结（一手 vs 框架）

- 一手素材：①《竹书纪年》殷纪自汤至太甲之干支编年；②《史记·殷本纪》继统叙事；③《孟子·万章上》年数；④《尚书序》《三统历》另一路年世；⑤殷墟周祭卜辞之祀典材料（不载年代）。
- 二手素材：《竹书统笺》之历日校算与按语、《古今图书集成》所引异本、赵岐注、程颐说，以及近现代学界关于祭序与即位序之争的诸家论述。
- 框架推断：干支链相对位置的整理、两套坐标（干支系统 vs 公历约数）之区分、事件与"思维影响"之对应——逐条标注，未伪称史载原话或可据公历。
- **传说/半信史声明**：外丙之年代属传说/半信史，材料有限，绝对年代不可定点，在位年数有异说；本底稿时间线为相对先后之示意，非编年实录。
