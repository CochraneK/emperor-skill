# 06 时间线 · 小乙（商·第廿一王，约前13世纪，祖丁之子、小辛之弟、武丁之父）

> 维度定义：即位到崩的编年（上古多为"约前XXXX年"，须带"约"字）+ 对思维的影响，含史料成书背景与互核情况。
> **年代声明**：小乙之绝对年代学界无定论。夏商周断代工程定盘庚迁殷约在公元前1300年、武丁元年约在公元前1250年，然**未颁小辛、小乙之王年**；今本《竹书纪年》所记干支（小辛元年甲午、小乙元年丁酉、武丁元年丁未）与断代工程年表不能密合（按《纪年》干支推算，武丁元年将早于前1250约二十余年）。故下表年份一律以"约前13世纪"相对示意，并附《纪年》干支原文，**不作定点**；在位年数则有十年、二十一年、二十八年三说并存（见下第四节）。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前1300（夏商周断代工程所定，一说） | 盘庚迁殷，"渡河南，复居成汤之故居……行汤之政，然后百姓由宁，殷道复兴"（《殷本纪》，背景） | 其全部施政前提：秩序刚从迁都的震荡中落定，"守住它"由此成为其本分；与其兄盘庚"以空间换秩序"的主动型执政，恰成两端 |
| 约前13世纪初 | 盘庚崩，弟小辛立；《殷本纪》"帝小辛立，殷复衰。百姓思盘庚，乃作《盘庚》三篇" | 其接位时面对"复衰"与"思旧主"的双重底色：朝野以盘庚之言为共识货币，而他本人无话可说、亦无话需说 |
| 约前13世纪前期（今本《纪年》："小辛名頌。元年甲午，王卽位居殷。三年，陟。"） | 小辛崩，弟小乙立；今本《纪年》："小乙名斂。元年丁酉，王卽位居殷。" | 定下"守盘庚之成、不再重启迁徙"的基调；末位承统，以"不缩水"自处；此为其主体思维之起点 |
| 约在位第6年（今本《纪年》："六年"） | 命世子武丁居于河，學于甘盤 | 资源投向由"朕做什么"转为"把谁养成什么样"；启兴之功自此埋线。此为史料系于其名下唯一"主动投入"的动作 |
| 武丁即位前数年（《无逸》经文所本；注疏以为其父小乙使之） | 武丁"旧劳于外，爰暨小人"——久居民间、劳于稼穑、与庶民同事 | 以"苦"与"民"为储君之课；此课后成武丁"不敢荒宁，嘉靖殷邦"之底色，并成为后世帝王学中"知小人之依"之典范 |
| 约在位第10年（今本《纪年》："十年，陟。"；《太平御览》引作二十八年、《资治通鉴外纪》作二十一年，三说并存） | 小乙崩，子武丁立；王位未还于诸兄之子 | "阳甲—盘庚—小辛—小乙"兄弟相继之一轮止于其处，"子帝武丁立"五字即成转折；其一生之成果自此全部转移至其子账下 |
| 其后（武丁之世） | 武丁即位，"思复兴殷"；三年不言，政事决定于冢宰；后举傅说为相，"修政行德，天下咸驩，殷道复兴"（《殷本纪》）；《无逸》以高宗为殷三宗之一 | 其"守成—托付"之链条的兑现期；武丁之治为其全部决策之后果所在。然史册于此仍不回头记其功 |
| 其后（武丁之世，甲骨） | 武丁时期卜辞尊称其为"父乙"（亦作小乙、小祖乙、后祖乙），卜问频繁，如"貞：婦好夢，不惟父乙？" | 其身后之位由子而定：生前史册无字，身后卜辞崇隆，成鲜明对照 |
| 其后（商末，甲骨） | 武乙时期卜骨："甲午貞：乙未〔彡〕高祖亥、大乙、祖乙、小乙、父丁，羌三、牛二，亡〔害〕？茲用。" | 其名号在商末仍稳定列于合祭祀典；"直系先王"之位由"有子为王"而确立，属制度性连带 |
| 异说（《太平御览》引、《资治通鉴外纪》） | 小乙在位二十八年（《御览》引）／二十一年（《外纪》）／十年（今本《纪年》） | 三说悬殊且无法互校；其直接后果是本 Skill 不能给出任何在位年数之定论，亦不能据在位长短推论其施政空间 |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》（西汉·司马迁）：小乙之**主源**，然系于其名下者仅"帝小辛崩，弟小乙立，是为帝小乙。帝小乙崩，子帝武丁立"十六字。其前后文所载"小辛立，殷复衰""百姓思盘庚，乃作《盘庚》三篇""武丁即位，思复兴殷"构成其完整的处境框架。司马迁距小乙约一千二百年，其所据当为商代流传之史料与战国旧说。
- 【史料原文/一手·今本】《竹书纪年》（今本，元明间辑录增改之本）：小乙材料之**最具体来源**，给出"名斂""元年丁酉王卽位居殷""六年命世子武丁居于河學于甘盤""十年陟"。其文献真伪有长期争议（王国维《今本竹书纪年疏证》视之为辑录增改之本），然商王名号一类可溯至《太平御览》所引之古本系统。
- 【史料原文/一手·先秦】《尚书·无逸》（今文尚书）：提供"其在高宗，时旧劳于外，爰暨小人""不敢荒宁，嘉靖殷邦""肆高宗之享国五十有九年"，为小乙教养之策的**间接依据**（经文只言武丁，注疏乃言其父使之）。
- 【史料原文/一手·先秦】《尚书·君奭》（今文尚书）："在武丁，时则有若甘盘。"——与今本《纪年》"学于甘盘"相合，为甘盘其人及武丁朝人事之最早旁证。
- 【甲骨/一手】武丁时期宾组卜辞中"父乙"（及小乙、小祖乙、后祖乙）辞例；武乙时期贞问祭祀先公先王刻辞卜骨（故宫博物院藏，见"甲午貞……小乙……"一版）。
- 【史论/二手】《太平御览》引《竹书纪年》在位年数、《资治通鉴外纪》在位年数；伪孔传与孔颖达《尚书正义》释《无逸》之"其父小乙使之"；故宫博物院藏品说明及学界通说对宾组卜辞称谓的系联。
- 【互核结论】**世系**：小乙为祖丁之子、小辛之弟、武丁之父——《殷本纪》、今本《纪年》、甲骨卜辞（武丁称"父乙"）三方相合，可视为可靠。**事功**：除"居殷不迁"与"命世子居河学于甘盘"之外几无内容，且此二条主要出自今本《纪年》一路，无法以其他材料独立校验；甲骨卜辞不载其任何政事。**年代**：无定论，本表年份仅示相对先后。**名讳**："斂"（《纪年》）与"钦"（故宫说明）形近存异。
- 【成书背景说明】小乙所留之记载极薄，与材料流转之选择性直接相关：上古史册（如《殷本纪》所本之商代史料与战国旧说）倾向于记载有事件之王（迁都、征伐、放废、中兴），而略过无事之王。故"小乙无字"未必等于"小乙无事"，然史料所及，亦只能到此为止——本 Skill 不作填补。

## 三、小结

- 一手节点出自《史记·殷本纪》、今本《竹书纪年》、《尚书·无逸》《君奭》及殷墟甲骨卜辞；二手节点出自《太平御览》《资治通鉴外纪》所引异说与汉唐注疏。世系三点互核相合，事功与年代则无法互核裁定。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言；"无事之王被史料略过"之判断亦属框架推断。
- **传说/半信史声明**：小乙一生无同时代文书为其佐证；甲骨只证其为武丁之父、入祀典，不证其事。本表不伪称一手确证，凡涉绝对年代一律带"约"字。
