# 06 时间线 · 太庚（商·第七任王，约前1541–约前1516，异说）

> 维度定义：即位到崩的编年 + 对思维的影响，含史料成书背景与互核情况。
> **纪年前提**：商初绝对年代不可确考。本题所列"约前XXXX"仅为通行一说（据《太平御览》卷八三引等所传在位二十五年之数上推），**凡带"约"字者皆非定论**。甲骨文可确证者仅至商后期（盘庚迁殷以后），商前期年代学界无共识。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 约前16世纪（太宗太甲之世） | 伊尹放太甲于桐宫，太甲悔过反善，伊尹迎而授之政；太甲修德，诸侯咸归殷，百姓以宁；伊尹作《太甲训》三篇，褒帝太甲，称太宗（背景） | 朕生于商室第一次中兴之余荫之中；"守成"的底本在此写成 |
| 约前16世纪（兄沃丁之世） | 伊尹卒，以天子之礼葬于亳；咎单训伊尹事，作〈沃丁〉，为卿士（背景） | 朕继位时面对的是一套由伊尹开创、咎单接续的辅政体制——不必自建也能运转 |
| 约前1541（各说不一） | 沃丁崩，朕以弟继位。古本竹书作「小庚辨即位，居亳」 | 位由兄终弟及而得、非争而得；塑造其"守制勿扰"的执政起点 |
| 约前1541–约前1516 之间（在位五年或二十五年，异说） | 史无政事可载：不迁都、不别命卿士、无征无诰无誓 | 无为之政的极端样本，史笔唯"立—崩—传"三事；亦使"究竟有无为之"永不可辨 |
| 约前1516（各说不一） | 朕崩。《殷本纪》曰「子帝小甲立」；《三代世表》曰「小甲，太庚弟也」（徐广《集解》引） | 继统两说并存，预示其后的弟子争立之端 |
| 继之（小甲、雍己之世） | 「殷道衰，诸侯或不至」一语在《殷本纪》中紧接雍己即位；系于小甲者，是合「小甲—雍己之际」为一世之读，属后世通说——两读并列，不裁决；唯《本纪》未载小甲本人有致衰之事 | 反证朕一代之平稳多系于"不改旧章"的惯性，而非某种自守能力 |
| 约前15世纪（中丁以降） | 本纪曰「自中丁以来，废适而更立诸弟子，弟子或争相代立，比九世乱，于是诸侯莫朝」 | 商初继统规则的模糊，其代价在朕身后数代集中爆发——朕享其利，后人承其弊 |
| 商晚期（祖甲至帝辛） | 周祭谱列「大庚」，与先王同享祀典；《甲骨文合集》36218 有「大庚配妣壬」 | 其合法性最终由商人自己的祭祀体系确认，而非由后世史书的字数确认 |
| 西汉（约前1世纪） | 司马迁据《秦记》以外的旧史与《世本》等成《殷本纪》，于朕仅记十八字 | 其"沉默"由史源决定：太史公所据材料中本无朕之事，非有意贬抑 |
| 1917 年 | 王国维《殷卜辞中所见先公先王考》以甲骨校订商王世系，"大庚"由卜辞得证 | 朕在三千余年后由上"名册"复现："无事迹"的君主，靠新出土的文字重新被看见 |

## 二、史料成书背景与互核

- 【史料原文/一手】《史记·殷本纪》（西汉·司马迁）为本题主源，其商初部分多本《世本》系统的商王世系；叙事以"崩—立"连缀，凡有事者必记其事，太庚之世无事可记。
- 【史料原文/一手】《史记·三代世表》以表格形式列商王世次，与《殷本纪》在"小甲是子还是弟"上不一致，是《史记》内部的一处互见矛盾。
- 【史料原文/一手】裴骃《集解》引徐广引《世表》之文，是这条矛盾的早期注家证据；司马贞《索隐》、张守节《正义》则主要处理地望（亳、隞、相、邢）而非太庚本人。
- 【史料原文/一手】王国维辑校《古本竹书纪年》所存"小庚辨即位，居亳"一条，出自《太平御览》八十三引，属战国魏人所记的编年古书，去商较近；与甲骨"大庚"相参，可证其人其名非后世伪造。
- 【史料原文/一手】《今本竹书纪年》记"元年壬子……五年陟"，然《今本》为后世辑本（王国维《疏证》已辨其"殆无一不袭他书"），故其干支与年数只能作为一说。
- 【史料原文/一手·甲骨】《甲骨文合集》36218「大庚配妣壬」与周祭卜辞祭序，是唯一的同时代文字证据；然其内容为祭祀，不含王事。
- 【史论/二手】王国维《殷周制度论》以商代继统"以弟及为主、以子继辅之"解释世系；常玉芝《商代周祭制度》整理周祭谱；杜勇、李玲玲《商代王位继承制的特质》指出中壬、沃丁、廩辛不见于周祭，并辨"祭序未必等于即位序"。
- 【互核结论】可互核者三：一是其人其名（《殷本纪》《古本竹书纪年》与甲骨"大庚"三系相合）；二是其继统关系为"兄终弟及"（本纪明载"弟"）；三是其入商人祀典（甲骨的周祭谱与《合集》36218）。**不可互核者**：在位年数（五年／二十五年）、继任者亲缘（子／弟）、都邑具体地望（南亳／西亳／北亳）、任何一件政事。
- 【成书背景说明】司马迁所据之商初材料本身极薄，《殷本纪》前段多属世系骨架而非叙事，故其"十八字"是史源之限，非史笔之贬。甲骨自1899年发现、1928年殷墟发掘以来，商王世系大体检证，但卜辞内容以祭祀与占卜为主，**极少与文献中的具体王事对应**；太庚（大庚）之在卜辞中"只有名分、没有事迹"，正是这一局限的典型个案。

## 三、小结

- 一手节点与互核均出《史记·殷本纪》《三代世表》、裴骃《集解》引徐广、王国维辑校《古本竹书纪年》、《甲骨文合集》36218；凡年月皆带"约"字，凡异说皆并列。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
