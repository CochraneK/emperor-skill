# 06 时间线 · 孙皓（吴末帝，242–283，264–280 在位）

> 维度定义：即位到崩（或亡国）的编年，表格（时间 | 事件 | 对思维的影响）。孙皓 242 年生，264 年（22 岁）被推即位，280 年亡国降晋，283 年卒于洛阳。凡《三国志》吴书三嗣主传未载之年月，宁标「史不载」。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 242 | 孙权之孙、废太子孙和之子皓生（字元宗） | 生于"废太子之后"，身份带"罪籍"底色，后虽为帝，宗室猜忌之结构已定 |
| 258–264 | 孙休（景帝）在位，皓居封地（乌程侯） | 封侯闲居，未预朝权，养成"一朝得志"之补偿心态（据本传推得） |
| 264 七月 | 孙休崩，太子幼；濮阳兴、张布迎立皓，改元元兴 | 被动继统，起于"才识明断"之名，非自主争位——思维底色"受推而立、急于自证" |
| 264–265 | 初政：减膳、撤乐、出宫女数千、振贫乏 | 短窗口"贤名期"，思维呈"收揽人心、示明断"；与后期暴虐对照，埋"得志而骄"之伏 |
| 265 前后 | 诛濮阳兴、张布，夷三族 | 杀拥立之功臣，"朕即法、功臣可诛"之确定性确立；思维由"示贤"转"示威" |
| 266（宝鼎元年） | 迁都武昌；民间作《太（溥）歌》诉苦 | "迁—扰民"决策暴露其"重象征轻民力"；思维偏"声威/陵寝"而非实务 |
| 266 后 | 凿昭明宫、穷极技巧、引水裸浴；科取美女 | 滥用民力与奢靡定型，"朕欲即取"思维成熟；陈寿"百姓愁劳"之因 |
| 269（建衡元年） | 还都建业 | 迁—还反复，显决策受近臣与民困牵制，非纯战略 |
| 270 前后 | 贺邵抗疏切谏，皓烧锯断其头；楼玄、万彧请息役被赐死 | "忠谏者诛"结构固化；思维"好恶即法"，拒谏自封 |
| 272–276 | 改元凤凰、天册、天玺（屡获"瑞"以自欺） | 频改元、伪造符瑞，思维"以天命自慰"，回避实政之败 |
| 277（天纪元年） | 晋大举备战，羊祜、杜预、王濬经营上游 | 皓"不为之备"，思维"轻晋、信符瑞"，边备松弛 |
| 280 三月 | 晋六路伐吴，王濬楼船下建业；皓肉袒面缚衔璧牵羊出降 | 末路"寂默无言、因流涕"，决策由"战"转"降"；思维归于"亡国之礼"之顺从 |
| 280 后 | 入洛阳，封归命侯；作《尔汝歌》、答贾充问刑 | 亡国后仍"反讽不屈"，思维底色"朕虽降、不卑" |
| 283 | 皓卒于洛阳（归命侯，约 42 岁） | 吴三嗣主之末，以"暴虐亡国"定评入史 |

## 编年要点说明（一手 vs 框架）

- 一手（史料原文）：《三嗣主传》载生年、即位、诛兴布、迁都、凿宫、科取美女、杀忠谏、出降；《晋书·武帝纪》载封归命侯；《通鉴》卷七九–八一载伐吴编年。
- 史论 / 二手：陈寿"淫刑所滥""忠谏者诛"、江表传《尔汝歌》与贾充对、现代"结构亡国"之辩，标【史论/二手】。
- 框架推断：258–264 闲居心态、"得志而骄"归因、皓"不为之备"之心理，逐条标注，未伪称史载。
