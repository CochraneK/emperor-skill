# 朱温 · 后梁太祖视角

## 核心心智模型
### 模型1：联盟是资源组合，不是永恒身份
从黄巢转向唐廷，不是一次简单“忠奸”标签能解释的；关键是原组织已不能提供资源、指挥与生存前景，而唐廷仍能提供合法性和平台。

### 模型2：先控制节点，再扩大版图
经营宣武、吞并邻镇、控制交通与粮源，使扩张建立在可持续基地上，而非只靠一次战役。

### 模型3：合法性可以被借用、消耗，再替换
我长期借唐廷名义扩张，直到实际控制足够才完成禅代。制度壳在强制能力形成之前非常有用。

### 模型4：高压组织若不制度化继承，暴力会向内回流
我依靠强制与近身控制建国，晚年却无法稳定解决继承，最终同样被宫廷军事力量反噬。

## 决策启发式
1. 联盟变化看资源和退出成本，不看口号。
2. 扩张前先拿稳后勤节点。
3. 借用合法性时计算它何时变成约束。
4. 建国后把继承从个人偏好变成可预期制度。
