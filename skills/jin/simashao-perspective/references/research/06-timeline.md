# 06 · 时间线（晋明帝太宁大事与思维演变）

> 调研目标：以时间线梳理司马绍从为太子到崩殂的关键节点及其对思维/决策风格的影响。时间与事件据《晋书·明帝纪》《王敦传》《资治通鉴》晋纪及《世说新语》。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 299（元康九年） | 生于琅邪，元帝司马睿长子，母荀氏（燕代，状类外氏须黄） | 宗室嫡脉、母族「胡相」之议，自幼处于门阀与血统之张力中 |
| 约 307 起 | 元帝镇建康，绍留侧，幼而聪哲，为元帝所宠异 | 「至孝、聪断」底色养成 |
| 数岁（永嘉中） | 元帝膝上「日近长安远」之对 | 早显「名实之辨、两可并存」之思维 |
| 317（建武元年） | 元帝称晋王，立绍为晋王太子 | 储位既定，承统之重自觉 |
| 318（太兴元年） | 元帝即帝位，立为皇太子 | 储君身份，渐预朝政 |
| 320s 初 | 王敦惮其聪断，称「黄须鲜卑奴」，欲废储；温峤正色护之 | 识「权臣逼储、须隐忍自保」之险 |
| 为太子时 | 微服至芜湖察王敦营垒，七宝鞭脱身 | 「亲侦敌情、示弱诱追」之胆略与机变 |
| 322（永昌元年闰十一月） | 元帝崩，绍即位（323 改元太宁） | 承乱即位，「忍而不发」之局始 |
| 323（太宁元年） | 王敦移镇姑孰，觊觎神器；帝优抚旧臣、阴备讨 | 忍让蓄势，明「时机未至不妄动」 |
| 324（太宁二年） | 王敦病，王含举兵；帝下诏亲征，平敦，敦死、含应败 | 「亲征定乱、以刚决患」之巅峰，雪国耻 |
| 324 后 | 追赠周顗、戴渊，不罪敦族，诏「共惟新」 | 平乱后「雪冤+安反侧」并举，宽断并用 |
| 325（太宁三年） | 后赵石勒略河南，欲大举北伐未发 | 「恢复中原」之志与「国步未复」之势相左 |
| 325 闰八月 | 崩，年二十七；遗诏托孤王导庾亮郗鉴卞壸，俭葬 | 「主相相维、简素至孝」留训，中兴未竟 |
| 325 后 | 成帝冲龄即位，庾太后临朝、庾亮辅政 | 托孤格局成，亦埋苏峻之乱之隐患 |
| 附：平敦后用人 | 以温峤掌丹阳尹屏护京师、郗鉴都督徐兖御石勒、王导总录尚书 | 文臣武将各任方面，「主相相维」由托孤落为常制 |

> 注：时间线与事件据《晋书·明帝纪》《王敦传》《资治通鉴》晋纪及《世说新语》互校；即位年从 323（太宁）为新纪，旧史异文（永昌元年即位说）不调和并列。微服察敦、日近长安远带轶事笔法，细节未逐字核，标轶事一手。明帝在位仅三载（323–325），编年跨度虽短而节点密集：储位之险、忍待之时、亲征之决、雪冤之宽、托孤之分、早崩之憾，皆在此表中可窥其思维演变之序。
