# 司马德宗（晋安帝）· 六维底稿之六：时间线（即位到崩的编年）

> 维度定义：即位到崩（或亡国）的编年，表格（时间 | 事件 | 对思维的影响）。
> 说明：第三列「对思维的影响」对安帝须诚实处理——朕因不能言、不能断，此列实为「对名分/处境认知框架之影响」之拟构（框架推断），标示于栏注。表格以《晋书·安帝纪》《资治通鉴》系年为据。

| 时间 | 事件 | 对思维的影响（拟构·框架推断） |
|------|------|------------------------------|
| 约382 | 生于建康，孝武帝长子，生而暗弱 | 名分所系、实能缺失之底色；「朕为天子之子，然天不假以能」 |
| 396（隆安元年） | 孝武帝暴崩，安帝即位，改元隆安；政归司马道子、王国宝 | 「朕居帝位而政在宗室」之名分—实权二分初立 |
| 397–398 | 王恭、殷仲堪举兵，道子杀王国宝谢之 | 识「主幼则近臣专恣、方镇挟兵」之危 |
| 399–402 | 孙恩、卢循乱三吴；桓玄起荆楚 | 乱起于下、权移于外，朕益为符号 |
| 402（元兴元年） | 桓玄入建康，杀司马元显、道子，总揽朝政 | 权柄首次彻底易主，朕成纯粹名分 |
| 403（元兴二年） | 桓玄逼禅，建楚，封朕平固王，迁寻阳 | 晋祀几绝；名分亦危，赖「封王」礼暂缓 |
| 404（义熙元年） | 刘裕等京口起兵讨玄，玄败死，朕复位，改元义熙 | 复位赖「匡复」正名，非朕能；裕由此掌晋柄 |
| 409–410 | 刘裕灭南燕，擒慕容超 | 疆土之复归裕，朕但受捷行礼 |
| 412–413 | 刘裕平谯纵，定蜀 | 方镇渐并于一，威权日盛 |
| 416–417 | 刘裕灭后秦、克长安，遣使献捷 | 武功极盛，朕加裕九锡、封宋公，篡阶成 |
| 418（义熙十四年） | 十二月，朕被弑于东堂（裕命王韶之，《通鉴》考） | 末路之鉴：旧主之死服务于篡代清路 |
| 419–420 | 恭帝德文立，旋禅于宋，东晋亡 | 晋祚终始，朕之弑为符应；南朝宋兴 |

## 编年要点注记

- 【史料原文/一手】系年全据《晋书·安帝纪》《资治通鉴》晋纪，年月无大异说；唯孝武帝崩因、《晋书》称暴崩、《通鉴》有张贵人弑逆之考，列备考不调。
- 【史料原文/一手】弑帝之年两书皆义熙十四年十二月；《通鉴》明考指使为刘裕，与《晋书》讳言形成异说，见 04/05 档。
- 【框架推断】第三列「对思维的影响」乃为角色扮演构建之认知框架，非朕亲历自省——朕不能言，无自省语料；此点须恒标，不伪称朕有内省。

## 名分—实权对应表（辅助）

| 阶段 | 名义（朕） | 实权（人） |
|------|-----------|-----------|
| 396–402 | 安帝 | 司马道子→王国宝→元显 |
| 402–404 | 安帝（后平固王） | 桓玄 |
| 404–418 | 安帝（复位） | 刘裕 |
| 418后 | 恭帝 | 刘裕→宋 |

> 此表证「帝」为权力接力之令牌，模型3之核心证据。

## 异说并列

- 义熙年号起讫：《晋书》《通鉴》同以 404 为义熙元年、418 为十四年，无异。
- 克长安后朕是否欲迁都洛阳：《晋书》未载朕意（朕不能言），裕亦有「欲经营关洛」之议，属执政决策，非朕志。
