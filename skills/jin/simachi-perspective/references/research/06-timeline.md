# 06 时间线 · 司马炽（晋怀帝，284 生—313 崩，307–313 在位）

> 维度定义：即位到崩的编年，表格（时间 | 事件 | 对思维的影响）。凡本纪所记经唐修史臣裁取，《资治通鉴》作编年互核；纪年以《晋书·怀帝纪》及《通鉴》晋纪互核，两晋一手史料以《晋书》《资治通鉴》《十六国春秋》辑本为准。

## 一、关键节点（附对思维之影响）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 284 | 生于洛阳，武帝司马炎第二十五子，母王媛姬；初封豫章王 | 宗室幼子、非储贰之身，养成"处中枢而近危、终须自证"的危机底色 |
| 290 | 武帝崩，惠帝即位，八王之乱酝酿 | "宗室相残"之局自幼入眼，埋下对骨肉相残之清醒认知 |
| 300–303 | 赵王伦、齐王冏、长沙王乂、河间王颙等相继乱政 | 亲历"权臣迭起、君权旁落"，养成"位高而柄轻"的无力感 |
| 304（永兴元年） | 河间王颙废司马覃，立炽为皇太弟 | 以"推立"而非"父传"得位，合法性自觉中带被动，养成"承乱而立"之思维 |
| 306（光熙元年） | 惠帝崩，太弟炽即皇帝位，是为怀帝 | 即位于"八王尾声、胡骑压境"之局，定"先固内、后御外"却难施展的基调 |
| 307（永嘉元年） | 春正月大赦、改元永嘉；亲览万机、下求言举贤诏 | 唯一主动施政窗口，养成"勤政求言、然号令不出洛阳"的落差感 |
| 308–309 | 汉赵（刘渊）屡寇并州、冀州，王弥、石勒扰边 | 外患骤紧，思维由"内政"转向"存亡"，然中枢已弱、应之乏力 |
| 310（永嘉四年） | 东海王司马越出镇许昌、专权；怀帝密诏苟晞讨越 | 与权臣决裂，首度以"密诏"示其主动，亦暴露"帝弱臣强"之实 |
| 311（永嘉五年）六月 | 司马越死；汉赵刘曜、王弥、石勒破洛阳，怀帝被俘（永嘉之乱） | "神州陆沉"之实落地，思维由"图存"转为"受辱、认命" |
| 311后–313 | 被掳平阳，刘聪封会稽郡公、加仪同三司；著青衣行酒 | 降格事敌、曲意全族，养成"皇天之意"式宿命思维以自解 |
| 313（嘉平三年） | 正月刘聪宴，复使青衣行酒，晋臣流涕；怀帝被害（毒杀） | 末帝之局以死收束；思维止于一"无力回天、辱及其身"之叹 |

## 二、史料成书背景与互核

- 【史料原文/一手】《晋书·怀帝纪》（房玄龄等，唐）为本纪主源，叙事至"永嘉之乱、北狩被执"；然唐臣奉敕修史，已带后世取舍与"以隋为鉴"的立场。
- 【史料原文/一手】《资治通鉴》卷八十六至八十八 晋纪（司马光，北宋）承《晋书》编年互证，胡三省注引习凿齿、孙盛，细化密诏讨越、青衣行酒、被害月份。
- 【史料原文/一手】《十六国春秋》辑本（崔鸿，北魏）以前赵视角载虏帝、封公、青衣行酒，与《晋书》《通鉴》互证被俘实录。
- 【史论/二手】习凿齿《汉晋春秋》、孙盛《晋阳秋》评西晋之亡溯至宣帝、世祖，怀帝仅为积弊承受者，属史论（二手），标【史论/二手】。
- 【互核结论】继统（太弟即位）、亲政、密诏讨越、永嘉之乱被俘、青衣行酒、被害六大节点在《怀帝纪》《通鉴》《十六国春秋》一致；唯"被害月份（永嘉七年正月/嘉平三年）""封号细节"存异文，并列不伪称定论。
- 【成书背景说明】怀帝纪经唐臣裁取，凡涉褒贬（如"帝非不贤、时实不济"）不得当本人主张，一律标史论/二手。

## 三、小结

- 一手节点与互核均出《晋书》《通鉴》《十六国春秋》；太弟继统、密诏讨越、永嘉被俘、青衣行酒四异说如实并列。
- 框架推断：各节点"对思维之影响"一栏为基于史事的归纳推断，非史书明言。
