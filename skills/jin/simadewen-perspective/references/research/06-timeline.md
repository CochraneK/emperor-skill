# 六、时间线底稿 · 晋恭帝司马德文（386–421）

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 386 | 生于建康，孝武帝子、安帝同母弟 | 生于帝胄而幼弱，无创业之志，底色「守成而非开拓」，认命先于进取 |
| 398/399 前后 | 封琅邪王，历车骑、中军等将军号 | 久居藩王之位，习于「恭顺事上」的生存姿态，远离实权中枢 |
| 403–404 | 桓玄之乱，与安帝俱徙；桓振欲害兄，以身蔽之 | 乱世初悟「以柔护身、以退全兄」之本能，顺受性格成型 |
| 418 十二月 | 安帝崩，刘裕矫诏立之为帝，改元元熙 | 被推上位，清醒知己为「权臣之具」，顺受成性、皇权名存实亡 |
| 419 | 屡上刘裕宋公、九锡、宋王之尊礼 | 以「进爵」绥靖，确认「皇权已空、唯余署名」的处境 |
| 420 六月 | 临朝宣禅诏、用传国玺，禅于宋，东晋亡 | 完成权力交割，以「本所甘心」自我说服求全身，善意推定胜者 |
| 420 夏秋 | 降零陵王，迁居秣陵，依山阳公故事 | 「退而求生」，然已入宋武彀中，礼数愈隆杀机愈近 |
| 420–421 | 与褚皇后共处自防，饮食自煮避鸩 | 求生之韧与结构性杀机之间的徒劳挣扎，认知到善意推定之虚 |
| 421（宋永初二年） | 宋武遣兵逾垣，进药不肯饮，以被掩杀，谥恭皇帝 | 算计落空，末帝以「静待」结束，晋祚讫于「昌明之后有二帝」之谶 |

> 编年依据《晋书·恭帝纪》《资治通鉴》卷一一八—一一九、《宋书·武帝纪》；纪年异说（如安帝崩具体月日、改元节点）依通行本，并存不强行调和。

## 编年补注（释其转折之机理）

- **出生即入局**：386 年恭帝生于孝武帝朝，时东晋已偏安江左、皇权与门阀相持；其「守成而非开拓」的底色，源自一个不再有创业冲动的王朝晚期。
- **藩王岁月**：399 年前后封琅邪王，历车骑、中军将军，长期在军事荣誉头衔中远离决策中枢，养成「恭顺事上」的习性，亦使其对实权始终陌生。
- **乱世试炼**：402–404 年桓玄之乱与桓振犯跸，是恭帝第一次直面生死；「以身蔽兄」并非深思熟虑的政治选择，而是宗法兄弟之义的本能反应，却奠定了其「以柔护身」的终身姿态。
- **被推上位**：418 年安帝崩（传刘裕所鸩），裕矫诏立德文，改元元熙。这一步并非恭帝主动，而是权臣为「造宋」选中的过渡符号——其皇帝身份从第一天起就是别人的工具。
- **绥靖铺路**：419 年累上刘裕宋公、九锡、宋王，每一次加礼都是皇权向权臣的递进让渡，至 420 年已无牌可打，禅让成为唯一出口。
- **交割与落空**：420 年六月临朝宣禅、用传国玺，以「本所甘心」自我说服；然善意推定终被结构逻辑击穿——421 年宋武遣人缢杀，末帝以静待收束。整条时间线是一部「顺受者如何被顺受反噬」的编年。
