# 06 · 时间线（司马曜·晋孝武帝，372–396）

> 调研目标：以编年梳理司马曜自即位至被弑之全程，表列「时间 | 事件 | 对思维的影响」。系年据《晋书·孝武帝纪》《资治通鉴》晋纪，异说并列不调和。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 362 | 生于建康，字昌明，简文帝司马昱第三子 | 宗室生于江左偏安之朝，承「元帝中兴」余绪 |
| 372（咸安二年） | 简文帝崩，遗诏初拟桓温摄政；谢安、王坦之力争，十岁嗣位，褚太后临朝 | 以幼主得位，深知「君位系于辅臣之扶持」，自幼倚贤 |
| 373（宁康元年） | 桓温死，谢安、王坦之辅政，朝局渐稳 | 「权在能臣」之局定型，养成托重将相之心 |
| 376（太元元年） | 太后归政，帝始亲览万机，年十五 | 由倚辅转亲政，渐生主断之意 |
| 383（太元八年） | 苻坚南侵，诏谢安都督、谢玄为前锋；冬淝水大捷 | 一生巅峰——「任将相、不遥制」成奇功，自许中兴之主 |
| 384（太元九年） | 谢玄北伐，收复河南、山东、梁益部分故地 | 拓土之志方张，然已伏「得易守难」之患 |
| 385（太元十年） | 谢安忧谗出镇，旋卒；帝收权，委道子 | 「功高见疏」之念萌，由任贤转亲亲、渐生猜防 |
| 387–390（太元中后） | 以弟司马道子录尚书事，委政宗弟；渐耽酒色 | 亲亲相托成习，怠政之根始生，朝柄移于佞幸 |
| 391–395（太元晚） | 帝与道子酣歌为务，昵尼僧姏姆，不亲万机；王恭、殷仲堪拥兵藩镇 | 「主暗臣欺」之局，国事日非而不自知 |
| 396（太元二十一年） | 戏张贵人「汝以年当废矣」，醉中被弑，年三十五；太子德宗（安帝）嗣 | 以最轻佻之言招最惨烈之祸，东晋由此急转直下 |
| 396后 | 安帝愚騃、道子乱政，孙恩乱起、桓玄篡，东晋走向覆亡 | 孝武之死为东晋由盛转衰之拐点，后事皆其遗患 |

## 附：思维转折节点

- **由倚到亲（376）**：太后归政，帝从「赖辅臣」转向「自断」，是自信之始，亦为日后「功成见忌」之伏笔。
- **由信到忌（385）**：谢安之死使「任贤不疑」让位于「收权亲亲」，帝王心术由开转狭。
- **由明到昏（390后）**：壮年逸乐取代壮年图治，「淝水之明」与「晚年之昏」形成一生最大张力。
- **由尊到弑（396）**：至尊之体亡于宠妃之手，以荒诞收场，恰证「主暗则臣欺」之理。

## 可信度

- 系年与事件：以《晋书·孝武帝纪》（卷九）、《资治通鉴》晋纪（卷一〇二—卷一〇八）为本纪一手；个别月日异同依两书互校，仍存不确定性【史料原文/一手】。
- 「对思维的影响」一栏系据本纪叙事推得之心理脉络，非帝自述，均属【框架推断】。
- 后世「由盛转衰拐点」之论属【史论/二手】，并列备参，不强行调和。

> 注：具体卷次以中华书局点校本《晋书》卷九、《资治通鉴》晋纪为准；个别异说（如谢安出镇动机）学界有争，本表依本纪主流。
