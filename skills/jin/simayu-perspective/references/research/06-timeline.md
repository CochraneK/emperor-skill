# 06 · 时间线（司马昱：从会稽王到简文帝崩）

> 调研目标：编年呈现司马昱自出生、为会稽王辅政、受桓温拥立为帝、至崩殂之全程，并记每事「对思维的影响」。据《晋书·简文帝纪》及《资治通鉴》晋纪核验。

| 时间 | 事件 | 对思维的影响 |
|------|------|--------------|
| 320（大兴三年） | 生于建康，元帝司马睿少子，母郑阿春 | 宗室幼子、生于深宫，性近清虚而非雄略之底色 |
| 326（咸和元年）前后 | 徙封会稽王 | 以闲王居会稽，渐成士族清谈之主，玄言名世 |
| 345（永和元年）后 | 以抚军、录尚书事辅政，引殷浩抗桓温 | 「以文制武、夹缝周旋」执政范式成型，识桓温之威 |
| 352（永和八年） | 殷浩北伐败，被桓温废 | 知「以文制武」之用人难，桓温势不可制之惧渐深 |
| 365（兴宁三年） | 哀帝崩无嗣，立司马奕（海西公） | 「立嗣顺温意」之实显，己权半在桓温 |
| 371（咸安元年十一月） | 桓温废海西公，立会稽王昱为帝，改元咸安 | 「受立而非自主」——即位即「拱默守道、常惧废黜」之始 |
| 371—372 | 在位大赦、封赏桓温，温表让；温威震内外 | 明其位危，取「不争」以全身保祚，不撄桓温之锋 |
| 372（咸安二年）初 | 桓温诬武陵王晞，简文未力护，晞废 | 夹缝之惧及于骨肉，「拱默」之限自见 |
| 372（咸安二年七月） | 帝不豫；初诏温居摄，王坦之毁诏改「如诸葛、王导故事」；崩，太子曜（孝武帝）立 | 一朝最关键之「守成」：遗诏不令桓温摄政，晋祚得延；在位仅八阅月 |
| 372 后 | 桓温加九锡之谋因简文崩、王谢缓之而未遂 | 其崩成桓温篡谋之滞点，托孤得人使东晋又延数十年 |

## 附：在位时长与国运定位

- **在位仅八阅月**（371 年十一月至 372 年七月），为东晋诸帝最短之一；其「功绩」不在作为，而在「不使国遽移于桓氏」之守。
- **思维总线索**：由清谈名士（会稽王）→ 夹缝辅政（抗桓温）→ 受立之君（拱默）→ 临终护祚（遗诏），其心智始终在「清虚守道」与「常惧废黜」之间往返，以「不争之守」换晋祚之续。

## 附：同期强臣与门阀格局（编年补注）

- **桓温之势**：桓温以荆襄军功、三次北伐（354 伐前秦、356 复洛阳、369 伐前燕）威震内外，废海西公立简文，是其权势顶点；加九锡之谋不成，旋于宁康元年（373）崩，桓氏之逼随其死而缓【一手：《晋书·桓温传》《资治通鉴》】。
- **王谢之起**：简文托孤王坦之、谢安，二人辅孝武帝，王坦之旋卒，谢安独撑，于淝水（383）破苻坚，东晋危而复兴——此乃简文「托得人」之远效【一手：《晋书·谢安传》《资治通鉴》】。
- **会稽王道子**：简文崩后，其弟司马道子（会稽王）渐录尚书事，后专权乱政，为东晋晚期之弊——简文一系之守成，终难敌制度之隙【史论/二手；据《晋书》叙事推】。
