# 帝王 -perspective Skills（蒸馏仓库）

把中国主要王朝帝王蒸馏为可运行的 `-perspective` Skill，供 LLM 以该人物视角回应。
本仓库**按朝代分文件夹**组织，与蒸馏主项目（nuwa-skill）解耦，便于独立分发与复用。

## 目录结构

```
emperor-skill/
├── ming/   # 明朝 16 帝（1368–1644）
├── qing/   # 清朝 12 帝（含后金大汗努尔哈赤、皇太极，1616–1912）
└── yuan/   # 元朝 11 帝（1271–1368）
```

每个帝王子目录结构一致：

```
<id>-perspective/
├── SKILL.md                 # 12 章固定结构：核心心智模型 / 表达DNA / 诚实边界 / 调研来源 …
├── references/research/     # 六份底稿（著作·对话·表达DNA·他者视角·决策·时间线），逐条标注出处
└── scripts/quality_check.py # 本地质量门禁（6 项）
```

## 蒸馏方法

- **六维调研流水线**：著作 / 对话 / 表达DNA / 他者视角 / 决策 / 时间线 → 框架提炼 → 构建 → 质检。
- **一手史料优先**：元朝取《元史》《元典章》《新元史》《蒙兀儿史记》拉施特《史集》佚名《元朝秘史》；
  明朝取《明史》《明实录》及权威传记；清朝取《清史稿》《清实录》及学术传记。各帝一手来源占比均 >50%。
- **框架零污染**：不以外来心理 / 系统框架作透镜嵌入正文；现代学术仅作交叉印证与补正。
- **诚实边界**：已故人物，基于公开作品近似，非本人，译文未逐字核对；史料讳饰处标注存疑。

## 质量门禁（6/6）

- 心智模型 3–7 个（每含「局限」）
- 表达DNA ≥ 3 项辨识特征
- 诚实边界 ≥ 3 条
- 内在张力 ≥ 2 处
- 一手来源占比 > 50%

**全库 39 位帝王，audit 100% 通过（6/6），零质量债务。**

## 使用

将某帝王子目录作为 Skill 载入支持 `-perspective` 的 agent 框架即可。触发示例：
「用朱棣的视角看迁都」「以忽必烈之心度之」「若乾隆面临 AI，他会怎么想」。
